= 图层和数据源

图层（Layer）是在地图上的一种数据组织方法。

图层可以是栅格层（raster）或矢量层（vector），栅格层由栅格图像（像素矩阵）组成，而矢量层由矢量几何图形组成。

[[tile-layer]]
== 瓦片层（TileLayer）

瓦片层（Tile Layer）的源需要能提供预渲染的地图瓦片，这些瓦片按缩放级别不同（在特定分辨率展示）提供不同的瓦片矩阵。

更多详情请参阅 https://openlayers.org/en/v8.2.0/apidoc/module-ol_layer_Tile-TileLayer.html[TileLayer 文档^]。

`TileLayer` 支持以下源：

* <<osm-source,OsmSource>>
* <<xyz-source,XyzSource>>
* <<wms-source,WmsSource>>
* <<wmts-source,WmtsSource>>

[[wmts-source]]
=== WmtsSource

来自 xref:maps:map-services.adoc#web-map-tile-service[WMTS]（Web 地图瓦片服务）服务器的瓦片数据源。详情参见 https://openlayers.org/en/v8.2.0/apidoc/module-ol_source_WMTS-WMTS.html[WMTS 文档^]。

WMTS 服务使用瓦片矩阵集发布预渲染的瓦片。如需配置 `WmtsSource`，请指定服务 URL 和图层标识符，然后选择一种瓦片网格配置模式：

* `tileGrid` - 显式定义分辨率、矩阵标识符、原点和瓦片大小。
* `webMercatorTileGrid` - 自动创建标准的 `EPSG:3857` 瓦片网格。
* `capabilities` - 下载 WMTS `GetCapabilities` 文档并从中派生源配置。

以下示例演示了显式配置瓦片网格的 `WmtsSource`：

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/layers-view.xml[tags=wmtsSource]
----

对于 Web 墨卡托服务，使用 `webMercatorTileGrid` 无需手动列出所有分辨率和矩阵标识符：

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/layers-view.xml[tags=wmtsWebMercatorSource]
----

默认情况下，`webMercatorTileGrid` 生成 `\{matrixSet}:\{zoom}` 格式的矩阵标识符，例如 `EPSG:900913:0`。如果 WMTS 服务使用数字矩阵标识符（如 `0`、`1`、`2`），则设置 `numericMatrixIds="true"`。

如需从 WMTS 能力文档配置源，请添加 `capabilities` 元素。如果无法从源 URL 派生能力文档，请使用 `url` 属性显式指定：

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/layers-view.xml[tags=wmtsCapabilitiesSource]
----

`capabilities` 模式在视图打开时异步加载文档。如果无法加载文档或找不到指定的图层，会在日志写入错误，地图视图仍可在没有此源的情况下使用。

以下应用程序属性仅影响 `capabilities` 模式：

[cols="1,1,1,3", options="header"]
|===
|属性
|类型
|默认值
|描述

|`jmix.maps.ui.wmts-capabilities-timeout`
|Duration
|`10s`
|下载 WMTS `GetCapabilities` 文档的超时时间。

|`jmix.maps.ui.wmts-capabilities-cache-ttl`
|Duration
|`10m`
|下载的 `GetCapabilities` 文档按 URL 缓存的时长。设置为 `0` 可禁用缓存。
|===

[[data-vector-source]]
=== DataVectorSource

`DataVectorSource` 支持通过 `dataContainer` 和 `property` 属性绑定 Jmix 数据容器。`property` 可以是属性名或者属性路径。

[source,xml,indent=0]
----
include::example$/maps-ex1/src/main/resources/com/company/onboarding/view/location/location-detail-view.xml[tags=geoMap]
----

[source,xml,indent=0]
----
<maps:vector id="vectorLayer">
    <maps:dataVectorSource dataContainer="ordersDc"
                           property="customer.address.point"/>
</maps:vector>
----
