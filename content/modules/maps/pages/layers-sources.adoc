= Слои и источники

Слой (Layer) - это способ организации данных на карте.

Слои могут быть растровыми или векторными. Растровые слои состоят из растровых изображений, которые представляют собой сетку пикселей, в то время как векторные слои состоят из векторных геометрий.

[[tile-layer]]
== TileLayer

Тайловый слой (`TileLayer`) - слой с источниками, которые предоставляют предварительно отрендеренные, разбитые на тайлы (плитки) изображения в сетках, организованных по уровням масштабирования для определенных разрешений.

Для получения более подробной информации см. https://openlayers.org/en/v8.2.0/apidoc/module-ol_layer_Tile-TileLayer.html[документацию TileLayer^].

`TileLayer` поддерживает следующие источники:

* <<osm-source,OsmSource>>
* <<xyz-source,XyzSource>>
* <<wms-source,WmsSource>>
* <<wmts-source,WmtsSource>>

=== OsmSource

Источник для загрузки тайлов с сервера https://www.openstreetmap.org[OpenStreetMap^] и из сервисов xref:maps:map-services.adoc#xyz-tiles[XYZ tile]. Для получения более подробной информации смотрите https://openlayers.org/en/v8.2.0/apidoc/module-ol_source_OSM-OSM.html[документацию OSM^].

[[xyz-source]]
=== XyzSource

Источник для тайловых данных с URL-адресами в заданном формате XYZ, которые определены в шаблоне URL. По умолчанию используется широко распространенная сетка Google, где x 0 и y 0 находятся в левом верхнем углу. `XyzSource` может загружать тайлы из сервисов xref:maps:map-services.adoc#xyz-tiles[XYZ tile]. Для получения более подробной информации смотрите https://openlayers.org/en/v8.2.0/apidoc/module-ol_source_XYZ-XYZ.html[документацию XYZ^].

[[wmts-source]]
=== WmtsSource

Источник тайловых данных с серверов xref:maps:map-services.adoc#web-map-tile-service[WMTS] (Web Map Tile Service). Подробности смотрите в https://openlayers.org/en/v8.2.0/apidoc/module-ol_source_WMTS-WMTS.html[документации WMTS^].

Сервисы WMTS публикуют предварительно отрисованные тайлы с использованием набора тайловых матриц. Чтобы настроить `WmtsSource`, укажите URL сервиса и идентификатор слоя, затем выберите один из поддерживаемых режимов конфигурации тайловой сетки:

* `tileGrid` - явно задает разрешения, идентификаторы матриц, начало координат и размер тайла.
* `webMercatorTileGrid` - автоматически создает стандартную тайловую сетку `EPSG:3857`.
* `capabilities` - загружает документ WMTS `GetCapabilities` и получает конфигурацию источника из него.

Следующий пример демонстрирует `WmtsSource` с явно настроенной тайловой сеткой:

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/layers-view.xml[tags=wmtsSource]
----

Для сервисов Web Mercator используйте `webMercatorTileGrid`, чтобы не перечислять все разрешения и идентификаторы матриц вручную:

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/layers-view.xml[tags=wmtsWebMercatorSource]
----

По умолчанию `webMercatorTileGrid` генерирует идентификаторы матриц в формате `\{matrixSet}:\{zoom}`, например `EPSG:900913:0`. Если ваш WMTS-сервер использует числовые идентификаторы матриц, такие как `0`, `1`, `2`, установите `numericMatrixIds="true"`.

Чтобы настроить источник на основе документа WMTS capabilities, добавьте элемент `capabilities`. Если документ capabilities нельзя получить из URL источника, укажите его явно с помощью атрибута `url`:

[source,xml,indent=0]
----
include::example$/maps-ex2/src/main/resources/com/company/mapssample/view/layers/layers-view.xml[tags=wmtsCapabilitiesSource]
----

Режим `capabilities` загружает документ асинхронно во время открытия экрана. Если документ не удается загрузить или указанный слой не найден, ошибка записывается в лог, а экран карты остается доступным без этого источника.

Следующие свойства приложения влияют только на режим `capabilities`:

[cols="1,1,1,3", options="header"]
|===
|Свойство
|Тип
|Значение по умолчанию
|Описание

|`jmix.maps.ui.wmts-capabilities-timeout`
|Duration
|`10s`
|Тайм-аут загрузки документа WMTS `GetCapabilities`.

|`jmix.maps.ui.wmts-capabilities-cache-ttl`
|Duration
|`10m`
|Время кэширования загруженного документа `GetCapabilities` для каждого URL. Установите `0`, чтобы отключить кэширование.
|===

[[data-vector-source]]
=== DataVectorSource

`DataVectorSource` позволяет выполнять привязку данных к контейнерам данных Jmix через атрибуты `dataContainer` и `property`. Атрибут `property` может принимать как простое свойство, так и путь к свойству (property path).

[source,xml,indent=0]
----
include::example$/maps-ex1/src/main/resources/com/company/onboarding/view/location/location-detail-view.xml[tags=geoMap]
----

[source,xml,indent=0]
----
<maps:vector id="vectorLayer">
    <maps:dataVectorSource dataContainer="ordersDc"
                           property="customer.address.point"/>
</maps:vector>
----
