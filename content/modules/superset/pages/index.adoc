= Superset

Дополнение Superset интегрирует приложения Jmix с https://superset.apache.org/[Apache Superset^] с помощью компонента xref:flow-ui:vc/components/supersetDashboard.adoc[SupersetDashboard], который встраивает дэшборды Superset в экраны приложения.

Чтобы отобразить дэшборд в вашем приложении, вам нужно только настроить URL и учетные данные Superset, а затем добавить компонент `SupersetDashboard` к экрану.
