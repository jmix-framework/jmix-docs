= Superset

The Superset add-on integrates Jmix applications with https://superset.apache.org/[Apache Superset^] through the xref:flow-ui:vc/components/supersetDashboard.adoc[SupersetDashboard] component, which embeds Superset dashboards into application views.

In order to display a dashboard in your application, all you need to do is configure the Superset URL and credentials, and add the component to a view.
