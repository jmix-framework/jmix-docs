= Superset

Superset 扩展组件通过 xref:flow-ui:vc/components/supersetDashboard.adoc[SupersetDashboard] 组件在 Jmix 应用程序中集成 https://superset.apache.org/[Apache Superset^]。`SupersetDashboard` 组件可以在应用程序中集成 Superset 仪表板。

在应用程序中集成仪表板时，只需配置 Superset 的 URL 和登录凭证，然后在视图中添加组件。
