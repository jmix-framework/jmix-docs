= Spreadsheet Component

The `spreadsheet` component embeds an Excel-compatible spreadsheet into a view. It renders an https://poi.apache.org[Apache POI^] workbook in the browser, lets the user edit it, and gives the view full programmatic access to the underlying POI model.

[cols="1h,1", options="autowidth", grid=none, frame=none]

|`spreadsheet`

|Java Class

|===

The spreadsheet is not bound to a xref:flow-ui:data/data-containers.adoc[data container]. Its content is either an <<loading, XLSX file>> that you load into it, or cells that you fill from <<filling-from-data, entity data>>. In both cases the workbook is kept in memory, and edits are lost on a page refresh unless they are saved explicitly.

[source,java,indent=0]

NOTE: Only the values are saved this way. Changes to the sheet itself, such as a new column, formatting, or formula, are lost when the view is closed.

[source,java,indent=0]
----
include::example$/vaadin-spreadsheet-ex1/src/main/java/com/company/vaadinspreadsheetex1/view/handlers/SpreadsheetHandlersView.java[tags=component-factory]
----

`getCustomComponentForCell()` is called first, and `getCustomEditorForCell()` only if it returns `null`.

Rows that contain components are never lower than the <<minimumRowHeightForComponents,minimumRowHeightForComponents>> value, so the components remain visible.

[source,java,indent=0]
----
include::example$/vaadin-spreadsheet-ex1/src/main/java/com/company/vaadinspreadsheetex1/view/sheets/SpreadsheetSheetsView.java[tags=delete-sheet]
----

Sheets are addressed by index, and there are two kinds of index. Methods without the `POIIndex` suffix count only visible sheets, which is what the user sees in the sheet selection bar. Methods with the suffix, such as `setActiveSheetWithPOIIndex()` and `deleteSheetWithPOIIndex()`, count all sheets of the workbook, including hidden ones. The <<activeSheetIndex,activeSheetIndex>> and <<activeSheetWithPOIIndex,activeSheetWithPOIIndex>> attributes work the same way.

[[attributes]]
== Attributes

The following attributes are specific to `spreadsheet`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[activeSheetIndex]]`activeSheetIndex`
|The index of the sheet shown initially, counting only visible sheets.
|—

|[[activeSheetWithPOIIndex]]`activeSheetWithPOIIndex`
|The index of the sheet shown initially, counting all sheets of the underlying POI workbook, including hidden ones.
|—

|[[chartsEnabled]]`chartsEnabled`
|If `true`, the charts contained in the loaded workbook are rendered.
|`false`

|[[colBufferSize]]`colBufferSize`
|The size, in pixels, of the horizontal buffer rendered to the left and right of the visible area. A larger buffer makes scrolling smoother at the cost of a larger payload.
|`200`

|[[defaultColumnCount]]`defaultColumnCount`
|The number of columns in a newly created sheet.
|—

|[[defaultColumnWidth]]`defaultColumnWidth`
|The default width of a column, in pixels.
|—

|[[defaultPercentageFormat]]`defaultPercentageFormat`
|The format applied to cells whose value is entered as a percentage.
|`0.00%`

|[[defaultRowCount]]`defaultRowCount`
|The number of rows in a newly created sheet.
|—

|[[defaultRowHeight]]`defaultRowHeight`
|The default height of a row, in points.
|—

|[[functionBarVisible]]`functionBarVisible`
|If `true`, the formula bar is shown above the sheet.
|`true`

|[[invalidFormulaErrorMessage]]`invalidFormulaErrorMessage`
|The message shown when the user enters a formula that cannot be parsed. Accepts a message key.
|—

|[[maxColumns]]`maxColumns`
|The number of columns rendered in the active sheet.
|—

|[[maxRows]]`maxRows`
|The number of rows rendered in the active sheet.
|—

|[[minimumRowHeightForComponents]]`minimumRowHeightForComponents`
|The minimum height, in points, applied to rows that contain embedded components, so that the components remain visible. See <<embedded-components, Adding Components to Cells>>.
|`30`

|[[reportStyle]]`reportStyle`
|If `true`, the function bar and the sheet selection bar are hidden. See <<report-style, Report Mode>>.
|`false`

|[[rowBufferSize]]`rowBufferSize`
|The size, in pixels, of the vertical buffer rendered above and below the visible area.
|`200`

|[[selection]]`selection`
|The initially selected cell or range in the A1 notation, for example `A1` or `B2:D8`. See <<working-with-selection, Selection>>.
|—

|[[sheetSelectionBarVisible]]`sheetSelectionBarVisible`
|If `true`, the sheet tabs are shown at the bottom of the component.
|`true`

|[[statusLabelValue]]`statusLabelValue`
|The text shown in the status area of the component. Accepts a message key.
|—

|[[theme]]`theme`
|The theme of the spreadsheet. Possible values: `LUMO`, `VALO`. `LUMO` aligns the component with the rest of the application; `VALO` is the classic spreadsheet look.
|`VALO`
