= Vaadin 电子表格

xref:flow-ui:vc/components/spreadsheet.adoc[电子表格] UI 组件在 Jmix 中集成了商业版 https://vaadin.com/docs/v25/components/spreadsheet[Vaadin Spreadsheet^]。将功能齐全、兼容 Excel 的电子表格嵌入到应用程序视图中。用户无需离开浏览器即可打开、编辑和保存 `.xlsx` 工作簿。

组件基于 https://poi.apache.org[Apache POI^] 构建，因此整个 POI 对象模型（工作簿、工作表、单元格、样式和公式）在服务器端都可用。

扩展组件提供以下功能：

* 读取、编辑和写入 XLS 和 XLSX 文件，并保留公式、格式和样式。
* 熟悉的电子表格体验，包括公式栏、多个工作表、锁定区域，以及图表。
* 在视图 XML 中以声明方式配置组件，并提供 Java 端的完整编程控制。
* 使用标准 `@Subscribe` 注解订阅单元格值、公式、选择和工作表更改事件。
* 单元格删除、超链接点击以及嵌入单元格组件的自定义处理器。
* 报表样式，可隐藏的工具栏，将生成的文档显示为简洁的输出。
* 在 Jmix Studio 中提供支持，可在视图设计器面板的 *Vaadin Commercial* 类别中找到该组件，并提供属性编辑器。

典型使用场景是在应用程序内编辑 Excel 文档、批量数据录入以及展示表格报表。

== 安装

[NOTE]
====
此扩展组件需要两个订阅：

* https://www.jmix.cn/subscription-plans-and-prices/[企业版 Jmix 订阅^]。如果没有订阅，可以按照 xref:ROOT:account-management.adoc#enterprise-trial[企业版试用] 介绍的方法试用。
* https://vaadin.com/vaadin-for-jmix[Vaadin for Jmix^] 订阅。
====

请按照 xref:ROOT:add-ons.adoc#installation[扩展组件] 章节的介绍通过 Jmix 市场自动安装。

手动安装步骤：

. 配置 premium 仓库的访问
+
include::ROOT:partial$premium-repo.adoc[]

. 在 `build.gradle` 中添加依赖：
+
[source,groovy,indent=0]
----
implementation 'io.jmix.vcc:vaadin-spreadsheet-starter'
----

有关组件、元素、属性和 Java API 的说明，请参阅 xref:flow-ui:vc/components/spreadsheet.adoc[]。
