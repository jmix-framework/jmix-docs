The Calendar add-on integrates the https://fullcalendar.io/[FullCalendar] JavaScript library into Jmix through the xref:flow-ui:vc/components/fullCalendar.adoc[calendar] component. It displays events in day, week, month, and other modes. Users can interact with these events by:

* *Dragging*: Moving events to different dates or times within the calendar.
* *Resizing*: Adjusting the duration of an event by dragging its edges.
