= JMX Console

Данное дополнение предоставляет веб-интерфейс для мониторинга и управления компонентами приложения через стандартный API Java Management Extensions (JMX). Это удобная альтернатива таким инструментам, как JConsole или VisualVM.

Экран *JMX Console* отображает все MBean, зарегистрированные в JVM приложения. Пользователь может просматривать и изменять атрибуты MBean и вызывать их операции.

[[installation]]
== Установка

Для автоматической установки через маркетплейс Jmix следуйте инструкциям в разделе xref:ROOT:add-ons.adoc#installation[Дополнения].

Для ручной установки добавьте следующую зависимость в `build.gradle` проекта:

[source,groovy,indent=0]
----
implementation 'io.jmix.jmxconsole:jmix-jmxconsole-starter'
----

[[jmix.jmxconsole.write-and-invoke-enabled]]
== Ограничение операций записи и вызова

По умолчанию пользователи с правами доступа к JMX-консоли могут изменять атрибуты и вызывать операции MBean. Вы можете ограничить консоль только режимом просмотра, задав свойству приложения `jmix.jmxconsole.write-and-invoke-enabled` значение `false`.

Если эта возможность отключена, операции записи и вызова блокируются на стороне сервера, а соответствующие действия редактирования и вызова отключаются в UI.

Эта возможность также управляется глобальным переключателем xref:ROOT:app-properties.adoc#jmix.core.unsafe-runtime-features-enabled[jmix.core.unsafe-runtime-features-enabled].
