= JMX 控制台

该扩展组件提供一个通过 Java Management Extensions（JMX）API 监控和管理应用程序组件的 web UI，与 JConsole 或 VisualVM 类似。

*JMX Console* 视图展示应用程序中所有注册的 MBeans。用户可以查看、修改 MBean 的属性或调用操作。

[[installation]]
== 安装

按照 xref:ROOT:add-ons.adoc#installation[扩展组件] 章节的说明通过 Jmix 市场自动进行安装。

手动安装，在 `build.gradle` 添加下列依赖：

[source,groovy,indent=0]
----
implementation 'io.jmix.jmxconsole:jmix-jmxconsole-starter'
----

[[jmix.jmxconsole.write-and-invoke-enabled]]
== 限制写入和调用操作

默认情况下，拥有 JMX 控制台权限的用户可以更改 MBean 属性和调用 MBean 操作。通过设置 `jmix.jmxconsole.write-and-invoke-enabled` 应用程序属性为 `false`，可以将控制台限制为只读。

当禁用时，后端会阻止写入和调用操作，并且相应的编辑和调用操作在 UI 中也被禁用。

此功能也受全局 xref:ROOT:app-properties.adoc#jmix.core.unsafe-runtime-features-enabled[jmix.core.unsafe-runtime-features-enabled] 开关控制。

默认值：`true`
