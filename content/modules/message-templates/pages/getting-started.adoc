= Начало работы

В этом руководстве показано, как использовать дополнение Message Templates в приложении для бронирования офисных комнат. После создания бронирования пользователь получает сообщение по email или уведомление внутри приложения.

Ниже приведены разделы, из которых состоит пример приложения:

* xref:message-templates:booking-creation.adoc[Настройка приложения бронирования] — создание приложения с CRUD-экранами.
* xref:message-templates:template-definition.adoc[Определение шаблона] — создание шаблонов темы и тела письма с параметрами.
* xref:message-templates:email-generation.adoc[Генерация email из шаблонов] — отправка писем, сформированных из шаблонов.
* xref:message-templates:advanced-notifications.adoc[Продвинутые уведомления на основе шаблонов] — использование шаблонов для уведомлений внутри приложения.
