= 开始使用

本指南演示如何在预订办公室的示例应用程序中使用消息模板扩展组件。在创建预订后，用户会通过电子邮件或应用内通知收到基于模板创建的消息。

请按以下各节逐步构建示例应用程序：

* xref:message-templates:booking-creation.adoc[] — 构建带有 CRUD 视图的示例预订应用程序。
* xref:message-templates:template-definition.adoc[] — 创建带有可配置参数，并且可复用的主题和正文模板。
* xref:message-templates:email-generation.adoc[] — 发送由模板生成的电子邮件。
* xref:message-templates:advanced-notifications.adoc[] — 应用内通知也使用模板。
