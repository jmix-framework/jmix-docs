= Пользовательский интерфейс

После установки дополнения Message Templates в главном меню приложения появляется раздел *Шаблоны сообщений*.

Этот раздел содержит три экрана:

* xref:message-templates:message-templates.adoc[*Шаблоны сообщений*]
* xref:message-templates:template-groups.adoc[*Группы шаблонов*]
* xref:message-templates:template-blocks.adoc[*Блоки шаблонов*]

Доступ к этим экранам можно предоставить с помощью следующих xref:security:resource-roles.adoc[ролей ресурсов]:

* *Message Templates: full access* - предоставляет полные административные и пользовательские права
* *Message Templates: minimal access* - позволяет просматривать и генерировать шаблоны сообщений
