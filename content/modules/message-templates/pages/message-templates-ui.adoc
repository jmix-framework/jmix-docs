= 消息模板 UI

在安装了消息模板扩展组件后，会在系统的主菜单添加一个 *Message Templates* 菜单。

包含三个视图：

* xref:message-templates:message-templates.adoc[*消息模板*]
* xref:message-templates:template-groups.adoc[*模板分组*]
* xref:message-templates:template-blocks.adoc[*模板块*]

可以通过以下 xref:security:resource-roles.adoc[资源角色] 授予对这些视图的访问权限：

* *Message Templates: full access*，提供完整的管理员和用户权限
* *Message Templates: minimal access*，允许用户查看和生成消息模板
