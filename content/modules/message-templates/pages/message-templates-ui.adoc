= Message Templates UI

After the Message Templates add-on is installed, the *Message Templates* section appears in the main application menu.

This section contains three views:

* xref:message-templates:message-templates.adoc[*Message templates*]
* xref:message-templates:template-groups.adoc[*Template groups*]
* xref:message-templates:template-blocks.adoc[*Template blocks*]

Access to these views can be granted through the following xref:security:resource-roles.adoc[resource roles]:

* *Message Templates: full access*, provides full administrative and user permissions
* *Message Templates: minimal access*, allows users to view and generate message templates
