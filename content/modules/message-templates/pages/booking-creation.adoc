= 1. 配置预订应用程序

在本章中，我们将创建一个很小的预订房间应用程序，包括一个枚举、一个实体以及 CRUD 页面。在后续的 xref:message-templates.adoc[模板定义] 中，我们也会用到这个应用程序。

TIP: 如果你对 Jmix 不熟悉，请先查看 xref:tutorial:index.adoc[入门指南]，这里对 Jmix 的通用操作解释的非常详细。

[[create-room-enum]]
== 创建 Room 枚举

假设办公室有三个不同大小的房间。创建包含以下值的 `Room` 枚举：

* `Small`
* `Medium`
* `Large`

[[create-booking-entity]]
== 创建 Booking 实体

创建 `Booking` 实体。

`Booking` 实体有以下属性：

* `title` - 预订记录的标题。必填。
* `room` - `Room` 枚举类型，表示预订的房间。必填。
* `startDate` - `LocalDateTime` 类型。预订开始时间。必填。
* `endDate` - `LocalDateTime` 类型。预订结束时间。必填。
* `creator` - 与 `User` 实体关联。必填。

[[create-crud]]
== 创建 CRUD 视图

为 `Booking` 实体创建实体的列表视图和详情视图。

. 打开 `Booking` 实体的视图创建向导。
. 选择 *List and detail views* 模板。
. 在 *Entity list view fetch plan* 步骤，需勾选 `creator` 属性。
. 其他步骤使用推荐的默认设置。

[[run-app]]
== 运行应用程序

从 Studio 运行应用程序。

当应用程序启动完成后，在浏览器打开 `++http://localhost:8080++`，并使用 `admin` / `admin` 登录。从左侧的菜单点击 *Bookings* 。
