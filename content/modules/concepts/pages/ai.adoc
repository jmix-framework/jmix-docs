= ИИ в Jmix

В этом разделе объясняется, почему Jmix хорошо подходит для работы с ИИ-агентами для написания кода, и перечислена документация об ИИ: как разрабатывать Jmix-приложения с помощью агентов и какие ИИ-функции можно добавить в ваши приложения.

[[why-jmix]]
== Jmix и разработка с помощью ИИ

Jmix уменьшает объем кода, которым управляет разработчик приложения, и придает этому коду предсказуемую структуру.

Меньше собственного кода::
Платформа и ее дополнения предоставляют UI-компоненты и стандартные экраны, фильтрацию, постраничный вывод и сортировку, контроль доступа к данным, аудит, отчеты, BPM и другие функции. Агенту не нужно писать этот код, а разработчику не нужно его поддерживать. См. xref:principles.adoc#ready-made-solutions[Готовые решения] и xref:ROOT:add-ons.adoc[].

Единая структура::
Каждое Jmix-приложение состоит из одних и тех же строительных блоков, таких как сущности, экраны, сервисы и роли. Studio одинаково отображает их в xref:studio:tool-window.adoc[окне инструментов Jmix]. Единая структура упрощает понимание и поддержку кода, независимо от того, кем он написан: разработчиком или агентом.

Небольшие изменения::
UI и бизнес-логика работают в одном приложении, а экраны работают с сущностями напрямую. При создании новой функциональности не нужны слой API, DTO и мапперы, поэтому изменение, которое нужно проверить, получается относительно небольшим. См. xref:principles.adoc#full-stack-development[Фулл-стек разработка].

Централизованная безопасность::
Правила доступа определяются один раз, в ролях. `DataManager` применяет разрешения на операции с сущностями и xref:security:row-level-roles.adoc#policies[политики уровня строк] при загрузке и сохранении данных. UI-компоненты, связанные с данными, и REST API применяют xref:security:resource-roles.adoc#entity-attribute-policy[разрешения на атрибуты]. Если функция загружает данные через `DataManager` и показывает их в стандартных UI-компонентах, агенту не нужно писать для нее проверки разрешений.

Адаптация во время выполнения::
Администраторы и опытные пользователи могут вносить многие изменения в работающее приложение без нового кода и повторного развертывания: создавать xref:security:resource-roles.adoc#create[роли] в UI, фильтровать данные с помощью компонента xref:flow-ui:vc/components/genericFilter.adoc[genericFilter], отслеживать изменения с помощью xref:audit:index.adoc[аудита], создавать xref:reports:index.adoc[отчеты] и добавлять сущности и атрибуты с помощью xref:dyn-model:index.adoc[динамической модели].

Стандартный технологический стек::
Jmix-приложение является приложением Spring Boot, написанным на Java или Kotlin. Фреймворк имеет открытый исходный код, а код приложения принадлежит вам. Ваша IDE, тесты, статический анализ и конвейеры CI/CD работают как обычно. См. xref:principles.adoc#using-mainstream-technologies[Использование мейнстрим-технологий].

[[developing-with-agents]]
== Разработка с ИИ-агентами

* В разделе xref:ROOT:agent-setup.adoc[] показано, как настроить проект для агента и как работать с агентом в этом проекте.
* xref:ROOT:agent-setup.adoc#toolkit[Jmix Agent Toolkit] добавляет в проект инструкции Jmix, навыки агентов и MCP-серверы. xref:studio:tool-window.adoc#settings[Действие AI Agents Toolkit] в Studio устанавливает набор инструментов в существующий проект.
* https://github.com/jmix-framework/jmix-docs-mcp[MCP-сервер Jmix Docs^] позволяет агенту искать по документации Jmix, Java API и примерам UI.
* xref:ROOT:setup.adoc#jmix-cli[Jmix CLI] создает проекты из командной строки. Агент может запустить его, чтобы создать проект.
* xref:studio:ai-assistant.adoc[Jmix AI Assistant] отвечает на вопросы о Jmix в браузере и в Studio.

[[ai-in-applications]]
== ИИ-функции в вашем приложении

* Дополнение xref:ai-tools:index.adoc[AI Tools] добавляет полноценного ассистента на основе Spring AI. Он отвечает на вопросы о данных приложения, вызывая инструменты, и включает пользовательский интерфейс чата.
* Дополнение xref:ai-chat:index.adoc[AI Chat] предоставляет продвинутые UI-компоненты для чат-интерфейсов. Подключение к модели реализует само приложение, поэтому компоненты работают с любым LLM-бэкендом.
* Тип набора данных xref:reports:creation/bands.adoc#structure_llm[AI-generated JPQL] в дополнении Reports создает запрос бэнда отчета по описанию на естественном языке.
