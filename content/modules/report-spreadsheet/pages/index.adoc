= 报表电子表格

报告电子表格（Report Spreadsheet）扩展组件结合了 xref:reports:index.adoc[] 与 xref:vaadin-spreadsheet:index.adoc[] 组件的功能，报表的 XLS 和 XLSX 输出在浏览器中以交互式电子表格打开。用户可以查看生成的文档，进行编辑，并以原始格式下载编辑后的版本。

扩展组件提供以下功能：

* *Run and open in spreadsheet（运行并在电子表格打开）* 操作，位于报表视图中普通运行按钮旁边。
* 电子表格查看器，以对话框或页面显示。
* 编辑生成的文档，然后再下载。
* 可以只选择查看器能渲染的模板和输出类型。
* 编程 API，可以在自定义代码中打开报告查看器。

[[installation]]
== 安装

[NOTE]
====
此扩展组件需要企业版 https://www.jmix.cn/subscription-plans-and-prices/[订阅^]。如果没有企业版订阅，可以按照 xref:ROOT:account-management.adoc#enterprise-trial[企业版试用] 介绍的方法试用。

还依赖其他两个扩展组件，也需要在项目中安装：

* xref:reports:index.adoc[]
* xref:vaadin-spreadsheet:index.adoc[]
====

请按照 xref:ROOT:add-ons.adoc#installation[扩展组件] 章节的介绍通过 Jmix 市场自动安装。

手动安装步骤：

. 配置 premium 仓库的访问：
+
include::ROOT:partial$premium-repo.adoc[]

. 在 `build.gradle` 中添加依赖：
+
[source,groovy,indent=0]
----
implementation 'io.jmix.vcc:vaadin-spreadsheet-starter'
implementation 'io.jmix.reportsspreadsheet:jmix-reports-spreadsheet-flowui-starter'
----

[[configuration]]
== 配置

默认情况下，生成的 XLS 和 XLSX 报表在电子表格查看器中以模态窗打开。如需以页面打开，设置 xref:reports:configuration.adoc#jmix.reports.spreadsheet.output-open-mode[jmix.reports.spreadsheet.output-open-mode] 应用程序属性为 `NAVIGATION`。
