= tabSheet
:page-aliases: vcl/containers/tab-sheet.adoc

`tabSheet` organizes content into tabs and displays one tab at a time.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML Element
|`tabSheet`

|Java Class
|`JmixTabSheet`
|===

Tab state allows users to easily determine which tab is currently active and which tabs may be temporarily unavailable or disabled. A `tab` can be selected, unselected, or disabled.

[[variants]]
== Theme Variants

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/tabsheet-theme-variant" class="live-demo-btn" target="_blank">LIVE DEMO</a>
</div>
++++

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to set a component theme.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`icon-on-top`
|Applies to an individual `tab` element. Set `themeNames="icon-on-top"` on the `tab` to position the icon above the label text.
|Lumo

|`centered`
|Centers the tabs within the container.
|Lumo

|`small`
|Makes the tabs smaller.
|Aura, Lumo

|`minimal`
|Reduces the visual style to emphasize labels only.
|Lumo

|`hide-scroll-buttons`
|Hides the scroll buttons used to navigate overflown tabs.
|Aura, Lumo

|`equal-width-tabs`
|Allocates equal width to all tabs and disables scrolling.
|Lumo

|`bordered`
|Adds a border around the tabs and content area.
|Lumo

|`no-padding`
|Removes the default padding from the content area.
|Aura, Lumo

|`no-border`
|Removes the border around the tab sheet.
|Aura
|===

== Attributes

xref:vc/common-attributes.adoc[Common attributes] apply to `tabSheet` and its `tab` elements. The following attribute is specific to `tab`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[lazy-loading]]`lazy`
|Defers creation of the tab content until the tab is selected.
|`false`
|===

== Handlers

[cols="2,5", options="header"]
|===
|Name
|Description

|xref:vc/common-handlers.adoc#AttachEvent[`AttachEvent`]
|Fires when `tabSheet` or a `tab` is attached to the UI.

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Fires when `tabSheet` or a `tab` is detached from the UI.

|[[selected-change-event]]`SelectedChangeEvent`
|Fires when the selected tab changes.
|===

== Elements

A `tabSheet` contains `tab` elements. Each `tab` accepts one content component and can contain xref:vc/components/tooltip.adoc[`tooltip`] as a nested element.
