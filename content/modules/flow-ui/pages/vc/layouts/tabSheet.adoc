= tabSheet 标签面板
:page-aliases: vcl/containers/tab-sheet.adoc

`tabSheet` 将内容组织到标签页中，一次显示一个标签页。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`tabSheet`

|Java 类
|`JmixTabSheet`
|===

== 标签页数量

当标签页过多超过了可用宽度时，标签栏会自动显示滚动按钮，确保用户可以访问所有的标签页。

image::visual-components/layouts/tabsheet-tabs-number.png[align="center", width="500"]

== 标签页状态

用户可以通过标签页状态判断哪个是目前使用的标签页，以及哪些标签页可能暂时不可用或被禁用。一个 `tab` 可以被选择、不选择或被禁用。

image::visual-components/components/tabs-states.png[align="center", width="316"]

[[variants]]
== 样式版本

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/tabsheet-theme-variant" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 设置组件的样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`icon-on-top`
|应用于独立的 `tab` 元素。在 `tab` 设置 `themeNames="icon-on-top"` 可以将图标放置在标签文本之上
|Lumo

|`centered`
|将标签页放置在容器或视图的中间
|Lumo

|`small`
|使用小尺寸标签页
|Aura, Lumo

|`minimal`
|仅展示标签页的标签，不显示其他可视化元素
|Lumo

|`hide-scroll-buttons`
|隐藏用于滚动标签页的按钮
|Aura, Lumo

|`equal-width-tabs`
|每个标签页调整为等宽，并禁用滚动按钮
|Lumo

|`bordered`
|为标签页和内容添加边框
|Lumo

|`no-padding`
|移除内容区域的默认内边距
|Aura, Lumo

|`no-border`
|移除 tab 的边框
|Aura
|===

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对 `tabSheet` 和 `tab` 都是一样的配置。下面是 `tab` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[lazy-loading]]`lazy`
|延迟创建标签页内容，直到选中标签页。
|`false`
|===

== XML 内部元素

一个 `tabSheet` 可以包含多个 `tab` 元素。每个 `tab` 可以有一个内容组件和一个 xref:vc/components/tooltip.adoc[`tooltip`] 内部元素。
