= tabSheet
:page-aliases: vcl/containers/tab-sheet.adoc

`tabSheet` организует содержимое по вкладкам и отображает по одной вкладке за раз.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`tabSheet`

|Java-класс
|`JmixTabSheet`
|===

[[basics]]

== Количество вкладок

Если надписи вкладок не помещаются по доступной ширине, на панели появляются кнопки прокрутки, с помощью которых можно открыть остальные вкладки.

image::visual-components/layouts/tabsheet-tabs-number.png[align="center", width="500"]

== Состояния

Состояние вкладки позволяет пользователям легко определить, какая вкладка активна в данный момент, а какие могут быть временно недоступны или отключены. Вкладка может быть выбрана, не выбрана или отключена.

image::visual-components/components/tabs-states.png[align="center", width="316"]

[[variants]]
== Варианты темы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/tabsheet-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы настроить тему компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`icon-on-top`
|Для отдельного элемента `tab` располагает значок над текстом метки. Установите `themeNames="icon-on-top"` у `tab`.
|Lumo

|`centered`
|Размещает вкладки по центру контейнера.
|Lumo

|`small`
|Уменьшает размер вкладок.
|Aura, Lumo

|`minimal`
|Упрощает визуальный стиль, оставляя акцент только на надписях.
|Lumo

|`hide-scroll-buttons`
|Скрывает кнопки прокрутки для навигации по не помещающимся вкладкам.
|Aura, Lumo

|`equal-width-tabs`
|Выделяет одинаковую ширину для всех вкладок и отключает прокрутку.
|Lumo

|`bordered`
|Добавляет границу вокруг вкладок и области содержимого.
|Lumo

|`no-padding`
|Удаляет стандартные внутренние отступы из области содержимого.
|Aura, Lumo

|`no-border`
|Удаляет границу вокруг `tabSheet`.
|Aura
|===

== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] применяются к `tabSheet` и его элементам `tab`. Следующий атрибут относится только к `tab`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[lazy-loading]]`lazy`
|Откладывает создание содержимого вкладки до её выбора.
|`false`
|===

== Обработчики

[cols="2,5", options="header"]
|===
|Имя
|Описание

|xref:vc/common-handlers.adoc#AttachEvent[`AttachEvent`]
|Срабатывает при присоединении `tabSheet` или `tab` к UI.

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Срабатывает при отсоединении `tabSheet` или `tab` от UI.

|[[selected-change-event]]`SelectedChangeEvent`
|Срабатывает при изменении выбранной вкладки.
|===

== Элементы

`tabSheet` содержит элементы `tab`. Каждый `tab` принимает один компонент содержимого и может содержать вложенный элемент xref:vc/components/tooltip.adoc[`tooltip`].
