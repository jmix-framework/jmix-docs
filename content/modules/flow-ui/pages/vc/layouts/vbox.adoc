[[attributes]]
== Атрибуты

В Jmix существует множество xref:vc/common-attributes.adoc[общих атрибутов], которые служат одной цели для всех компонентов.

Следующие атрибуты специфичны для `vbox`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[boxSizing]]boxSizing
|Задает способ вычисления общей ширины и высоты элемента. Возможные значения: `UNDEFINED`, `CONTENT_BOX`, `BORDER_BOX`. Смотрите также: https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[страницу MDN о box-sizing^].
|`UNDEFINED`
|[[expand]]expand
|Задаёт идентификатор дочернего компонента, для которого значение `flex-grow` устанавливается в `1`. Благодаря этому компонент занимает оставшееся пространство по вертикали.
|—
|[[justifyContent]]justifyContent
|Задаёт распределение пространства между элементами содержимого и вокруг них.
Примеры использования приведены в разделе xref:vc/layout-rules.adoc#justify-content-mode[Правила компоновки].
|`START`
|[[margin]]margin
|Добавляет внешние отступы со всех четырёх сторон контейнера. См. https://developer.mozilla.org/en-US/docs/Web/CSS/margin[описание margin^] на MDN.
|`false`
|[[padding]]padding
|Добавляет внутренние отступы со всех четырёх сторон контейнера. См. https://developer.mozilla.org/en-US/docs/Web/CSS/padding[описание padding^] на MDN.
|`true`
|[[spacing]]spacing
|Добавляет между дочерними компонентами интервалы, заданные темой.
|`true`
|[[wrap]]wrap
|Если установлено значение `true`, переносит компоненты в новый столбец, когда заканчивается пространство по вертикали. См. раздел https://vaadin.com/docs/v25/components/vertical-layout#wrapping[Wrapping^] в документации Vaadin.
|`false`
|===
