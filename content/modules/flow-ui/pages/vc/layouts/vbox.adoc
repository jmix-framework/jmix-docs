[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `vbox` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[boxSizing]]boxSizing
|设置如何计算元素的总宽度和总高度。可选值为：`UNDEFINED`、`CONTENT_BOX`、`BORDER_BOX`。参阅： https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[MDN 关于 box-sizing^]。
|`UNDEFINED`
|[[expand]]expand
|设置为子组件的 ID，为子组件设置 `flex-grow: 1`，使其能够沿主轴占据剩余空间。
|—
|[[justifyContent]]justifyContent
|定义浏览器如何在内容条目之间和周围分配空间。
相关用例，请参考 xref:vc/layout-rules.adoc#justify-content-mode[布局规则]。
|`START`
|[[margin]]margin
|在布局的四边添加外边距。参阅 MDN 文档 https://developer.mozilla.org/en-US/docs/Web/CSS/margin[margin^]。
|`false`
|[[padding]]padding
|在布局的四边添加内边距。参阅 MDN 文档 https://developer.mozilla.org/en-US/docs/Web/CSS/padding[padding^]。
|`false`
|[[spacing]]spacing
|是否在子元素之间添加主题定义的空间。
|`true`
|[[wrap]]wrap
|如果为 `true`，当垂直空间不足时将组件移入下一列。参阅 Vaadin 文档 https://vaadin.com/docs/v25/components/vertical-layout#wrapping[换行]。
|`false`
|===
