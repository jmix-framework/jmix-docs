[[attributes]]
== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.

The following attributes are specific to `vbox`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[boxSizing]]boxSizing
|Sets how the total width and height of an element is calculated. Possible values are: `UNDEFINED`, `CONTENT_BOX`, `BORDER_BOX`. See also: https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[MDN page about box-sizing^].
|`UNDEFINED`
|[[expand]]expand
|Specifies the ID of a child component whose flex-grow value is set to `1`, allowing it to take up remaining vertical space.
|—
|[[justifyContent]]justifyContent
|Defines how the browser distributes space between and around content items.
For usage examples, see xref:vc/layout-rules.adoc#justify-content-mode[Layout Rules].
|`START`
|[[margin]]margin
|Adds margin outside the layout on all four sides. See https://developer.mozilla.org/en-US/docs/Web/CSS/margin[margin^] on MDN.
|`false`
|[[padding]]padding
|Adds padding inside the layout on all four sides. See https://developer.mozilla.org/en-US/docs/Web/CSS/padding[padding^] on MDN.
|`true`
|[[spacing]]spacing
|Adds theme-defined spacing between child components.
|`true`
|[[wrap]]wrap
|When `true`, moves components to a new column when vertical space runs out. See https://vaadin.com/docs/v25/components/vertical-layout#wrapping[Wrapping] in the Vaadin documentation.
|`false`
|===

== Elements

A `vbox` can contain components and layouts arranged in a vertical sequence.
