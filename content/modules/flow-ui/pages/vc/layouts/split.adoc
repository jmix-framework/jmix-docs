`split` 创建了两块内容区域，由一个可拖拽的分隔条区分。默认的分隔方向是垂直分隔，但是也可以配置为水平分隔。

* XML 元素：`split`

* Java 类：`JmixSplitLayout`

== 基本用法

`split` 必须包含两个内部的容器或组件，这些组件将显示在分隔条的两侧。初始的分隔条位置根据组件的大小确定。用户可以拖拽分隔条以修改分隔位置。

[[orientation]]
=== orientation

++++

定义组件的分隔方向，可能值：

* `VERTICAL` -  内部组件垂直放置，默认值。
* `HORIZONTAL` - 内部组件水平放置。
