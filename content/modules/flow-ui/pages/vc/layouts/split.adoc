= split
:page-aliases: vcl/containers/split-panel.adoc

`split` создаёт две области содержимого с перемещаемым разделителем.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`split`

|Java-класс
|`JmixSplitLayout`
|===

== Обзор

image::visual-components/layouts/split-basic.png[align="center", width="445"]

[[basics]]
== Основы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/split-simple" class="live-demo-btn" target="_blank">ДЕМО</a>

`split` должен содержать ровно два компонента или контейнера. В примере основная область занимает 45 % доступного пространства благодаря `splitterPosition="45"`, а во вторичной области находится вложенный вертикальный разделитель. Пользователи могут перемещать любой разделитель, изменяя размер областей.

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы настроить тему компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`minimal`
|Скрывает визуальное оформление разделителя.
|Aura, Lumo

|`small`
|Использует более тонкий разделитель, который становится видимым при наведении.
|Aura, Lumo

|`splitter-spacing`
|Добавляет отступы вокруг разделителя.
|Aura, Lumo
|===

[[attributes]]
== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] имеют одинаковое назначение для всех компонентов. Следующие атрибуты относятся только к `split`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[orientation]]`orientation`
|Задаёт расположение областей содержимого: рядом (`HORIZONTAL`) или одна над другой (`VERTICAL`).
|`HORIZONTAL`

|[[splitterPosition]]`splitterPosition`
|Задаёт исходное положение разделителя в процентах от размера контейнера.
|—
|===

== Элементы

`split` должен содержать ровно два компонента или контейнера: основную и вторичную области содержимого.
