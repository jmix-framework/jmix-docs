= split 分隔布局
:page-aliases: vcl/containers/split-panel.adoc

`split` 创建两块内容区域，由一个可拖拽的分隔条区分。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`split`

|Java 类
|`JmixSplitLayout`
|===

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 设置组件的样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`minimal`
|隐藏分隔布局的样式。
|Aura, Lumo

|`small`
|使用一个更薄的分隔符，只有鼠标悬停才会出现。
|Aura, Lumo

|`splitter-spacing`
|在分隔符周边添加一些空白。
|Aura, Lumo
|===

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。下面是 `split` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[orientation]]`orientation`
|定义组件的分隔方向：`HORIZONTAL` - 水平分隔；`VERTICAL` - 垂直分隔。
|`HORIZONTAL`

|[[splitterPosition]]`splitterPosition`
|设置初始时分隔条的位置，使用百分数设置。
|—
|===
