== 标题和副标题

标题用于识别卡片，而副标题在其下方添加次要文本。分别使用 `title` 和 `subtitle` 属性来定义，还可以使用同名的内部元素。内部元素优先级高于属性。

当使用了 <<slot-header,自定义 header>> 时，会忽略这两个属性的配置。

[[slot-headerPrefix]]
`headerPrefix` 插槽一般包含一个 xref:flow-ui:vc/components/avatar.adoc[头像]、xref:vc/components/icon.adoc[图标] 或其他可视化的标识符元素。

[[slot-headerSuffix]]
`headerSuffix` 插槽一般包含状态提示符或者操作。

[[slot-media]]
== 媒体

指定一个可视化组件，例如 xref:flow-ui:vc/html-components/image.adoc[图片]、xref:flow-ui:vc/components/avatar.adoc[头像] 或 xref:flow-ui:vc/components/icon.adoc[图标]，作为卡片的媒体内容显示。

如需控制媒体内容的尺寸，请使用 `themeNames` 属性设置 `stretch-media` 或 `cover-media` <<variants,样式>>。

----

[[slot-footer]]
== Footer

定义卡片的底部区域。此插槽支持多个元素，可为操作、状态指示和补充信息提供灵活的布局。

Footer 位于主要内容之后，当卡片的高度足够时，在底部显示。

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 设置组件的样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`outlined`
|为卡片添加边框
|Aura, Lumo

|`elevated`
|为卡片添加阴影效果。
|Aura, Lumo

|`horizontal`
|卡片内容水平布局。
|Aura, Lumo

|`stretch-media`
|调整媒体内容以填满其容器。
|Aura, Lumo

|`cover-media`
|裁剪媒体内容以覆盖其容器。
|Aura, Lumo
|===

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `card` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[subtitle]]`subtitle`
|设置具有预定义样式的次要文本内容。参考 <<title-subtitle,标题和副标题>>。
|—
|[[title]]`title`
|设置具有预定义样式的文本内容。参考 <<title-subtitle,标题和副标题>>。
|—
|[[titleHeadingLevel]]`titleHeadingLevel`
|设置通过标题（`title` 属性）的 `aria-level`。取值有效范围是 1 至 6。该配置对自定义标题组件无效。
|`2`
|===

== XML 内部元素
