== Title and Subtitle

The title identifies the card, while the subtitle adds secondary text below it. Define them with the `title` and `subtitle` attributes or with nested elements of the same names. A nested element takes precedence over the corresponding attribute.

Neither value is rendered when a <<slot-header,custom header>> is present.

== Theme Variants

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/card-theme-variant" class="live-demo-btn" target="_blank">LIVE DEMO</a>

++++

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to set a component theme.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`outlined`
|Applies a border around the card.
|Aura, Lumo

|`elevated`
|Adds a shadow effect to create elevation.
|Aura, Lumo

|`horizontal`
|Arranges the card content horizontally.
|Aura, Lumo

|`stretch-media`
|Scales the media content to fill its container.
|Aura, Lumo

|`cover-media`
|Crops the media content to cover its container.
|Aura, Lumo
|===

== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.

The following attributes are specific to `card`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[subtitle]]`subtitle`
|Sets secondary text with predefined styling. See <<title-subtitle,Title and Subtitle>>.
|—
|[[title]]`title`
|Sets the title text with predefined styling. See <<title-subtitle,Title and Subtitle>>.
|—
|[[titleHeadingLevel]]`titleHeadingLevel`
|Sets the `aria-level` of a title defined with the `title` attribute. It does not affect a custom title component. Use a value from 1 through 6 to preserve a valid heading hierarchy.
|`2`
|===

== Elements

A `card` can contain the <<slot-title,title>>, <<slot-subtitle,subtitle>>, <<slot-header,header>>, <<slot-headerPrefix,headerPrefix>>, <<slot-headerSuffix,headerSuffix>>, <<slot-media,media>>, <<slot-content,content>>, and <<slot-footer,footer>> elements described above.
