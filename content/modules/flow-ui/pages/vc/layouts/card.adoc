= card

`card` группирует связанное содержимое и действия в структурированной карточке.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`card`

|Java-класс
|`JmixCard`
|===

== Заголовок и подзаголовок

Заголовок обозначает карточку, а подзаголовок добавляет под ним вспомогательный текст. Задайте их с помощью атрибутов `title` и `subtitle` или одноимённых вложенных элементов. Вложенный элемент имеет приоритет над соответствующим атрибутом.

Если задан <<slot-header,пользовательский заголовок>>, эти значения не отображаются.

Карточка с атрибутами `title` и `subtitle`:

[[slot-headerPrefix]]
Слот `headerPrefix` обычно содержит xref:flow-ui:vc/components/avatar.adoc[аватар], xref:vc/components/icon.adoc[значок] или другой визуальный идентификатор.

[[slot-headerSuffix]]
Слот `headerSuffix` обычно содержит индикатор состояния или действие.

[[slot-media]]
== Медиа карточки

Слот `media` задаёт визуальный компонент, например xref:flow-ui:vc/html-components/image.adoc[изображение], xref:flow-ui:vc/components/avatar.adoc[аватар] или xref:flow-ui:vc/components/icon.adoc[значок], который отображается как медиасодержимое карточки.

Чтобы настроить размер медиасодержимого, примените <<variants,вариант темы>> `stretch-media` или `cover-media` с помощью атрибута `themeNames`.

Слот `content` содержит основное содержимое карточки. В него можно добавить любое количество элементов, чтобы создавать сложные компоновки.

[[slot-footer]]
== Нижний колонтитул карточки

Слот `footer` задаёт область нижнего колонтитула карточки. Он поддерживает несколько элементов для действий, индикаторов состояния и дополнительной информации.

Нижний колонтитул расположен после основного содержимого и остаётся внизу, если карточка имеет дополнительную высоту.

== Варианты темы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/card-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы настроить тему компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`outlined`
|Применяет границу вокруг карточки.
|Aura, Lumo

|`elevated`
|Добавляет тень для создания ощущения глубины.
|Aura, Lumo

|`horizontal`
|Располагает содержимое карточки горизонтально.
|Aura, Lumo

|`stretch-media`
|Масштабирует медиа-контент, чтобы заполнить его контейнер.
|Aura, Lumo

|`cover-media`
|Обрезает медиа-контент для заполнения его контейнера.
|Aura, Lumo
|===

TIP: Все варианты темы можно комбинировать.

== Атрибуты

Следующие атрибуты относятся только к `card`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[subtitle]]`subtitle`
|Задаёт вспомогательный текст со стандартным оформлением. См. <<title-subtitle,Заголовок и подзаголовок>>.
|—
|[[title]]`title`
|Задаёт текст заголовка со стандартным оформлением. См. <<title-subtitle,Заголовок и подзаголовок>>.
|—
|[[titleHeadingLevel]]`titleHeadingLevel`
|Задаёт `aria-level` заголовка, определённого атрибутом `title`. Не влияет на пользовательский компонент заголовка. Используйте значение от 1 до 6, чтобы сохранить правильную иерархию заголовков.
|`2`
|===
