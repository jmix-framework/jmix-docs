= accordion
:page-aliases: vcl/containers/accordion.adoc

`accordion` создаёт панели с содержимым, которое можно сворачивать и разворачивать.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`accordion`

|Java-класс
|`JmixAccordion`
|===

[[basics]]
== Основы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/accordion-simple" class="live-demo-btn" target="_blank">ДЕМО</a>

++++

Используйте `accordion` для группировки или скрытия однотипного содержимого. Контент размещается во вложенных элементах `accordionPanel`. Таких панелей может быть несколько, но одновременно может быть развернута только одна.

В интерактивном примере определены две панели. В показанном фрагменте панель содержит форму, а её `summaryText` остаётся видимым, когда вложенное содержимое свёрнуто:

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы настроить тему компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`filled`
|Применяет стиль с заливкой фона к панели.
|Aura, Lumo

|`reverse`
|Отображает значок переключателя после текста заголовка.
|Aura, Lumo

|`small`
|Уменьшает размер панели.
|Aura, Lumo

|`no-padding`
|Удаляет стандартные внутренние отступы из области содержимого.
|Aura
|===

[[attributes]]
== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] применяются к `accordion` и `accordionPanel`. Следующие атрибуты относятся только к `accordionPanel`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[opened]]`opened`
|Определяет, развёрнута ли панель.
|`false`

|[[summaryText]]`summaryText`
|Задаёт заголовок, который остаётся видимым, когда панель свёрнута.
|—
|===

[[handlers]]
== Обработчики

Одинаковые обработчики можно настроить для `accordion` и `accordionPanel`.

[cols="2,5", options="header"]
|===
|Имя
|Описание

|xref:vc/common-handlers.adoc#AttachEvent[`AttachEvent`]
|Срабатывает при присоединении компонента к UI.

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Срабатывает при отсоединении компонента от UI.

|[[OpenedChangeEvent]]`OpenedChangeEvent`
|Срабатывает при разворачивании или сворачивании панели. Обработчик `accordion` отслеживает все панели, а обработчик `accordionPanel` — только эту панель.
|===

== Элементы

`accordion` содержит один или несколько элементов `accordionPanel`. Каждая панель может содержать один или несколько компонентов или контейнеров.
