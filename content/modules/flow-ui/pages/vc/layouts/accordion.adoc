= accordion 折叠面板
:page-aliases: vcl/containers/accordion.adoc

`accordion` 中包含内容的面板是可以展开和折叠的。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML Element
|`accordion`

|Java Class
|`JmixAccordion`
|===

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 设置组件的样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`filled`
|面板使用填充背景样式。
|Aura, Lumo

|`reverse`
|在文本后面显示开关图标。
|Aura, Lumo

|`small`
|面板较小。
|Aura, Lumo

|`no-padding`
|移除内容区域的默认内边距。
|Aura
|===

[[attributes]]
== XML 属性

`accordion` 和 `accordionPanel` 使用了一些 Jmix 的 xref:vc/common-attributes.adoc[通用属性]。下面是 `accordionPanel` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[opened]]`opened`
|设置面板是否打开。
|`false`

|[[summaryText]]`summaryText`
|为面板的内容设置标题。即使内容折叠，标题依然显示。
|—
|===

[[handlers]]
== 事件和处理器

`accordion` 和 `accordionPanel` 额可以配置相同的处理器。

[cols="2,5", options="header"]
|===
|名称
|描述

|[[OpenedChangeEvent]]`OpenedChangeEvent`
|`OpenedChangedEvent` 每次当面板折叠或展开时发送。为 `accordion` 设置该处理器可以监听所有的面板状态。为某个 `accordionPanel` 设置则监听其自己的状态。
|===

下面是 `accordion` 和 `accordionPanel` 支持的其他通用事件：

xref:vc/common-handlers.adoc#AttachEvent[AttachEvent] -
xref:vc/common-handlers.adoc#DetachEvent[DetachEvent]

== XML 内部元素

一个 `accordion` 可以包含多个 `accordionPanel` 元素。每个面板内可以放任意多个组件或布局。
