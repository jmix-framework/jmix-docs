[[justification]]
== Content Justification

容器对齐模式可以定义内部元素如何在可用的水平空间中排布。支持：

* `START`（默认）
+
内部元素对齐在左侧（从左到右的地区语言）或右侧（从右到左的地区语言）。

* `CENTER`
+
内部所有元素放置于布局容器的中间。

* `END`
+
内部元素对齐在右侧（从左到右的地区语言）或左侧（从右到左的地区语言）。

* `BETWEEN`
+
在内部元素之间均匀分配可用空间。在第一个元素之前或最后一个元素之后没有额外的空间。

* `AROUND`
+
在内部元素之间均匀分配可用空间。在第一个元素之前或最后一个元素之后的额外的空间是元素之间空间的一半。

* `EVENLY`
+
在内部元素之间均匀分配可用空间。在第一个元素之前或最后一个元素之后的额外的空间跟元素之间空间一样。

使用 <<justifyContent,justifyContent>> 属性设置布局的内容对齐。

更多用例，请参阅 xref:vc/layout-rules.adoc#justify-content-mode[布局规则]。

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。

下面是 `hbox` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[boxSizing]]boxSizing
|设置内部元素的宽高如何计算。支持值：`UNDEFINED`、`CONTENT_BOX`、`BORDER_BOX`。参阅 https://developer.mozilla.org/en-US/docs/Web/CSS/box-sizing[MDN^]。
|`UNDEFINED`
|[[expand]]expand
|设置为子组件的 ID，为子组件设置 `flex-grow: 1`，使其能够沿主轴占据剩余空间。
|—
|[[justifyContent]]justifyContent
|定义浏览器如何在子组件之间分配空间。参阅 <<justification,内容对齐>>。
|`START`
|[[margin]]margin
|在布局的四边添加外边距。参阅 MDN 文档 https://developer.mozilla.org/en-US/docs/Web/CSS/margin[margin^]。
|`false`
|[[padding]]padding
|在布局的四边添加内边距。参阅 MDN 文档 https://developer.mozilla.org/en-US/docs/Web/CSS/padding[padding^]。
|`false`
|[[spacing]]spacing
|是否在子元素之间添加主题定义的空间。
|`true`
|[[wrap]]wrap
|如果为 `true`，当水平空间不足时将组件移入下一行。参阅 Vaadin 文档 https://vaadin.com/docs/v25/components/horizontal-layout#wrapping[换行]。
|`false`
|===
