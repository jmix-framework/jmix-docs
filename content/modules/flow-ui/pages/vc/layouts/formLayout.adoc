[[auto-responsive-mode]]
== Auto-Responsive Mode

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/form-layout-auto-responsive" class="live-demo-btn" target="_blank">LIVE DEMO</a>
</div>
++++

Set `autoResponsive="true"` to let `formLayout` determine the number of columns from the available width, configured column width, and spacing. Each `formRow` starts a new row. If its fields do not fit, they wrap to rows reserved for that `formRow`.

IMPORTANT: When auto-responsive mode is enabled, <<responsive-steps,responsive steps>> are ignored.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/containers/formlayout/autoresponsive/form-layout-auto-responsive.xml[tags=auto-responsive]
----

For automatic distribution without explicit `formRow` elements, set `autoRows="true"`. The `minColumns`, `maxColumns`, `columnWidth`, `columnSpacing`, `rowSpacing`, `expandColumns`, and `expandFields` attributes refine how the generated grid uses the available space.

== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `formLayout`.

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[autoResponsive]]autoResponsive
|Enables the layout to automatically calculate and adjust the number of columns based on the available width of its container. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|`false`
|[[autoRows]]autoRows
|Configures whether the layout should automatically distribute fields across columns, filling each row sequentially before wrapping to the next line. This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|`false`
|[[columnWidth]]columnWidth
|Defines the fixed width for all columns. Value must be a valid CSS length unit (for example, `"100px"`, `"10em"`). This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|`12em`
|[[columnSpacing]]columnSpacing
|Defines the gap between columns using a CSS length.
|—
|[[expandColumns]]expandColumns
|When enabled, columns evenly distribute to fill any remaining horizontal space after the initial column calculation. This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|`false`
|[[expandFields]]expandFields
|When enabled, fields stretch to fill all available width within their containing column. This also applies to fields wrapped in `formItem` elements. This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|`false`
|[[labelsAside]]labelsAside
|Specifies whether `formItem` elements within the layout should position their labels beside the associated fields instead of above them. This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|`false` (labels are positioned above fields)
|[[labelSpacing]]labelSpacing
|Defines the gap between a side-positioned label and its field using a CSS length, for example, `1em`.
|—
|[[labelsPosition]]labelsPosition
|Sets the label position for the default responsive steps and for nested `responsiveStep` elements that omit `labelsPosition`.

- `ASIDE` - labels are positioned to the side of the components.

- `TOP` - labels are positioned above the components.
|`TOP`
|[[labelWidth]]labelWidth
|Sets the width of side-positioned labels using a CSS length, for example, `8em`.
|—
|[[maxColumns]]maxColumns
|Sets the maximum number of columns the layout can create. The actual number will not exceed this limit, even if there is sufficient space. This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|10
|[[minColumns]]minColumns
|Sets the minimum number of columns the layout will create, regardless of container width. This attribute works only when <<autoResponsive,autoResponsive>> is enabled. See <<auto-responsive-mode,Auto-Responsive Mode>>.
|1
|[[rowSpacing]]rowSpacing
|Defines the gap between rows using a CSS length.
|—
|===

== Elements

A `formLayout` can contain fields directly or wrap them in `formItem` and `formRow` elements. The `responsiveSteps` element contains `responsiveStep` entries used by <<responsive-steps,Responsive Steps Mode>>.
