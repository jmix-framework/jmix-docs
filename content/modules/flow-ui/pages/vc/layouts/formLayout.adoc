== Автоматический адаптивный режим

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/form-layout-auto-responsive" class="live-demo-btn" target="_blank">ДЕМО</a>

Установите `autoResponsive="true"`, чтобы `formLayout` определял количество столбцов по доступной ширине, заданной ширине столбца и интервалам. Каждый `formRow` начинает новую строку. Если поля не помещаются, они переносятся в дополнительные строки, выделенные этому `formRow`.

IMPORTANT: При включении автоматического адаптивного режима <<responsive-steps,адаптивные шаги>> игнорируются.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/containers/formlayout/autoresponsive/form-layout-auto-responsive.xml[tags=auto-responsive]
----

Для автоматического распределения без явных элементов `formRow` установите `autoRows="true"`. Атрибуты `minColumns`, `maxColumns`, `columnWidth`, `columnSpacing`, `rowSpacing`, `expandColumns` и `expandFields` уточняют, как созданная сетка использует доступное пространство.

== Атрибуты

В Jmix есть множество xref:vc/common-attributes.adoc[общих атрибутов], которые выполняют одну и ту же функцию для всех компонентов.
Ниже приведены атрибуты, специфичные для `formLayout`.

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[autoResponsive]]autoResponsive
|Включает автоматический расчет и адаптацию количества столбцов на основе доступной ширины контейнера. Смотрите <<auto-responsive-mode,Автоматический адаптивный режим>>.
|`false`
|[[autoRows]]autoRows
|Настраивает автоматическое распределение полей по столбцам, с последовательным заполнением строк перед переносом на следующую. Работает только при включенном <<autoResponsive,autoResponsive>>. Смотрите <<auto-responsive-mode,Автоматический адаптивный режим>>.
|`false`
|[[columnWidth]]columnWidth
|Задаёт фиксированную ширину всех столбцов. Значение должно быть допустимой CSS-величиной длины, например `"100px"` или `"10em"`. Атрибут работает только при включённом <<autoResponsive,autoResponsive>>. См. <<auto-responsive-mode,Автоматический адаптивный режим>>.
|`12em`
|[[columnSpacing]]columnSpacing
|Задаёт интервал между столбцами как CSS-величину длины.
|—
|[[expandColumns]]expandColumns
|Если включён, равномерно расширяет столбцы, чтобы после исходного расчёта заполнить оставшееся пространство по горизонтали. Атрибут работает только при включённом <<autoResponsive,autoResponsive>>. См. <<auto-responsive-mode,Автоматический адаптивный режим>>.
|`false`
|[[expandFields]]expandFields
|Если включён, растягивает поля на всю доступную ширину столбца. Это также относится к полям, обёрнутым в элементы `formItem`. Атрибут работает только при включённом <<autoResponsive,autoResponsive>>. См. <<auto-responsive-mode,Автоматический адаптивный режим>>.
|`false`
|[[labelsAside]]labelsAside
|Определяет, должны ли элементы `formItem` располагать надписи рядом со связанными полями, а не над ними. Атрибут работает только при включённом <<autoResponsive,autoResponsive>>. См. <<auto-responsive-mode,Автоматический адаптивный режим>>.
|`false` (надписи располагаются над полями)
|[[labelSpacing]]labelSpacing
|Задаёт интервал между надписью сбоку и её полем как CSS-величину длины, например `1em`.
|—
|[[labelsPosition]]labelsPosition
|Задаёт положение надписей для адаптивных шагов по умолчанию и вложенных элементов `responsiveStep`, в которых не указан `labelsPosition`.

- `ASIDE` — сбоку от компонентов.

- `TOP` — над компонентами.
|`TOP`
|[[labelWidth]]labelWidth
|Задаёт ширину надписей сбоку как CSS-величину длины, например `8em`.
|—
|[[maxColumns]]maxColumns
|Задаёт максимальное количество столбцов, которое может создать контейнер. Фактическое количество не превысит это ограничение, даже если пространства достаточно. Атрибут работает только при включённом <<autoResponsive,autoResponsive>>. См. <<auto-responsive-mode,Автоматический адаптивный режим>>.
|10
|[[minColumns]]minColumns
|Задаёт минимальное количество столбцов, которое создаст контейнер независимо от его ширины. Атрибут работает только при включённом <<autoResponsive,autoResponsive>>. См. <<auto-responsive-mode,Автоматический адаптивный режим>>.
|1
|[[rowSpacing]]rowSpacing
|Задаёт интервал между строками как CSS-величину длины.
|—
|===

== Элементы

`formLayout` может содержать поля напрямую или оборачивать их в элементы `formItem` и `formRow`. Элемент `responsiveSteps` содержит элементы `responsiveStep`, используемые в <<responsive-steps,режиме адаптивных шагов>>.
