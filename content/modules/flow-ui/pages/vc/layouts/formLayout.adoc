= formLayout 表单布局
:page-aliases: vcl/components/form.adoc, vcl/containers/responsive-grid-layout.adoc

`formLayout` 在响应式的列布局中排列表单字段。

|XML 元素
|`formLayout`

|Java 类

|===

[[auto-responsive-mode]]
== 自动响应模式

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/form-layout-auto-responsive" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

设置 `autoResponsive="true"` 时，`formLayout` 根据可用宽度、配置的列宽和空间来确定列数。每个 `formRow` 表示一个新行。如果其字段无法适配宽度，会自动换到下一行（为 `formRow` 保留的行）。

IMPORTANT: 当自动响应模式启用时，会忽略 <<responsive-steps,响应式列数>>。

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/containers/formlayout/autoresponsive/form-layout-auto-responsive.xml[tags=auto-responsive]
----

对于没有显式配置 `formRow` 元素而需要自动分配时，请设置 `autoRows="true"`。`minColumns`、`maxColumns`、`columnWidth`、`columnSpacing`、`rowSpacing`、`expandColumns` 和 `expandFields` 元素可以微调生成的网格如何使用可用空间。

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `formLayout` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[autoResponsive]]`autoResponsive`
|布局根据其容器的可用宽度自动计算和调整列数。参阅 <<auto-responsive-mode>>。
|`false`
|[[autoRows]]`autoRows`
|配置布局是否应自动将字段分布到各列，顺序填充每行后再换到下一行。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode>>。
|`false`
|[[columnWidth]]`columnWidth`
|为所有列定义固定宽度。值必须是有效的 CSS 长度单位（例如 `"100px"`、`"10em"`）。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode,自动响应模式>>。
|`12em`
|[[columnSpacing]]`columnSpacing`
|使用 CSS 长度单位定义列之间的间距。
|—
|[[expandColumns]]`expandColumns`
|启用后，列会均匀分布以填充初始列计算后剩余的水平空间。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode,自动响应模式>>。
|`false`
|[[expandFields]]`expandFields`
|启用后，字段会拉伸以填充其所在列的所有可用宽度。这也适用于包裹在 `formItem` 元素中的字段。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode,自动响应模式>>。
|`false`
|[[labelsAside]]`labelsAside`
|指定布局中的 `formItem` 元素应将其标签放在相关字段的旁边而不是上方。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode,自动响应模式>>。
|`false`（标签位于字段上方）
|[[labelSpacing]]`labelSpacing`
|当标签放在字段旁边时，定义标签与对应字段之间的间距（CSS 长度）。例如 `1em`。
|—
|[[labelsPosition]]`labelsPosition`
|为默认响应式档位配置标签位置，也应用于不带 `labelsPosition` 的 `responsiveStep` 元素。

- `ASIDE` - 标签位于组件侧边。

- `TOP` - 标签位于组件上方。
|`TOP`
|[[labelWidth]]`labelWidth`
|设置侧置标签的宽度（CSS 长度）。例如 `1em`。
|—
|[[maxColumns]]`maxColumns`
|设置布局可以创建的最大列数。即使有足够空间，实际列数也不会超过此限制。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode,自动响应模式>>。
|10
|[[minColumns]]`minColumns`
|设置布局将创建的最小列数，无论容器宽度如何。此属性仅在启用 <<autoResponsive,autoResponsive>> 时有效。参阅 <<auto-responsive-mode,自动响应模式>>。
|1
|[[rowSpacing]]`rowSpacing`
|定义行之间的间距（ CSS 长度）。
|—
|===

== XML 内部元素

一个 `formLayout` 可以直接包含字段组件或由 `formItem` 和 `formRow` 元素包裹的字段组件。`responsiveSteps` 元素及其内部的 `responsiveStep` 定义 <<responsive-steps,响应式档位>>。
