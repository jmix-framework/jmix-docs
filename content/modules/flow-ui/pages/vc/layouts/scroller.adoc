= scroller 滚动盒子
:page-aliases: vcl/containers/scroll-box-layout.adoc

`scroller` 是一个支持内容区域滚动的布局容器。

|XML 元素
|`scroller`

++++
<div class="jmix-ui-live-demo-container">

`scroller` 在一个比较小的区域展示超出范围的内容。其内部只能放置一个组件；如果有多个组件必须同时滚动，请使用布局组件包装，例如，xref:flow-ui:vc/layouts/vbox.adoc[]。

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。下面是 `scroller` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[scrollBarsDirection]]`scrollBarsDirection`
|当内容溢出时可滚动的方向：`VERTICAL`、`HORIZONTAL`、`BOTH` 或 `NONE`。
|`BOTH`
|===
