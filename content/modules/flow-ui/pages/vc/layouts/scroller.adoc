= scroller
:page-aliases: vcl/containers/scroll-box-layout.adoc

`scroller` is a layout that creates a scrollable content area.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML Element
|`scroller`

|Java Class
|`JmixScroller`
|===

== Basics

`scroller` displays overflowing content within a smaller area. It accepts one content component; use a layout such as xref:flow-ui:vc/layouts/vbox.adoc[] when several components must scroll together.

----

[[attributes]]
== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components. The following attribute is specific to `scroller`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[scrollBarsDirection]]`scrollBarsDirection`
|Controls overflow scrolling: `VERTICAL`, `HORIZONTAL`, `BOTH`, or `NONE`.
|`BOTH`
|===

== Elements

A `scroller` accepts one component or layout as its scrollable content.
