= scroller
:page-aliases: vcl/containers/scroll-box-layout.adoc

`scroller` — контейнер, который создаёт прокручиваемую область содержимого.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`scroller`

|Java-класс
|`JmixScroller`
|===

`scroller` отображает содержимое с прокруткой в области меньшего размера. Он принимает один компонент содержимого. Если несколько компонентов должны прокручиваться вместе, поместите их в контейнер, например xref:flow-ui:vc/layouts/vbox.adoc[].

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/containers/scroller/scroller.xml[tags=basics]
----

[[attributes]]
== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] имеют одинаковое назначение для всех компонентов. Следующий атрибут относится только к `scroller`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[scrollBarsDirection]]`scrollBarsDirection`
|Задаёт направление прокрутки переполненного содержимого: `VERTICAL`, `HORIZONTAL`, `BOTH` или `NONE`.
|`BOTH`
|===

[[handlers]]
== Обработчики

[cols="2,5", options="header"]
|===
|Имя
|Описание

|xref:vc/common-handlers.adoc#AttachEvent[`AttachEvent`]
|Срабатывает при присоединении компонента к UI.

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Срабатывает при отсоединении компонента от UI.
|===

== Элементы

`scroller` принимает один компонент или контейнер в качестве прокручиваемого содержимого.
