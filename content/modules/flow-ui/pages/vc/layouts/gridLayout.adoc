= gridLayout 表格布局

`gridLayout` 将内部的子组件或数据排布在一个响应式、二维的 CSS 表格中。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`gridLayout`

|Java 类
|`GridLayout`
|===

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。下面是 `gridLayout` 或其子组件的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[alignSelf]]`alignSelf`
|在子组件设置。子组件在网格单元格内沿块轴（列轴）的对齐方式。对应于 CSS 的 https://developer.mozilla.org/en-US/docs/Web/CSS/align-self[align-self^] 属性。
|`AUTO`
|[[columnMinWidth]]`columnMinWidth`
|设置 `gridLayout` 中网格列的最小宽度。可以防止在容器调整大小时列变得过窄。
该值为 CSS 长度值（例如 `"50px"`、`"10rem"`）。
|`19rem`
|[[gap]]gap
|网格单元格之间的间距（包括行间距和列间距）。该值为 CSS 长度值（例如 `"10px"`、`"1rem"`）。
|`0.5rem`
|[[justifySelf]]`justifySelf`
|在子组件设置。子组件在网格单元格内沿内轴（行轴）的对齐方式。对应于 CSS 的 https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/justify-self[justify-self^] 属性。
|`AUTO`
|===

== 事件和处理器

xref:vc/common-handlers.adoc[通用事件和处理器] 对所有组件都是一样的配置。

下面是 `gridLayout` 的特殊事件和处理器：

[cols="2,5", options="header"]
|===
|名称
|描述
|[[itemLabelGenerator]]`itemLabelGenerator`
|为条目生成自定义的显示文本。
|[[renderer]]renderer
|设置条目的渲染器，对每个条目创建一个组件。参考 <<rendering-items,自定义条目渲染>>。
|===

== XML 内部元素

一个非数据感知的 `gridLayout` 可以直接包含 UI 组件。一个数据感知的布局可以包含 xref:vc/miscellaneous/renderers.adoc#fragment-renderer[`fragmentRenderer`]，为每个条目创建组件。
