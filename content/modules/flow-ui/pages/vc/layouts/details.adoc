`details` 是一个可展开的面板，用于展示或隐藏一些内容。

* XML 元素：`details`

* Java 类：`JmixDetails`

== 基本用法

使用 `details` 隐藏一些附加信息或可选的操作。`details` 可以包含任何组件或布局。

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 设置组件的样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`filled`
|面板使用填充背景样式。
|Aura, Lumo

|`reverse`
|在文本后面显示开关图标。
|Aura, Lumo

|`small`
|面板较小。
|Aura, Lumo

|`no-padding`
|移除内容区域的默认内边距。
|Aura
|===
