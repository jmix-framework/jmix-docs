== Theme Variants

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/details-theme-variant" class="live-demo-btn" target="_blank">LIVE DEMO</a>

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to set a component theme.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`filled`
|Applies a filled background style.
|Aura, Lumo

|`reverse`
|Displays the toggle icon after the summary text.
|Aura, Lumo

|`small`
|Makes the component smaller.
|Aura, Lumo

|`no-padding`
|Removes the default padding from the content area.
|Aura
|===

[[attributes]]
== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components. The following attributes are specific to `details`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[opened]]`opened`
|Controls whether the content is expanded.
|`false`

|[[summaryText]]`summaryText`
|Sets the summary that remains visible when the content is collapsed.
|—

|[[themeNames]]`themeNames`
|Applies one or more variants listed in <<variants,Theme Variants>>.
|—
|===

[[handlers]]
== Handlers

[cols="2,5", options="header"]
|===
|Name
|Description

|xref:vc/common-handlers.adoc#AttachEvent[`AttachEvent`]
|Fires when the component is attached to the UI.

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Fires when the component is detached from the UI.

|[[OpenedChangeEvent]]`OpenedChangeEvent`
|Fires when the component is expanded or collapsed.
|===

== Elements

A `details` element can contain one or more components or layouts as its content and xref:vc/components/tooltip.adoc[`tooltip`] as a nested element.
