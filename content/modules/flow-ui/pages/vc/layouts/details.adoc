= details 详情面板
:page-aliases: vcl/containers/group-box-layout.adoc

`details` 是一个可展开的面板，用于展示或隐藏一些内容。

|XML 元素
|`details`

|Java 类
|`JmixDetails`
|===

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 设置组件的样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`filled`
|面板使用填充背景样式。
|Aura, Lumo

|`reverse`
|在文本后面显示开关图标。
|Aura, Lumo

|`small`
|面板较小。
|Aura, Lumo

|`no-padding`
|移除内容区域的默认内边距。
|Aura
|===

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。下面是 `details` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[opened]]`opened`
|设置面板是否展开。
|`false`

|[[summaryText]]`summaryText`
|为内容设置简短摘要。即使内容折叠，摘要依然显示。
|—

|[[themeNames]]`themeNames`
|使用 <<variants,样式版本>> 中列出的一个或多个样式。
|—
|===

== XML 内部元素

一个 `details` 可以包含一个或多个组件或容器作为其内容，以及 xref:vc/components/tooltip.adoc[`tooltip`] 作为内部元素。
