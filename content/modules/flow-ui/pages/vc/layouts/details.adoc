Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы настроить тему компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`filled`
|Применяет стиль с заливкой фона.
|Aura, Lumo

|`reverse`
|Отображает значок переключателя после текста заголовка.
|Aura, Lumo

|`small`
|Уменьшает размер компонента.
|Aura, Lumo

|`no-padding`
|Удаляет стандартные внутренние отступы из области содержимого.
|Aura
|===

[[attributes]]
== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] имеют одинаковое назначение для всех компонентов. Следующие атрибуты относятся только к `details`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[opened]]`opened`
|Определяет, развёрнуто ли содержимое.
|`false`

|[[summaryText]]`summaryText`
|Задаёт заголовок, который остаётся видимым, когда содержимое свёрнуто.
|—

|[[themeNames]]`themeNames`
|Применяет один или несколько вариантов из раздела <<variants,Варианты темы>>.
|—
|===

== Элементы

Элемент `details` может содержать один или несколько компонентов или контейнеров, а также вложенный элемент xref:vc/components/tooltip.adoc[`tooltip`].
