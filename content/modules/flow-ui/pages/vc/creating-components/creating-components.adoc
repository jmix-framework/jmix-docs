Этот раздел описывает различные способы создания пользовательских UI-компонентов в приложениях Jmix.

В нем рассматриваются низкоуровневый Element API, композитные компоненты, обёртки над JavaScript-библиотеками, пользовательские Web Components, интеграция с XML и замена стандартных компонентов.
