= fieldSet 字段组

`fieldSet` 组件可以将视图中相关的组件显示为一个分组，便于理解 UI 布局。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`fieldSet`

|Java 类
|`FieldSet`
|===

[[basics]]
== 基本用法

将相关联的组件加入 `fieldSet` 内部，同时也可以添加一个 `legendText` 文本标识该分组。

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `fieldSet` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[legendText]]`legendText`
|为组件分组提供一个标题。
|—
|===
