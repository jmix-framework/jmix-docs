= fieldSet

`fieldSet` группирует связанные элементы формы под необязательным заголовком.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`fieldSet`

|Java-класс
|`FieldSet`
|===

[[basics]]
== Основы

Поместите связанные элементы управления в `fieldSet` и при необходимости задайте `legendText`, чтобы обозначить группу.

== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] выполняют ту же функцию для всех компонентов.
Следующие атрибуты специфичны для `fieldSet`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[legendText]]`legendText`
|Задаёт подпись или заголовок для сгруппированных компонентов.
|—
|===

== Обработчики

[cols="2,5", options="header"]
|===
|Имя
|Описание

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Срабатывает при отсоединении группы полей от UI.

== Элементы

`fieldSet` может содержать элементы формы и контейнеры, относящиеся к группе.
