= fieldSet

`fieldSet` groups related form controls under an optional caption.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML Element
|`fieldSet`

|Java Class
|`FieldSet`
|===

== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `fieldSet`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[legendText]]`legendText`
|Provides a caption or title for the grouped fields.
|—
|===

== Handlers

[cols="2,5", options="header"]
|===
|Name
|Description

|xref:vc/common-handlers.adoc#AttachEvent[`AttachEvent`]
|Fires when the field set is attached to the UI.

|xref:vc/common-handlers.adoc#DetachEvent[`DetachEvent`]
|Fires when the field set is detached from the UI.
|===

== Elements

A `fieldSet` can contain the form controls and layouts that belong to the group.
