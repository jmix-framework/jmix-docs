= image
:page-aliases: vcl/components/image.adoc

`image` отображает изображение из контейнера данных, ресурса приложения, URL или программно заданного источника.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`image`

|Java-класс
|`JmixImage`
|===

[[variants]]
== Варианты темы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/image-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Используйте `themeNames`, чтобы настроить размещение изображения в заданных размерах.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`fill`
|Растягивает изображение по ширине и высоте.
|Aura, Lumo

|`contain`
|Масштабирует изображение без обрезки, чтобы оно полностью поместилось в области.
|Aura, Lumo

|`cover`
|Масштабирует и обрезает изображение, чтобы заполнить всю область.
|Aura, Lumo

|`scale-down`
|Выбирает меньший размер из исходного и полученного при варианте `contain`.
|Aura, Lumo
|===

== Атрибуты

В Jmix существует множество xref:vc/common-attributes.adoc[общих атрибутов], которые служат одной цели для всех компонентов.
Следующие атрибуты относятся только к `image`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[alternateText]]`alternateText`
|Задаёт доступный альтернативный текст, который также отображается, если изображение не загрузилось.
|—
|[[resource]]`resource`
|Задаёт расположение изображения. См. <<resources,URL и программные источники>>.
|—
|[[themeNames]]`themeNames`
|Применяет один или несколько вариантов из раздела <<variants,Варианты темы>>.
|—
|===

[[handlers]]
== Обработчики

В Jmix существует множество xref:vc/common-handlers.adoc[общих обработчиков], которые настраиваются одинаково для всех компонентов.
Следующие обработчики специфичны для `image`:

[cols="2,5", options="header"]
|===
|Имя
|Описание
|[[ClickEvent]]`ClickEvent`
|Срабатывает при нажатии на изображение. Используйте subject `click`, `singleClick` или `doubleClick`, чтобы выбрать тип нажатия.
|===
