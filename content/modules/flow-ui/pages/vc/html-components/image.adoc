[[variants]]
== Theme Variants

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/image-theme-variant" class="live-demo-btn" target="_blank">LIVE DEMO</a>
</div>
++++

Use `themeNames` to control how an image fits within its dimensions.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`fill`
|Stretches the image to fill both dimensions.
|Aura, Lumo

|`contain`
|Scales the image to fit without cropping.
|Aura, Lumo

|`cover`
|Scales and crops the image to cover its area.
|Aura, Lumo

|`scale-down`
|Uses the smaller result of the natural size and `contain` sizing.
|Aura, Lumo
|===

== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `image`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[alternateText]]`alternateText`
|Provides accessible alternative text and fallback text when the image cannot be loaded.
|—
|[[resource]]`resource`
|Specifies the location of the image. See <<resources,URL and Programmatic Sources>>.
|—
|[[themeNames]]`themeNames`
|Applies one or more variants listed in <<variants,Theme Variants>>.
|—
|===
