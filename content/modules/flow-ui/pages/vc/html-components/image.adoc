== 样式版本

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/image-theme-variant" class="live-demo-btn" target="_blank">在线示例</a>

使用 `themeNames` 设置图片如何适配两个空间维度。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`fill`
|拉伸图像以填充两个维度。
|Aura, Lumo

|`contain`
|缩放图像以适应空间（不裁剪）。
|Aura, Lumo

|`cover`
|缩放并剪裁图片以覆盖整个空间。
|Aura, Lumo

|`scale-down`
|使用自然尺寸和 `contain` 中的较小结果。
|Aura, Lumo
|===

== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `image` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[alternateText]]`alternateText`
|设置图片的替代文本。如果图片资源未设置或不可用。
|—
|[[resource]]`resource`
|设置图片的资源位置。参阅 <<resources, URL 和编程式资源>>。
|—
|[[themeNames]]`themeNames`
|使用 <<variants,样式版本>> 中列出的一个或多个样式。
|—
|===
