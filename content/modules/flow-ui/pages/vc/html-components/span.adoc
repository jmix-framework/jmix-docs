= span

`span` отображает небольшой фрагмент текста, который можно оформить отдельно.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`span`

|Java-класс
|`Span`
|===

[[basics]]
== Основы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/html-declaratively" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Как и одноимённый HTML-элемент, `span` добавляет и оформляет встроенный текст. Каждый `span` — отдельный компонент, поэтому оформление применяется ко всему значению его атрибута `text`.

TIP: Используйте компонент xref:vc/components/html.adoc[html], чтобы включить исходный HTML-код напрямую.

В примере несколько элементов `span` помещены в один пункт списка, чтобы отдельные части предложения имели разное оформление:

[[variants]]
== Варианты темы

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы оформить текст как бейдж. Сочетайте `badge` с вариантами цвета, акцента, формы или размера.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`badge`
|Применяет оформление бейджа.
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|Применяет семантический цвет.
|Aura, Lumo

|`primary`
|Добавляет более выраженный визуальный акцент.
|Aura, Lumo

|`pill`
|Скругляет углы бейджа.
|Aura, Lumo

|`small`
|Уменьшает размер бейджа.
|Aura, Lumo

|`normal`
|Использует обычный размер бейджа.
|Aura, Lumo
|===
