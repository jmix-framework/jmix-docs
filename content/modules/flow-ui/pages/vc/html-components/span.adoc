= span 文本

`span` 显示简短的文本。可以单独设置样式。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`span`

|Java 类
|`Span`
|===

[[basics]]
== 基本用法

++++
<div class="jmix-ui-live-demo-container">

++++

与 HTML 中的同名元素一样，`span` 组件可以用来添加内联文本且设置样式。每个 `span` 是一个单独的组件，因此样式会应用在 `text` 属性配置的全部文本上。

TIP: 使用 xref:vc/components/html.adoc[html] 组件直接添加原生 HTML。

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性将该组件设为徽标样式。将 `badge` 与颜色、强调、形状或尺寸样式名结合使用。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`badge`
|徽标样式。
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|应用语义颜色。
|Aura, Lumo

|`primary`
|应用主强调色。
|Aura, Lumo

|`pill`
|将徽标设置为圆角。
|Aura, Lumo

|`small`
|缩小尺寸。
|Aura, Lumo

|`normal`
|使用矩形徽标的尺寸。
|Aura, Lumo
|===

下面是 `span` 的特殊属性：

|描述

|—
|===
