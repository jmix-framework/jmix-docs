[[variants]]
== Theme Variants

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to style the component as a badge. Combine `badge` with color, emphasis, shape, or size variants.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`badge`
|Applies badge styling.
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|Applies a semantic color.
|Aura, Lumo

|`primary`
|Adds stronger visual emphasis.
|Aura, Lumo

|`pill`
|Rounds the badge corners.
|Aura, Lumo

|`small`
|Makes the badge smaller.
|Aura, Lumo

|`normal`
|Uses the regular badge size.
|Aura, Lumo
|===

[[attributes]]
== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `div`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[themeNames]]`themeNames`
|Applies one or more variants listed in <<variants,Theme Variants>>.
|—
|===

[[handlers]]
== Handlers

xref:vc/common-handlers.adoc[Common handlers] are configured in the same way for all components.
The following handlers are specific to `div`:

[cols="2,5", options="header"]
|===
|Name
|Description
|[[ClickEvent]]`ClickEvent`
|Fires when the component is clicked. Use the `click`, `singleClick`, or `doubleClick` subject to select the click pattern.
|===

== Elements

A `div` can display text or contain nested components and layouts. If child elements are present, the `text` attribute is ignored.
