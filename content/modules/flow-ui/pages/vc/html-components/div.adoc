[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性将该组件设为徽标样式。将 `badge` 与颜色、强调、形状或尺寸样式名结合使用。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`badge`
|徽标样式。
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|应用语义颜色。
|Aura, Lumo

|`primary`
|应用主强调色。
|Aura, Lumo

|`pill`
|将徽标设置为圆角。
|Aura, Lumo

|`small`
|缩小尺寸。
|Aura, Lumo

|`normal`
|使用矩形徽标的尺寸。
|Aura, Lumo
|===

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `div` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[themeNames]]`themeNames`
|使用 <<variants,样式版本>> 中列出的一个或多个样式。
|—
|===

[[handlers]]
== 事件和处理器

xref:vc/common-handlers.adoc[通用事件和处理器] 对所有组件都是一样的配置。
下面是 `div` 的特殊事件和处理器：

[cols="2,5", options="header"]
|===
|名称
|描述
|[[ClickEvent]]`ClickEvent`
|当用户点击组件时触发。使用 `click`、`singleClick` 或 `doubleClick` 选择点击模式。
|===

== XML 内部元素

`div` 可以显示文本或包含任意内部组件和布局。如果存在子元素，`text` 属性将被忽略。
