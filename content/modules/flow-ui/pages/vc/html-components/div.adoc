|===
|XML-элемент
|`div`

|===

[[variants]]
== Варианты темы

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы оформить компонент как бейдж. Сочетайте `badge` с вариантами цвета, акцента, формы или размера.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`badge`
|Применяет оформление бейджа.
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|Применяет семантический цвет.
|Aura, Lumo

|`primary`
|Добавляет более выраженный визуальный акцент.
|Aura, Lumo

|`pill`
|Скругляет углы бейджа.
|Aura, Lumo

|`small`
|Уменьшает размер бейджа.
|Aura, Lumo

|`normal`
|Использует обычный размер бейджа.
|Aura, Lumo
|===

[[attributes]]
== Атрибуты

В Jmix существует множество xref:vc/common-attributes.adoc[общих атрибутов], которые служат одной цели для всех компонентов.
Следующие атрибуты специфичны для `div`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[themeNames]]`themeNames`
|Применяет один или несколько вариантов из раздела <<variants,Варианты темы>>.
|—
|===

[[handlers]]
== Обработчики

В Jmix существует множество xref:vc/common-handlers.adoc[общих обработчиков], которые настраиваются одинаково для всех компонентов.
Следующие обработчики специфичны для `div`:

[cols="2,5", options="header"]
|===
|Имя
|Описание
|[[ClickEvent]]`ClickEvent`
|Срабатывает при нажатии на компонент. Используйте subject `click`, `singleClick` или `doubleClick`, чтобы выбрать тип нажатия.
|===

== Элементы

`div` может отображать текст или содержать вложенные компоненты и контейнеры. Если есть дочерние элементы, атрибут `text` игнорируется.
