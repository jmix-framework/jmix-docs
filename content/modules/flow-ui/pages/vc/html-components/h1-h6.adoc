= h1-h6

Элементы HTML от `h1` до `h6` представляют шесть уровней заголовков.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элементы
|`h1`, `h2`, `h3`, `h4`, `h5`, `h6`

|Java-классы
|`H1`, `H2`, `H3`, `H4`, `H5`, `H6`
|===

[[variants]]
== Варианты темы

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы оформить заголовок как бейдж. Сочетайте `badge` с вариантами цвета, акцента, формы или размера.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`badge`
|Применяет оформление бейджа.
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|Применяет семантический цвет.
|Aura, Lumo

|`primary`
|Добавляет более выраженный визуальный акцент.
|Aura, Lumo

|`pill`
|Скругляет углы бейджа.
|Aura, Lumo

|`small`
|Уменьшает размер бейджа.
|Aura, Lumo

|`normal`
|Использует обычный размер бейджа.
|Aura, Lumo
|===

[[attributes]]
== Атрибуты

В Jmix существует множество xref:vc/common-attributes.adoc[общих атрибутов], которые служат одной цели для всех компонентов.
Следующие атрибуты специфичны для заголовков:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[themeNames]]`themeNames`
|Применяет один или несколько вариантов из раздела <<variants,Варианты темы>>.
|—
|===

[[handlers]]
== Обработчики

В Jmix существует множество xref:vc/common-handlers.adoc[общих обработчиков], которые настраиваются одинаково для всех компонентов.
Следующие обработчики специфичны для заголовков:

[cols="2,5", options="header"]
|===
|Имя
|Описание
|[[ClickEvent]]`ClickEvent`
|Срабатывает при нажатии на заголовок. Используйте subject `click`, `singleClick` или `doubleClick`, чтобы выбрать тип нажатия.
|===
