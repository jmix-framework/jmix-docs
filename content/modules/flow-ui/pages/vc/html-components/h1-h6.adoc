= h1-h6

HTML 的 `h1` 至 `h6` 元素用于展示 6 个级别的标题。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`h1`, `h2`, `h3`, `h4`, `h5`, `h6`

|Java 类
|`H1`, `H2`, `H3`, `H4`, `H5`, `H6`
|===

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性将该组件设为徽标样式。将 `badge` 与颜色、强调、形状或尺寸样式名结合使用。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`badge`
|徽标样式。
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|应用语义颜色。
|Aura, Lumo

|`primary`
|应用主强调色。
|Aura, Lumo

|`pill`
|将徽标设置为圆角。
|Aura, Lumo

|`small`
|缩小尺寸。
|Aura, Lumo

|`normal`
|使用矩形徽标的尺寸。
|Aura, Lumo
|===
