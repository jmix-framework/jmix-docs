== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] выполняют ту же функцию для всех компонентов.
Следующие атрибуты специфичны для `iframe`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[allow]]`allow`
|Задаёт политику разрешений для функций, доступных встроенному содержимому.
|—

|[[importance]]`importance`
|Указывает браузеру приоритет ресурса при отображении страницы: `AUTO`, `HIGH` или `LOW`.
|`AUTO`

|[[name]]`name`
|Задаёт имя встроенного контекста просмотра, которое можно использовать как цель ссылки или формы.
|—

|[[resource]]`resource`
|Путь к статическому ресурсу, например `resource="pdf/tutorial.pdf"` или URL.
|—

|[[resourceDoc]]`resourceDoc`
|Задаёт экранированное встроенное HTML-содержимое. См. <<inline-html,Встроенное HTML-содержимое>>.
|—

|[[sandbox]]`sandbox`
|Ограничивает возможности встроенного содержимого. Укажите через запятую значения `SandboxType`, например `RESTRICT_ALL` или `ALLOW_SCRIPTS`. Если атрибут не задан, ограничения песочницы не применяются.
|—
|===
