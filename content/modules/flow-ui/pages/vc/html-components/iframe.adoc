== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `iframe` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[allow]]`allow`
|为嵌入内容可用的功能权限策略。
|—

|[[importance]]`importance`
| 告诉浏览器渲染的页面的重要程度。支持：`AUTO`、`HIGH`、`LOW`
| `AUTO`

|[[name]]`name`
|设置嵌入式浏览上下文的名称，可用作链接或表单目标。
|—

|[[resource]]`resource`
|设置静态资源的路径，例如 `resource="pdf/tutorial.pdf"` 或站点的 URL。
| –

|[[resourceDoc]]resourceDoc
|在组件内显示 HTML 代码。但是需要转义代码，示例：
| –

|[[sandbox]]`sandbox`
|限制嵌入内容的能力。配置以逗号分隔的 `SandboxType` 值，例如 `RESTRICT_ALL` 或 `ALLOW_SCRIPTS`。如未配置，则无限制。
|—
|===
