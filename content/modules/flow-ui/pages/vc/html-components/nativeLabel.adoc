= nativeLabel 原生标题
:page-aliases: vc/html-components/label.adoc, vcl/components/label.adoc

`nativeLabel` 可用于为组件创建标题。

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML 元素
|`nativeLabel`

|Java 类
|`NativeLabel`
|===

[[basics]]
== 基本用法

当需要一个单独的标签组件，而 Jmix 组件的 xref:vc/common-attributes.adoc#label[label] 属性不能满足要求时使用 `nativeLabel`。

将 <<setFor, setFor>> 属性设置为目标组件的 id。下面的示例中为 `checkbox` 创建了一个独立标签：

[source, xml, indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/htmlcomponent/label/label-view.xml[tags=basics]
----

image::visual-components/html-components/label-basic.png[align="center", width="185"]

将 label 与组件关联可以使得辅助功能技术能正确地解析组件的标题，比如屏幕阅读器。

如需添加不与组件关联的文本，请使用 `span` 或 `div` 组件。

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性将该组件设为徽标样式。将 `badge` 与颜色、强调、形状或尺寸样式名结合使用。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`badge`
|徽标样式。
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|应用语义颜色。
|Aura, Lumo

|`primary`
|应用主强调色。
|Aura, Lumo

|`pill`
|将徽标设置为圆角。
|Aura, Lumo

|`small`
|缩小尺寸。
|Aura, Lumo

|`normal`
|使用矩形徽标的尺寸。
|Aura, Lumo
|===

[[attributes]]
== XML 属性

xref:vc/common-attributes.adoc[通用属性] 对所有组件都是一样的配置。
下面是 `nativeLabel` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值
|[[themeNames]]`themeNames`
|使用 <<variants,样式版本>> 中列出的一个或多个样式。
|—
|[[setFor]]`setFor`
|标签通过元素的 id 与特定元素关联，从而使屏幕阅读器等辅助技术能正确理解。
|—
|===
