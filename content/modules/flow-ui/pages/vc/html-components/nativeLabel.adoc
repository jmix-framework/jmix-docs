= nativeLabel
:page-aliases: vc/html-components/label.adoc, vcl/components/label.adoc

`nativeLabel` creates a text caption associated with another component.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML Element
|`nativeLabel`

|Java Class
|`NativeLabel`
|===

[[basics]]
== Basics

Use `nativeLabel` when a separate label component is needed instead of a component's xref:vc/common-attributes.adoc#label[label] attribute.

Set <<setFor,setFor>> to the ID of the component that the label describes. The following example associates a label with a `checkbox`:

[source, xml, indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/htmlcomponent/label/label-view.xml[tags=basics]
----

image::visual-components/html-components/label-basic.png[align="center", width="185"]

Having the label associated with a component makes the label text correctly interpreted by assistive technologies, such as screen readers.

To add text that is not associated with a component, use the `span` or `div` components.

[[variants]]
== Theme Variants

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to style the label as a badge. Combine `badge` with color, emphasis, shape, or size variants.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`badge`
|Applies badge styling.
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|Applies a semantic color.
|Aura, Lumo

|`primary`
|Adds stronger visual emphasis.
|Aura, Lumo

|`pill`
|Rounds the badge corners.
|Aura, Lumo

|`small`
|Makes the badge smaller.
|Aura, Lumo

|`normal`
|Uses the regular badge size.
|Aura, Lumo
|===

[[attributes]]
== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `nativeLabel`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default
|[[themeNames]]`themeNames`
|Applies one or more variants listed in <<variants,Theme Variants>>.
|—
|[[setFor]]`setFor`
|Associates the label with the component whose ID is specified, enabling assistive technologies to interpret the relationship.
|—
|===
