= nativeLabel
:page-aliases: vc/html-components/label.adoc

`nativeLabel` создаёт текстовую метку, связанную с другим компонентом.

[cols="1h,1" grid=none, width=50%, frame=none]
|===
|XML-элемент
|`nativeLabel`

|Java-класс
|`NativeLabel`
|===

[[basics]]
== Основы

Используйте `nativeLabel`, когда вместо атрибута xref:vc/common-attributes.adoc#label[label] нужна отдельная метка.

Задайте в <<setFor,setFor>> идентификатор компонента, который описывает метка. В следующем примере метка связана с `checkbox`:

[source, xml, indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/htmlcomponent/label/label-view.xml[tags=basics]
----

image::visual-components/html-components/label-basic.png[align="center", width="185"]

Связывание надписи с компонентом позволяет вспомогательным технологиям, таким как программы чтения с экрана, правильно интерпретировать текст надписи.

Для добавления текста, не связанного с компонентом, используйте компоненты `span` или `div`.

[[variants]]
== Варианты темы

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы оформить метку как бейдж. Сочетайте `badge` с вариантами цвета, акцента, формы или размера.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`badge`
|Применяет оформление бейджа.
|Aura, Lumo

|`success`, `warning`, `error`, `contrast`
|Применяет семантический цвет.
|Aura, Lumo

|`primary`
|Добавляет более выраженный визуальный акцент.
|Aura, Lumo

|`pill`
|Скругляет углы бейджа.
|Aura, Lumo

|`small`
|Уменьшает размер бейджа.
|Aura, Lumo

|`normal`
|Использует обычный размер бейджа.
|Aura, Lumo
|===

[[attributes]]
== Атрибуты

В Jmix существует множество xref:vc/common-attributes.adoc[общих атрибутов], которые служат одной цели для всех компонентов.
Следующие атрибуты специфичны для `nativeLabel`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию
|[[themeNames]]`themeNames`
|Применяет один или несколько вариантов из раздела <<variants,Варианты темы>>.
|—
|[[setFor]]`setFor`
|Связывает метку с компонентом по указанному идентификатору, чтобы вспомогательные технологии могли интерпретировать эту связь.
|—
|===
