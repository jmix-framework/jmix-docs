== Data Binding

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/big-decimal-field-dataaware" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Компонент можно связать с атрибутом сущности, которая хранится в xref:data/data-containers.adoc[контейнере данных].

Чтобы связать `bigDecimalField` с атрибутом сущности:

. Укажите имя контейнера данных в значении атрибута xref:flow-ui:vc/common-attributes.adoc#dataContainer[dataContainer].
. Укажите имя атрибута сущности в значении атрибута xref:flow-ui:vc/common-attributes.adoc#property[property].

Атрибут сущности должен иметь тип `BigDecimal`.

== Варианты темы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/big-decimal-field-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames] для настройки темы компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`small`
|Уменьшает размер компонента.
|Aura, Lumo

|`align-left`
|Выравнивает значение поля по левому краю.
|Aura, Lumo

|`align-center`
|Выравнивает значение поля по центру.
|Aura, Lumo

|`align-right`
|Выравнивает значение поля по правому краю.
|Aura, Lumo

|`helper-above-field`
|Размещает вспомогательный текст над полем, под меткой.
|Aura, Lumo
|===
