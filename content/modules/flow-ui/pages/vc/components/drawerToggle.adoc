= drawerToggle 侧边栏开关

`drawerToggle` 控制应用程序菜单是否显示。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`drawerToggle`

|Java 类
|`DrawerToggle`
|===

[[basics]]
== 基本用法

`drawerToggle` 组件是一个开关按钮，用于控制包含 xref:menu-config.adoc[主菜单] 的 `drawerLayout` 元素的打开和关闭状态。

为了使用户在整个应用程序中都能访问主菜单，`drawerToggle` 一般放置在主应用程序视图的 `navigationBar` 组件中。

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`primary`
|侧边开关更明显
|Aura

|`tertiary`
|侧边开关不那么明显
|Aura
|===
