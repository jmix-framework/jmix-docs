= drawerToggle

`drawerToggle` controls the visibility of an application menu drawer.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`drawerToggle`

|Java Class
|`DrawerToggle`
|===

[[basics]]
== Basics

The `drawerToggle` component creates a toggle button that controls the opening and closing of the `drawerLayout` containing xref:menu-config.adoc[main menu] items.

To ensure users can access the main menu across the application, `drawerToggle` is usually placed within the `navigationBar` component of the main application view.

[[variants]]
== Theme Variants

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to apply one or more theme variants.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`primary`
|Makes the drawer toggle more prominent.
|Aura

|`tertiary`
|Makes the drawer toggle less prominent.
|Aura
|===
