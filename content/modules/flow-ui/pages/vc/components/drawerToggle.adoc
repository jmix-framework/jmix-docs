= drawerToggle

`drawerToggle` управляет видимостью панели меню приложения.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`drawerToggle`

|Java-класс
|`DrawerToggle`
|===

[[basics]]
== Основы

Компонент `drawerToggle` создаёт кнопку-переключатель, которая управляет открытием и закрытием компонента `drawerLayout`, содержащего элементы xref:menu-config.adoc[главного меню].

Чтобы главное меню было доступно во всём приложении, `drawerToggle` обычно размещают в компоненте `navigationBar` главного экрана приложения.

[[variants]]
== Варианты темы

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы применить один или несколько вариантов темы.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`primary`
|Делает переключатель более заметным.
|Aura

|`tertiary`
|Делает переключатель менее заметным.
|Aura
|===
