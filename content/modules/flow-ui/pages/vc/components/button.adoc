= button
:page-aliases: vcl/components/button.adoc, vcl/components/link-button.adoc

A button to trigger an action when a user clicks on it.

* XML element: `button`

* Java class: `JmixButton`

== Action

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/button-action" class="live-demo-btn" target="_blank">LIVE DEMO</a>

Instead of creating a <<ClickEvent,ClickEvent>> handler, you can associate the button with an existing xref:actions.adoc[Action]. Using existing actions provides a more efficient approach, as it automatically updates various attributes and behavior of the button. This can include button's state, visibility, text, title, icon, and user interaction outcome.

If the action is defined for the view, specify the action id in the button's `action` attribute:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/button/action/button-action.xml[tags=action]
----

If the action is defined for a component, such as xref:vc/components/dataGrid.adoc[dataGrid], specify the component id and action id separated by the dot in the button's `action` attribute:

[source,xml,indent=0]
----

== Theme Variants

++++
<div class="jmix-ui-live-demo-container">

Use xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to set a component theme.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`primary`
|Applies the primary button style.
|Aura, Lumo

|`success`
|Applies the success style.
|Aura, Lumo

|`warning`
|Applies the warning style.
|Aura, Lumo

|`error`
|Applies the error style.
|Aura, Lumo

|`contrast`
|Applies the contrast style.
|Lumo

|`large`
|Makes the button larger.
|Aura, Lumo

|`small`
|Makes the button smaller.
|Aura, Lumo

|`icon`
|Reduces the whitespace around the icon.
|Aura, Lumo

|`tertiary`
|Applies a lower-emphasis button style.
|Aura, Lumo

|`tertiary-inline`
|Applies an inline button style intended for use inside text content.
|Lumo
|===

[[disable-on-click]]
=== disableOnClick

If the `disableOnClick` attribute is set to `true`, the button will be automatically disabled when clicked, typically to prevent (accidental) extra clicks on a button. You can later re-enable the button by invoking the `setEnabled(true)` method.
