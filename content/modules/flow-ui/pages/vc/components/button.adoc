== XML 属性

The following attributes are specific to `button`:

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|`action`
|设置按钮关联的视图和组件操作。参见 <<action,声明式操作>>。
|—

|[[disable-on-click]]`disableOnClick`
|按钮在点击之后就自动禁用，主要用来防止（意外的）多次点击。之后可以通过调用 `setEnabled(true)` 把按钮恢复成可点击状态。
|`false`

|[[icon]]`icon`
|设置按钮的图标。
|—

|[[iconAfterText]]`iconAfterText`
|将图标放在按钮文本之后。
|`false`

|[[whiteSpace]]`whiteSpace`
|控制按钮文本中的空格和换行如何处理。
|`NORMAL`
|===

== 事件和处理器

下面是 `button` 的特殊事件和处理器：

[cols="2,5", options="header"]
|===
|名称
|描述

|[[ClickEvent]]`clickListener`
|当用户点击按钮时发送。用 `addClickListener()` 方法可以编程式添加处理方法。

|[[doubleClickListener]]`doubleClickListener`
|当用户在短时间点击按钮两次时发送。

|[[singleClickListener]]`singleClickListener`
|当用户单击后，距离下一次点击的时间超出双击的判断时，发送单击事件。
|===
