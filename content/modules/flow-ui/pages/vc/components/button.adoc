= button
:page-aliases: vcl/components/button.adoc, vcl/components/link-button.adoc

A button to trigger an action when a user clicks on it.

* XML-элемент: `button`

* Java-класс: `JmixButton`

== Использование Action

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/button-action" class="live-demo-btn" target="_blank">ДЕМО</a>

Instead of creating a <<ClickEvent,ClickEvent>> handler, you can associate the button with an existing xref:actions.adoc[Action]. Using existing actions provides a more efficient approach, as it automatically updates various attributes and behavior of the button. This can include button's state, visibility, text, title, icon, and user interaction outcome.

Если действие определено для экрана, укажите его идентификатор в атрибуте `action` кнопки:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/button/action/button-action.xml[tags=action]
----

Если действие определено для компонента, например xref:vc/components/dataGrid.adoc[dataGrid], укажите в атрибуте `action` кнопки идентификатор компонента и идентификатор действия, разделённые точкой:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/button/button-view.xml[tags=layout;action-3]

[[disable-on-click]]
=== disableOnClick

При установке атрибута `disableOnClick` в значение `true` кнопка будет автоматически отключаться после нажатия. Это предотвращает случайные повторные клики.

Чтобы снова включить кнопку, используйте метод `setEnabled(true)`:

[[doubleClickListener]]
=== doubleClickListener

Обрабатывает событие `com.vaadin.flow.component.ClickEvent` с параметром `doubleClick`. Срабатывает, когда пользователь дважды быстро нажимает на кнопку.

Например:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/button/ButtonView.java[tags=doubleClickListener]
----

Для программной регистрации обработчика события используйте метод компонента `addDoubleClickListener()`.

[[singleClickListener]]
=== singleClickListener

Генерирует событие `com.vaadin.flow.component.ClickEvent` с параметром `singleClick`. Событие возникает с задержкой (timeout), чтобы гарантировать, что это не двойной клик.

Например:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/button/ButtonView.java[tags=singleClickListener]
----

Для программной регистрации обработчика события используйте метод компонента `addSingleClickListener()`.
