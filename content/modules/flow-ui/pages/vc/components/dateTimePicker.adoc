= dateTimePicker 日期时间
:page-aliases: vcl/components/date-field.adoc

== 数据类型

`dateTimePicker` 是一个带类型的组件，支持常见的日期时间数据类型：

* `date`
* `dateTime`
* `localDateTime`
* `offsetTime`
* `localTime`
* `offsetDateTime`
* `time`
* `localDate`

当 <<data-binding, 绑定组件>> 与实体属性时，会自动使用该属性的数据类型。如果需要显示设置类型，请使用 xref:vc/common-attributes.adoc#datatype[datatype] 属性指定。

[[step]]
== 间隔

选择弹窗中显示时间的默认间隔为 1 小时。但是也可以使用 xref:vc/common-attributes.adoc#step[step] 属性自定义间隔，支持 XML 和编程式设置。`step` 属性支持通过不同的时间（chrono）单位设置灵活的间隔。时间值支持通过单位后缀实现便捷设置。

在视图 XML 中设置 `step`：

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/datetimepicker/date-time-picker-view.xml[tags=step]
----
<1> 2 小时间隔。
<2> 1600 秒（26 分 40 秒）间隔。
<3> 20 分钟间隔。
<4> 不带后缀表示按“分钟”。

视图控制器中也可以设置：

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/datetimepicker/DateTimePickerView.java[tags=dateTimePicker;onInit;step]
----

设置的时间间隔必须能整除一小时或一天。例如，“15分钟”、“30分钟”、“2小时” 都是有效的间隔；而 “42分钟” 则不是。

NOTE: 弹窗不会显示小于 15 分钟的间隔，是为了避免无效的时间选取。
