= dateTimePicker
:page-aliases: vcl/components/date-field.adoc

An input field to select both a date and a time of the day. To select either a date or a time, use xref:vc/components/datePicker.adoc[datePicker] or xref:vc/components/timePicker.adoc[timePicker], respectively.

* XML-элемент: `dateTimePicker`

* Java-класс: `TypedDateTimePicker`

== Типы данных

`dateTimePicker` - это типизированный компонент, который поддерживает общие типы данных для хранения как даты, так и времени:

* `date`
* `dateTime`
* `localDateTime`
* `offsetTime`
* `localTime`
* `offsetDateTime`
* `time`
* `localDate`

Когда вы <<data-binding, связываете компонент>> с атрибутом сущности, он автоматически принимает тип данных этого атрибута. Чтобы установить тип явно, используйте атрибут xref:vc/common-attributes.adoc#datatype[datatype].

[[step]]
== Шаг

По умолчанию интервал между значениями во всплывающем списке времени составляет один час. Чтобы изменить его в XML или программно, используйте атрибут xref:vc/common-attributes.adoc#step[step]. Значение можно задавать в разных единицах времени с соответствующим суффиксом.

Установка атрибута `step` в XML-дескрипторе экрана:

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/datetimepicker/date-time-picker-view.xml[tags=step]
----
<1> Интервалы в 2 часа.
<2> Интервалы в 1600 секунд (26 минут 40 секунд).
<3> Интервалы в 20 минут.
<4> Число без суффикса означает минуты.

То же самое можно сделать в контроллере экрана:

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/datetimepicker/DateTimePickerView.java[tags=dateTimePicker;onInit;step]
----

image::visual-components/components/date-time-picker-step.png[align="center", width="420"]
Шаг должен разделить час или день поровну. Например, «15 минут», «30 минут» и «2 часа» являются допустимыми шагами, а «42 минуты» — нет.

NOTE: Всплывающая панель не отображается для шагов менее 15 минут, чтобы избежать показа непрактичного количества вариантов выбора.

[[autoOpen]]
=== autoOpen

Определяет, открываются ли всплывающие панели, когда пользователь начинает вводить дату.

* Если установлено значение `true`, всплывающие панели открываются как при вводе данных пользователем, так и при нажатии на соответствующую кнопку или поле.

* Если установлено значение `false`, всплывающие панели открываются только при нажатии на соответствующую кнопку.

[[datePlaceholder]]
=== datePlaceholder

Указывает текст, который будет отображаться внутри поля даты, когда оно пусто.
