= comboButton 下拉按钮

`comboButton` 将操作按钮放置在一个下拉列表中，提供关联的操作。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`comboButton`
|Java 类

|`ComboButton`
|===

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`primary`
|主要按钮样式
|Aura, Lumo

|`tertiary`
|低优先级的按钮样式
|Aura, Lumo

|`tertiary-inline`
|适用于文本内容内部使用的内联按钮样式
|Lumo

|`icon`
|使用图标按钮样式
|Lumo

|`small`
|按钮较小
|Aura, Lumo

|`large`
|按钮较大
|Aura, Lumo

|`success`
|成功样式
|Aura, Lumo

|`warning`
|警告样式
|Aura, Lumo

|`error`
|错误样式
|Aura, Lumo

|`contrast`
|对比样式
|Lumo
|===

== XML 属性

下面是 `comboButton` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[action]]`action`
|关联组件的操作。
|—

|[[dropdownIcon]]`dropdownIcon`
|设置 `comboButton` 的下拉图标。
|`VaadinIcon.CHEVRON_DOWN`

|[[icon]]`icon`
|设置图标
|—

|[[openOnHover]]`openOnHover`
|当鼠标悬浮在组件上时，是否打开操作列表。
|—
|===
