= emailField 电子邮件字段

`emailField` 是一个标准的 xref:vc/components/textField.adoc[textField]，但是只能输入电子邮件地址。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`emailField`

|Java 类
|`JmixEmailField`
|===

[[basics]]
== 基本用法

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/email-field-simple" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

`emailField` 组件是输入和验证电子邮件地址的特殊输入控件。扩展于基础的 `textField` 组件，添加了与电子邮件地址相关的功能和验证。

`customerDc` 实例容器中包含了 `Customer` 实体。`dataContainer` 和 `property` 属性将组件与实体的 `email` 属性绑定。

|描述

|`small`

|Aura, Lumo

|`align-left`
|字段值左对齐
|Aura, Lumo

|`align-center`
|字段值居中
|Aura, Lumo

|`align-right`
|字段值右对齐
|Aura, Lumo

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo
