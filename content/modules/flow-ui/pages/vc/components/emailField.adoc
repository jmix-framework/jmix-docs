= emailField

`emailField` — это стандартный xref:vc/components/textField.adoc[textField], который принимает в качестве входных данных только адреса электронной почты.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`emailField`

|Java-класс
|`JmixEmailField`
|===

[[basics]]

Компонент `emailField` — специализированное поле для ввода и проверки адресов электронной почты. Он расширяет базовый `textField` функциями и проверками для адресов электронной почты.

== `emailField` связанный с данными

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/email-field-dataaware" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Привязка данных означает связывание визуального компонента с xref:data/data-containers.adoc[контейнером данных]. Изменения в визуальном компоненте или соответствующем контейнере данных могут вызывать обновления друг друга. Смотрите xref:flow-ui:data/data-examples.adoc[Использование компонентов данных] для получения дополнительной информации.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/emailfield/dataaware/email-field-dataaware.xml[tags=data-binding]
----

Контейнер экземпляра `customerDc` хранит сущность `Customer`. Атрибуты `dataContainer` и `property` связывают компонент с её атрибутом `email`.

|Aura, Lumo
