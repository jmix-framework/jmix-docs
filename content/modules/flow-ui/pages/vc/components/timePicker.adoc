= timePicker 时间选择
:page-aliases: vcl/components/time-field.adoc

`timePicker` 支持用户输入或选择时间。

|Java 类

== 数据类型

`timePicker` 是一个带类型的组件，支持通用的时间类型：

* `localTime`
* `offsetTime`
* `time`

如需修改类型，使用 xref:vc/common-attributes.adoc#datatype[datatype] 属性。

[[step]]
== 间隔

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/time-picker-custom-range" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

弹窗中显示时间的默认间隔为 1 小时。通过 xref:vc/common-attributes.adoc#step[step] 属性可以自定义间隔。

在视图 XML 中设置 `step` 属性:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/timepicker/customrange/time-picker-custom-range.xml[tags=step]
----
`m` <<suffix,后缀>> 表示分钟。

[[suffix]]
`step` 属性支持通过不同的时间（chrono）单位设置灵活的间隔。时间值支持通过单位后缀实现便捷设置。

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/timepicker/time-picker-view.xml[tags=step-unit]
----
<1> 2 小时间隔。
<2> 1600 秒（26 分 40 秒）间隔。
<3> 20 分钟间隔。

视图控制器中也可以设置：

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/timepicker/TimePickerView.java[tags=timePicker;onInit;step]
----

设置的时间间隔必须能整除一小时或一天。例如，“15分钟”、“30分钟”、“2小时” 都是有效的间隔；而 “42分钟” 则不是。

NOTE: 弹窗不会显示小于 15 分钟的间隔，是为了避免无效的时间选取。
