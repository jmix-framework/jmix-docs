= dropdownButton 列表按钮
:page-aliases: vcl/components/popup-button.adoc

`dropdownButton` 显示一个主按钮，当点击主按钮时，显示一个下拉菜单。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`dropdownButton`

|Java 类
|`DropdownButton`
|===

[[basics]]
== 基本用法

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/dropdown-button-simple" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

主按钮显示组件的主要 xref:vc/common-attributes.adoc#text[标签] 和 xref:vc/components/button.adoc#icon[图标]。用户点击此按钮以访问下拉菜单。

下拉菜单包含一个操作列表，每个操作由一个可点击的条目表示。

下拉菜单中的每一项都可以表示一个操作。当用户点击某个操作时，会触发相应的事件处理器。

以下示例定义了一个 `dropdownButton`，其 `text`、`icon` 和提示（`title` 属性）从 xref:localization:message-bundles.adoc[消息包] 中获取：

|Lumo
