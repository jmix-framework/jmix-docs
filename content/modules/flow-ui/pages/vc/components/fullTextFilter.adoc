= FullTextFilter 全文搜索过滤器
:page-aliases: search:full-text-filter-component.adoc

[NOTE.addon-component]
====
This component requires the free xref:search:index.adoc#installation[Search add-on].
====

`FullTextFilter` 组件在功能上与 xref:flow-ui:vc/components/propertyFilter.adoc[] 组件类似，但是在所有实体字段索引中进行全文搜索。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`fullTextFilter`

|Java 类
|`io.jmix.searchflowui.component.FullTextFilter`
|===

[[basics]]
== 基本用法

[[basic]]

在视图 XML 中声明 `search` 命名空间：

[source,xml,indent=0]
----
include::search:example$/search-ex1/src/main/resources/com/company/demo/view/search/search-view.xml[tags=xmlns]
----

[TIP]
====
当使用顶部操作面板中的 *Add Component* 操作添加组件时，Studio 会自动添加该命名空间。请参见 xref:studio:view-designer.adoc#component-palette[组件面板]。
====

通过 <<dataLoader,dataLoader>> 属性将 `fullTextFilter` 与集合数据加载器进行绑定。下面的示例中，声明了数据、过滤器和结果表格：

[source,xml,indent=0]
----
include::search:example$/search-ex1/src/main/resources/com/company/demo/view/search/filter-view.xml[tags=data;layout;fullTextFilter;dataGrid]
----

`FullTextFilter` 组件的操作方式如下：

. 执行全文搜索以查找与搜索条件匹配的实体标识符。

. 将包含这些标识符的条件附加到关联的 `dataLoader` 上。

. 当 `DataGrid`（或其他列表组件）与此数据加载器关联时，仅显示与全文搜索条件匹配的那些记录。

全文条件还可以与数据加载器的其他过滤器结合使用，提供更精细的结果集。
