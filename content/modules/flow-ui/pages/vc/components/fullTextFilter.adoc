= fullTextFilter
:page-aliases: search:full-text-filter-component.adoc

[NOTE.addon-component]
====
Для работы компонента требуется дополнение xref:search:index.adoc#installation[Search].
====

`fullTextFilter` работает аналогично xref:flow-ui:vc/components/propertyFilter.adoc[], но выполняет полнотекстовый поиск по индексированным полям сущностей.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`fullTextFilter`

|Java-класс
|`FullTextFilter`
|===

[[basics]]
== Основы

[[basic]]

Объявите пространство имен `search` в XML-дескрипторе экрана:

[source,xml,indent=0]
----
include::search:example$/search-ex1/src/main/resources/com/company/demo/view/search/search-view.xml[tags=xmlns]
----

[TIP]
====
Studio автоматически добавляет пространство имен, когда вы добавляете компонент с помощью действия *Add Component* на верхней панели действий. См. xref:studio:view-designer.adoc#component-palette[Палитра компонентов].
====


Свяжите `fullTextFilter` с загрузчиком коллекции данных с помощью обязательного атрибута <<dataLoader,dataLoader>>. В следующем примере объявлены данные, фильтр и таблица результатов:

[source,xml,indent=0]
----
include::search:example$/search-ex1/src/main/resources/com/company/demo/view/search/filter-view.xml[tags=data;layout;fullTextFilter;dataGrid]
----

Компонент `FullTextFilter` работает следующим образом:

. Выполняет полнотекстовый поиск и получает идентификаторы сущностей, соответствующих критериям поиска.

. Добавляет условие с этими идентификаторами в связанный `dataLoader`.

. Если `DataGrid` или другой компонент списка связан с этим загрузчиком, он отображает только записи, соответствующие критериям полнотекстового поиска.

Условие полнотекстового поиска объединяется с другими фильтрами загрузчика данных, уточняя набор результатов.
