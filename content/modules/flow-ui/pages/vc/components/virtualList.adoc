= virtualList

The `virtualList` component is designed for displaying lists of items with a complex content. Only the visible portion of items is rendered at a time.

* XML-элемент: `virtualList`

* Java-класс: `JmixVirtualList`

`virtualList` подключен к xref:flow-ui:data/data-containers.adoc[контейнер данных]. По умолчанию отображается xref:data-model:entities.adoc#instance-name[имя экземпляра] объекта в контейнере. Используя обработчик <<Renderer,renderer>>, вы можете отображать пользовательский контент.

[[fragment-renderer]]
Альтернативно можно рендерить элементы с помощью вложенного элемента `fragmentRenderer`. Подробнее смотрите раздел xref:flow-ui:vc/miscellaneous/renderers.adoc#fragment-renderer[Рендерер фрагментов].
