== 基本用法

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/switch-simple" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

`switch` 与 xref:flow-ui:vc/components/checkbox.adoc[checkbox] 组件类似，但可以更加直观地展示二进制状态。开关适合用于

* 在两个相互排斥的选项（例如on/off）之间切换。
* 提供即时的视觉反馈。
* 启用或禁用立即生效的设置。

而 `checkbox` 和 xref:flow-ui:vc/components/checkboxGroup.adoc[checkboxGroup] 组件更适合下面的场景：

* 从列表中选择一个或多个选项。
* 允许多个非排他性选择。
* 选择后不会立即生效的场景。

== 状态

`switch` 有以下几种状态，不同的状态具有不同的外观和功能。

[[enabled-state]]
*启用*

* 禁用：`switch` 处于非激活状态，无法与用户交互。通常显示为灰色，表示已禁用。
* 启用：`switch` 可进行交互并响应用户的输入。用户可以通过点击改变组件的状态。

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/switchcomponent/switch-view.xml[tags=enabled]
----

[[read-only-state]]
*只读*

`readOnly` 属性控制用户是否可以更改组件的状态。如果设置为 `true`，则 `checkbox` 为只读状态，用户无法更改状态。

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/switchcomponent/switch-view.xml[tags=readOnly]
----

[[required-state]]
*必填*

`switch` 也可以通过 <<required,required>> 配置或绑定一个带 `@NotNull` 验证的必需属性设置为必填项。


当该组件标记为必填时，组件标签附近会显示一个指示器，提示用户必须选择。如果 `switch` 默认开启（已选择），然后被关闭（取消选择），则该组件会标记为无效，直至满足必填条件。

NOTE: 与输入字段类似，只有当 `switch` 非空（即勾选）时才能通过 `@NotNull` 验证。该行为的默认值可以通过 xref:ui-properties.adoc#jmix.ui.component.checkbox-required-state-initialization-enabled[jmix.ui.component.checkbox-required-state-initialization-enabled] 属性修改，以支持非选择状态为 `false`。

== XML 属性

下面是 `switch` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[enabled]]`enabled`
|设置组件启用或禁用。参阅 <<enabled-state,启用状态>>。
|`true`

|[[readOnly]]`readOnly`
|设置 `switch` 为只读模式。参阅 <<read-only-state,只读状态>>。
|`false`

|[[required]]`required`
|设置 `switch` 的必填状态。参阅 <<required-state,必填状态>>。
|`false`

|[[value]]`value`
|设置组件值。
|—
