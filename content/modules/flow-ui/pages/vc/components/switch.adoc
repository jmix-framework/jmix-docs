= switch

`switch` allows users to toggle between two states: on/off or true/false, making it ideal for enabling/disabling settings, preferences, or binary options. Its visual design mimics a physical toggle switch with a sliding handle.

`switch` — альтернатива компоненту xref:flow-ui:vc/components/checkbox.adoc[checkbox], предназначенная для чёткого и интуитивного представления двоичных состояний. Переключатели лучше всего подходят для:

Когда использовать `switch`:

* Переключение между двумя взаимоисключающими состояниями (например, Вкл/Выкл).
* Мгновенная визуальная обратная связь.
* Включение/отключение настроек с немедленным применением.

Компоненты `checkbox` и xref:flow-ui:vc/components/checkboxGroup.adoc[checkboxGroup], в свою очередь, больше подходят для:

* Выбора одного или нескольких пунктов из списка.
* Возможности множественного, неисключающего выбора.
* Сценариев, где изменения не применяются мгновенно

== Состояния

`switch` может находиться в нескольких состояниях, определяющих его внешний вид и функциональность.

[[enabled-state]]
*Enabled*

* Отключено: переключатель неактивен и не реагирует на действия пользователя. Визуально он часто отображается серым цветом, чтобы указать на его неактивное состояние.
* Включено: переключатель интерактивный и реагирует на действия пользователя. Пользователи могут щелкнуть по нему, чтобы изменить его состояние.

image::visual-components/components/switch-enable-disable.png[align="center", width="206"]
[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/switchcomponent/switch-view.xml[tags=enabled]
----

[[read-only-state]]
*Только чтение*

Атрибут `readOnly` управляет возможностью взаимодействия пользователя с компонентом `switch`. Если он установлен в `true`, переключатель становится доступным только для чтения, то есть пользователь не может изменить его состояние.

image::visual-components/components/switch-readonly.png[align="center", width="203"]
[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/switchcomponent/switch-view.xml[tags=readOnly]
----

[[required-state]]
*Required*

Компонент можно настроить как обязательный, используя атрибут <<required,required>> или связав его с обязательным атрибутом c `@NotNull` валидацией.

image::visual-components/components/switch-required.png[align="center", width="209"]
Если поле обязательное, рядом с подписью отображается соответствующий индикатор. Если `switch` был включён, а затем выключен, поле будет отмечено как недопустимое, пока обязательное условие снова не будет выполнено.

== Атрибуты

В Jmix есть множество xref:vc/common-attributes.adoc[общих атрибутов], которые выполняют одну и ту же функцию для всех компонентов.

Ниже приведены атрибуты, специфичные для `switch`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Название*
|*Описание*
|*Значение по умолчанию*
|[[enabled]]enabled
|Устанавливает компонент явно отключенным или включенным. Смотрите <<enabled-state,Состояние Enabled>>.
|`true`
|[[readOnly]]readOnly
|Указывает, находится ли компонент `switch` в режиме только для чтения. Смотрите <<read-only-state,Состояние Read-Only>>.
|`false`
|[[required]]required
|Устанавливает обязательное состояние для `switch`. Смотрите <<required-state,Состояние Required>>.
|`false`
|===
