= decimalSlider 浮点滑动输入

[.since]
Jmix 3.1+

`decimalSlider` 支持用户沿轨道拖动手柄选择 `Double` 值。用户也可以使用方向键移动手柄。

如需处理 `Integer` 值，请使用 xref:vc/components/integerSlider.adoc[integerSlider]。如需选择值的范围，请使用 xref:vc/components/decimalRangeSlider.adoc[decimalRangeSlider]。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`decimalSlider`

|Java 类
|`JmixDecimalSlider`
|===

[[data-binding]]
== 数据感知的 `decimalSlider`

数据绑定是指将可视化组件与 xref:data/data-containers.adoc[数据容器] 关联。可视组件或相应数据容器中的更改可以触发彼此的更新。更多细节请参阅 xref:data/data-examples.adoc[]。

如需将 `decimalSlider` 与实体属性绑定，请设置 xref:vc/common-attributes.adoc#dataContainer[dataContainer] 和 xref:vc/common-attributes.adoc#property[property] 属性。实体属性必须是 `Double` 类型。

当用户松开手柄时，滑块会向服务端发送新值。如需在拖动的每一步都发送值，请将 xref:vc/common-attributes.adoc#valueChangeMode[valueChangeMode] 设置为 `EAGER`。

[[empty-value]]
== 空值

滑块无法显示空值。当没有值时，会改为显示 <<min,min>> 值。滑块将其视为空值：

* 如果绑定的属性为 `null`，滑块会显示 `min`，但不会将其写入实体，xref:data/data-context.adoc[DataContext] 也不会注册更改。只有当用户移动手柄或在代码中设置值时，该属性才会获得值。
* 未绑定的滑块在用户移动手柄或在代码中设置值之前为空。
* 调用 `clear()` 或 `setValue(null)` 会将手柄移动到 `min` 并使滑块的值为空。与实体绑定的滑块还会将属性设置为 `null`。

`isEmpty()` 方法对空滑块返回 `true`，但此时 `getValue()` 返回 `min`。验证器获取到的空滑块值为 `null`。如果滑块是 xref:vc/common-attributes.adoc#required[required]，则空滑块无法通过验证。

[[range-and-step]]
== 范围和步长

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://vaadin.com/docs/v25/components/slider#step" class="vaadin-docs-btn" target="_blank">Vaadin</a>
</div>
++++

<<min,min>> 和 <<max,max>> 属性设置值的范围，<<step,step>> 设置值之间的间隔。用户可以选择的值从 `min` 开始计算：`min`、`min + step`、`min + 2 * step`，依此类推。参考 <<basics,上面的示例>>。

滑块不会更改超出范围的值。此类值可能来自绑定的属性或代码。滑块会使用 xref:vc/miscellaneous/validator.adoc#DoubleMinValidator[doubleMin] 和 xref:vc/miscellaneous/validator.adoc#DoubleMaxValidator[doubleMax] 验证器检查该值，如超出范围，则显示验证错误。这些验证器是自动添加的，并在更改 `min` 或 `max` 时更新。

[[value-display]]
== 值显示

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/slider-simple" class="live-demo-btn" target="_blank">在线示例</a>

默认情况下，滑块仅在用户与其交互时在手柄上方显示当前值。将 <<valueAlwaysVisible,valueAlwaysVisible>> 设置为 `true` 可始终显示值，例如 <<basics,上面的示例>>。

<<minMaxVisible,minMaxVisible>> 属性会在轨道下方显示 `min` 和 `max` 值。

== XML 属性

下面是 `decimalSlider` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[max]]`max`
|设置滑块的最大值。大于 `max` 的值会使组件无效。参考 <<range-and-step>>。
|`100`

|[[min]]`min`
|设置滑块的最小值。小于 `min` 的值会使组件无效。空滑块显示该值。参考 <<empty-value>>。
|`0`

|[[minMaxVisible]]`minMaxVisible`
|在轨道下方显示 `min` 和 `max` 值。
|`false`

|[[step]]`step`
|设置用户可选值之间的间隔。步长必须大于 0。参考 <<range-and-step>>。
|`1`

|[[value]]`value`
|设置组件值。
|—

|[[valueAlwaysVisible]]`valueAlwaysVisible`
|始终在手柄上方显示当前值。如果为 `false`，则仅在用户与滑块交互时显示值。
|`false`
|===
