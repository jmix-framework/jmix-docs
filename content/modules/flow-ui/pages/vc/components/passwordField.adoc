= passwordField
:page-aliases: vcl/components/password-field.adoc

`passwordField` is a masked input field for entering passwords.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`passwordField`

|Java Class
|`JmixPasswordField`
|===

== Theme Variants

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/password-field-theme-variant" class="live-demo-btn" target="_blank">LIVE DEMO</a>

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to apply one or more theme variants.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`small`
|Makes the component smaller.
|Aura, Lumo

|`align-left`
|Aligns the field value to the left side.
|Aura, Lumo

|`align-center`
|Centers the field value.
|Aura, Lumo

|`align-right`
|Aligns the field value to the right side.
|Aura, Lumo

|`helper-above-field`
|Renders the helper text above the field, below the label.
|Aura, Lumo
|===
