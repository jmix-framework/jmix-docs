= passwordField 密码输入
:page-aliases: vcl/components/password-field.adoc

`passwordField` 用于输入密码。组件中输入的字符会默认进行掩码处理。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`passwordField`

|Java 类
|`JmixPasswordField`
|===

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`small`
|组件尺寸较小
|Aura, Lumo

|`align-left`
|字段值左对齐
|Aura, Lumo

|`align-center`
|字段值居中
|Aura, Lumo

|`align-right`
|字段值右对齐
|Aura, Lumo

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo
|===
