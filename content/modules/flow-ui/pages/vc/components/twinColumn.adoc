= twinColumn
:page-aliases: vcl/components/twin-column.adoc

A component to intuitively select items from a list or collection by moving them between two columns.

* XML-элемент: `twinColumn`

* Java-класс: `TwinColumn`

[[basics]]
== Основы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/twin-column-dataaware" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

image::visual-components/components/twin-column-basics.png[align="center", width="553"]
Компонент размещает два столбца рядом. В левом находятся доступные для выбора элементы, а в правом — выбранные. Пользователь может выбрать один или несколько элементов и перемещать их между столбцами с помощью кнопок, добавляя в выбор или удаляя из него.

Для создания компонента используйте XML-элемент `twinColumn` и задайте его атрибут `itemsContainer`, указав xref:data/collection-container.adoc[контейнер коллекции]. Элементы из этого контейнера будут отображаться в колонках.

== Варианты темы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/twin-column-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>

Use xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to set a component theme.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`no-border`
|Удаляет внешнюю границу компонента.
|Aura, Lumo

|`no-row-border`
|Удаляет разделители между строками.
|Lumo

|`checkmarks`
|Использует галочки для обозначения выбранных элементов вместо изменения цвета фона строки.
|Lumo

|`no-spaces-between-actions`
|Удаляет промежутки между кнопками действий.
|Aura, Lumo
|===

TIP: Вы можете комбинировать несколько тем, перечисляя их через пробел, чтобы изменить несколько аспектов внешнего вида одновременно.
