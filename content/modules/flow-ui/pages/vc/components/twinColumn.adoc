= twinColumn 双列
:page-aliases: vcl/components/twin-column.adoc

`twinColumn` 支持用户在候选列和已选列之间移动条目。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`twinColumn`

|Java 类
|`TwinColumn`
|===

[[basics]]
== 基本用法

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/twin-column-dataaware" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

该组件中的两列并排放置。左列包含用户可以选择的条目。右列显示当前已选定的条目。用户可以选择一个或多个条目，然后点击按钮在两列中移动条目进行选择或移除。

在 XML 中使用 `twinColumn` 创建双列组件，设置 `itemsContainer` 属性为一个 xref:data/collection-container.adoc[集合容器]。容器内的条目将展示在列中。

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`no-border`
|不显示组件的边框
|Aura, Lumo

|`no-row-border`
|不显示行分隔符
|Lumo

|`checkmarks`
|用对钩表示选择的条目，而非修改背景色。
|Lumo

|`no-spaces-between-actions`
|不显示操作按钮之间的空隙
|Aura, Lumo
|===

== XML 属性

下面是 `twinColumn` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[itemsColumnLabel]]`itemsColumnLabel`
|设置选项列的标签。参考 <<column-labels,列标签>>。
|—

|[[itemsContainer]]`itemsContainer`
|设置选项的数据容器。参考<<basics, 基本用法>>。

|[[reorderable]]`reorderable`
|用户是否可以调整组件中选项的顺序。参考 <<items-order,条目顺序>>。
|—

|[[selectAllButtonsVisible]]`selectAllButtonsVisible`
|是否显示全选和全部清除的按钮。参考 <<multi-select,多选>>。
|—

|[[selectedItemsColumnLabel]]`selectedItemsColumnLabel`
|设置已选项列的标签。参考 <<column-labels,列标签>>。
|—
