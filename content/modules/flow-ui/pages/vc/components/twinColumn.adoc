= twinColumn
:page-aliases: vcl/components/twin-column.adoc

`twinColumn` lets users select items by moving them between available and selected columns.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`twinColumn`

|Java Class
|`TwinColumn`
|===

[[basics]]
== Basics

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/twin-column-dataaware" class="live-demo-btn" target="_blank">LIVE DEMO</a>
</div>
++++

The component puts two columns side by side. The left column contains items that the user can select from. The right column displays currently selected items. Users can select one or more items and click buttons to move them between columns, adding or removing them from the selection.

To create the component, use `twinColumn` XML element and set its `itemsContainer` attribute to a xref:data/collection-container.adoc[collection container]. The items within this container will appear in the columns.

== Theme Variants

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/twin-column-theme-variant" class="live-demo-btn" target="_blank">LIVE DEMO</a>

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to apply one or more theme variants.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`no-border`
|Removes the outer border of the component.
|Aura, Lumo

|`no-row-border`
|Removes the separators between rows.
|Lumo

|`checkmarks`
|Uses checkmarks to indicate selected items instead of changing the row background color.
|Lumo

|`no-spaces-between-actions`
|Removes the space between action buttons.
|Aura, Lumo
|===
