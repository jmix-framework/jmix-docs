= gridColumnVisibility

`gridColumnVisibility` позволяет пользователям показывать или скрывать столбцы в xref:flow-ui:vc/components/dataGrid.adoc[dataGrid].

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`gridColumnVisibility`

|Java-класс
|`JmixGridColumnVisibility`
|===

[[basics]]
== Основы

`gridColumnVisibility` состоит из кнопки и выпадающего меню со списком столбцов.

[[setting-up-dropdown-menu]]
== Настройка выпадающего меню

[[menuItem]]
=== menuItem

По умолчанию текст пункта копируется из заголовка столбца. Изменить его можно с помощью элемента `menuItem`.

По умолчанию текст элемента меню копируется из заголовка столбца. Вы можете изменить это, используя элемент `menuItem`.

Например, в предыдущем примере элемент `menuItem` используется для установки другого локализованного сообщения для столбца `name`, отличного от того, которое указано в заголовке `dataGrid`.

[[include]]
=== include

Атрибут `include` используется для указания того, какие столбцы следует включить в выпадающее меню `gridColumnVisibility`.

[[exclude]]
=== exclude

Атрибут `exclude` используется для указания того, какие столбцы следует исключить из выпадающего меню `gridColumnVisibility`.

Например, в предыдущем примере мы исключили столбец `duration` из выпадающего меню `gridColumnVisibility`.

[[hideAllEnabled]]
=== hideAllEnabled

Атрибут `hideAllEnabled` определяет видимость пункта *Скрыть все* в выпадающем меню `gridColumnVisibility`.

[[showAllEnabled]]
=== showAllEnabled

Атрибут `showAllEnabled` определяет видимость пункта *Показать все* в выпадающем меню `gridColumnVisibility`.

[[attributes]]
== Атрибуты

`gridColumnVisibility` имеет следующие уникальные атрибуты:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[dataGrid]]`dataGrid`
|Устанавливает сетку, столбцы которой будут управляться этим компонентом.
|—

|`exclude`
|Указывает столбцы, которые необходимо исключить из меню видимости. См. <<exclude,exclude>>.
|—

|`hideAllEnabled`
|Определяет, содержит ли меню видимости элемент *Скрыть все*. См. <<hideAllEnabled,hideAllEnabled>>.
|—

|[[icon]]`icon`
|Задаёт значок.
|—

|`include`
|Указывает столбцы для включения в меню видимости. См. <<include,include>>.
|—

|`showAllEnabled`
|Определяет, содержит ли меню видимости элемент *Показать все*. См. <<showAllEnabled,showAllEnabled>>.
|—
