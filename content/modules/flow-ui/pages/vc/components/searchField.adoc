= searchField

[[settings-button]]
== Runtime Configuration

The `searchField` includes a *settings button* (vertical ellipsis `⋮`) that opens a configuration dialog, allowing users to dynamically adjust search parameters without modifying the XML.

image::search:search-settings-dialog.png[align="center", width="483"]

Users can configure the following options at runtime:

[cols="2,2,4", options="header"]
|===
| Configuration | Corresponding Attribute | Description

| Search Strategy
| <<searchStrategy,searchStrategy>>
| Determines how the search term is processed

| Size
| <<searchSize,searchSize>>
| Limits the number of search results

| Entities
| <<entities,entities>>
| Specifies which entities to search (multiple entities can be selected)
|===

[[search-results-view]]
== Search Results View

By default, the `searchField` opens the built-in `SearchResultsView`. This view handles the search engine querying process and displays results either in the current navigation view or in a dialog, depending on the <<openMode,openMode>> attribute.

To modify this behavior, configure a `SearchCompletedHandler`. This can be done either declaratively using the `@Install` annotation or programmatically using `setSearchCompletedHandler()`.

[[attributes]]
== Attributes

The following attributes are specific to `searchField`:

[cols="2,5a,1", options="header"]
|===
|Name
|Description
|Default

|[[entities]]`entities`
|Specifies which entities to search. Multiple entities can be listed as a comma-separated sequence.

[source,xml,indent=0]
----
include::search:example$/search-ex1/src/main/resources/com/company/demo/view/search/my-search-view.xml[tags=search-field]
----
|—

|[[openMode]]`openMode`
|Specifies how the <<search-results-view,search results view>> is opened when a search is executed. `NAVIGATION` replaces the main content area; `DIALOG` opens a modal window.
|`NAVIGATION`

|[[searchButtonVisible]]`searchButtonVisible`
|Shows or hides the search button.
|`true`

|[[searchSize]]`searchSize`
|Limits the number of search results displayed on a single page of search results.
|Inherited from the application property xref:search:search-properties.adoc#jmix.search.searchResultPageSize[jmix.search.search-result-page-size].

|[[searchStrategy]]`searchStrategy`
|Determines the search strategy applied. See xref:search:search-in-ui.adoc#search-strategies[Search Strategies].
|xref:search:search-properties.adoc#jmix.search.defaultSearchStrategy[jmix.search.default-search-strategy]

|[[settingsButtonVisible]]`settingsButtonVisible`
|Shows or hides the settings button (`⋮`). See <<settings-button,Runtime Configuration>>.
|`true`
|===
