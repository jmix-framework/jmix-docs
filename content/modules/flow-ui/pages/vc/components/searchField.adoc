= searchField

[[settings-button]]
== Конфигурация во время выполнения

`searchField` включает *кнопку настроек* (вертикальное многоточие `⋮`), которая открывает диалог конфигурации, позволяя пользователям динамически изменять параметры поиска без изменения XML.

image::search:search-settings-dialog.png[align="center", width="483"]

Пользователи могут настроить следующие параметры во время выполнения:

[cols="2,2,4", options="header"]
|===
| Конфигурация | Соответствующий атрибут | Описание

| Стратегия поиска
| <<searchStrategy,searchStrategy>>
| Определяет, как обрабатывается поисковый термин

| Размер
| <<searchSize,searchSize>>
| Ограничивает количество результатов поиска

| Сущности
| <<entities,entities>>
| Определяет, по каким сущностям выполнять поиск (можно выбрать несколько сущностей)
|===

[[search-results-view]]
== Экран результатов поиска

По умолчанию `searchField` открывает встроенный `SearchResultsView`. Этот экран управляет процессом выполнения запроса к поисковому движку и отображает результаты либо в текущем контейнере навигации, либо в диалоговом окне, в зависимости от атрибута <<openMode,openMode>>.

Чтобы изменить это поведение, настройте `SearchCompletedHandler`. Это можно сделать либо декларативно, используя аннотацию `@Install`, либо программно, используя `setSearchCompletedHandler()`.

[[attributes]]
== Атрибуты

xref:flow-ui:vc/common-attributes.adoc[Общие атрибуты] служат одной и той же цели для всех компонентов.
Следующие атрибуты являются специфичными для `searchField`:

[cols="2,5a,1", options="header"]
|===
|*Название*|*Описание*|*Значение по умолчанию*

|[[entities]]entities
| Определяет, по каким сущностям выполнять поиск. Несколько сущностей могут быть перечислены в виде последовательности, разделенной запятыми.

[source,xml,indent=0]
----
include::search:example$/search-ex1/src/main/resources/com/company/demo/view/search/my-search-view.xml[tags=search-field]
----
|—

|[[openMode]]openMode
| Определяет, как открывается <<search-results-view,экран результатов поиска>> при выполнении поиска. `NAVIGATION` заменяет основную область контента; `DIALOG` открывает модальное окно.
|`NAVIGATION`

|[[searchButtonVisible]]searchButtonVisible
| Показывает или скрывает кнопку поиска.
|`true`

|[[searchSize]]searchSize
| Ограничивает количество результатов поиска, отображаемых на одной странице результата поиска.
| Наследуется от свойства приложения xref:search:search-properties.adoc#jmix.search.searchResultPageSize[jmix.search.search-result-page-size].

|[[searchStrategy]]searchStrategy
|Определяет применяемую стратегию поиска. См. xref:search:search-in-ui.adoc#search-strategies[Стратегии поиска].
|xref:search:search-properties.adoc#jmix.search.defaultSearchStrategy[jmix.search.default-search-strategy]

|[[settingsButtonVisible]]settingsButtonVisible
|Показывает или скрывает кнопку настроек (`⋮`). Смотрите <<settings-button,Конфигурация во время выполнения>>.
|`true`
|===
