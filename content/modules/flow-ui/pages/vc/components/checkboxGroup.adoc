= checkboxGroup 复选框组
:page-aliases: vcl/components/check-box-group.adoc

`checkboxGroup` 支持用户从复选框组中选择多个值。

|`checkboxGroup`

|Java 类

|===

== 数据感知的 `checkboxGroup`

该组件支持绑定至 xref:data/data-containers.adoc[data container] 中的实体属性。

如需将 `checkBoxGroup` 绑定至实体属性：

. 使用 xref:flow-ui:vc/common-attributes.adoc#dataContainer[dataContainer] 属性指定数据容器的名称。
. 使用 xref:flow-ui:vc/common-attributes.adoc#property[property] 属性指定实体属性的名称。

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/checkboxgroup/checkboxgroup-view.xml[tags=data;userDc;hobbiesDc;layout;data-bind]
----

示例中，`checkBoxGroup` 会展示 `Hobby` 实体的实例名，`getTypedValue()` 方法返回选择实例的 `Collection`.

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`vertical`
|内容垂直排布
|Lumo

|`horizontal`
|内容水平排布
|Aura

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo
|===

== 事件和处理器

下面是 `checkboxGroup` 的特殊事件和处理器：

[cols="2,5", options="header"]
|===
|名称
|描述

|[[itemEnabledProvider]]`itemEnabledProvider`
|控制每个选项是否启用。

|[[itemLabelGenerator]]`itemLabelGenerator`
|为每个选项提供文本显示。

|[[renderer]]`renderer`
|为每个选项提供渲染的组件。参考 <<custom-item-presentation,自定义选项展示>>。

|[[validator]]`validator`
|验证组件值。
|===
