= progressBar
:page-aliases: vcl/components/progress-bar.adoc

A visual indicator to provide feedback about the status and completion of an ongoing task, such as a file transfer, loading data, complex computations, or any other lengthy task. It helps users understand how much time a task will take.

* XML-элемент: `progressBar`

* Java-класс: `ProgressBar`

В зависимости от типа задачи и доступности сведений о ходе выполнения индикатор может быть определённым или неопределённым.

[[determinate-mode]]
=== Детерминированный режим

По умолчанию `progressBar` отображает прогресс в детерминированном режиме. Этот режим предоставляет пользователям визуальное представление оставшегося времени до завершения задачи.

image::visual-components/components/progress-bar-determinate.png[align="center", width="380"]
[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/progressbar/simple/progress-bar-simple.xml[tags=basics]
----

Используйте детерминированный индикатор прогресса, когда время выполнения задачи известно заранее или можно отслеживать прогресс.

[[indeterminate-mode]]
=== Недетерминированный режим

Установив атрибут <<indeterminate,indeterminate>> в значение `true`, вы можете перевести индикатор прогресса в недетерминированный режим. В этом режиме `progressBar` циклически анимируется по всей длине полосы, не отображая конкретного значения прогресса.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/progressbar/simple/progress-bar-simple.xml[tags=indeterminate]
----

Используйте этот режим для задач, которые не предоставляют значение прогресса или для обозначения непрерывно выполняющегося процесса.

== Диапазон значений

По умолчанию индикатор прогресса принимает значения от 0.0 до 1.0, что соответствует 0% и 100% соответственно. Это стандартное поведение, которое можно изменить с помощью атрибутов <<min,min>> и <<max,max>>.

Например, если ваша задача состоит из 10 шагов, вы можете установить `min="1"` и `max="10"`, чтобы соответствовать диапазону прогресса задачи. Достижение 5-го шага будет означать, что значение прогресса также достигло 5:

== Диалог прогресса

Если требуется, чтобы пользователь дождался завершения задачи, можно использовать xref:dialogs.adoc#background-task-dialog[диалог фоновой задачи].

image::dialogs/backgroundtask-dialog.png[align="center" width="402"]
Это диалоговое окно блокирует работу с остальной частью приложения, пока задача не завершится или пользователь не отменит её.
