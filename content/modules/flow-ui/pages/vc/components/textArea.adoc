= textArea
:page-aliases: vcl/components/resizable-text-area.adoc, vcl/components/text-area.adoc

`textArea` — поле ввода для ввода нескольких строк текста.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`textArea`

|Java-класс
|`JmixTextArea`
|===

[[basics]]
== Основы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/text-area-simple" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Используйте `textArea` для многострочного текста, например комментариев или описаний.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/textarea/simple/text-area-simple.xml[tags=basics]
----

Если не задана фиксированная высота, компонент автоматически подстраивает высоту под содержимое. Минимальная и стандартная высота - две строки текста.

[[Data-Binding]]
== `textArea` связанный с данными

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/text-area-dataaware" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Используйте атрибуты `dataContainer` и `property`, чтобы связать `textArea` с атрибутом сущности типа String. Контейнер данных предоставляет экземпляр сущности, а `property` указывает редактируемый атрибут.

Пример создания `textArea` с привязкой к данным:

.XML
[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/textarea/dataaware/text-area-dataaware.xml[tags=data-binding]
----

.Java
[source,java,indent=0]
----
include::example$ui-samples/main/java/io/jmix/uisamples/view/flowui/components/textarea/dataaware/TextAreaDataawareSample.java[tags=data-binding]
----

Убедитесь, что атрибут сущности, к которому выполняется привязка, имеет строковый тип. В отличие от xref:vc/components/textField.adoc[], `textArea` специально предназначен для работы с текстовыми данными.

|Выравнивает значение поля по левому краю.

|`helper-above-field`
|Размещает вспомогательный текст над полем, под меткой.
|Aura, Lumo
|===

== Обработчики

`textArea` имеет следующие уникальные обработчики:

[cols="2,5", options="header"]
|===
|Имя
|Описание

|[[AttachEvent]]`AttachEvent`
|Запускается, когда компонент прикреплен к пользовательскому интерфейсу.

|[[BlurEvent]]`BlurEvent`
|Вызывается, когда компонент теряет фокус.

|[[ClientValidatedEvent]]`ClientValidatedEvent`
|Возникает после изменения состояния допустимости компонента при проверке на стороне клиента.

|[[ComponentValueChangeEvent]]`ComponentValueChangeEvent`
|Вызывается при изменении значения компонента.

|[[CompositionEndEvent]]`CompositionEndEvent`
|Вызывается, когда завершается сеанс составления текста.

|[[CompositionStartEvent]]`CompositionStartEvent`
|Вызывается при запуске сеанса составления текста.

|[[CompositionUpdateEvent]]`CompositionUpdateEvent`
|Вызывается при изменении текста в активном сеансе композиции.

|[[DetachEvent]]`DetachEvent`
|Запускается, когда компонент отсоединен от пользовательского интерфейса.

|[[FocusEvent]]`FocusEvent`
|Запускается, когда компонент получает фокус.

|[[InputEvent]]`InputEvent`
|Запускается, когда пользователь меняет входное значение.

|[[KeyDownEvent]]`KeyDownEvent`
|Запускается, когда пользователь нажимает клавишу, когда компонент находится в фокусе.

|[[KeyPressEvent]]`KeyPressEvent`
|Вызывается при нажатии клавиши создания символов.

|[[statusChangeHandler]]`statusChangeHandler`
|Обрабатывает изменения статуса проверки компонента.

|[[validator]]`validator`
|Добавляет экземпляр xref:vc/miscellaneous/validator.adoc[валидатор] к компоненту.
|===
