= textArea
:page-aliases: vcl/components/resizable-text-area.adoc, vcl/components/text-area.adoc

`textArea` is an input field for entering multiple lines of text.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`textArea`

|Java Class
|`JmixTextArea`
|===

++++

Use `textArea` when the expected input could span multiple lines such as commentary or descriptions.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/textarea/simple/text-area-simple.xml[tags=basics]
----

Unless set to a fixed height, `textArea` adjusts its height automatically based on its content. The default and minimum height is two rows of text.

[[Data-Binding]]
== Data-aware `textArea`

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/text-area-dataaware" class="live-demo-btn" target="_blank">LIVE DEMO</a>
</div>
++++

Use the `dataContainer` and `property` attributes to bind `textArea` to a String entity attribute. The data container provides the entity instance, and `property` identifies the attribute to edit.

The following example produces a data-aware `textArea`:

.XML
[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/textarea/dataaware/text-area-dataaware.xml[tags=data-binding]
----

.Java
[source,java,indent=0]
----
include::example$ui-samples/main/java/io/jmix/uisamples/view/flowui/components/textarea/dataaware/TextAreaDataawareSample.java[tags=data-binding]
----

Ensure that the entity attribute you are binding to is of String type. Unlike xref:vc/components/textField.adoc[], `textArea` is specifically designed to work with textual data.

== Theme Variants

Use the xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to apply one or more theme variants.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`small`
|Makes the component smaller.
|Aura, Lumo

|`align-left`
|Aligns the field value to the left side.
|Aura, Lumo

|`align-center`
|Centers the field value.
|Aura, Lumo

|`align-right`
|Aligns the field value to the right side.
|Aura, Lumo

|`helper-above-field`
|Renders the helper text above the field, below the label.
|Aura, Lumo
|===

== Handlers

The following handlers are specific to `textArea`:

|===
|Name
|Description

|Fired when the component loses focus.

|[[ClientValidatedEvent]]`ClientValidatedEvent`
|Fired after client-side validation changes the component's validity.

|[[ComponentValueChangeEvent]]`ComponentValueChangeEvent`
|Fired when the component value changes.

|[[CompositionEndEvent]]`CompositionEndEvent`
|Fired when a text composition session ends.

|[[CompositionStartEvent]]`CompositionStartEvent`
|Fired when a text composition session starts.

|[[CompositionUpdateEvent]]`CompositionUpdateEvent`
|Fired when text in an active composition session changes.

|Fired when the component is detached from the UI.

|[[FocusEvent]]`FocusEvent`
|Fired when the component receives focus.

|[[InputEvent]]`InputEvent`
|Fired when the user changes the input value.

|[[KeyDownEvent]]`KeyDownEvent`
|Fired when the user presses a key while the component has focus.
