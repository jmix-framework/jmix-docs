Unless set to a fixed height, `textArea` adjusts its height automatically based on its content. The default and minimum height is two rows of text.

----
include::example$ui-samples/main/java/io/jmix/uisamples/view/flowui/components/textarea/dataaware/TextAreaDataawareSample.java[tags=data-binding]

Ensure that the entity attribute you are binding to is of String type. Unlike xref:vc/components/textField.adoc[], `textArea` is specifically designed to work with textual data.

== Theme Variants

Use xref:vc/common-attributes.adoc#themeNames[themeNames] attribute to set a component theme.

[cols="1,4,1", options="header"]
|===
|Variant
|Description
|Supported By

|`small`
|Makes the component smaller.
|Aura, Lumo

|`align-left`
|Aligns the field value to the left side.
|Aura, Lumo

|`align-center`
|Centers the field value.
|Aura, Lumo

|`align-right`
|Aligns the field value to the right side.
|Aura, Lumo

|`helper-above-field`
|Renders the helper text above the field, below the label.
|Aura, Lumo
|===

== Attributes

xref:vc/common-attributes.adoc[Common attributes] serve the same purpose for all components.
The following attributes are specific to `textArea`:

[cols="1h,5,1", grid=rows, frame=none]
|===
|*Name*
|*Description*
|*Default*
|[[autoselect]] autoselect
| Set to `true` to always have the field value automatically selected when the field gains focus, false otherwise.
| –
|[[maxRows]]maxRows
|Sets the maximum number of rows.
| –
|[[minRows]]minRows
|Sets the minimum number of rows.
| 2
|[[trimEnabled]]trimEnabled
|If `true`, the component trims spaces at the beginning and at the end of the input. For example: " aaa bbb " will be saved as "aaa bbb".

Configure this setting application-wide using the xref:ui-properties.adoc#jmix.ui.component.default-trim-enabled[jmix.ui.component.default-trim-enabled] property.
| –
|===
