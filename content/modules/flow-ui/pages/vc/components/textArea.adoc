= textArea 文本域
:page-aliases: vcl/components/resizable-text-area.adoc, vcl/components/text-area.adoc

`textArea` 一个支持输入多行文本的区域。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`textArea`

|Java 类
|`JmixTextArea`
|===

[[basics]]
== 基本用法

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/text-area-simple" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

当输入可能跨越多行（例如评论或描述）时，请使用 `textArea`。

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/textarea/simple/text-area-simple.xml[tags=basics]
----

如果未设置固定高度，`textArea` 会根据内容自动调整高度。默认高度和最小高度是两行文字。

[[Data-Binding]]
== 数据感知的 `textArea`

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/text-area-dataaware" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

使用 `dataContainer` 和 `property` 属性将 `textArea` 与一个实体属性绑定。数据容器提供实体实例，`property` 表示需要使用该组件编辑的属性。

数据感知的 `textArea` 示例：

.XML
[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/textarea/dataaware/text-area-dataaware.xml[tags=data-binding]
----

.Java
[source,java,indent=0]
----
include::example$ui-samples/main/java/io/jmix/uisamples/view/flowui/components/textarea/dataaware/TextAreaDataawareSample.java[tags=data-binding]
----

确保需要绑定的实体属性为字符串类型。与 xref:vc/components/textField.adoc[] 不同，`textArea` 是专门为处理文本数据而设计的。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`small`
|组件尺寸较小
|Aura, Lumo

|`align-left`
|字段值左对齐
|Aura, Lumo

|`align-center`
|字段值居中
|Aura, Lumo

|`align-right`
|字段值右对齐
|Aura, Lumo

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo
|===

== XML 属性

下面是 `textArea` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[clearButtonVisible]]`clearButtonVisible`
|设置组件是否显示清除按钮。
|`false`

|[[maxRows]]`maxRows`
|设置最大行数。
|—

|[[minRows]]`minRows`
|设置最小行数。
|2

|[[autoselect]]`autoselect`
|设置当组件获得焦点时，是否自动选中文本。
|—

|[[trimEnabled]]`trimEnabled`
|如果为 `true`，组件会去掉输入开头和结尾的空格。例如：" aaa bbb " 将保存为 "aaa bbb"。在使用 `EAGER`、`LAZY` 或 `TIMEOUT` xref:vc/common-attributes.adoc#valueChangeMode[valueChangeMode] 时，需考虑与 xref:vc/common-attributes.adoc#valueChangeMode-trimEnabled[trimEnabled] 的相互作用。可以通过 xref:ui-properties.adoc#jmix.ui.component.default-trim-enabled[jmix.ui.component.default-trim-enabled] 属性在应用程序级别配置此设置。
|—
|===
