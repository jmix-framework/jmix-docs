= integerField 整数字段

`integerField` 与 xref:vc/components/textField.adoc[textField] 功能相似，但仅允许输入 `Integer` 类型。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`integerField`

|Java 类
|`JmixIntegerField`
|===

[[about-step]]
== 步长

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://vaadin.com/docs/v25/components/number-field#step" class="vaadin-docs-btn" target="_blank">Vaadin</a>
</div>
++++

`step`（步长）属性用于控制用户使用向上/向下箭头（也称为步长按钮）交互时的增减值。步长决定每次交互时值的变化量。可以用来定义 `integerField` 的精度级别。

NOTE: `step` 属性通常与 <<min,min>> 和 <<max,max>> 属性结合使用，以定义数字的有效范围。

`stepButtonsVisible` 属性控制是否显示步长按钮。

== XML 属性

下面是 `integerField` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[autoselect]]`autoselect`
|当组件获得焦点时，是否自动选中文本。
|—

|[[clearButtonVisible]]`clearButtonVisible`
|设置组件是否显示一个清除按钮。
|`false`

|[[max]]`max`
|指定允许输入的最大值。大于 `max` 的值会导致验证失败。
|—

|[[min]]`min`
|指定允许输入的最小值。小于 `min` 的值会导致验证失败。
|—

|[[step]]`step`
|设置控件的值变化量。设置当点击增加/减少按钮时，数字变化的步长。参阅 <<about-step, 步长>>。
|`1`

|[[stepButtonsVisible]]`stepButtonsVisible`
|设置步长按钮的可见性。参阅 <<about-step, 步长>>。
|`false`

|[[themeNames]]`themeNames`
|为组件设置主题样式。
|—

|[[value]]`value`
|设置组件的值。
|—
|===
