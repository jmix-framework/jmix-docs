== 基本用法

在视图的 XML 中声明 `charts` 命名空间：

----

[[responsive-sizing]]
== 响应式尺寸

`chart` 组件由 Apache ECharts 渲染，在渲染或重新渲染时需要可计算的非零尺寸。当图表放置在响应式布局、隐藏容器或尺寸动态变化的容器中时（例如应用菜单折叠或展开时），需要注意这个特性。

如果将多个图表并排放置，请避免仅依赖父容器的 `width="100%"`。图表在可用区域增大时可以延展尺寸，但当周围容器变窄时可能无法正确收缩。在这种情况下，请使用 flex 布局并对图表容器使用 `flex-grow`：

[source,xml,indent=0]
----
include::charts:example$/charts-ex1/src/main/resources/com/company/demo/view/responsivechart/responsive-chart-view.xml[tag=chart]
----

同时确保图表或其父容器具有显式的 `height` 或 `minHeight`。如果图表放置在 `height="100%"` 的容器中，但没有任何父容器具有可计算的高度，图表可能会以零高度渲染。

因此，对于最初使用 `visible="false"` 隐藏、之后以编程方式显示的图表需要特别注意。

[[series]]
== 系列

++++
<div class="jmix-ui-live-demo-container">
<a href="https://echarts.apache.org/en/option.html#series" class="echarts-docs-btn" target="_blank">ECharts</a>
</div>

`series` 元素定义需要显示的图表类型（例如折线图、柱状图、散点图）。每种图表类型可以在 `series` 元素中以不同方式配置。

Jmix 支持的基本图表类型包括：

* https://demo.jmix.io/ui-samples/sample/line-series-simple[折线图^]
* https://demo.jmix.io/ui-samples/sample/bar-series-simple[柱状图^]
* https://demo.jmix.io/ui-samples/sample/pie-series-simple[饼图^]
* https://demo.jmix.io/ui-samples/sample/scatter-series-simple[散点图^] 和 https://demo.jmix.io/ui-samples/sample/effect-scatter-series[特效散点图^]
* https://demo.jmix.io/ui-samples/sample/candlestick-series-simple[K 线图^]
* https://demo.jmix.io/ui-samples/sample/funnel-series-simple[漏斗图^]
* https://demo.jmix.io/ui-samples/sample/gauge-series-simple[仪表盘^]
* https://demo.jmix.io/ui-samples/sample/radar-series-simple[雷达图^]

示例：

[source,xml,indent=0]

NOTE: `nativeJson` 配置会与现有属性合并，并覆盖 XML 中定义的相应属性。

== XML 属性

下面是 `chart` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[animation]]`animation`
|启用或禁用图表动画。
|`true`

|[[animationDelay]]`animationDelay`
|设置初始动画前的延迟，单位为毫秒。
|—

|[[animationDelayUpdate]]`animationDelayUpdate`
|设置更新动画前的延迟，单位为毫秒。
|—

|[[animationDuration]]`animationDuration`
|设置初始动画的持续时间，单位为毫秒。
|—

|[[animationDurationUpdate]]`animationDurationUpdate`
|设置更新动画的持续时间，单位为毫秒。
|—

|[[animationEasing]]`animationEasing`
|设置初始动画的缓动效果。
|—

|[[animationEasingUpdate]]`animationEasingUpdate`
|设置更新动画的缓动效果。
|—

|[[animationThreshold]]`animationThreshold`
|是否开启动画的阈值，当单个系列显示的图形数量大于这个阈值时会关闭动画。
|—

|[[backgroundColor]]`backgroundColor`
|以 CSS 颜色设置图表背景色。
|—

|[[blendMode]]`blendMode`
|设置全局混合模式。可能的值为 `SOURCE_OVER`、`SOURCE_IN`、`SOURCE_OUT`、`SOURCE_ATOP`、`DESTINATION_OVER`、`DESTINATION_IN`、`DESTINATION_OUT`、`DESTINATION_ATOP`、`LIGHTER`、`COPY`、`XOR`、`MULTIPLY`、`SCREEN`、`OVERLAY`、`DARKEN`、`LIGHTEN`、`COLOR_DODGE`、`COLOR_BURN`、`HARD_LIGHT`、`SOFT_LIGHT`、`DIFFERENCE`、`EXCLUSION`、`HUE`、`SATURATION`、`COLOR` 和 `LUMINOSITY`。
|`SOURCE_OVER`

|[[colorPalette]]`colorPalette`
|设置图表系列使用的逗号分隔的 CSS 颜色调色板。
|—

|[[hoverLayerThreshold]]`hoverLayerThreshold`
|设置元素数量阈值，超过该阈值时悬停元素在单独的层上渲染。
|—

|[[renderer]]`renderer`
|选择客户端渲染器。支持 `CANVAS` 和 `SVG`。
|`CANVAS`

|[[useUtc]]`useUtc`
|设置 ECharts 是否应以 UTC 解析和显示时间值。
|—
|===

== XML 内部元素

`chart` 可以包含 `title`、`legend`、`scrollableLegend`、`tooltip`、`toolbox`、`brush`、`grid`、`aria`、`xAxes`、`yAxes`、`polar`、`radiusAxis`、`angleAxis`、`radar`、`dataZoom`、`visualMap`、`axisPointer`、`dataSet`、`series`、`textStyle`、`stateAnimation` 和 `nativeJson` 作为内部元素。这些元素对应于 Apache ECharts 配置模型的选项。
