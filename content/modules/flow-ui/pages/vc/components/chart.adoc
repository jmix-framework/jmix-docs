[[basics]]
== Основы

Объявите пространство имен `charts` в XML-дескрипторе экрана:

[source,xml]
----
<view xmlns="http://jmix.io/schema/flowui/view"
      xmlns:charts="http://jmix.io/schema/charts/ui"/>
----

[TIP]
====
Studio автоматически добавляет пространство имен, когда вы добавляете компонент с помощью действия *Add Component* на верхней панели действий. См. xref:studio:view-designer.adoc#component-palette[Палитра компонентов].
====


Затем объявите и настройте график с помощью вложенных XML-элементов и атрибутов:

[source,xml,indent=0]
----
include::charts:example$charts-ex1/src/main/resources/com/company/demo/view/vehiclecount/vehicle-count-chart-view.xml[tags=chart]
----

Дополнительные свойства можно задать программно на Java:

[source,java,indent=0]
----
include::charts:example$/charts-ex1/src/main/java/com/company/demo/view/vehiclecount/VehicleCountChartView.java[tag=configure]
----

Получившийся график выглядит следующим образом:

image::charts:chart-component-1.png[align="center", width="675"]

[TIP]
====
При настройке графика можно обратиться к https://echarts.apache.org/en/option.html#title[официальной документации Apache ECharts^], найти нужные свойства и использовать соответствующие свойства Jmix Chart. В большинстве случаев JavaScript API и Jmix API совпадают.
====

[[series]]
== Серии

++++
<div class="jmix-ui-live-demo-container">
<a href="https://echarts.apache.org/en/option.html#series" class="echarts-docs-btn" target="_blank">ECharts</a>
</div>
++++

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/charts" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Элемент `series` определяет тип графика (например, линейный, столбчатый, рассеяния). Каждый тип графика может быть настроен по-разному внутри элемента `series`.

Основные типы графиков, поддерживаемые Jmix, включают:

* https://demo.jmix.ru/ui-samples/sample/line-series-simple[Line series^]
* https://demo.jmix.ru/ui-samples/sample/bar-series-simple[Bar series^]
* https://demo.jmix.ru/ui-samples/sample/pie-series-simple[Pie series^]
* https://demo.jmix.ru/ui-samples/sample/scatter-series-simple[Scatter^] и https://demo.jmix.ru/ui-samples/sample/effect-scatter-series[effect-scatter series^]
* https://demo.jmix.ru/ui-samples/sample/candlestick-series-simple[Candlestick series^]
* https://demo.jmix.ru/ui-samples/sample/funnel-series-simple[Funnel series^]
* https://demo.jmix.ru/ui-samples/sample/gauge-series-simple[Gauge series^]
* https://demo.jmix.ru/ui-samples/sample/radar-series-simple[Radar series^]

В следующем примере элемент `series` определяет круговую диаграмму:

[source,xml,indent=0]
----
include::charts:example$charts-ex1/src/main/resources/com/company/demo/view/vehiclecount/vehicle-count-chart-view.xml[tags=series-pie]
----

Элемент `label` настраивает текстовые метки сегментов круговой диаграммы. Атрибут `formatter` определяет шаблон, который может включать имя элемента данных и значение. Подробнее о https://echarts.apache.org/en/option.html#series-pie.label[метке^] и https://echarts.apache.org/en/option.html#series-pie.label.formatter[форматтере^] см. в документации ECharts.

Получившаяся круговая диаграмма выглядит следующим образом:

image::charts:chart-component-series-1.png[align="center", width="507"]

NOTE: Элемент `chart` может включать несколько конфигураций `series`, в таком случае данные будут общими для всех типов графиков.

[[data-zoom]]
== Масштабирование данных

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://echarts.apache.org/en/option.html#dataZoom" class="echarts-docs-btn" target="_blank">ECharts</a>
</div>
++++

Свойство `dataZoom` предоставляет две основные функции:

* *Inside data zoom* позволяет пользователям масштабировать или перемещаться в координатных системах с помощью перетаскивания мышью, движения колесика мыши или жестов касания пальцем на сенсорных экранах.

* *Slider type data zoom* предлагает различные функции для определения местоположения в пределах диапазона данных графика: миниатюры данных для быстрого обзора, масштабирование внутрь/наружу, выборка, перетаскивание для перемещения.

Например:

[source,xml,indent=0]
----
include::charts:example$charts-ex1/src/main/resources/com/company/demo/view/vehiclecount/vehicle-count-chart-view.xml[tags=dataZoom]
----

[[native-json]]
== Native JSON

Свойство `nativeJson` предоставляет возможность конфигурации с помощью непосредственной строки JSON, если Java API компонента или атрибутов XML недостаточно для выполнения необходимых настроек. Эта функция предоставляет доступ ко всем возможностям конфигурации ECharts.

Например:

[source,xml,indent=0]
----
include::charts:example$charts-ex1/src/main/resources/com/company/demo/view/vehiclecount/vehicle-count-chart-view.xml[tags=nativeJson]
----

Здесь элемент `nativeJson` настраивает заголовок графика так же, как в XML-конфигурации <<title,выше>>.

NOTE: Конфигурация `nativeJson` объединяется с существующими свойствами и переопределяет соответствующие свойства, определенные в XML.

== Атрибуты

Следующие атрибуты относятся к `chart`:

[cols="2,5,1", options="header"]
|===
|Название
|Описание
|Значение по умолчанию

|[[animation]]`animation`
|Включает или отключает анимацию графика.
|`true`

|[[animationDelay]]`animationDelay`
|Задает задержку перед начальной анимацией в миллисекундах.
|—

|[[animationDelayUpdate]]`animationDelayUpdate`
|Задает задержку перед анимацией обновления в миллисекундах.
|—

|[[animationDuration]]`animationDuration`
|Задает продолжительность начальной анимации в миллисекундах.
|—

|[[animationDurationUpdate]]`animationDurationUpdate`
|Задает продолжительность анимации обновления в миллисекундах.
|—

|[[animationEasing]]`animationEasing`
|Задает функцию сглаживания начальной анимации.
|—

|[[animationEasingUpdate]]`animationEasingUpdate`
|Задает функцию сглаживания анимации обновления.
|—

|[[animationThreshold]]`animationThreshold`
|Задает максимальное количество графических элементов, при котором анимация остается включенной.
|—

|[[backgroundColor]]`backgroundColor`
|Задает цвет фона графика в формате CSS.
|—

|[[blendMode]]`blendMode`
|Задает глобальный режим смешивания. Допустимые значения: `SOURCE_OVER`, `SOURCE_IN`, `SOURCE_OUT`, `SOURCE_ATOP`, `DESTINATION_OVER`, `DESTINATION_IN`, `DESTINATION_OUT`, `DESTINATION_ATOP`, `LIGHTER`, `COPY`, `XOR`, `MULTIPLY`, `SCREEN`, `OVERLAY`, `DARKEN`, `LIGHTEN`, `COLOR_DODGE`, `COLOR_BURN`, `HARD_LIGHT`, `SOFT_LIGHT`, `DIFFERENCE`, `EXCLUSION`, `HUE`, `SATURATION`, `COLOR` и `LUMINOSITY`.
|`SOURCE_OVER`

|[[colorPalette]]`colorPalette`
|Задает разделенный запятыми набор CSS-цветов для серий графика.
|—

|[[hoverLayerThreshold]]`hoverLayerThreshold`
|Задает порог количества элементов, после которого элементы под указателем отображаются на отдельном слое.
|—

|[[renderer]]`renderer`
|Выбирает клиентский механизм отрисовки. Допустимые значения: `CANVAS` и `SVG`.
|`CANVAS`

|[[useUtc]]`useUtc`
|Определяет, должна ли ECharts разбирать и отображать значения времени в UTC.
|—
|===

include::flow-ui:vc/handler-generation-tip.adoc[]

[cols="2,5", options="header"]
|===
|Название
|Описание

|Возникает, когда указатель входит в область элемента графика.

|[[ChartMouseUpEvent]]`ChartMouseUpEvent`
|Возникает при отпускании кнопки указателя над графиком.

|[[ChartRenderedEvent]]`ChartRenderedEvent`
|Возникает после отрисовки или повторной отрисовки графика.

|[[ChartRestoreEvent]]`ChartRestoreEvent`

== Элементы

`chart` может содержать вложенные элементы `title`, `legend`, `scrollableLegend`, `tooltip`, `toolbox`, `brush`, `grid`, `aria`, `xAxes`, `yAxes`, `polar`, `radiusAxis`, `angleAxis`, `radar`, `dataZoom`, `visualMap`, `axisPointer`, `dataSet`, `series`, `textStyle`, `stateAnimation` и `nativeJson`. Они соответствуют параметрам модели конфигурации Apache ECharts.
