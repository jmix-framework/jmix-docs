= spreadsheet 电子表格
:page-aliases: vaadin-spreadsheet:spreadsheet-component.adoc

[NOTE.addon-component]
====
该组件需要安装商业版 xref:vaadin-spreadsheet:index.adoc#installation[Vaadin Spreadsheet 插件]。
====

`spreadsheet` 组件可以在视图中嵌入兼容 Excel 的电子表格。在浏览器中渲染 https://poi.apache.org[Apache POI^] 工作簿，支持用户编辑，并为视图提供对底层 POI 模型的完整编程式访问。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`spreadsheet`

|Java 类
|`Spreadsheet`
|===

[source,java,indent=0]

[source,java,indent=0]
----
include::vaadin-spreadsheet:example$/vaadin-spreadsheet-ex1/src/main/java/com/company/vaadinspreadsheetex1/view/handlers/SpreadsheetHandlersView.java[tags=component-factory]
----

包含组件的行高不会低于 <<minimumRowHeightForComponents,minimumRowHeightForComponents>>，因此组件总是可见。

[[charts-within-spreadsheet]]
== 电子表格中的图表

`spreadsheet` 组件可以渲染 Excel 工作簿中已包含的图表。图表默认显示。设置 <<chartsEnabled,chartsEnabled>> 为 `false` 可隐藏。组件可以反映图表数据点的变化，但不支持更改图表配置、源单元格范围或位置。需要在原始 Excel 文件中进行此类更改。

更多信息，请参考 Vaadin 文档中的 https://vaadin.com/docs/latest/components/spreadsheet#charts-within-spreadsheets[电子表格中的图表^]。

|===
|名称
|描述
|默认值

|最初显示的工作表索引，仅计算可见工作表。
|—

|[[activeSheetWithPOIIndex]]`activeSheetWithPOIIndex`
|最初显示的工作表索引，计算底层 POI 工作簿的所有工作表，包括隐藏的。

|如果为 `true`，则渲染加载的工作簿中包含的图表。

|[[colBufferSize]]`colBufferSize`
|在可见区域左右渲染的水平缓冲区大小，单位为像素。较大的缓冲区使滚动更平滑，但会增加负载。

|[[defaultColumnCount]]`defaultColumnCount`
|新建工作表的列数。
|`52`

|列的默认宽度，单位为像素。
|—

|[[defaultPercentageFormat]]`defaultPercentageFormat`
|默认的百分比值格式。
|`0.00%`

|[[defaultRowCount]]`defaultRowCount`
|新建工作表的行数。
|`200`

|[[defaultRowHeight]]`defaultRowHeight`
|行的默认高度，单位为磅。
|—

|[[functionBarVisible]]`functionBarVisible`
|如果为 `true`，则在工作表上方显示公式栏。
|`true`

|[[invalidFormulaErrorMessage]]`invalidFormulaErrorMessage`
|用户输入无法解析的公式时显示的消息。支持消息键值。
|—

|[[maxColumns]]`maxColumns`
|活跃工作表中渲染的列数。
|—

|[[maxRows]]`maxRows`
|活跃工作表中渲染的行数。
|—

|[[minimumRowHeightForComponents]]`minimumRowHeightForComponents`
|包含嵌入组件的行的最小高度（单位为磅），需要保持组件可见。请参见 <<embedded-components,在单元格添加组件>>。
|`30`

|[[reportStyle]]`reportStyle`
|如果为 `true`，则隐藏函数栏和工作表选择栏。请参见 <<report-style,报表模式>>。
|`false`

|[[rowBufferSize]]`rowBufferSize`
|在可见区域上下渲染的垂直缓冲区大小，单位为像素。
|`200`

|[[selection]]`selection`
|初始选中的单元格或范围，使用 A1 表示法，例如 `A1` 或 `B2:D8`。请参见 <<working-with-selection,选择>>。
|—

|[[sheetSelectionBarVisible]]`sheetSelectionBarVisible`
|如果为 `true`，则在组件底部显示工作表标签页。
|`true`

|[[statusLabelValue]]`statusLabelValue`
|组件状态区域中显示的文本。支持消息键值。
|—

|[[theme]]`theme`
|电子表格的主题。支持：`LUMO`、`VALO`。`LUMO` 使组件与应用程序其他样式一致；`VALO` 是经典的电子表格外观。
|`VALO`

[[handlers]]
== 事件和处理器

下面是 `spreadsheet` 的特殊事件和处理器：

include::flow-ui:vc/handler-generation-tip.adoc[]

[cols="2,5", options="header"]
|===
|名称
|描述

|[[CellValueChangeEvent]]`CellValueChangeEvent`
|当用户更改了一个或多个单元格的值时发送。

|[[cellValueHandler]]`cellValueHandler`
|当用户通过默认文本编辑器更新单元格时调用 `Spreadsheet.CellValueHandler`。可以自定义输入值如何应用于单元格。返回 `true` 继续按组件的默认值解析，如果处理器有自定义逻辑处理该值则返回 `false`。

|[[hyperlinkCellClickHandler]]`hyperlinkCellClickHandler`
|`Spreadsheet.HyperlinkCellClickHandler`，定义用户点击包含超链接的单元格时如何处理。可以用来导航到应用视图而不是打开外部 URL。

|[[ProtectedEditEvent]]`ProtectedEditEvent`
|当用户尝试编辑受保护工作表上的锁定单元格时发送。

|[[RowHeaderDoubleClickEvent]]`RowHeaderDoubleClickEvent`

|[[SelectionChangeEvent]]`SelectionChangeEvent`

|[[SheetChangeEvent]]`SheetChangeEvent`
|当用户切换到另一个工作表时发送。

|[[spreadsheetComponentFactory]]`spreadsheetComponentFactory`
|`SpreadsheetComponentFactory`，提供单元格内渲染的组件，用于显示或编辑。请参见 <<embedded-components,在单元格添加组件>>。

|[[spreadsheetHandler]]`spreadsheetHandler`
|`SpreadsheetHandlerImpl`，处理组件的客户端-服务端协议。仅当无法通过任何其他扩展点实现所需行为时才使用。
