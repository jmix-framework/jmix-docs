= fileStorageUploadField 文件存储上传
:page-aliases: vcl/components/file-storage-upload-field.adoc

`fileStorageUploadField` 支持用户将文件上传至 Jmix xref:files:file-storage.adoc[文件存储]。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`fileStorageUploadField`

|Java 类
|`FileStorageUploadField`
|===

[[basics]]
== 基本用法

这个组件可以包含标题、已上传文件的链接和一个上传按钮。当点击上传按钮的时候，会弹出标准的文件选择器，用户可以在这里选择需要上传的文件。

`fileStorageUploadField` 既可以 <<data-binding,绑定实体属性>>，也可以不绑定数据。

下面的示例我们展示在没有数据绑定的情况下使用组件。可以用来直接处理上传的文件，而无需将其与任何 Jmix 实体关联。

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/filestorageupload/file-storage-upload-view.xml[tags=FileUploadSucceededEvent]
----

可以直接在 <<FileUploadSucceededEvent,FileUploadSucceededEvent>> 事件中处理上传的文件。

[TIP]
====
如需以字节数组的格式在实体属性保存文件，而不是 `FileRef`，那么请使用 xref:flow-ui:vc/components/fileUploadField.adoc[fileUploadField] 组件。

如需同时上传多个文件，请使用 xref:flow-ui:vc/components/upload.adoc[upload] 组件。
====

NOTE: `fileStorageUploadField` 在内部使用了 Vaadin 的 `UploadHandler` API。上传的文件会立即保存在默认的 `FileStorage` 中。如需以编程的方式控制文件的存储，可以使用 <<fileStoragePutMode,fileStoragePutMode>> 属性。
