= richTextEditor 富文本编辑器
:page-aliases: vcl/components/rich-text-area.adoc

`richTextEditor` 组件支持用户创建和编辑富文本。

|===
|XML 元素
|`richTextEditor`

|Java 类

== 工具栏的操作

用户可以使用工具栏进行的操作：加粗、斜体、下划线和删除线格式；选择标题级别；添加下标或上标；创建有序和无序列表；对齐内容；插入图片和链接；添加引用块和代码块；以及清除格式。
