= numberField 数字字段

`numberField` 与 xref:vc/components/textField.adoc[textField] 功能相似，但仅允许输入数字类型。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`numberField`

|Java 类
|`JmixNumberField`
|===

[[validation]]
== 验证

如需检查 `numberField` 组件输入的值，可以在内部元素 `validators` 中添加一个 xref:vc/miscellaneous/validator.adoc[validator]元素。

`numberField` 可以使用下列预定义的验证器：

|描述

|`align-left`
|字段值左对齐
|Aura, Lumo

|`align-center`
|字段值居中
|Aura, Lumo

|`align-right`
|字段值右对齐
|Aura, Lumo

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo
|===

== XML 属性

下面是 `numberField` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[autoselect]]`autoselect`
|当组件获得焦点时，是否自动选中组件的文本。
|—

|[[clearButtonVisible]]`clearButtonVisible`
|组件是否显示一个清除按钮。
|`false`

|[[max]]`max`
|设置最大值。
|—

|[[min]]`min`
|设置最小值。
|—

|[[step]]`step`
|设置步长。
|—

|[[stepButtonsVisible]]`stepButtonsVisible`
|设置是否显示调整步长的按钮。
|—

|[[value]]`value`
|设置组件值。
|—
|===
