`groupDataGrid` — более функциональная версия базовой таблицы данных с широкими возможностями группировки строк. Компонент группирует строки по повторяющимся значениям колонок в сворачиваемые блоки и поддерживает многоуровневую группировку и изменение ее порядка перетаскиванием.

|`groupDataGrid`

|Java-класс
|`GroupDataGrid`
|===

[[basics]]
== Основы

[[Basics]]

Объявите пространство имен `groupg` в XML-дескрипторе экрана:

[source,xml,indent=0]
----
<view xmlns="http://jmix.io/schema/flowui/view"
      xmlns:groupg="http://jmix.io/schema/groupgrid/ui">
----

[TIP]
====
Studio автоматически добавляет пространство имен, когда вы добавляете компонент с помощью действия *Add Component* на верхней панели действий. См. xref:studio:view-designer.adoc#component-palette[Палитра компонентов].
====

[[data-binding]]
== Привязка данных

Привязка данных — это связывание визуального компонента с контейнером данных. Чтобы связать компонент с данными, используйте атрибут `dataContainer` со ссылкой на xref:flow-ui:data/collection-container.adoc[контейнер коллекции]. См. пример выше.

[[group-item]]
== Элемент группы

Элементы группы — это специальные записи, создаваемые при группировке. Они отображаются как строки, содержащие только заголовок группы.

image::groupdatagrid:groupdatagrid-group-items.png[align="center",width="1097"]

Для отображения элементов группы уровень привязки данных создаёт временный пустой экземпляр сущности или DTO. Этот экземпляр не добавляется в xref:flow-ui:data/collection-container.adoc[контейнер коллекции] и существует только в памяти на время группировки.

[[hide-group-item-count]]
=== Скрытие счётчика элементов группы

По умолчанию элементы группы отображают количество вложенных записей. Чтобы скрыть это число, используйте свойство `displayItemCount` элемента <<groupColumn,groupColumn>>.

image::groupdatagrid:groupdatagrid-hide-count.png[align="center",width="1097"]

[[multi-level-grouping]]
== Многоуровневая группировка

Компонент поддерживает группировку по нескольким колонкам. Щёлкните значок колонки группировки, чтобы открыть диалог *Group by*, а затем добавьте или удалите колонки.

image::groupdatagrid:groupdatagrid-multiple.png[align="center",width="1100"]

[[sorting]]
== Сортировка

Настройка сортировки такая же, как в xref:flow-ui:vc/components/dataGrid.adoc#sorting[dataGrid]. Атрибут <<sortByGroupEnabled,sortByGroupEnabled>> определяет, влияет ли сортировка на порядок групп.

[[disable-grouping]]
== Отключение группировки

Чтобы запретить пользователям группировку по определённой колонке, установите её свойству `groupAllowed` значение `false`. Это убирает колонку из диалога *Group by*. В примере ниже колонка *Country* не может быть сгруппирована:

image::groupdatagrid:groupdatagrid-groupallowed.png[align="center",width="1100"]

.XML code
[%collapsible]
====
[source,xml,indent=0]
----
include::groupdatagrid:example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/disablegrouping/disable-grouping-view.xml[tags=disable-grouping]
----
====

Чтобы полностью отключить группировку для пользователей, установите `displayColumnsGrouperOnIconClick="false"` на элементе <<groupColumn>>.

NOTE: Группировку по умолчанию можно всё равно задать с помощью элемента <<groupBy>> или программно, вызвав метод `groupBy()`.

[[custom-grouping-column]]
== Настраиваемая колонка группировки

Чтобы использовать нестандартное значение для группировки, опишите новое свойство группировки в контроллере экрана. В следующем примере вводится новое свойство группировки, объединяющее имя и фамилию.

Такое синтетическое свойство не сортируется автоматически. Чтобы включить сортировку, укажите свойства сортировки в дескрипторе свойства группировки с помощью `.withSortProperties(...)`.

image::groupdatagrid:groupdatagrid-custom-column.png[align="center",width="1097"]

.XML code
[%collapsible]
====
[source,xml,indent=0]
----
include::groupdatagrid:example$/groupdatagrid-ex1/src/main/resources/com/company/groupdatagridex1/view/customgrouping/custom-grouping-view.xml[tags=custom-grouping]
----
====
.Java code
[%collapsible]
====
[source,java,indent=0]
----
include::groupdatagrid:example$/groupdatagrid-ex1/src/main/java/com/company/groupdatagridex1/view/customgrouping/CustomGroupingView.java[tags=custom-grouping;renderer]
----
<1> Описывает новое свойство группировки, объединяющее `firstName` и `lastName`.
<2> `.withSortProperties(List.of("firstName", "lastName"))` указывает компоненту, как сортировать синтетическое свойство.
<3> Группировка по `fullName` по умолчанию.
<4> Предоставляет запасной вариант отображения для колонки Full Name, когда она не участвует в группировке; без этого колонка будет отображаться пустой.
====

[[export-to-excel]]
== Экспорт в Excel

Функциональность экспорта предоставляется бесплатным дополнением xref:grid-export:index.adoc[], которое поддерживает все виды таблиц: `groupDataGrid`, `dataGrid` и `treeDataGrid`.

image::groupdatagrid:groupdatagrid-export.png[align="center",width="1090"]

Дополнение предоставляет три варианта экспорта. Они влияют как на охват данных, так и на формат итоговой таблицы:

* *Все строки* — экспортирует все строки, разворачивая группировку в плоский список.
* *Текущая страница* — экспортирует только видимые строки, *сохраняя структуру группировки как в таблице*.
* *Выбранные строки* — экспортирует выбранные строки, разворачивая группировку в плоский список.

=== Иконка группировки

Компонент отображает `+` для свёрнутой группы и `-` для развёрнутой. Чтобы изменить иконки, добавьте нужные значки в таблицу стилей приложения. Замените значения `content` по умолчанию на коды нужных символов (например, `e7c1` и `e7bf` из коллекции https://github.com/vaadin/web-components/blob/main/packages/icons/assets/vaadin-font-icons.json[иконок шрифта Vaadin^]):

.application.css
[source,css,indent=0]
----
vaadin-grid-tree-toggle.jmix-group-toggle {
    &::part(toggle)::before {
        content: "\e7c1";
    }

    &[expanded]::part(toggle)::before {
        content: "\e7bf";
    }
}
----

=== Иконка колонки группировки

Иконка колонки группировки настраивается через атрибут `groupIcon` элемента <<groupColumn,groupColumn>>. Чтобы скрыть иконку, установите `groupIconVisible` в значение `false`.

== Элементы

`groupDataGrid` может содержать непосредственные вложенные элементы `actions`, <<groupBy,groupBy>>, <<columns,columns>>, `contextMenu` и `emptyStateComponent`. Элемент `columns` может содержать <<column,column>>, <<groupColumn,groupColumn>> и xref:flow-ui:vc/components/dataGrid.adoc#actions-column[editorActionsColumn]. Общие элементы таблицы описаны в разделах xref:flow-ui:vc/components/dataGrid.adoc#actions[actions], xref:flow-ui:vc/components/dataGrid.adoc#context-menu-element[contextMenu] и xref:flow-ui:vc/components/dataGrid.adoc#empty-state-component-element[emptyStateComponent].

[TIP]
====
Чтобы добавить элемент к выбранному компоненту, нажмите кнопку xref:studio:screen-designer.adoc#add-column[Add] в панели инспектора *Jmix UI*.
====

[[groupBy]]
=== groupBy

Элемент `groupBy` содержит один или несколько элементов <<columnRef,columnRef>>, определяющих, по каким колонкам выполняется группировка.

[[columnRef]]
=== columnRef

Элемент `columnRef` определяет колонку, используемую для группировки.
Обязательный атрибут `key` должен совпадать с ключом объявленной колонки.

[[columns]]
=== columns

Элемент `columns` содержит отдельные элементы `column` и задаёт набор атрибутов, общих для этих колонок. Он поддерживает `includeAll`, `exclude`, `sortable`, `resizable` и `filterable`, как описано для xref:flow-ui:vc/components/dataGrid.adoc#columns[колонок dataGrid].

[[column]]
=== column

Элемент `column` описывает отдельную колонку. Атрибуты, заданные для конкретной `column`, имеют приоритет над атрибутами `columns`. Элемент поддерживает конфигурацию xref:flow-ui:vc/components/dataGrid.adoc#column[колонки dataGrid] и дополнительный атрибут `groupAllowed`, который определяет возможность группировки по колонке. См. <<disable-grouping,Отключение группировки>>.

[[groupColumn]]
=== groupColumn

Элемент `groupColumn` описывает колонку, используемую для группировки, и ее относительное положение среди других колонок. Он может содержать вложенный элемент `groupIcon`, задающий пользовательский компонент значка.
