= treeDataGrid

[[actions]]
== Действия

Компонент `treeDataGrid` реализует интерфейс `HasActions` и может содержать как стандартные xref:flow-ui:actions/list-actions.adoc[действия списка], так и пользовательские действия. Действия вызываются через кнопки или <<context-menu, контекстное меню>> (по правому клику).

[TIP]
====
Для добавления действия в Jmix Studio:

. Выберите компонент в XML-дескрипторе или на панели структуры *Jmix UI*.
. Нажмите xref:studio:screen-designer.adoc#add-action[Add->Action] в панели инспектора *Jmix UI*.
====

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/treedatagrid/tree-data-grid-view.xml[tags=actions]
----

<1> Определяет `hbox` для размещения кнопок действий.
<2> Определяет стандартное действие `list_create`.
<3> Определяет пользовательское действие `getInfo`. Значение его атрибута xref:flow-ui:vc/common-attributes.adoc#text[text] задаёт текст действия в контекстном меню и используется как текст кнопки.

[[context-menu]]
== Контекстное меню

Контекстное меню предоставляет альтернативный способ доступа к <<actions, действиям>> через правую кнопку мыши. Каждое действие представлено отдельным пунктом меню.

Используйте элемент `contextMenu` для настройки списка пунктов меню, организуя их с помощью разделителей и иерархической структуры.

[source,xml,indent=0]
----
include::example$/onboarding/src/main/resources/com/company/onboarding/view/component/treedatagrid/tree-data-grid-view.xml[tags=context-menu]
----
<1> Скрыть все действия из меню. Или скрыть конкретное действие с помощью атрибута xref:vc/common-attributes.adoc#visible[visible].
<2> Явно добавить пункты меню для нужных действий.
<3> Вложенные пункты создают иерархическую структуру.

|Aura, Lumo

|Aura, Lumo

Это означает, что вместо того, чтобы отображать только видимые строки и загружать новые по мере прокрутки пользователем, сетка будет отображать все строки в DOM одновременно. *Использование этой функции не рекомендуется для большого количества элементов, поскольку это может вызвать проблемы с производительностью.*

|`50`

|[[rowDraggable]]`rowDraggable`

|`SINGLE`

|[[showOrphans]]`showOrphans`
|Если указано `false`, записи без загруженного родителя не отображаются. При значении `true` такие записи выводятся на верхнем уровне как корневые. Такая ситуация может возникнуть при частичной загрузке данных из-за фильтрации или постраничного вывода. Скрытие записей без родителя может привести к появлению пустых или частично заполненных страниц. Не рекомендуется использовать `treeDataGrid` вместе с `simplePagination`.
|`false`

|Определяет, какие строки можно перетаскивать, вместо включения этой возможности для всех строк с помощью <<rowDraggable,rowDraggable>>.

|[[partNameGenerator]]`partNameGenerator`
|Генерирует части имён CSS-классов для ячеек на основе заданных условий. Позволяет настраивать внешний вид ячеек в зависимости от отображаемых данных.

== Элементы

Элементы `dataGrid` предоставляют множество параметров для управления внешним видом, поведением и функциями всех колонок или каждого колонки отдельно.

====
Чтобы добавить элемент к выбранному компоненту, нажмите кнопку xref:studio:screen-designer.adoc#add-column[Add] в панели инспектора *Jmix UI*.

.Атрибуты
[cols="1h,5,1", grid=rows]
|===
|*Название*
|*Описание*
|*Значение по умолчанию*
|[[exclude]]exclude
|Исключает из отображения определённые атрибуты. Некоторые атрибуты необходимо разделять запятой. Например: `exclude = "id, version, sortValue"`.
|—

|Если указано `true`, включает все атрибуты из фетч-плана соответствующего контейнера данных.
