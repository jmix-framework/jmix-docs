= radioButtonGroup 单选组
:page-aliases: vcl/components/radio-button-group.adoc

`radioButtonGroup` 支持使用单选按钮从选项列表中选择单个值。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`radioButtonGroup`

|Java 类
|`JmixRadioButtonGroup`
|===

[[rendering-items]]
== 选项渲染

框架提供了自定义选项渲染的功能。渲染器会对每个选项生效并创建选项的外观组件。

可以使用 `setRenderer()` 方法或 `@Supply` 注解实现。

[source,java,indent=0]
----
include::example$/onboarding/src/main/java/com/company/onboarding/view/component/radiobuttongroup/RadioButtonGroupView.java[tags=autowired;renderer]
----

[[fragment-renderer]]
或者，可以使用内部的 `fragmentRenderer` 元素来渲染条目。有关详细信息，请参阅 xref:flow-ui:vc/miscellaneous/renderers.adoc#fragment-renderer[Fragment 渲染器] 部分。

== 事件和处理器

下面是 `radioButtonGroup` 的特殊事件和处理器：

[cols="2,5", options="header"]
|===
|名称
|描述

|[[itemEnabledProvider]]`itemEnabledProvider`
|`itemEnabledProvider` 会应用在每个选项上，以确定选项是启用（`true`）还是禁用（`false`）。参阅 <<item-enabled-provider,选项启用>>。

|[[itemLabelGenerator]]`itemLabelGenerator`
|自定义每个单选按钮的显示标签。参阅 <<customizing-item-labels,自定义选项标签>>。

|[[renderer]]`renderer`
|设置选项的渲染器。参阅 <<rendering-items,选项渲染>>。

|[[validator]]`validator`
|验证组件值。
|===
