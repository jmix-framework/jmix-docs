= datePicker 日期选择
:page-aliases: vcl/components/date-picker.adoc

`datePicker` 支持用户输入日期，或者通过日历选择日期。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`datePicker`

|Java Class
|`TypedDatePicker`
|===

[[basics]]
== 基本用法

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/date-picker-simple" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

与常规输入控件不同，`datePicker` 带有一个日历按钮和一个日历选择弹窗。当用户点击按钮、点击输入框或者开始输入日期时，会自动打开日历弹窗。

日历支持鼠标滚动，用户可以在右侧面板选择年份。点击底部的 *Today* 按钮可以直接返回今天的日期。

== 数据类型

`datePicker` 是一个带类型的组件，支持常见的日期数据类型：

* `date`
* `dateTime`
* `localDateTime`
* `offsetDateTime`
* `localDate`

当 <<data-binding, 绑定组件>> 与实体属性时，会自动使用该属性的数据类型。如果需要显示设置类型，请使用 xref:vc/common-attributes.adoc#datatype[datatype] 属性指定。
