= dashboard 仪表盘
:page-aliases: vaadin-dashboard:dashboard-component.adoc

[NOTE.addon-component]
====
此组件需要商业版 xref:vaadin-dashboard:index.adoc#installation[Vaadin Dashboard 扩展组件]。
====

`dashboard` 组件以小部件网格的形式显示内容。网格会根据可用宽度更改列数。一个小部件可以跨越多列和多行，还可以按用户可折叠的分区进行分组。在可编辑模式下，用户可以自行移动、调整大小和移除小部件。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`dashboard`

|Java 类
|`JmixDashboard`
|===

[[widgets]]
== 小部件

小部件（widget）由 `dashboardWidget` 元素声明。需要一个 `id`，并在内部的 `content` 元素中包含一个组件。`title` 属性设置小部件标题中显示的文本，并支持消息键值：

[source,xml,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/resources/com/company/vaadindashboardex1/view/widgets/dashboard-widgets-view.xml[tags=content]
----

`content` 元素中可以放入视图中的任何组件。如需在一个小部件中显示多个组件，则可以将多个组件放在一个布局容器中，如上所示。

[[widget-header]]
=== 小部件 Header

除了标题之外，小部件还可以有 `headerContent` 元素。其组件显示在小部件的 header 栏。可用于放置刷新按钮、过滤器或状态徽章：

[source,xml,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/resources/com/company/vaadindashboardex1/view/widgets/dashboard-widgets-view.xml[tags=header-content]
----

`content` 和 `headerContent` 都必须仅包含一个元素。如果设置多个元素，会在视图打开时抛出开发异常。

[[widget-size]]
=== 小部件尺寸

默认情况下，一个小部件占用网格的一个单元格。使用 `colspan` 和 `rowspan` 属性可以跨越多行和多列：

[source,xml,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/resources/com/company/vaadindashboardex1/view/widgets/dashboard-widgets-view.xml[tags=widget-size]
----

小部件占用的列数不会超过网格的列数。在窄屏幕上，宽的小部件会收缩到可用的列数。

[[sections]]
== 分区

小部件可以使用 `dashboardSection` 元素进行分组，同一个组的小部件使用共同的标题。用户可以折叠分区，隐藏其所有小部件：

[source,xml,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/resources/com/company/vaadindashboardex1/view/sections/dashboard-sections-view.xml[tags=sections]
----

与小部件一样，分区需要一个 `id`。一个分区只能包含 `dashboardWidget` 元素，并且不能将分区放入另一个分区中。直接在 `dashboard` 元素中声明的小部件和分区内的小部件可以以任意顺序混合。

=== 以编程方式创建分区

要创建分区，请使用 `addSection()` 方法，然后向其中添加小部件，例如使用 <<creating-widgets-programmatically,以编程方式创建小部件>> 中的 `createWidget()` 方法。移除分区时，其小部件也会被移除：

[source,java,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/java/com/company/vaadindashboardex1/view/programmatic/DashboardProgrammaticView.java[tags=create-section]
----

[[responsive-grid]]
== 响应式网格

仪表盘根据自身的宽度和列宽限制计算列数。列的宽度不会小于 <<minimumColumnWidth,minimumColumnWidth>> 值。当仪表盘变窄时，列数会减少。<<maximumColumnCount,maximumColumnCount>> 属性设置宽屏幕上的最大列数：

[source,xml,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/resources/com/company/vaadindashboardex1/view/grid/dashboard-grid-view.xml[tags=grid]
----

<<denseLayout,denseLayout>> 属性设置网格间隙的填充方式。如果为 `true`，较小的小部件会向上移动，填充较大部件留下的空白空间，此时不会保持部件声明的顺序。

所有这些属性都有 setter，因此可以在运行时 Java 中设置：

[source,java,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/java/com/company/vaadindashboardex1/view/grid/DashboardGridView.java[tags=grid-java]
----

[[editable-mode]]
== 可编辑模式

默认情况下，用户看到的小部件与声明时完全一致。如果将 <<editable,editable>> 属性设置为 `true`，用户可以移动、调整大小和移除小部件，以及更改分区的顺序：

[source,xml,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/resources/com/company/vaadindashboardex1/view/editable/dashboard-editable-view.xml[tags=editable]
----

在此模式下，每个小部件都会显示一个拖动手柄、一个调整大小手柄和一个移除按钮。这些操作也可以通过键盘执行。用户选择获得焦点的部件进行编辑，然后使用方向键移动或调整其大小。

可以在运行时切换可编辑模式，例如通过一个自定义的按钮实现：

[source,java,indent=0]
----
include::vaadin-dashboard:example$/vaadin-dashboard-ex1/src/main/java/com/company/vaadindashboardex1/view/editable/DashboardEditableView.java[tags=toggle]
----

用户每次更改时，仪表盘都会发送一个事件。请参见 <<handlers,事件和处理器>>。

[[persisting-widget-layout]]
=== 部件布局持久化

仪表盘不会自动持久化用户的更改。如需保留自定义布局，请定义一个数据模型，存储每个小部件的固定标识符和布局属性，例如顺序、分区、列跨度和行跨度。在用户完成编辑时保存当前小部件配置，并在视图打开时根据存储的配置重新创建小部件。如果每个用户可以有不同布局，请将存储的配置还需要与用户关联。

一个简单实现的示例，请参见 Vaadin 文档中的 https://vaadin.com/docs/latest/components/dashboard#persisting-and-loading-widgets[小部件的持久化和加载^]。

[[theme-variants]]
== 主题样式

使用 xref:flow-ui:vc/common-attributes.adoc#themeNames[themeNames] 属性设置组件主题。

[cols="1,4", options="header"]
|===
|样式
|描述

|`shaded-background`
|为仪表盘添加阴影背景，使小部件更加突出。

|`elevated-widgets`
|显示带有阴影的小部件。

|`flat-widgets`
|显示无边框和阴影的小部件。
|===

还可以通过 xref:flow-ui:vc/common-attributes.adoc#classNames[classNames] 属性为仪表盘、分区和小部件添加自定义 CSS 类名。

[[attributes]]
== XML 属性

下面是 `dashboard` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[denseLayout]]`denseLayout`
|如果为 `true`，较小的小部件会向上移动以填充较大部件留下的间隙，并且不保持部件声明的顺序。请参见 <<responsive-grid,响应式网格>>。
|`false`

|[[editable]]`editable`
|如果为 `true`，用户可以移动、调整大小和移除小部件，以及更改分区的顺序。请参见 <<editable-mode,可编辑模式>>。
|`false`

|[[gap]]`gap`
|小部件之间的间距，以 CSS 长度表示，例如 `1em`。
|—

|[[maximumColumnCount]]`maximumColumnCount`
|最大列数，无论仪表盘的宽度如何。如果未设置，列数取决于 <<minimumColumnWidth,minimumColumnWidth>>。
|—

|[[maximumColumnWidth]]`maximumColumnWidth`
|列的最大宽度，以 CSS 长度表示。
|—

|[[minimumColumnWidth]]`minimumColumnWidth`
|列的最小宽度，以 CSS 长度表示。列的宽度不会小于该值。如果空间不够，会减少一行内的列数。请参见 <<responsive-grid,响应式网格>>。
|—

|[[minimumRowHeight]]`minimumRowHeight`
|行的最小高度，以 CSS 长度表示。如果内容需要更多空间，行会变高。
|—

|[[padding]]`padding`
|仪表盘边框与其小部件之间的内边距，以 CSS 长度表示。
|—

|[[rootHeadingLevel]]`rootHeadingLevel`
|生成的标记中根级项目标题的标题级别。仅影响可访问性。
|`2`
|===

|描述
