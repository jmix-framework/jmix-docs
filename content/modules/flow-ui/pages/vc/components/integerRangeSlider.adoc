= integerRangeSlider

[.since]
Since Jmix 3.1

`integerRangeSlider` lets users select a range of `Integer` values. It has two handles on a track: one sets the start of the range, and the other sets the end.

To work with `Double` values, use xref:vc/components/decimalRangeSlider.adoc[decimalRangeSlider]. To select a single value, use xref:vc/components/integerSlider.adoc[integerSlider].

[[value]]
== Value

The value of `integerRangeSlider` is an `IntegerRangeSliderValue` record. Its `start()` and `end()` methods return the start and the end of the selected range. The start cannot be greater than the end.

To set the range in code, pass a new `IntegerRangeSliderValue(start, end)` object to the `setValue()` method. The `clear()` method selects the whole range from `min` to `max`.

`integerRangeSlider` cannot be bound to a data container and does not support validators. Read its value in the view controller, as shown in the <<filter,example below>>. To show an error, set the xref:vc/common-attributes.adoc#errorMessage[errorMessage] attribute and call `setInvalid(true)` in the controller.

The `ComponentValueChangeEvent` handler passes the start and the end of the selected range to the loader query parameters and loads the data again. The slider sends a new value to the server when the user releases a handle, so the view loads the data once for each new range. To send the value on every step of the drag, set xref:vc/common-attributes.adoc#valueChangeMode[valueChangeMode] to `EAGER`.

[[value-display]]
== Value Display

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://vaadin.com/docs/v25/components/slider#persistent-value-display" class="vaadin-docs-btn" target="_blank">Vaadin</a>
</div>
++++

By default, the slider shows the current values above the handles only while the user interacts with them. Set <<valueAlwaysVisible,valueAlwaysVisible>> to `true` to show the values all the time.

The <<minMaxVisible,minMaxVisible>> attribute shows the `min` and `max` values below the track, as in the <<range-and-step,example above>>.

== Attributes

The following attributes are specific to `integerRangeSlider`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[accessibleNameEnd]]`accessibleNameEnd`
|Sets the accessible name of the handle that sets the end of the range. See <<accessible-names>>.
|—

|[[accessibleNameStart]]`accessibleNameStart`
|Sets the accessible name of the handle that sets the start of the range. See <<accessible-names>>.
|—

|[[endValue]]`endValue`
|Sets the end of the initial range. If only `startValue` is set, the end is `max`.
|—

|[[max]]`max`
|Sets the maximum value of the slider. See <<range-and-step>>.
|`100`

|[[min]]`min`
|Sets the minimum value of the slider. See <<range-and-step>>.
|`0`

|[[minMaxVisible]]`minMaxVisible`
|Shows the `min` and `max` values below the track.
|`false`

|[[required]]`required`
|Shows the required indicator. The component does not check its value.
|`false`

|[[startValue]]`startValue`
|Sets the start of the initial range. If only `endValue` is set, the start is `min`.
|—

|[[step]]`step`
|Sets the interval between the values that the user can select. The step must be greater than 0. See <<range-and-step>>.
|`1`

|[[valueAlwaysVisible]]`valueAlwaysVisible`
|Shows the current values above the handles all the time. If `false`, the values are shown only while the user interacts with the slider.
|`false`
|===
