= integerRangeSlider 整数范围滑动输入

[.since]
Jmix 3.1+

`integerRangeSlider` 支持用户选择 `Integer` 值的范围。在轨道上有两个手柄：一个设置范围的起点，另一个设置终点。

如需处理 `Double` 值，请使用 xref:vc/components/decimalRangeSlider.adoc[decimalRangeSlider]。如需选择单个值，请使用 xref:vc/components/integerSlider.adoc[integerSlider]。

[[value]]
== 值

`integerRangeSlider` 的值是一个 `IntegerRangeSliderValue` record。其 `start()` 和 `end()` 方法返回所选范围的起点和终点。起点不能大于终点。

如需在代码中设置范围值，将 `IntegerRangeSliderValue(start, end)` 对象传递给 `setValue()` 方法。`clear()` 方法会将范围值重置为从 `min` 到 `max`。

`integerRangeSlider` 不能绑定到数据容器，也不支持验证器。因此，需要在视图控制器中手动读取值。使用范围滑块过滤数据的示例，请参阅 <<filter,下面的示例>>。如需显示错误信息，请设置 xref:vc/common-attributes.adoc#errorMessage[errorMessage] 属性，并在控制器中调用 `setInvalid(true)`。

`ComponentValueChangeEvent` 事件的处理程序将所选范围传递给加载器的查询参数，并重新加载数据。滑块在用户释放控件时会将新值发送到服务端，因此视图在每次范围变更时加载一次数据。如需在拖动的每一步发送值，请将 xref:vc/common-attributes.adoc#valueChangeMode[valueChangeMode] 设置为 `EAGER`。

== 值显示

++++
<div class="jmix-ui-live-demo-container">

默认情况下，滑块仅在用户与手柄交互时在手柄上方显示当前值。将 <<valueAlwaysVisible,valueAlwaysVisible>> 设置为 `true` 可始终显示值，例如 <<basics,上面的示例>>。

== XML 属性

下面是 `integerRangeSlider` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[accessibleNameEnd]]`accessibleNameEnd`
|设置范围终点手柄的无障碍名称。参考 <<accessible-names>>。
|—

|[[accessibleNameStart]]`accessibleNameStart`
|设置范围起点手柄的无障碍名称。参考 <<accessible-names>>。
|—

|[[endValue]]`endValue`
|设置初始范围的终点。如果只设置了 `startValue`，则终点为 `max`。
|—

|[[max]]`max`
|设置滑块的最大值。参考 <<range-and-step>>。
|`100`

|[[min]]`min`
|设置滑块的最小值。参考 <<range-and-step>>。
|`0`

|[[minMaxVisible]]`minMaxVisible`
|在轨道下方显示 `min` 和 `max` 值。
|`false`

|[[required]]`required`
|显示必填指示符。但组件不会检查值。
|`false`

|[[startValue]]`startValue`
|设置初始范围的起点。如果只设置了 `endValue`，则起点为 `min`。
|—

|[[step]]`step`
|设置用户可选值之间的间隔。步长必须大于 0。参考 <<range-and-step>>。
|`1`

|[[valueAlwaysVisible]]`valueAlwaysVisible`
|始终在手柄上方显示当前值。如果为 `false`，则仅在用户与滑块交互时显示值。
|`false`
|===
