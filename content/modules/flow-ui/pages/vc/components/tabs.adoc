= tabs 选项卡

`tabs` 支持用户切换想关联的内容区域，但组件本身不包含内容区域。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`tabs`

|Java 类
|`Tabs`
|===

[[variants]]
== 样式版本

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/tabs-theme-variant" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`icon-on-top`
|作用于单个 `tab` 元素。在 `tab` 上设置 `themeNames="icon-on-top"` 可将图标置于标签文本上方。
|Lumo

|`centered`
|在容器内居中标签页。
|Lumo

|`small`
|使标签页更小。
|Aura, Lumo

|`minimal`
|弱化视觉样式，仅突出显示标签文本。
|Lumo

|`hide-scroll-buttons`
|隐藏用于导航溢出标签页的滚动按钮。
|Aura, Lumo

|`equal-width-tabs`
|为所有标签页分配等宽并禁用滚动。
|Lumo
|===
