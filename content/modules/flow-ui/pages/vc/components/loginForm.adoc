[[basics]]
== Основы

Базовая форма `loginForm` содержит поля имени пользователя и пароля, а также кнопку входа. Кроме того, она может отображать выбор локали, флажок *Запомнить меня* и кнопку *Забыли пароль?*.

[[labels-messages]]
=== Надписи и сообщения

Во вложенном элементе `form` задаются заголовок формы, подписи полей и текст кнопки. Значения можно указать напрямую или получить по ключам из xref:localization:message-bundles.adoc[message-bundle]. В примере также задаются содержимое `errorMessage` для ошибки аутентификации и `additionalInformation` под формой:

[[remember-me]]
=== Запоминание пользователя

Параметр *Запомнить меня* сохраняет в браузере постоянный токен, поэтому аутентифицированный сеанс может продолжаться после завершения HTTP-сеанса и перезапуска приложения. При аутентификации получайте состояние флажка из `LoginEvent`. Если интерфейс должен сразу реагировать на изменение флажка, используйте <<RememberMeChangedEvent,RememberMeChangedEvent>>.

Подробное описание механизма аутентификации см. в https://docs.spring.io/spring-security/reference/servlet/authentication/rememberme.html[документации Spring Security по функции Remember Me^].

[[authentication]]
== Аутентификация

Стандартный экран входа подписывается на `LoginEvent`, применяет выбранную локаль и передаёт введённые учётные данные и состояние *Запомнить меня* в `AuthenticationManager`. Ошибки аутентификации отображаются через состояние ошибки формы:

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/login/LoginView.java[tags=login-form;on-login-handler]
----
<1> Инжектирует форму, чтобы контроллер мог обновлять её состояние.
<2> Применяет локаль, выбранную в форме.
<3> Передаёт состояние флажка в токен аутентификации.

== Обработка исключений

Расширьте обработчик входа, если пользователю нужно сообщить конкретную причину ошибки аутентификации. В примере определяется заблокированная учётная запись, выводится соответствующее сообщение и регистрируется неудачная попытка входа:

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/loginform/LoginFormView.java[tags=exception-handling]
----
<1> Выбирает сообщение об ошибке для `LockedException`.
<2> Записывает неудачную попытку входа в журнал.

== Обработчики

`loginForm` имеет следующие уникальные обработчики:

[cols="2,5", options="header"]
|===
|Имя
|Описание

|[[ForgotPasswordEvent]]ForgotPasswordEvent
|Запускается, когда пользователь нажимает *Забыли пароль*.

|[[LocaleChangedEvent]]LocaleChangedEvent
|Запускается, когда пользователь выбирает другую локаль.

|[[LoginEvent]]LoginEvent
|Запускается, когда пользователь отправляет введённые учетные данные.

|[[RememberMeChangedEvent]]RememberMeChangedEvent
|Вызывается при изменении состояния флажка *Запомнить меня*.

|[[localeItemLabelGenerator]]`localeItemLabelGenerator`
|Предоставляет метку, отображаемую для каждого языкового стандарта в селекторе.
|===

== Элементы

`loginForm` может содержать элементы `form`, `errorMessage` и `additionalInformation`. Элемент `form` задаёт подписи и текст кнопки, `errorMessage` — содержимое при ошибке аутентификации, а `additionalInformation` — дополнительное содержимое под формой.
