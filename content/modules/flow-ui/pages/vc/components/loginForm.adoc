[[basics]]
== 基本用法

基本的 `loginForm` 包含用户名和密码字段以及一个登录按钮。还可以显示地区语言选择器、*记住我* 复选框以及 *忘记密码* 按钮。

[[remember-me]]
=== 记住我

*Remember me* 选项保存一个持久化的浏览器 token，因此即使 HTTP 会话过期或应用程序重启，这个保存的认证会话依然有效。如果有其他 UI 逻辑需要对这个选项的更改做出响应，可以在认证时从 `LoginEvent` 中读取选择状态并使用 <<RememberMeChangedEvent,RememberMeChangedEvent>> 事件。

请参考 https://docs.spring.io/spring-security/reference/servlet/authentication/rememberme.html[Spring Security Remember-Me 文档^] 了解底层的认证逻辑。

== XML 内部元素

一个 `loginForm` 可以包含 `form`、`errorMessage` 和 `additionalInformation` 作为其内部元素。`form` 元素定义标签和按钮文本，`errorMessage` 定义认证失败消息，`additionalInformation` 在表单下方添加辅助内容。
