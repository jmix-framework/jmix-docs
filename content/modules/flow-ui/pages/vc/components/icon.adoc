= icon 图标

`icon` 展示图标集的一个图形。有两个内置的图标集：Vaadin 和 Lumo。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`icon`

|Java 类
|`Icon`
|===

[[icon-sets]]
== 图标集

框架内置两套图标集：Vaadin 和 Lumo。通过图表名称的前缀区分，如果没添加前缀，则默认使用 Vaadin 图标集。

[source, xml, indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/icon/icon-view.xml[tags=icon-sets]
----

[[embedding]]
== 带图标的组件

图标可以是其他组件的一部分。参考在 xref:vc/components/button.adoc[button] 组件中使用图标的示例。

|名称

|—

|[[icon]]`icon`
|设置图标。
|—

|[[size]]`size`
