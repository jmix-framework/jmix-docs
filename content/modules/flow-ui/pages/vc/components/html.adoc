= html

`html` 渲染原生 HTML，内容可由字符串、CDATA 或文件提供。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`html`

|Java 类
|`Html`
|===

[[basics]]
== 基本用法

该元素用于在 XML 中嵌入 HTML。支持单独的 HTML 元素或 HTML 代码块。HTML 代码中，只能包含一个根元素，例如，`<header>`、`<footer>`、`<main>` 或 `<div>`。根元素内可以有任意个 `<div>` 元素用于显示内容。

CAUTION: 开发者需要确保 HTML 内容的清洁，在通过组件展示给用户之前，需要删除其中的危险代码。原始内容直接展示给用户用可能会造成跨站脚本攻击。

HTML 代码也可以用下列方法之一通过文件提供。

[[static-resource]]
== 静态资源内容

文件可以由应用程序静态托管。假设文件位于：
`/src/main/resources/META-INF/resources/html/html-file.html`，则可以这样使用：

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/html/htmlcomponent/html-component.xml[tags=file-content]
----

NOTE: 默认情况下，静态内容托管在 classpath 的 `/static`、`/public`、`/resources` 或 `/META-INF/resources` 目录。详情参考： https://docs.spring.io/spring-boot/docs/current/reference/html/web.html#web.servlet.spring-mvc.static-content[Spring Boot 文档^]。

== XML 属性

下面是 `html` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[content]]`content`
|指定组件需要渲染的 HTML 内容，可以是消息包内的键值或者 XML 中的 CDATA 数据。
|—

|[[file]]`file`
|指定获取 HTML 内容的文件路径。
|—
|===
