= menuFilterField 菜单过滤器 

`menuFilterField` 组件对通过菜单的文本对主菜单项进行过滤。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`menuFilterField`

|Java 类
|`MenuFilterField`
|===

[[basics]]
== 基本用法

将 `menuFilterField` 放在主视图中，并设置 `menu` 属性为需要过滤的 `listMenu` 的 ID。当用户输入时，组件根据配置的 `filterMode` 对菜单项进行过滤：

<1> 指向 `listMenu` 组件，提供需要过滤的菜单。

NOTE: 目前暂不支持对 xref:flow-ui:vc/components/horizontalMenu.adoc[horizontalMenu] 进行过滤。

[[theme-variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`align-left`
|字段值左对齐。
|Aura, Lumo

|`align-center`
|字段值居中对齐。
|Aura, Lumo

|`align-right`
|字段值右对齐。
|Aura, Lumo

|`align-start`
|根据当前文本方向，将字段值向起始侧对齐。
|Aura

|`align-end`
|根据当前文本方向，将字段值向末尾侧对齐。
|Aura

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo

|`small`
|组件更小。
|Aura, Lumo
|===

[[attributes]]
== XML 属性

下面是 `menuFilterField` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[filterMode]]`filterMode`
|匹配时是否大小写敏感。
|`CASE_INSENSITIVE`

|[[menu]]`menu`
|指向需要通过 `listMenu` 过滤的菜单。
|—

|[[clearButtonVisible]]`clearButtonVisible`
|是否显示一个清除当前值的按钮。
|`false`

|[[autoselect]]`autoselect`
|当输入组件获得焦点时，是否自动选中内容。
|`false`
|===
