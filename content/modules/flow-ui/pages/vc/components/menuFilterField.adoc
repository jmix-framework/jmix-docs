= menuFilterField

Компонент `menuFilterField` фильтрует пункты главного меню по текстовым подписям.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`menuFilterField`

|Java-класс
|`MenuFilterField`
|===

== Обзор

[cols="a", options="autowidth", frame=all, grid=none, align=center]
|===
|image::visual-components/components/menuFilterField.png[Поле фильтра меню, align="center", width="961"]
|===

[[basics]]
== Основы

Разместите `menuFilterField` на главном экране и укажите в обязательном атрибуте `menu` идентификатор фильтруемого `listMenu`. По мере ввода поле ограничивает видимые пункты меню в соответствии с настроенным `filterMode`:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/main/main-view.xml[tags=menuFilterField]
----
<1> Ссылается на компонент `listMenu`, который предоставляет элементы для фильтрации.

NOTE: Компонент не поддерживает фильтрацию xref:flow-ui:vc/components/horizontalMenu.adoc[horizontalMenu].

[[theme-variants]]
== Варианты темы

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы настроить внешний вид компонента.

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`align-left`
|Выравнивает значение поля по левому краю.
|Aura, Lumo

|`align-center`
|Выравнивает значение поля по центру.
|Aura, Lumo

|`align-right`
|Выравнивает значение поля по правому краю.
|Aura, Lumo

|`align-start`
|Выравнивает значение поля по начальной стороне с учетом текущего направления текста.
|Aura

|`align-end`
|Выравнивает значение поля по конечной стороне с учетом текущего направления текста.
|Aura

|`helper-above-field`
|Размещает вспомогательный текст над полем, под меткой.
|Aura, Lumo

|`small`
|Уменьшает размер компонента.
|Aura, Lumo
|===

[[attributes]]
== Атрибуты

`menuFilterField` имеет следующие уникальные атрибуты:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[filterMode]]`filterMode`
|Определяет, учитывается ли при сопоставлении регистр.
|`CASE_INSENSITIVE`

|[[menu]]`menu`
|Ссылается на фильтруемый компонент `listMenu`.
|—

|[[clearButtonVisible]]`clearButtonVisible`
|Отображает кнопку очистки текущего значения.
|`false`

|[[autoselect]]`autoselect`
|Выделяет всё значение при получении полем фокуса.
|`false`
|===
