= markdown

`markdown` 组件将 Markdown 内容渲染为经过清理的 HTML。

`markdown` 组件支持基本的文本格式、列表、链接以及其他常见的 Markdown 特性。下面的示例中，通过内部的 `content` 元素提供源文本：

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/markdowncomponents/markdown/markdown.xml[tags=content-element]
----

IMPORTANT: 避免在 `content` 元素内部的行首添加空格。Markdown 语法对缩进敏感，多余的空格可能会改变标题、列表和代码块的显示效果。

有关 Markdown 的语法，请参考 https://www.markdownguide.org/basic-syntax/[Markdown 指南^]。
