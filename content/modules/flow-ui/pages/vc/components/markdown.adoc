Компонент `markdown` поддерживает базовое форматирование текста, списки, ссылки и другие распространённые возможности Markdown. В следующем примере исходный текст передаётся через вложенный элемент `content`:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/markdowncomponents/markdown/markdown.xml[tags=content-element]
----

IMPORTANT: Не добавляйте пробелы в начале строк внутри элемента `content`. Синтаксис Markdown учитывает отступы, поэтому лишние пробелы могут изменить отображение заголовков, списков и блоков кода.

Подробную информацию о синтаксисе Markdown см. в документе https://www.markdownguide.org/basic-syntax/[Markdown Guide^].
