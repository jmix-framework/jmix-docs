[[itemsPerPageVisible]]
`simplePagination` 有一个特殊的 `comboBox` 提供选项可以限制每页展示的条数。设置 `itemsPerPageVisible` 属性为 `true` 可以显示。默认值为 `false`。

该列表的默认值通过 xref:flow-ui:ui-properties.adoc#jmix.ui.component.pagination-items-per-page-items[jmix.ui.component.pagination-items-per-page-items] 属性配置。

[[itemsPerPageItems]]
也可以通过 `itemsPerPageItems` 属性配置自定义的选项列表。属性值必须是逗号分隔的选项：

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/simplepagination/itemsperpage/simple-pagination-items-per-page.xml[tags=items-per-page]
----

小于等于 `0` 的选项会被忽略。大于实体 <<max-fetch-size,最大加载数>> 的选项会用该值替换。

----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/simplepagination/itemsperpage/simple-pagination-items-per-page.xml[tags=items-per-page]

[[itemsPerPageUnlimitedItemVisible]]
`itemsPerPageUnlimitedItemVisible` 属性设置是否在每页显示数量的下拉列表中显示无限制（null）选项。默认值为 `true`。

当在 `comboBox` 中选择 null 选项时，组件会尝试在当前最大加载数的限制下加载所有数据。

[[max-fetch-size]]
[NOTE]
====
所有实体的最大加载数是通过 xref:flow-ui:ui-properties.adoc#jmix.ui.default-max-fetch-size[jmix.ui.default-max-fetch-size] UI 属性定义。默认值为 10000。某些特定实体可能有不同的加载要求，可以用 xref:flow-ui:ui-properties.adoc#jmix.ui.entity-max-fetch-size[jmix.ui.entity-max-fetch-size] 设置。
====

[[items-per-page-empty-label]]
== 空项标签

当 <<itemsPerPageUnlimitedItemVisible,itemsPerPageUnlimitedItemVisible>>=`"true"` 时，下拉列表会显示一个空项，用来加载所有数据（受最大获取量限制）。默认情况下，此项显示为空字符串。

可以通过向 xref:localization:message-bundles.adoc[消息包] 添加消息键值自定义此项的标签：

[source,properties]
----
pagination.itemsPerPage.emptySelectionCaption=Show all
----

[NOTE]
====
如果消息包中存在消息键值 `pagination.itemsPerPage.emptySelectionCaption`，则其值将显示在下拉列表中，而不是显示为空项。如果未找到该键值，则该项显示为空。
====

== XML 属性

下面是 `simplePagination` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[autoLoad]]`autoLoad`
|是否自动加载数据的数量。
|—

|[[dataLoader]]`dataLoader`
|将 `simplePagination` 与 `dataLoader` 关联。
|—

|`itemsPerPageDefaultValue`
|设置每页数量的默认值。参考 <<items-per-page,每页数量>>。
|—

|`itemsPerPageItems`
|设置每页显示数量中的配置。参考 <<items-per-page,每页数量>>。
|—

|`itemsPerPageUnlimitedItemVisible`
|每页数量列表中是否显示一个加载全部数据的选项。参考 <<items-per-page,每页数量>>。
|—

|`itemsPerPageVisible`
|是否显示每页数量的选择器。参考 <<items-per-page,每页数量>>。
|—
|===
