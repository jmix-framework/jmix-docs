= simplePagination
:page-aliases: vcl/components/pagination.adoc, vcl/components/simple-pagination.adoc

`simplePagination` загружает данные на страницы и предоставляет элементы управления для навигации между ними.

[[itemsPerPageVisible]]
Компонент `simplePagination` содержит специальный `comboBox` с вариантами ограничения количества элементов на странице. Для его отображения установите атрибут `itemsPerPageVisible` в значение `true`. По умолчанию: `false`.

Значение этого списка по умолчанию задаётся свойством xref:flow-ui:ui-properties.adoc#jmix.ui.component.pagination-items-per-page-items[jmix.ui.component.pagination-items-per-page-items].

[[itemsPerPageItems]]
Вы можете настроить собственный список вариантов через атрибут `itemsPerPageItems`. Значение должно быть списком чисел, разделенных запятыми:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/simplepagination/itemsperpage/simple-pagination-items-per-page.xml[tags=items-per-page]
----

Варианты со значением, меньшим или равным `0`, игнорируются. Варианты, превышающие <<max-fetch-size,максимально допустимый размер выборки>> сущности, заменяются на максимальное значение.

[[itemsPerPageDefaultValue]]
Для установки значения по умолчанию используйте атрибут `itemsPerPageDefaultValue`:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/simplepagination/itemsperpage/simple-pagination-items-per-page.xml[tags=items-per-page]
----

[[itemsPerPageUnlimitedItemVisible]]
Атрибут `itemsPerPageUnlimitedItemVisible` управляет отображением варианта `null` в `comboBox`. По умолчанию: `true`.

При выборе null-варианта компонент попытается загрузить все данные в пределах ограничения максимально допустимого размера выборки.

[[max-fetch-size]]
[NOTE]
====
Максимально допустимый размер выборки для всех сущностей определяется свойством xref:flow-ui:ui-properties.adoc#jmix.ui.default-max-fetch-size[jmix.ui.default-max-fetch-size] (по умолчанию 10000). Для конкретной сущности можно задать отдельное ограничение через xref:flow-ui:ui-properties.adoc#jmix.ui.entity-max-fetch-size[jmix.ui.entity-max-fetch-size].
====

[[items-per-page-empty-label]]
== Надпись пустого элемента

Когда <<itemsPerPageUnlimitedItemVisible,itemsPerPageUnlimitedItemVisible>>=`"true"`, в выпадающем списке отображается пустой элемент, который позволяет загрузить все данные (ограниченные максимальным размером выборки). По умолчанию этот элемент отображается как пустая строка.

Вы можете настроить надпись для этого пустого элемента, добавив ключ сообщения в ваш xref:localization:message-bundles.adoc[пакет сообщений]:

[source,properties]
----
pagination.itemsPerPage.emptySelectionCaption=Show all
----

[NOTE]
====
Если ключ сообщения `pagination.itemsPerPage.emptySelectionCaption` присутствует в пакете сообщений, его значение будет отображаться вместо пустого элемента в выпадающем списке. Если ключ не найден, элемент остается пустым.
====

== Атрибуты

`simplePagination` имеет следующие уникальные атрибуты:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[autoLoad]]`autoLoad`
|Атрибут `autoLoad` определяет, должно ли количество элементов загружаться автоматически.
|—

|[[dataLoader]]`dataLoader`
|Чтобы создать `simplePagination`, связанный с данными, используйте атрибут `dataLoader`.
|—

|`itemsPerPageDefaultValue`
|Устанавливает значение по умолчанию для количества элементов на странице. См. <<items-per-page,Элементов на странице>>.
|—

|`itemsPerPageItems`
|Устанавливает количество элементов на странице. См. <<items-per-page,Элементов на странице>>.
|—

|`itemsPerPageUnlimitedItemVisible`
|Определяет, включает ли список элементов на странице возможность загрузки всех доступных элементов. См. <<items-per-page,Элементов на странице>>.
|—

|`itemsPerPageVisible`
|Управляет отображением селектора элементов на странице. См. <<items-per-page,Элементов на странице>>.
|—
|===

== Обработчики

`simplePagination` имеет следующие уникальные обработчики:

[cols="2,5", options="header"]
|===
|Имя
|Описание

|[[AfterRefreshEvent]]`AfterRefreshEvent`
|`io.jmix.flowui.component.PaginationComponent.AfterRefreshEvent` запускается после обновления данных.

|[[BeforeRefreshEvent]]`BeforeRefreshEvent`
|`io.jmix.flowui.component.PaginationComponent.BeforeRefreshEvent` запускается перед обновлением данных, когда пользователь нажимает кнопку «Далее», «Предыдущее» и т. д.

|[[totalCountDelegate]]`totalCountDelegate`
|Устанавливает делегат, который используется для получения общего количества элементов.
|===
