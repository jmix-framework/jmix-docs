= horizontalMenu - 水平菜单
:page-aliases: vcl/components/app-menu.adoc

`horizontalMenu` 组件展示包含层级下拉子菜单的水平菜单栏。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`horizontalMenu`

|Java 类
|`HorizontalMenu`
|===

[[basics]]
== 基本用法

在 XML 中添加组件：

[source, xml, indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/horizontalmenu/horizontal-menu-view.xml[tags=horizontalMenu]
----

也可以在 Java 控制器中创建并添加组件：

[source, java, indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/horizontalmenu/HorizontalMenuView.java[tags=horizontalMenu]
----

== XML 属性

下面是 `horizontalMenu` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[loadMenuConfig]]`loadMenuConfig`
|控制是否从 xref:flow-ui:menu-config.adoc[菜单配置] 中加载菜单结构。
|`true`
|===
