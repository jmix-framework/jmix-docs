= badge 徽标

[.since]
Jmix 3.1+

`badge` 用于展示简短的信息，例如某个状态、一个计数或者一个小标签。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`badge`

|Java 类
|`Badge`
|===

[[data-binding]]
== 数据感知的 `badge`

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/badge-dataaware" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

徽标可以显示一个实体的属性值。通过 xref:vc/common-attributes.adoc#dataContainer[dataContainer] 和 xref:vc/common-attributes.adoc#property[property] 属性绑定 xref:data/data-containers.adoc[数据容器]：

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/badge/dataaware/badge-dataaware.xml[tags=data-binding]
----

绑定是只读的。徽标以文本形式显示属性值，并在值发生变化时更新。值会根据数据类型进行格式化。例如，枚举值显示为本地化标题，而 `null` 值显示一个空徽标。

如果当前用户无权查看该属性，则徽标不显示。

[[numbers]]
== 数字

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/badge-theme-variant" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

<<number,number>> 属性在徽标上显示一个数字，例如未读消息的数量。如果徽标既有文本又有数字，则会同时显示。

`number-only` 样式仅显示数字。与 `icon-only` 一样，最好也同时设置文本：

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/badge/themevariant/badge-theme-variant.xml[tags=number-only]
----

在视图控制器中，使用 `setNumber()` 方法更改数字，使用 `setNumber(null)` 移除。

屏幕阅读器只读取徽标的内容。单独的数字可能会让用户感到困惑，因此需设置一个说明计数内容的文本。如果在视图打开时数字发生变化，请将 <<ariaRole,ariaRole>> 设置为 `status`，屏幕阅读器将会朗读新值。

[[theme-variants]]
== 样式版本

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.io/ui-samples/sample/badge-theme-variant" class="live-demo-btn" target="_blank">在线示例</a>
</div>
++++

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置样式。可以同时配置多个样式，例如 `themeNames="success filled"`。在视图控制器中，使用 `addThemeVariants()` 方法，参数为 `BadgeVariant` 枚举类型。

image::visual-components/components/badge-visual-variants.png["Badges with the filled, icon-only, number-only and dot variants", align="center", width="191"]

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`success`, `warning`, `error`
|应用语义颜色。
|Aura, Lumo

|`contrast`
|应用中性高对比色。
|Lumo

|`filled`
|使用纯色背景而不是淡色背景，表示更多的强调。可以与所有其他样式结合使用。
|Aura, Lumo

|`small`
|尺寸较小。
|Aura, Lumo

|`icon-only`
|仅显示图标。参考 <<icons>>。
|Aura, Lumo

|`number-only`
|仅显示数字。参考 <<numbers>>.
|Aura, Lumo

|`dot`
|将徽标显示为一个小点，隐藏所有内容。
|Aura, Lumo
|===

[[attributes]]
== XML 属性

下面是 `badge` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[ariaRole]]`ariaRole`
|设置屏幕阅读器使用的 ARIA 角色。例如，`status`（徽标内容发生变化时朗读）。参考 <<numbers>>。
|—

|[[icon]]`icon`
|设置文本前显示的图标。参考 <<icons>>。
|—

|[[number]]`number`
|设置徽标显示的数字。参考 <<numbers>>。
|—

|[[themeNames]]`themeNames`
|应用 <<theme-variants>> 中列举的一个或多个样式。
|—
|===
