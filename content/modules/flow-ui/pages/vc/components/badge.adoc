= badge

[.since]
Начиная с Jmix 3.1

`badge` отображает небольшой фрагмент информации, например статус, счётчик или метку.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`badge`

|Java-класс
|`Badge`
|===

[[basics]]

Атрибут xref:vc/common-attributes.adoc#text[text] задаёт надпись на бейдже. Делайте её короткой: одно или два слова. <<theme-variants,Варианты темы>> `success`, `warning` и `error` задают цвет бейджа. Без варианта бейдж использует акцентный цвет темы.

[source,xml,indent=0]
----

----

image::visual-components/components/badge-basics.png["Бейджи с цветом по умолчанию и цветами success, warning и error", align="center", width="322"]

Бейджи похожи на кнопки, но не реагируют на действия пользователя.

[[data-binding]]
== `badge`, связанный с данными

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/badge-dataaware" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Бейдж может показывать значение атрибута сущности. Свяжите его с xref:data/data-containers.adoc[контейнером данных] с помощью атрибутов xref:vc/common-attributes.adoc#dataContainer[dataContainer] и xref:vc/common-attributes.adoc#property[property]:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/badge/dataaware/badge-dataaware.xml[tags=data-binding]
----

Связь работает только на чтение. Бейдж показывает значение атрибута как текст и обновляет его при изменении значения. Значение форматируется в соответствии с его типом данных. Например, значение перечисления показывается как его локализованное название, а значение `null` — как пустой бейдж.

Если у текущего пользователя нет прав на просмотр атрибута, бейдж скрыт.

[[numbers]]
== Число

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/badge-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Атрибут <<number,number>> показывает число в бейдже, например количество непрочитанных сообщений. Если у бейджа есть и текст, и число, он показывает и то, и другое.

Вариант `number-only` показывает только число. Как и для `icon-only`, задайте текст для программ чтения с экрана:

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/badge/themevariant/badge-theme-variant.xml[tags=number-only]
----

В контроллере экрана используйте метод `setNumber()`, чтобы изменить число, и `setNumber(null)`, чтобы убрать его.

Программы чтения с экрана читают только содержимое бейджа. Одно число может запутать пользователей, поэтому задайте текст, который говорит, что именно подсчитано. Если число меняется, пока экран открыт, установите для <<ariaRole,ariaRole>> значение `status`, и программы чтения с экрана будут озвучивать новое значение.

[[theme-variants]]
== Варианты темы

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/badge-theme-variant" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Используйте атрибут xref:vc/common-attributes.adoc#themeNames[themeNames], чтобы применить варианты. Можно сочетать несколько вариантов, например `themeNames="success filled"`. В контроллере экрана используйте метод `addThemeVariants()` с перечислением `BadgeVariant`.

image::visual-components/components/badge-visual-variants.png["Бейджи с вариантами filled, icon-only, number-only и dot", align="center", width="191"]

[cols="1,4,1", options="header"]
|===
|Вариант
|Описание
|Поддерживается в

|`success`, `warning`, `error`
|Применяет смысловой цвет.
|Aura, Lumo

|`contrast`
|Применяет нейтральный высококонтрастный цвет.
|Lumo

|`filled`
|Использует сплошной фон вместо полупрозрачного, чтобы привлечь больше внимания. Можно сочетать со всеми остальными вариантами.
|Aura, Lumo

|`small`
|Делает бейдж меньше.
|Aura, Lumo

|`icon-only`
|Показывает только иконку. См. <<icons>>.
|Aura, Lumo

|`number-only`
|Показывает только число. См. <<numbers>>.
|Aura, Lumo

|`dot`
|Показывает бейдж в виде маленькой точки и скрывает всё его содержимое.
|Aura, Lumo
|===

[[attributes]]
== Атрибуты

xref:vc/common-attributes.adoc[Общие атрибуты] служат одной и той же цели для всех компонентов.
Следующие атрибуты специфичны для `badge`:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[ariaRole]]`ariaRole`
|Задаёт ARIA-роль бейджа, которую используют программы чтения с экрана. Например, `status` заставляет программы чтения с экрана озвучивать изменения содержимого бейджа. См. <<numbers>>.
|—

|[[icon]]`icon`
|Задаёт иконку, отображаемую перед текстом. См. <<icons>>.
|—

|[[number]]`number`
|Задаёт число, отображаемое в бейдже. См. <<numbers>>.
|—

|[[themeNames]]`themeNames`
|Применяет один или несколько вариантов, перечисленных в разделе <<theme-variants>>.
|—
|===
