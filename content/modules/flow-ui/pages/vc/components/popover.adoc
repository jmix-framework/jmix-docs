= popover

[.since]
Начиная с Jmix 3.1

`popover` — всплывающее окно, которое открывается рядом с другим компонентом, называемым целевым. В отличие от xref:vc/components/tooltip.adoc[tooltip], всплывающее окно может содержать любые компоненты: поля, кнопки, контейнеры. Пользователь может с ними работать.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`popover`

|Java-класс
|`Popover`
|===

[source,xml,indent=0]
----

----

image::visual-components/components/popover-basics.png[Всплывающее окно под целевым компонентом, align="center", width="400"]

Всплывающее окно не занимает места среди других компонентов экрана, а его содержимое видно, только когда окно открыто. По умолчанию окно открывается, когда пользователь нажимает на целевой компонент. Окно закрывается при повторном нажатии на целевой компонент, при нажатии за пределами окна или клавишей *Esc*.

Всплывающее окно и его содержимое — обычные компоненты экрана. Их можно инжектировать в контроллер экрана и подписываться на их события. В примере выше кнопка во всплывающем окне закрывает его методом `close()`:

[[about-target]]
== Целевой компонент

Атрибут `target` содержит идентификатор компонента того же экрана или фрагмента. Целевой компонент можно объявить как до, так и после всплывающего окна. Если компонента с таким идентификатором нет, экран не откроется и выбросит `GuiDevelopmentException`.

Атрибут `target` необязателен. Если целевой компонент создаётся в контроллере экрана, объявите всплывающее окно без `target`:

[[opening-and-closing]]
== Открытие и закрытие

Атрибуты `openOnClick`, `openOnHover` и `openOnFocus` определяют, какие действия пользователя открывают всплывающее окно. По умолчанию включён только `openOnClick`. Можно включить несколько атрибутов одновременно.

[[open-on-hover]]
*Открытие при наведении*

Следующее всплывающее окно открывается, когда пользователь наводит курсор мыши на аватар:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/popover/popover-view.xml[tags=hover]
----

Окно закрывается, когда курсор покидает и целевой компонент, и само окно. Поэтому пользователь может перевести курсор на окно и нажать на ссылку в нём.

Атрибут `hoverDelay` задаёт задержку перед открытием окна, а `hideDelay` — перед закрытием. Обе задержки указываются в миллисекундах и по умолчанию равны 500.

[[closing]]
*Закрытие*

Как бы ни было открыто всплывающее окно, закрыть его можно нажатием за его пределами или клавишей *Esc*. Чтобы отключить это поведение, установите атрибутам `closeOnOutsideClick` и `closeOnEsc` значение `false`.

[[about-positioning]]
== Положение

Атрибут `position` определяет, где открывается всплывающее окно относительно целевого компонента: сверху (`TOP_START`, `TOP`, `TOP_END`), снизу (`BOTTOM_START`, `BOTTOM`, `BOTTOM_END`), перед ним (`START_TOP`, `START`, `START_BOTTOM`) или после него (`END_TOP`, `END`, `END_BOTTOM`). По умолчанию используется `BOTTOM`. Если с этой стороны не хватает места, окно открывается с противоположной стороны.

[[modal-popover]]
== Модальное всплывающее окно

Модальное всплывающее окно работает как небольшой диалог рядом с целевым компонентом. Пока оно открыто, пользователь не может работать с остальным интерфейсом, а фокус остаётся внутри окна. Установите `modal="true"`, чтобы сделать окно модальным, и `backdropVisible="true"`, чтобы затемнить интерфейс за ним.

По умолчанию модальное окно закрывается при нажатии за его пределами. В следующем примере задан `closeOnOutsideClick="false"`, поэтому окно остаётся открытым, пока пользователь не нажмёт одну из кнопок в нём:

[[size-and-styling]]
== Размер и стили

Атрибуты `width` и `height` задают размер содержимого всплывающего окна. Используйте абсолютные единицы, например `px` или `em`: с относительными единицами, такими как `%`, результат непредсказуем. Без этих атрибутов окно принимает размер своего содержимого. Атрибуты `minWidth`, `maxWidth`, `minHeight` и `maxHeight` не поддерживаются.

Всплывающее окно отображается в отдельном слое поверх экрана, поэтому атрибут `css` не поддерживается, а метод `getStyle()` в Java выбрасывает `UnsupportedOperationException`. Чтобы задать стиль окна, добавьте ему имена классов атрибутом xref:vc/common-attributes.adoc#classNames[classNames] и опишите стили в теме приложения.

|По умолчанию

|[[closeOnOutsideClick]]`closeOnOutsideClick`

|`true`

|[[focusDelay]]`focusDelay`
|Задаёт задержку в миллисекундах перед открытием всплывающего окна, когда целевой компонент получает фокус. См. <<open-on-focus,Открытие при получении фокуса>>.

|[[height]]`height`

|—

|[[hideDelay]]`hideDelay`
|Задаёт задержку в миллисекундах перед закрытием всплывающего окна, когда курсор покидает целевой компонент и окно. Если целевой компонент теряет фокус, окно закрывается сразу. См. <<open-on-hover,Открытие при наведении>>.
|`500`

|[[hoverDelay]]`hoverDelay`
|Задаёт задержку в миллисекундах перед открытием всплывающего окна, когда курсор наводится на целевой компонент. См. <<open-on-hover,Открытие при наведении>>.
|`500`

|[[modal]]`modal`
|Если `true`, пока всплывающее окно открыто, пользователь не может работать с остальным интерфейсом. См. <<modal-popover,Модальное всплывающее окно>>.
|`false`

|[[openOnClick]]`openOnClick`
|Если `true`, нажатие на целевой компонент открывает всплывающее окно. См. <<opening-and-closing,Открытие и закрытие>>.
|`true`

|[[openOnFocus]]`openOnFocus`
|Если `true`, всплывающее окно открывается, когда целевой компонент получает фокус. См. <<open-on-focus,Открытие при получении фокуса>>.
|`false`

|[[openOnHover]]`openOnHover`
|Если `true`, всплывающее окно открывается при наведении курсора на целевой компонент. См. <<open-on-hover,Открытие при наведении>>.
|`false`

|[[position]]`position`
|Задаёт положение всплывающего окна относительно целевого компонента. См. <<about-positioning,Положение>>.
|`BOTTOM`

|[[tabFocusEnabled]]`tabFocusEnabled`
|Если `true`, пользователь может перевести фокус с целевого компонента на содержимое всплывающего окна клавишей *Tab*. Если `false`, *Tab* пропускает окно. На модальные окна атрибут не влияет.

|[[target]]`target`
|Задаёт идентификатор целевого компонента. См. <<about-target,Целевой компонент>>.

|[[themeNames]]`themeNames`

|—

|[[width]]`width`
|Задаёт ширину содержимого всплывающего окна. См. <<size-and-styling,Размер и стили>>.
