= popover 浮窗

[.since]
Jmix 3.1+

`popover` 是一个浮窗，在另一个组件（称为目标）旁边打开。与 xref:vc/components/tooltip.adoc[tooltip] 不同，popover 可以包含任何组件，例如字段、按钮和布局，用户可以与之交互。

|XML 元素
|`popover`

|Java 类
|`Popover`
|===

[[opening-and-closing]]
== 打开和关闭

`openOnClick`、`openOnHover` 和 `openOnFocus` 属性定义用户的哪些操作会打开 popover。默认仅启用 `openOnClick`。也可以启用多种方式。

[[closing]]
*关闭*

无论 popover 如何打开，点击其外部和 *Esc* 键都会将其关闭。将 `closeOnOutsideClick` 和 `closeOnEsc` 属性设置为 `false` 可禁用此行为。

[[about-positioning]]
== 定位

`position` 属性定义浮窗相对于目标的打开位置：在其上方（`TOP_START`、`TOP`、`TOP_END`）、下方（`BOTTOM_START`、`BOTTOM`、`BOTTOM_END`）、左方（`START_TOP`、`START`、`START_BOTTOM`）或右方（`END_TOP`、`END`、`END_BOTTOM`）。默认为 `BOTTOM`。如果该侧空间不足，浮窗会在对侧打开。

[[modal-popover]]
== 模态浮窗

模态浮窗（设置 `modal="true"`）显示为目标旁边的小对话框。当其打开时，用户无法与 UI 的其余部分交互，焦点保持在浮窗中。设置 `backdropVisible="true"` 使背后的 UI 变暗。

[[size-and-styling]]
== 尺寸和样式

`width` 和 `height` 属性设置浮窗内容的大小。最好使用绝对单位，例如 `px` 或 `em`。相对单位（如 `%`）会产生不可预知的结果。没有配置这些属性时，浮窗遵循其内容的大小。不支持 `minWidth`、`maxWidth`、`minHeight` 和 `maxHeight` 属性。

由于浮窗显示在视图布局之外，因此不支持 `css` 属性。在 Java 中，`getStyle()` 会抛出 `UnsupportedOperationException`。如需设置浮窗的样式，请使用 xref:vc/common-attributes.adoc#classNames[classNames] 属性添加类名，在应用程序主题中定义样式。

[[attributes]]
== XML 属性

下面是 `popover` 的特殊属性：

[cols="2,5,1", options="header"]
|===
|名称
|描述
|默认值

|[[ariaRole]]`ariaRole`
|设置 popover 的 ARIA 角色，屏幕阅读器使用该角色。
|`dialog`

|[[autofocus]]`autofocus`
|当为 `true` 时，popover 打开时其内容时获得焦点。模态 popover 默认执行此操作。
|`false`

|[[backdropVisible]]`backdropVisible`
|当为 `true` 时，将浮窗背后的 UI 变暗。请参见 <<modal-popover,模态浮窗>>。
|`false`

|[[closeOnEsc]]`closeOnEsc`
|当为 `true` 时，*Esc* 键关闭 popover。请参见 <<closing,关闭>>。
|`true`

|[[closeOnOutsideClick]]`closeOnOutsideClick`
|当为 `true` 时，点击 popover 外部会将其关闭。请参见 <<closing,关闭>>。
|`true`

|[[focusDelay]]`focusDelay`
|设置当目标获得焦点时 popover 打开前的延迟，单位为毫秒。请参见 <<open-on-focus,获得焦点时打开>>。
|`500`

|[[height]]`height`
|设置 popover 内容的高度。请参见 <<size-and-styling,尺寸和样式>>。
|—

|[[hideDelay]]`hideDelay`
|设置当指针离开目标和 popover 时浮窗关闭前的延迟，单位为毫秒。当目标失去焦点时，popover 立即关闭。请参见 <<open-on-hover,悬停时打开>>。
|`500`

|[[hoverDelay]]`hoverDelay`
|设置当指针移到目标上时 popover 打开前的延迟，单位为毫秒。请参见 <<open-on-hover,悬停时打开>>。
|`500`

|[[modal]]`modal`
|当为 `true` 时，popover 打开期间用户无法与 UI 的其余部分交互。请参见 <<modal-popover,模态 Popover>>。
|`false`

|[[openOnClick]]`openOnClick`
|当为 `true` 时，点击目标打开 popover。请参见 <<opening-and-closing,打开和关闭>>。
|`true`

|[[openOnFocus]]`openOnFocus`
|当为 `true` 时，目标获得焦点时 popover 打开。请参见 <<open-on-focus,获得焦点时打开>>。
|`false`

|[[openOnHover]]`openOnHover`
|当为 `true` 时，指针移到目标上时 popover 打开。请参见 <<open-on-hover,悬停时打开>>。
|`false`

|[[position]]`position`
|设置 popover 相对于目标的位置。请参见 <<about-positioning,定位>>。
|`BOTTOM`

|[[tabFocusEnabled]]`tabFocusEnabled`
|当为 `true` 时，用户可以使用 *Tab* 键将焦点从目标移到 popover 内容。当为 `false` 时，*Tab* 会跳过 popover。对模态 popover 无效。
|`true`

|[[target]]`target`
|设置目标组件的 id。请参见 <<about-target,目标>>。
|—

|[[themeNames]]`themeNames`
|使用 <<variants,主题样式>> 中列出的一个或多个样式。
|—

|[[width]]`width`
|设置 popover 内容的宽度。请参见 <<size-and-styling,尺寸和样式>>。
|—
|===
