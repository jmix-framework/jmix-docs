= popover

[.since]
Since Jmix 3.1

`popover` is an overlay that opens next to another component, called the target. Unlike xref:vc/components/tooltip.adoc[tooltip], a popover can contain any components, such as fields, buttons and layouts, and users can work with them.

== Target

The `target` attribute contains the id of a component in the same view or fragment. The target can be declared before or after the popover. If there is no component with this id, the view fails to open with a `GuiDevelopmentException`.

[[closing]]
*Closing*

However the popover was opened, a click outside it and the *Esc* key close it. Set the `closeOnOutsideClick` and `closeOnEsc` attributes to `false` to turn this off.

[[position]]
== Position

The `position` attribute defines where the popover opens relative to the target: above (`TOP_START`, `TOP`, `TOP_END`), below (`BOTTOM_START`, `BOTTOM`, `BOTTOM_END`), before (`START_TOP`, `START`, `START_BOTTOM`) or after (`END_TOP`, `END`, `END_BOTTOM`) it. The default is `BOTTOM`. If there is not enough space on that side, the popover opens on the opposite side.

[[modal]]
== Modal Popover

A modal popover works as a small dialog next to its target. When it is open, users cannot interact with the rest of the UI, and the focus stays in the popover. Set `modal="true"` to make the popover modal and `backdropVisible="true"` to dim the UI behind it.

[[size-and-styling]]
== Size and Styling

The `width` and `height` attributes set the size of the popover content. Use absolute units, such as `px` or `em`. Relative units, such as `%`, give unexpected results. Without these attributes, the popover takes the size of its content. The `minWidth`, `maxWidth`, `minHeight` and `maxHeight` attributes are not supported.

The popover is shown outside the view layout, so it does not support the `css` attribute. In Java, `getStyle()` throws `UnsupportedOperationException`. To style a popover, add class names to it with the xref:vc/common-attributes.adoc#classNames[classNames] attribute and define the styles in the application theme.

[[attributes]]
== Attributes

The following attributes are specific to `popover`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[ariaRole]]`ariaRole`
|Sets the ARIA role of the popover, which screen readers use.
|`dialog`

|[[autofocus]]`autofocus`
|When `true`, the popover content receives focus when the popover opens. Modal popovers do this by default.
|`false`

|[[backdropVisible]]`backdropVisible`
|When `true`, the UI behind the popover is dimmed while the popover is open. See <<modal,Modal Popover>>.
|`false`

|[[closeOnEsc]]`closeOnEsc`
|When `true`, the *Esc* key closes the popover. See <<closing,Closing>>.
|`true`

|[[closeOnOutsideClick]]`closeOnOutsideClick`
|When `true`, a click outside the popover closes it. See <<closing,Closing>>.
|`true`

|[[focusDelay]]`focusDelay`
|Sets the delay in milliseconds before the popover opens when the target receives focus. See <<open-on-focus,Opening on Focus>>.
|`500`

|[[height]]`height`
|Sets the height of the popover content. See <<size-and-styling,Size and Styling>>.
|—

|[[hideDelay]]`hideDelay`
|Sets the delay in milliseconds before the popover closes when the pointer leaves the target and the popover. When the target loses focus, the popover closes at once. See <<open-on-hover,Opening on Hover>>.
|`500`

|[[hoverDelay]]`hoverDelay`
|Sets the delay in milliseconds before the popover opens when the pointer moves over the target. See <<open-on-hover,Opening on Hover>>.
|`500`

|[[modal-attribute]]`modal`
|When `true`, users cannot interact with the rest of the UI while the popover is open. See <<modal,Modal Popover>>.
|`false`

|[[openOnClick]]`openOnClick`
|When `true`, a click on the target opens the popover. See <<opening-and-closing,Opening and Closing>>.
|`true`

|[[openOnFocus]]`openOnFocus`
|When `true`, the popover opens when the target receives focus. See <<open-on-focus,Opening on Focus>>.
|`false`

|[[openOnHover]]`openOnHover`
|When `true`, the popover opens when the pointer moves over the target. See <<open-on-hover,Opening on Hover>>.
|`false`

|[[position-attribute]]`position`
|Sets the position of the popover relative to the target. See <<position,Position>>.
|`BOTTOM`

|[[tabFocusEnabled]]`tabFocusEnabled`
|When `true`, the user can move the focus from the target to the popover content with the *Tab* key. When `false`, *Tab* skips the popover. It has no effect on modal popovers.
|`true`

|[[target-attribute]]`target`
|Sets the id of the target component. See <<target,Target>>.
|—

|[[themeNames]]`themeNames`
|Applies one or more variants listed in <<variants,Theme Variants>>.
|—

|[[width]]`width`
|Sets the width of the popover content. See <<size-and-styling,Size and Styling>>.
|—
