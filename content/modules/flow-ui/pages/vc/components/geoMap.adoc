[[layer]]
== 图层

`GeoMap` 组件可以包含多个显示不同地理信息的图层。
初始化时，地图不包含任何图层。

地图扩展组件提供以下类型的图层：

* xref:maps:layers-sources.adoc#tile-layer[瓦片层] 显示预渲染的地图瓦片，瓦片在不同的缩放级别组织。
* xref:maps:layers-sources.adoc#image-layer[图像层] 显示静态图片或从网络图片服务（WMS）获取的图片。
* xref:maps:layers-sources.adoc#vector-layer[矢量层] 显示地图要素和几何图案。
* xref:maps:high-density-data-visualization.adoc#heatmap[热力图层] 将点要素渲染为热力图。

参考 xref:maps:layers-sources.adoc[图层和数据源] 了解每个图层支持的数据源和示例。

== 数据源

一个 xref:maps:layers-sources.adoc[源] 表示在地图组件渲染图层的数据。数据源提供定义地图图层内容和外观的空间信息。

地图扩展组件提供下列数据源类型：

* `TileLayer`：xref:maps:layers-sources.adoc#osm-source[`OsmSource`]、xref:maps:layers-sources.adoc#xyz-source[`XyzSource`] 和 xref:maps:layers-sources.adoc#wms-source[`WmsSource`]。
* `ImageLayer`：xref:maps:layers-sources.adoc#image-static-source[`ImageStaticSource`] 和 xref:maps:layers-sources.adoc#image-wms-source[`ImageWmsSource`]。
* `VectorLayer`：xref:maps:layers-sources.adoc#vector-source[`VectorSource`]、xref:maps:layers-sources.adoc#data-vector-source[`DataVectorSource`] 和 xref:maps:high-density-data-visualization.adoc#cluster-source[`ClusterSource`]。
* `HeatmapLayer`：xref:maps:high-density-data-visualization.adoc#heatmap[`HeatmapDataVectorSource`] 和 `VectorSource`。

参考 xref:maps:layers-sources.adoc[图层和数据源] 了解详细内容和示例。

[[view]]
== 视图

https://openlayers.org/en/v8.2.0/apidoc/module-ol_View-View.html[视图^] 定义地图显示的方式，包括中心点、缩放级别、旋转角度以及投影。其本质是当地图加载到用户界面时设置初始状态。

默认情况下，`geoMap` 显示一个世界地图，初始地理中心为 `(0,0)`。

[source,xml,indent=0]
----
include::maps:example$/maps-ex2/src/main/resources/com/company/mapssample/view/mapbasic/map-basic-view.xml[tags=mapView]
----

可以设置其他参数：

* `centerX` 定义地图初始地理中心的纬度。传递给 `org.locationtech.jts.geom.Coordinate` 对象。
* `centerY` 定义地图初始地理中心的经度。传递给 `org.locationtech.jts.geom.Coordinate` 对象。
* `maxZoom` - 设置视图的最大缩放级别。
//默认值为 28。详情请参见 https://openlayers.org/en/v8.1.0/apidoc/module-ol_View-View.html#setMaxZoom[setMaxZoom^]。
* `minZoom` - 设置视图的最小缩放级别。
//默认值为 0。详情请参见 https://openlayers.org/en/v8.1.0/apidoc/module-ol_View-View.html#setMinZoom[setMinZoom^]。
* `projection` 定义在地图上显示地理数据的坐标参考系（CRS）。将三维地球坐标转换为二维平面。常见的投影包括 `EPSG:3857`（Web 墨卡托）和 `EPSG:4326`（WGS 84）。默认投影为 https://epsg.io/3857[EPSG:3857^]。还可以设置 <<custom-projection,自定义投影>>。
* `rotation` - 设置视图的旋转角度，单位为弧度（正值为顺时针旋转，0 表示正北）。详情请参见 https://openlayers.org/en/v8.2.0/apidoc/module-ol_View-View.html#setRotation[setRotation^]。
* `zoom` 定义具体的缩放级别。缩放级别从 0 开始，表示最大的缩小视图，级别随着地图放大而逐渐增大。

[[extent]]
== 范围

https://openlayers.org/en/v8.2.0/apidoc/module-ol_extent.html#~Extent[范围（extent）^] 以坐标形式指定地图 <<view,视图>> 或特定 <<layer,图层>> 的地理边界，定义地图上的可见区域。

范围通常由最小（左上角）和最大（右下角）坐标值定义，形式为 [`minX`、`minY`、`maxX`、`maxY`]，表示该区域的边界框。

在 *Jmix UI* 结构面板或视图 XML 描述符中选择图层或 `mapView` 元素，然后点击组件属性面板中的 *Add* 按钮。从下拉列表中选择 *Extent*，并按下文所述配置 `minX`、`minY`、`maxX` 和 `maxY` 属性。

[[extent-constraint-options]]
=== 范围约束选项

默认情况下，当 `mapView` 有 `extent` 时，OpenLayers 会约束整个视口保持在该范围内。在响应式布局中，如果地图容器的宽高比与范围的宽高比不同，这可能会导致地图被放大。

使用 `mapView` 的下列属性调整此行为：

* `showFullExtent` - 允许缩小到足以显示整个配置的范围，即使容器的宽高比与之不同。默认值为 `false`。
* `constrainOnlyCenter` - 仅对视图中心使用范围约束，因此视口边缘可能会移出范围。默认值为 `false`。
* `smoothExtentConstraint` - 平滑地使用范围约束，允许轻微过度滚动并带有回弹效果，而不是硬性停止。默认值为 `true`。

这些属性是创建时选项。在初始化期间传递给 OpenLayers 视图，并且无法在运行时更改。

----

== XML 内部元素

一个 `geoMap` 可以包含一个 `mapView` 元素以及一个必须的 `layers` 元素。`layers` 元素内可以包含 `tile`、`image`、`vector` 和 `heatmap` 等图层元素，每个图层元素都有各自的数据源和样式元素。
