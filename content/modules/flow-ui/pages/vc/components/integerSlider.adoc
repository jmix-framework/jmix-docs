= integerSlider

[.since]
Начиная с Jmix 3.1

`integerSlider` позволяет выбрать значение типа `Integer`, перетаскивая ползунок по шкале. Ползунок также можно перемещать клавишами со стрелками.

Для значений типа `Double` используйте xref:vc/components/decimalSlider.adoc[decimalSlider]. Чтобы выбрать диапазон значений, используйте xref:vc/components/integerRangeSlider.adoc[integerRangeSlider].

[[empty-value]]
== Пустое значение

Слайдер не может показать пустое значение. Когда значения нет, он показывает значение <<min,min>>. Слайдер при этом считается пустым:

* Если связанный атрибут равен `null`, слайдер показывает `min`, но не записывает его в сущность, и xref:data/data-context.adoc[DataContext] не регистрирует изменение. Атрибут получает значение, только когда пользователь передвигает ползунок или значение задаётся в коде.
* Слайдер, не связанный с данными, остаётся пустым, пока пользователь не передвинет ползунок или значение не будет задано в коде.
* Вызов `clear()` или `setValue(null)` перемещает ползунок в `min` и делает слайдер пустым. Слайдер, связанный с данными, также записывает в атрибут `null`.

Метод `isEmpty()` возвращает `true` для пустого слайдера, хотя `getValue()` возвращает `min`. Валидаторы получают `null` в качестве значения пустого слайдера. Если для слайдера задан атрибут xref:vc/common-attributes.adoc#required[required], пустой слайдер не проходит валидацию.

[[range-and-step]]
== Диапазон и шаг

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/slider-simple" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

Атрибуты <<min,min>> и <<max,max>> задают диапазон значений, а <<step,step>> — интервал между ними. Значения, которые может выбрать пользователь, отсчитываются от `min`: `min`, `min + step`, `min + 2 * step` и так далее.

[source,xml,indent=0]
----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/slider/simple/slider-simple.xml[tags=step]
----

Слайдер не изменяет значение, которое выходит за пределы диапазона. Такое значение может прийти из связанного атрибута или из кода. Слайдер проверяет значение валидаторами xref:vc/miscellaneous/validator.adoc#MinValidator[min] и xref:vc/miscellaneous/validator.adoc#MaxValidator[max] и показывает ошибку валидации. Эти валидаторы добавляются автоматически и обновляются при изменении `min` или `max`.

[[value-display]]
== Отображение значения

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://vaadin.com/docs/v25/components/slider#persistent-value-display" class="vaadin-docs-btn" target="_blank">Vaadin</a>

По умолчанию слайдер показывает текущее значение в пузырьке над ползунком, только пока пользователь взаимодействует с ним. Установите для атрибута <<valueAlwaysVisible,valueAlwaysVisible>> значение `true`, чтобы значение было видно всегда.

Атрибут <<minMaxVisible,minMaxVisible>> показывает значения `min` и `max` под шкалой, как в <<range-and-step,примере выше>>.

== Атрибуты

`integerSlider` имеет следующие уникальные атрибуты:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[max]]`max`
|Задаёт максимальное значение слайдера. Значение больше `max` делает компонент недействительным. См. <<range-and-step>>.
|`100`

|[[min]]`min`
|Задаёт минимальное значение слайдера. Значение меньше `min` делает компонент недействительным. Пустой слайдер показывает это значение. См. <<empty-value>>.
|`0`

|[[minMaxVisible]]`minMaxVisible`
|Показывает значения `min` и `max` под шкалой.
|`false`

|[[step]]`step`
|Задаёт интервал между значениями, которые может выбрать пользователь. Шаг должен быть больше 0. См. <<range-and-step>>.
|`1`

|[[value]]`value`
|Задаёт значение компонента.
|—

|[[valueAlwaysVisible]]`valueAlwaysVisible`
|Показывает текущее значение над ползунком постоянно. Если `false`, значение видно, только пока пользователь взаимодействует со слайдером.
|`false`
