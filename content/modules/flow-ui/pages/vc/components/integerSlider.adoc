= integerSlider

[.since]
Since Jmix 3.1

`integerSlider` lets users select an `Integer` value by dragging a handle along a track. Users can also move the handle with the arrow keys.

To work with `Double` values, use xref:vc/components/decimalSlider.adoc[decimalSlider]. To select a range of values, use xref:vc/components/integerRangeSlider.adoc[integerRangeSlider].

[[empty-value]]
== Empty Value

A slider cannot show an empty value. When it has no value, it shows the <<min,min>> value instead. The slider treats it as an empty value:

* If the bound attribute is `null`, the slider shows `min`, but does not write it to the entity, and the xref:data/data-context.adoc[DataContext] does not register a change. The attribute gets a value only when the user moves the handle or when you set a value in code.
* An unbound slider is empty until the user moves the handle or you set a value in code.
* Calling `clear()` or `setValue(null)` moves the handle to `min` and makes the slider empty. A bound slider also sets the attribute to `null`.

The `isEmpty()` method returns `true` for an empty slider, although `getValue()` returns `min`. Validators get `null` as the value of an empty slider. If the slider is xref:vc/common-attributes.adoc#required[required], an empty slider fails validation.

== Range and Step

The <<min,min>> and <<max,max>> attributes set the range of values, and <<step,step>> sets the interval between them. The values that the user can select are counted from `min`: `min`, `min + step`, `min + 2 * step`, and so on.

----
include::example$ui-samples/main/resources/io/jmix/uisamples/view/flowui/components/slider/simple/slider-simple.xml[tags=step]
----

The slider does not change a value that is outside the range. Such a value can come from the bound attribute or from code. The slider checks the value with the xref:vc/miscellaneous/validator.adoc#MinValidator[min] and xref:vc/miscellaneous/validator.adoc#MaxValidator[max] validators and shows a validation error. The validators are added automatically and are updated when you change `min` or `max`.

== Value Display

By default, the slider shows the current value above the handle only while the user interacts with it. Set <<valueAlwaysVisible,valueAlwaysVisible>> to `true` to show the value all the time.

The <<minMaxVisible,minMaxVisible>> attribute shows the `min` and `max` values below the track, as in the <<range-and-step,example above>>.

== Attributes

The following attributes are specific to `integerSlider`:

[cols="2,5,1", options="header"]
|===
|Name
|Description
|Default

|[[max]]`max`
|Sets the maximum value of the slider. A value greater than `max` invalidates the component. See <<range-and-step>>.
|`100`

|[[min]]`min`
|Sets the minimum value of the slider. A value less than `min` invalidates the component. An empty slider shows this value. See <<empty-value>>.
|`0`

|[[minMaxVisible]]`minMaxVisible`
|Shows the `min` and `max` values below the track.
|`false`

|[[step]]`step`
|Sets the interval between the values that the user can select. The step must be greater than 0. See <<range-and-step>>.
|`1`

|[[value]]`value`
|Sets the component value.
|—

|[[valueAlwaysVisible]]`valueAlwaysVisible`
|Shows the current value above the handle all the time. If `false`, the value is shown only while the user interacts with the slider.
|`false`
|===
