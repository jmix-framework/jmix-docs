= decimalRangeSlider

[.since]
Начиная с Jmix 3.1

`decimalRangeSlider` позволяет выбрать диапазон значений типа `Double`. На шкале компонента два ползунка: один задаёт начало диапазона, другой — его конец.

Для значений типа `Integer` используйте xref:vc/components/integerRangeSlider.adoc[integerRangeSlider]. Чтобы выбрать одно значение, используйте xref:vc/components/decimalSlider.adoc[decimalSlider].

[[value]]
== Значение

Значение `decimalRangeSlider` — это запись (record) `DecimalRangeSliderValue`. Её методы `start()` и `end()` возвращают начало и конец выбранного диапазона. Начало не может быть больше конца.

Чтобы задать диапазон в коде, передайте в метод `setValue()` новый объект `DecimalRangeSliderValue(start, end)`. Метод `clear()` выбирает весь диапазон от `min` до `max`.

`decimalRangeSlider` нельзя связать с контейнером данных, и он не поддерживает валидаторы. Получайте его значение в контроллере экрана. Пример слайдера диапазона, который фильтрует данные, приведён на странице xref:vc/components/integerRangeSlider.adoc#filter[integerRangeSlider]. Чтобы показать ошибку, задайте атрибут xref:vc/common-attributes.adoc#errorMessage[errorMessage] и вызовите `setInvalid(true)` в контроллере.

Слайдер отправляет новое значение на сервер, когда пользователь отпускает ползунок. Чтобы значение отправлялось на каждом шаге перетаскивания, установите для атрибута xref:vc/common-attributes.adoc#valueChangeMode[valueChangeMode] значение `EAGER`.

[[range-and-step]]
== Диапазон и шаг

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://vaadin.com/docs/v25/components/slider#step" class="vaadin-docs-btn" target="_blank">Vaadin</a>
</div>
++++

Атрибуты <<min,min>> и <<max,max>> задают диапазон значений, а <<step,step>> — интервал между ними. Значения, которые может выбрать пользователь, отсчитываются от `min`: `min`, `min + step`, `min + 2 * step` и так далее. Смотрите <<basics,пример выше>>.

[[value-display]]
== Отображение значений

++++
<div class="jmix-ui-live-demo-container">
    <a href="https://demo.jmix.ru/ui-samples/sample/range-slider-simple" class="live-demo-btn" target="_blank">ДЕМО</a>
</div>
++++

По умолчанию слайдер показывает текущие значения в пузырьках над ползунками, только пока пользователь взаимодействует с ними. Установите для атрибута <<valueAlwaysVisible,valueAlwaysVisible>> значение `true`, чтобы значения были видны всегда, как в <<basics,примере выше>>.

Атрибут <<minMaxVisible,minMaxVisible>> показывает значения `min` и `max` под шкалой.

== Атрибуты

`decimalRangeSlider` имеет следующие уникальные атрибуты:

[cols="2,5,1", options="header"]
|===
|Имя
|Описание
|По умолчанию

|[[accessibleNameEnd]]`accessibleNameEnd`
|Задаёт доступное имя ползунка конца диапазона. См. <<accessible-names>>.
|—

|[[accessibleNameStart]]`accessibleNameStart`
|Задаёт доступное имя ползунка начала диапазона. См. <<accessible-names>>.
|—

|[[endValue]]`endValue`
|Задаёт конец исходного диапазона. Если задан только `startValue`, конец равен `max`.
|—

|[[max]]`max`
|Задаёт максимальное значение слайдера. См. <<range-and-step>>.
|`100`

|[[min]]`min`
|Задаёт минимальное значение слайдера. См. <<range-and-step>>.
|`0`

|[[minMaxVisible]]`minMaxVisible`
|Показывает значения `min` и `max` под шкалой.
|`false`

|[[required]]`required`
|Показывает индикатор обязательного поля. Компонент не проверяет своё значение.
|`false`

|[[startValue]]`startValue`
|Задаёт начало исходного диапазона. Если задан только `endValue`, начало равно `min`.
|—

|[[step]]`step`
|Задаёт интервал между значениями, которые может выбрать пользователь. Шаг должен быть больше 0. См. <<range-and-step>>.
|`1`

|[[valueAlwaysVisible]]`valueAlwaysVisible`
|Показывает текущие значения над ползунками постоянно. Если `false`, значения видны, только пока пользователь взаимодействует со слайдером.
|`false`
|===
