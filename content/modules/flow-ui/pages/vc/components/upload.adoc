= upload 上传
:page-aliases: vcl/components/file-multi-upload-field.adoc

`upload` 支持用户上传一个或多个文件，并显示每个文件的上传进度和状态。可以通过单击 *Upload files* 按钮或将文件拖放至组件进行上传。

|Java 类

[[auto-upload]]
== 自动上传

`autoUpload` 属性设置组件是否在用户选择了文件之后自动上传，或者是需要用户主动触发上传。

* 当设置为 `true` 时，文件会在选择后自动上传。此时会显示上传进度，用户还可以按需取消上传。
* 当设置为 `false` 时，文件不会自动上传。用户必须点击 *Upload* 按钮开始上传。

默认值为 `true`。

[[drag-drop]]
== 拖放

`upload` 组件支持拖放功能，用户可以从文件系统直接拖拽文件至该组件实现上传。

拖放功能默认开启。如需禁用，请设置 xref:flow-ui:vc/components/fileStorageUploadField.adoc#dropAllowed[dropAllowed] 属性为 `false`。

`dropLabel` 属性设置组件中引导用户拖放文件的文本。

该属性的值可以是一个纯文本，或 xref:localization:message-bundles.adoc[消息包] 中的一个键值。如果是键值，需要以 `msg://` 开头。

`dropLabelIcon` 属性设置一个 `dropLabel` 文本旁边可以显示的图标。

默认情况下，`upload` 不限制用户可以上传的文件数量。可以通过 `maxFiles` 属性控制用户能上传的文件数。

设置允许用户上传的最大文件个数。如果设置为 1，则系统原生的文件选择器将不允许选择多个文件。

默认不会在 UI 显示文件上传的异常。请使用 <<FileRejectedEvent,FileRejectedEvent>> 捕捉异常，然后可以使用通知为用户展示异常。

== XML 属性

|===

|描述
|默认值

|—

|[[autoUpload]]`autoUpload`
|设置组件是否在选择文件后自动上传。参阅 <<auto-upload,自动上传>>。
|`true`

|[[dropAllowed]]`dropAllowed`
|设置是否支持拖拽文件至控件实现上传。
|—

|[[dropLabel]]`dropLabel`
|设置组件中引导用户拖放文件的文本。参阅 <<drag-drop,拖放>>。
|—

|[[dropLabelIcon]]`dropLabelIcon`
|设置 dropLabel 的图标。用户可以拖放文件时该图标可见。参阅 <<drag-drop,拖放>>。
|—

|[[maxFileSize]]`maxFileSize`
|设置允许上传的最大文件大小。
|—

|[[maxFiles]]`maxFiles`
|设置允许上传的最大文件数量。参阅 <<file-count,文件计数>>
|无限制

|[[uploadHandlerFqn]]`uploadHandlerFqn`
|为该 `upload` 组件设置自定义上传实现的完整限定名称。该类必须实现 Vaadin 的 `UploadHandler` 接口。示例：`com.company.app.upload.CustomUploadHandler`

|[[uploadHandlerType]]`uploadHandlerType`
|设置预定义的上传处理器。支持：`IN_MEMORY` – 用 `InMemoryUploadHandler` 将上传的数据保存在内存中。在 `UploadSucceededEvent<V>` 事件中，上传数据的格式是 `byte[]`；`FILE_TEMPORARY_STORAGE` 将上传的文件保存在 xref:files:uploading-files.adoc#using-temporary-storage[临时存储]。
|`IN_MEMORY`

|[[uploadIcon]]`uploadIcon`
|设置图标。
|—

|[[uploadText]]`uploadText`
|设置文本。
|—

== 事件和处理器

下面是 `upload` 的特殊事件和处理器：

[cols="2,5", options="header"]
|===
|名称
|描述

|[[AllFinishedEvent]]`AllFinishedEvent`
|`com.vaadin.flow.component.upload.AllFinishedEvent` 当 `upload` 组件处理完队列中所有的文件之后发送，无论上传是否成功。

|[[FailedEvent]]`FailedEvent`
|`com.vaadin.flow.component.upload.FailedEvent` 当 `upload` 组件上传的文件被接收但由于某些原因中断时发送。Java 中使用 `addUploadFailedListener()` 方法。

|[[FileRejectedEvent]]`FileRejectedEvent`
|`com.vaadin.flow.component.upload.FileRejectedEvent` 当选择的文件不满足 `upload` 的要求时发送，例如，xref:flow-ui:vc/components/fileStorageUploadField.adoc#maxFileSize[文件大小限制] 或 <<maxFiles,文件数量限制>>。参阅 <<file-count,文件数量>>。

|[[FileRemovedEvent]]`FileRemovedEvent`
|`com.vaadin.flow.component.upload.FileRemovedEvent` 当文件从上传队列移除时发送。

|[[FinishedEvent]]`FinishedEvent`
|`com.vaadin.flow.component.upload.FinishedEvent` 当 `upload` 接收了文件后发送，不论是否成功。Java 中使用 `addUploadFinishedListener()`。

|[[ProgressUpdateEvent]]`ProgressUpdateEvent`
|`com.vaadin.flow.component.upload.ProgressUpdateEvent` 用于跟踪上传文件的进度。Java 中使用 `addUploadProgressListener()`。

|[[StartedEvent]]`StartedEvent`
|`com.vaadin.flow.component.upload.StartedEvent` 当 `upload` 开始接收文件时发送。Java 中使用 `addUploadStartedListener()`，或在视图控制器中添加组件的事件监听器。

|[[UploadSucceededEvent]]`UploadSucceededEvent`
|文件上传成功时发送。通过事件的 `getData()` 方法获取上传的数据。
|===
