= svg

[.since]
Since Jmix 3.1

The `svg` component renders SVG markup directly in the view.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`svg`

|Java Class
|`Svg`
|===

[[basics]]
== Basics

Add the markup to the nested `content` element and wrap it in a CDATA section:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=content]
----

IMPORTANT: The CDATA section is required. Without it, the XML parser reads the SVG tags as elements of the view descriptor, and the view fails to open with a `GuiDevelopmentException`.

CAUTION: The component renders the markup as is. If the SVG comes from an untrusted source, such as a file uploaded by a user, sanitize it before passing it to the component. Otherwise, it can lead to cross-site scripting attacks.

The component has no size attributes. The size of the image is defined by the `width`, `height`, and `viewBox` attributes of the root `<svg>` element in the markup.

The markup becomes part of the page, so the styles of the page apply to it. If the markup uses `currentColor` for strokes and fills, as in the example above, the image takes the text color of the component, and you can change it with CSS. The xref:vc/html-components/image.adoc[image] and xref:icons/custom-icons.adoc#standalone-svg-images[svgIcon] components work differently. They display an SVG file by URL, and the page styles do not apply inside the image.

[[file]]
== Content from a File

Use the `file` attribute to load the markup from a file:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=file]
----

The path is resolved by the xref:features:resources.adoc[Resources] interface. By default, the file is loaded from the classpath. You can also use the `classpath:` prefix, a URL, or a path to a file in the configuration directory. See xref:features:resources.adoc#resource-locations[Resource Locations] for details.

If the file is not found, the view fails to open with a `GuiDevelopmentException`. If both `content` and `file` are set, the component uses `content`.

----

Then set the markup in the view controller using the `setSvg()` method:

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/svg/SvgView.java[tags=programmatic]
----

The `setSvg()` method also accepts an `InputStream`, for example, to read the markup from a file.

The markup must contain an `<svg>` element. An XML declaration and a document type declaration before it are removed. If the markup does not contain `<svg>`, the method throws an `IllegalArgumentException`.
