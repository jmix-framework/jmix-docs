= svg

[.since]
Начиная с Jmix 3.1

Компонент `svg` встраивает SVG-разметку непосредственно в экран.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`svg`

|Java-класс
|`Svg`
|===

[[basics]]
== Основы

Поместите разметку во вложенный элемент `content` и оберните её в секцию CDATA:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=content]
----

IMPORTANT: Секция CDATA обязательна. Без неё XML-парсер воспринимает SVG-теги как элементы дескриптора экрана, и экран не откроется, выбросив `GuiDevelopmentException`.

CAUTION: Компонент выводит разметку как есть. Если SVG получен из ненадёжного источника, например из файла, загруженного пользователем, перед передачей в компонент удалите из разметки опасное содержимое, такое как скрипты и обработчики событий. Иначе возможны межсайтовые скриптовые атаки (XSS).

У компонента нет атрибутов размера. Размер изображения определяют атрибуты `width`, `height` и `viewBox` корневого элемента `<svg>` в разметке.

Разметка становится частью страницы, поэтому к ней применяются стили страницы. Если в разметке для контуров и заливки используется `currentColor`, как в примере выше, изображение принимает цвет текста компонента, и этот цвет можно изменить через CSS. Компоненты xref:vc/html-components/image.adoc[image] и xref:icons/custom-icons.adoc#standalone-svg-images[svgIcon] работают иначе: они показывают SVG-файл по URL, и стили страницы внутри изображения не действуют.

[[about-file]]
== Содержимое из файла

Чтобы загрузить разметку из файла, используйте атрибут `file`:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=file]
----

Файл ищется с помощью интерфейса xref:features:resources.adoc[Resources]. По умолчанию файл загружается из classpath. Также можно указать префикс `classpath:`, URL или путь к файлу в каталоге конфигурации. Подробнее см. в разделе xref:features:resources.adoc#resource-locations[Расположение ресурсов].

Если файл не найден, экран не откроется, выбросив `GuiDevelopmentException`. Если заданы и `content`, и `file`, компонент использует `content`.

[[programmatic]]
== Программная установка содержимого

Объявите компонент без `content` и `file`:

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=programmatic]
----

Затем задайте разметку в контроллере экрана методом `setSvg()`:

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/svg/SvgView.java[tags=programmatic]
----

Метод `setSvg()` также принимает `InputStream`, например, чтобы прочитать разметку из файла.

Разметка должна содержать элемент `<svg>`. XML-объявление и объявление типа документа перед ним удаляются. Если в разметке нет `<svg>`, метод выбрасывает `IllegalArgumentException`.
