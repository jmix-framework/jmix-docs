= svg

[.since]
Jmix 3.1+

`svg` 组件可以直接在视图中渲染 SVG。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`svg`

|Java 类
|`Svg`
|===

[[basics]]
== 基本用法

将 SVG 的内容添加至内部 `content` 元素的 CDATA 中：

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=content]
----

IMPORTANT: CDATA 块是必需的。如果没有，XML 解析器会将 SVG 标签读取为视图描述符的元素，将导致视图无法打开，并抛出 `GuiDevelopmentException`。

CAUTION: 组件按原生内容渲染 SVG。如果 SVG 来自不受信任的来源（例如用户上传的文件），请在将其传递给组件之前对其进行清理。否则，可能导致跨站脚本攻击。

组件没有尺寸属性。图像的大小由 `<svg>` 根元素的 `width`、`height` 和 `viewBox` 属性定义。

SVG 在页面渲染后会成为页面的一部分，因此也会应用页面的样式。如果使用 `currentColor` 作为描边和填充（如上例所示），图像会采用组件的文本颜色，样式可以通过 CSS 更改。Jmix 的 xref:vc/html-components/image.adoc[image] 和 xref:icons/custom-icons.adoc#standalone-svg-images[svgIcon] 组件的工作方式与该组件不同，它们是通过 URL 显示 SVG 文件，页面样式不会应用于图像内部。

[[about-file]]
== 来自文件的内容

使用 `file` 属性从文件加载 SVG：

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=file]
----

文件路径由 xref:features:resources.adoc[Resources] 接口解析。默认情况下，文件从类路径加载。还可以使用 `classpath:` 前缀、URL 或使用配置目录中文件的路径。详情请参见 xref:features:resources.adoc#resource-locations[资源位置]。

如果找不到文件，视图将无法打开，并抛出 `GuiDevelopmentException`。如果同时设置了 `content` 和 `file`，组件使用 `content`。

[[programmatic]]
== 编程方式设置内容

声明组件时不设置 `content` 和 `file`：

[source,xml,indent=0]
----
include::example$onboarding/src/main/resources/com/company/onboarding/view/component/svg/svg-view.xml[tags=programmatic]
----

然后在视图控制器中使用 `setSvg()` 方法设置：

[source,java,indent=0]
----
include::example$onboarding/src/main/java/com/company/onboarding/view/component/svg/SvgView.java[tags=programmatic]
----

`setSvg()` 方法还接收 `InputStream`，例如从文件读取 SVG。

SVG 必须包含 `<svg>` 元素。其前面的 XML 声明和文档类型声明会被移除。如果标记不包含 `<svg>`，该方法会抛出 `IllegalArgumentException`。
