= multiValuePicker 多值选择器
:page-aliases: vcl/components/values-picker.adoc

`multiValuePicker` 可以处理任意类型值的列表。由一个文本框和一组由操作定义的按钮组成。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`multiValuePicker`

|Java 类
|`JmixMultiValuePicker`
|===

当用户点击选择按钮时，会展示 *Select Value（选择值）* 视图。用户可以在这个视图中新建或删除值。需要添加值时，可以点击 *Add（添加）* 按钮或按下 *Enter* 添加值。

NOTE: *Select Value* 视图可以自定义。该自定义视图需要实现 `MultiValueSelectView` 接口，然后通过操作的 `viewClass` 或 `viewId` 属性设置该视图。

[[actions]]
== 操作

可以给 `multiValuePicker` 添加自定义或预定义的操作，操作作为按钮显示在右侧。有两种方式：

* **XML** 中用内部的 `actions` 元素定义操作。
* **控制器** 中使用 `addAction()` 方法编程式添加。

[TIP]
====
如需在 Jmix Studio 中添加 `action`，可以在视图 XML 或者 *Jmix UI* 结构面板中选择组件，然后点击组件面板的 xref:studio:view-designer.adoc#add-picker-action[Add] 按钮。
====

[[predefined-action]]
== 预定义操作

框架为 `multiValuePicker` 提供了两种预定义操作：`value_clear` 和 `multi_value_select`。

`multi_value_select` 操作使用一个值选择视图为 `multiValuePicker` 设置值。这个视图会根据提供的数据类型生成一个特定的组件用于选择或创建值。`multi_value_select` 操作可用来选择各种类型的值，包括：

* Java 类型，例如，`String`、`Integer`、`Long`、`Double`、`BigDecimal`，日期和时间类型以及 `UUID`
* xref:data-model:enumerations.adoc[枚举] 值
* xref:data-model:entities.adoc[实体] 实例

[[java-class]]
使用 `javaClass` 属性指定一个 Java 数据类型。例如，<<values-picker-example1,前面的示例>> 使用了 `java.lang.String`。

[[variants]]
== 样式版本

使用 xref:vc/common-attributes.adoc#themeNames[themeNames] 属性配置一个或多个样式。

[cols="1,4,1", options="header"]
|===
|样式
|描述
|支持的主题

|`align-left`
|字段值左对齐。
|Aura, Lumo

|`align-center`
|字段值居中对齐。
|Aura, Lumo

|`align-right`
|字段值右对齐。
|Aura, Lumo

|`align-start`
|根据当前文本方向，将字段值向起始侧对齐。
|Aura

|`align-end`
|根据当前文本方向，将字段值向末尾侧对齐。
|Aura

|`helper-above-field`
|帮助文字显示在字段上方，标题下方。
|Aura, Lumo

|`small`
|组件更小。
|Aura, Lumo
|===
