= Icons

This section explains how to use icons, add custom icons, and change the default icons used throughout an application.

* xref:icons/default-icons.adoc[] describes the built-in icon sets and the ways to place icons in UI components.
* xref:icons/custom-icons.adoc[] explains how to add standalone SVG files, SVG sprites, and icon fonts.
* xref:icons/override-icons.adoc[] explains how to replace individual default icons or the default icon font.
