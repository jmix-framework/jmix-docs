= 添加自定义图标

自定义图标以独立 SVG 文件、SVG 精灵图（Sprite）或图标字体的形式添加。

== 选择格式

[cols="2,3,4", options="header"]
|===
|格式
|最适合
|特点

|独立 SVG 文件
|少量自定义图标
|每个图标存储在单独的文件中。浏览器只加载 UI 中使用的图标。

|SVG 精灵图
|一组自定义图标
|多个图标作为符号存储在一个文件中，并通过标识符选择。

|图标字体
|已有的基于字体的图标库
|需要字体文件和 CSS 配置。图标通过 CSS 类、连字或字符代码选择。
|===

有关使用属性、XML 元素或 Java 配置图标的信息，请参见 xref:icons/default-icons.adoc[]。

[[icon-fonts]]
== 图标字体

图标字体是一组以字体形式提供的图标。图标被渲染为该字体中的字符。

TIP: 添加自定义图标字体后，可以用自定义图标覆盖默认的图标。详情请参见 xref:icons/override-icons.adoc[]。

添加图标字体时，需要以下内容：

* 一个或多个字体文件 - 通常是 `.woff2`，其他格式如 `.woff`、`.ttf` 或 `.otf`。
* 全局 `@font-face` 声明 - 通常放在一个需要导入到主样式表（`styles.css`）的样式表中。
* 可选地，包含图标 CSS 类的样式表 - 通常与 `@font-face` 声明一起添加，并同样导入到 `styles.css` 中。

=== 使用本地字体文件

要在不使用外部服务的情况下使用 Material Icons，请在激活的 xref:flow-ui:themes/themes.adoc#application-theme-files[应用主题] 目录中创建一个 `material` 子目录。

添加以下文件：

* `material-icons.woff2`
* `material-icons.woff`
* `material-icons.ttf`
* `material-icons.css` – 包含 `@font-face` 声明和图标的 CSS 类：
+
.material-icons.css
[source,css]
----
include::example$/onboarding/src/main/resources/META-INF/resources/themes/onboarding-aura/material/material-icons.css[tags=material-font-face;material-css]
----

浏览器会使用它支持的第一种字体格式。因此，`src` 中声明的每个字体文件都必须下载并放在 `material-icons.css` 同级目录。

将样式表导入到主题的主样式表中：

.styles.css
[source,css]
----
include::example$/onboarding/src/main/resources/META-INF/resources/themes/onboarding-aura/styles.css[tags=import-material]
----

=== 使用 Google Fonts

还可以从 Google Fonts 在线加载 Material Icons，而不是将字体文件存储在本地。此选项要求用户的浏览器能够通过网络访问 Google Fonts。

从主题的 `styles.css` 中移除对 `material/material-icons.css` 的导入，改为添加以下导入：

.styles.css
[source,css]
----
include::example$/onboarding/src/main/resources/META-INF/resources/themes/onboarding-aura/material/google-fonts.css[tags=import-material-google]
----

导入的 Google Fonts 样式表提供了 Material Icons 的 `@font-face` 声明和 CSS 类，因此不需要本地字体文件或额外的 `@font-face` 声明。

=== 使用字体图标

使用任何方式配置字体后，使用 `fontIcon` 组件创建图标。

根据字体及其样式表的不同，`fontIcon` 组件可以通过两种方式识别图标：

* 连字，例如 `calendar`，通过 `ligature` 属性设置。这需要支持连字的字体。
* 十六进制字符代码，例如 `f199`，通过 `charCode` 属性设置。
+
