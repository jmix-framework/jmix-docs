= Начало работы

В этом разделе показано, как включить ассистента в приложении: добавить зависимости, подключить модель, выдать доступ и задать первый вопрос.

[[prerequisites]]
== Предварительные требования

Перед продолжением установите дополнение, как описано в разделе xref:ai-tools:index.adoc#installation[Установка].

[[configure-model]]
== Подключение модели

Дополнение взаимодействует с LLM через Spring AI `ChatClient`, которому требуется настроенный провайдер модели. Выберите один из https://docs.spring.io/spring-ai/reference/api/index.html[стартеров моделей Spring AI^] и добавьте его в `build.gradle`. Например, для OpenAI:

[source, groovy, indent=0]
----
implementation 'org.springframework.ai:spring-ai-starter-model-openai'
----

Затем укажите настройки провайдера в `application.properties`. Это стандартные свойства https://docs.spring.io/spring-ai/reference/[Spring AI^], а не свойства самого дополнения:

[source, properties, indent=0]
----
spring.ai.openai.api-key=${OPENAI_API_KEY}
spring.ai.openai.chat.options.model=gpt-4o-mini
----

TIP: Не храните секреты, такие как API-ключ, в `application.properties`. Передавайте их через переменные окружения или другой внешний источник конфигурации, как показано выше.

Если модель не настроена, приложение все равно запускается и UI чата отображается, но ассистент не может отвечать. Поле ввода сообщений отключается, а пользователь видит уведомление. Это позволяет добавить UI заранее, до настройки модели.

[[grant-access]]
== Доступ к чату

Доступ к чату контролируется ресурсной ролью `aitools-chat-user`. Назначьте ее пользователям, которым должен быть доступен ассистент. Подробности см. в разделе xref:ai-tools:ui.adoc#roles[Роль безопасности].

[[first-question]]
== Задайте вопрос

После перезапуска приложения в главном меню в разделе *AI* появится новый пункт *Chats*.

Откройте чат и отправьте запрос на естественном языке, например: _"Сколько в приложении активных пользователей?"_.

image::ai-tools-chat.png[AI tools chat, align="center", width = 560]

Можно настроить, к каким данным ассистент имеет доступ и какой объем данных он включает в ответы. Подробности см. в xref:ai-tools:tools.adoc[] и xref:ai-tools:properties.adoc[].
