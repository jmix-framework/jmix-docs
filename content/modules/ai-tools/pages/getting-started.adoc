= Getting Started

This section walks you through enabling the assistant in an application: adding the dependencies, connecting a model, granting access and asking the first question.

[[add-dependencies]]
== Adding Dependencies

Add the add-on starters as described in the xref:ai-tools:index.adoc#installation[Installation] section:

[source, groovy, indent=0]
----
include::example$/ai-tools-ex1/build.gradle[tags=dependencies]
----

[[configure-model]]
== Connecting a Model

The add-on talks to the LLM through a Spring AI `ChatClient`, which in turn needs a configured model provider. Pick one of the https://docs.spring.io/spring-ai/reference/api/index.html[Spring AI model starters^] and add it to your `build.gradle`. For example, for OpenAI:

[source, groovy, indent=0]
----
implementation 'org.springframework.ai:spring-ai-starter-model-openai'
----

Then provide the provider's settings in `application.properties`. These are standard https://docs.spring.io/spring-ai/reference/[Spring AI^] properties — they are not defined by this add-on:

[source, properties, indent=0]
----
spring.ai.openai.api-key=${OPENAI_API_KEY}
spring.ai.openai.chat.options.model=gpt-4o-mini
----

TIP: Keep secrets such as the API key out of `application.properties` — pass them through an environment variable or another externalized configuration source, as shown above.

If no model is configured, the application still starts and the chat UI still renders, but the assistant cannot answer — the composer is disabled and a notification informs the user. This lets you ship the UI before the model is wired up.

[[grant-access]]
== Granting Access

Access to the chat is controlled by the `aitools-chat-user` resource role. Assign it to the users who should be able to use the assistant — see xref:ai-tools:ui.adoc#roles[Security Role] for details.

[[first-question]]
== Asking the First Question

After restarting the application, a new *AI Assistant* item appears in the main menu. It opens the chat hub: a screen with a message composer, the most recent conversations and a searchable history.

// TODO: screenshot — the AI Assistant chat hub with the composer and recent conversations.

Type a request in natural language, for example _"How many active users are there?"_, and submit it. The assistant inspects the available entities, runs a read-only query and answers in the conversation view. Steps such as discovering the model or running a query are shown as transient status lines while the answer is being prepared.
