= 开始使用

本节介绍如何在应用程序中启用 AI 助手：添加依赖项、连接模型、授予访问权限，以及提出第一个问题。

[[prerequisites]]
== 前置条件

在继续之前，请按照 xref:ai-tools:index.adoc#installation[安装] 中的说明安装扩展组件。

[[configure-model]]
== 连接模型

该扩展组件通过 Spring AI 的 `ChatClient` 与 LLM 通信，需要配置一个模型 provider。请选择一个 https://docs.spring.io/spring-ai/reference/api/index.html[Spring AI 模型 starters^]，并添加到 `build.gradle` 中。例如，对于 OpenAI：

[source, groovy, indent=0]
----
implementation 'org.springframework.ai:spring-ai-starter-model-openai'
----

然后在 `application.properties` 中配置 provider。这些是标准的 https://docs.spring.io/spring-ai/reference/[Spring AI^] 属性，而非扩展组件定义的属性：

[source, properties, indent=0]
----
spring.ai.openai.api-key=${OPENAI_API_KEY}
spring.ai.openai.chat.options.model=gpt-4o-mini
----

TIP: 不要将 API 密钥等机密信息保存在 `application.properties` 中。如上所示，通过环境变量或其他外部化配置源传递。

如果未配置模型，应用程序仍然会启动，聊天 UI 也会渲染，但助手无法提供回答。会禁用输入框，用户可以看到通知。因此可以在配置模型之前先添加 UI。

[[grant-access]]
== 授予访问权限

聊天的访问权限由 `aitools-chat-user` 资源角色控制。将其分配给需要使用助手的用户。详情请参见 xref:ai-tools:ui.adoc#roles[安全角色]。

[[first-question]]
== 提出第一个问题

重新启动应用程序后，主菜单中的 *AI* 部分下会显示新的 *Chats* 项。

打开页面后，可以用自然语言提交请求，例如 *"有多少活跃用户？"*。

image::ai-tools-chat.png[AI tools chat, align="center", width = 560]

还可以配置助手能访问哪些数据以及响应中包含多少数据。详情请参见 xref:ai-tools:tools.adoc[] 和 xref:ai-tools:properties.adoc[]。
