[[data-load-service]]
== AiDataLoadService

`io.jmix.aitools.dataload.AiDataLoadService` 是用于数据加载的专用入口点。除了对话式的 `send` 和 `stream` 方法外，还提供：

* `loadData(String userText)` – 为请求生成 JPQL 查询并运行，然后返回结构化的 `EntityDataLoadResult`。

`EntityDataLoadResult` 通过以下字段加载的完整结果：

* `query` — LLM 生成的查询语句（修复前）；
* `validationResult` — 验证输出；
* `rows` — 获取的行，每行是一个按结果属性名称和内容的 `Map`；
* `hasMore` — 是否还有更多行；
* `executed` — 查询是否实际运行；
* `executionError` — 错误消息。

当需要的是数据本身而非自然语言答案时，可以使用该服务。

[[system-prompt]]
== 自定义系统提示词

`AiAssistantService` 使用的系统提示词由 `AiAssistantSystemPromptProvider` bean 提供。默认实现会加载一个介绍助手和工具使用规则的模板。如需使用自定义的提示词，请注册一个实现 `AiAssistantSystemPromptProvider` 并返回提示词模板的 bean。

NOTE: 默认的 `AiAssistantSystemPromptProvider` 仅当应用程序尚未定义该类型的 bean 时才会注册。如果提供了自定义的实现，则自动优先使用。
