= 应用程序属性

本页面介绍了 AI Tools 扩展组件定义的配置属性。模型 provider 需要通过标准的 https://docs.spring.io/spring-ai/reference/[Spring AI^] 属性（例如 `spring.ai.openai.*`）单独配置。请参见 xref:ai-tools:getting-started.adoc#configure-model[连接模型]。

[[jmix.aitools.enabled]]
== jmix.aitools.enabled

是否启用 AI Tools 自动配置。

默认值：`true`

[[dataload]]
[[jmix.aitools.dataload.enabled]]
== jmix.aitools.dataload.enabled

是否启用数据加载自动配置，包括预定义的数据加载工具。

默认值：`true`

[[jmix.aitools.dataload.exclude-system-level-entities]]
== jmix.aitools.dataload.exclude-system-level-entities

是否对 AI 隐藏系统级实体。

默认值：`true`

[[jmix.aitools.dataload.include-entities]]
== jmix.aitools.dataload.include-entities

即使原本会被隐藏，也要开放给 AI 的实体名称，以索引列表形式配置。所列出的实体会被添加到默认集合中，并覆盖系统级、DTO 和 `exclude-packages` 的排除规则。`exclude-entities` 的优先级仍然高于此列表。

[source,properties,indent=0]
----
jmix.aitools.dataload.include-entities[0]=sample_Customer
jmix.aitools.dataload.include-entities[1]=sample_Order
----

默认值：空（没有显式包含）

[[jmix.aitools.dataload.exclude-entities]]
== jmix.aitools.dataload.exclude-entities

对 AI 隐藏的实体名称，以索引列表形式指定。

默认值：空

[[jmix.aitools.dataload.include-packages]]
== jmix.aitools.dataload.include-packages

即使原本会被隐藏，也要开放给 AI 的实体包前缀，以索引列表形式配置。与 `include-entities` 类似，此属性是附加性的：匹配的实体会被添加到默认集合中，包括默认隐藏的实体（例如框架或系统级实体）。不会限制模型仅使用这些包。

[source,properties,indent=0]
----
jmix.aitools.dataload.include-packages[0]=com.company.sample
----

默认值：空

[[jmix.aitools.dataload.exclude-packages]]
== jmix.aitools.dataload.exclude-packages

对 AI 隐藏的包前缀，以索引列表形式配置。默认情况下，框架自身的实体被排除。可以使用 `include-entities` 或 `include-packages` 显式开放特定的实体。

默认值：`io.jmix`

[[jmix.aitools.dataload.max-repair-attempts]]
== jmix.aitools.dataload.max-repair-attempts

修复生成的无效查询语句的最大尝试次数。

默认值：`1`

[[jmix.aitools.dataload.jpql-execution-max-result]]
== jmix.aitools.dataload.jpql-execution-max-result

当生成的查询语句未指定行数时的默认最大行数。

默认值：`20`

[[jmix.aitools.dataload.jpql-execution-max-result-limit]]
== jmix.aitools.dataload.jpql-execution-max-result-limit

单个查询语句可以请求的行数的硬上限。任何更大的值，无论是由查询语句提供还是从默认值继承，在执行前都会被限制为此上限。

默认值：`100`

[[jmix.aitools.ui.chat-hub-recent-chats-count]]
== jmix.aitools.ui.chat-hub-recent-chats-count

聊天中心视图中聊天输入框旁边显示的最近聊天数量。也可以通过 `AiChatHubFragment.setRecentChatsCount(int)` 在每个 fragment 中覆盖该设置。

默认值：`6`

[[jmix.aitools.ui.assistant-response-timeout]]
== jmix.aitools.ui.assistant-response-timeout

调用 LLM 并生成助手响应的后台任务的超时时间。当超时到期时，任务将被取消并调用失败处理方法。

默认值：`5m`

[[jmix.aitools.ui.data.enabled]]
== jmix.aitools.ui.data.enabled

是否启用 AI Tools Flow UI 数据自动配置，包括数据库支持的聊天历史和工作聊天服务。

默认值：`true`

[[jmix.aitools.ui.data.chat-memory-max-messages]]
== jmix.aitools.ui.data.chat-memory-max-messages

保留作为聊天记忆并与每个请求一起发送的最近对话消息的最大数量。

默认值：`20`
