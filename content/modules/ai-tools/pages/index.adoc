= AI Tools

The AI Tools add-on brings a Large Language Model (LLM) powered assistant into your Jmix application. Out of the box it provides a ready-to-use chat UI in which users ask questions in natural language and the assistant answers them, using xref:ai-tools:tools.adoc[tools] to discover the application's data model and to load business data with read-only queries that respect the current user's xref:security:index.adoc[data access] permissions.

The add-on is built on top of https://docs.spring.io/spring-ai/reference/[Spring AI^]. It does not bundle a specific model provider: you choose and configure a Spring AI model (OpenAI, Anthropic, Azure OpenAI, Ollama, and so on), and the add-on uses it through the standard Spring AI `ChatClient`.

[[overview]]
== Overview

The add-on offers three groups of functionality:

* Predefined tools and the data-load flow. A set of Spring AI tools lets the assistant inspect the available entities and their attributes, then generate, validate and execute a read-only JPQL query to load the data the user asked for. See xref:ai-tools:tools.adoc[].

* Extensible tool registry. Any Spring bean can contribute its own tools, and the predefined tools can be overridden. The `AiToolRegistry` collects all tools of the application. See xref:ai-tools:tools.adoc#custom-tools[Custom Tools and the Registry].

* Chat UI. Ready-made views and reusable fragments embed a complete chat experience — a chat hub with conversation history and an individual conversation view — into your application. Chat history is persisted. See xref:ai-tools:ui.adoc[].

In addition, the assistant is available xref:ai-tools:programmatic-api.adoc[programmatically], so you can call it from your own beans without the UI.

[[modules]]
== Add-on Structure

The add-on is split into layers so you only add what you need:

[cols="1,3", grid=rows, frame=none]
|===
|Starter |Description

|`jmix-aitools-starter`
|Core: the tool registry, the predefined data-load tools and the programmatic assistant API. Has no UI and no persistence.

|`jmix-aitools-flowui-starter`
|FlowUI layer: chat views, fragments and the security role. On its own it provides the UI shell but leaves the chat services as no-op stubs.

|`jmix-aitools-flowui-data-starter`
|Persistence layer: stores conversations and messages in the database and provides the working implementations of the chat services.
|===

The starters build on each other: `jmix-aitools-flowui-data-starter` depends on `jmix-aitools-flowui-starter`, which in turn depends on the core `jmix-aitools-starter`.
