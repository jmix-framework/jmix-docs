= AI Chat Components

The AI Chat Components add-on provides Flow UI components for building AI chat interfaces in a Jmix application: a complete chat, the parts it is assembled from, and a code block that renders source code in and outside a conversation.

The add-on supplies the user interface, not the model. Answers are produced by an `LLMProvider` that the application implements, so the components work with any backend — Spring AI, a vendor SDK, or your own service.

Key features:

* *Ready-made chat*: xref:ai-chat:aiChat.adoc[aiChat] composes a transcript, a composer, and an empty state over a streaming provider. One element and a provider are enough to get a working chat.
* *Streaming answers*: tokens appear as they arrive, with a thinking indicator and an optional live feed of what the assistant is doing.
* *Markdown transcript*: assistant messages render Markdown, including fenced code blocks, which become real xref:ai-chat:aiCodeBlock.adoc[aiCodeBlock] components.
* *Attachments*: files are attached by drag and drop or from a file picker, stored in Jmix file storage, and remain downloadable from the conversation history.
* *Data binding and persistence*: bind the chat to a collection container over your own message entity and persist the conversation.
* *Per-message actions*: ordinary Jmix actions per message role, with built-in copy and regenerate actions.
* *Standalone components*: the transcript, the composer, and the code block are usable on their own, outside a chat.

[NOTE]
====
The add-on is experimental. Its API may change in future releases, and Studio and IntelliJ IDEA mark calls to its classes with an *experimental API* warning. The warning is expected on correct code.
====

[[relation-to-ai-tools]]
== Relation to the AI Tools Add-on

The xref:ai-tools:index.adoc[AI Tools] add-on solves a different problem. It ships a finished assistant: a chat UI with conversation history, a registry of tools the assistant can call, and predefined tools that inspect and query application data. You install it and configure a model.

This add-on ships the building blocks. There is no assistant, no tool registry, and no persistence — you decide what a message is, where it is stored, and what answers it.

Choose AI Tools when you want an assistant over your application data. Choose AI Chat Components when the conversation is part of your own domain, or when you need a chat interface the ready-made one does not provide.
