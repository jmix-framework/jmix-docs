= aiMessageInput

`aiMessageInput` 组件为用户提供编写消息的功能：包含一个大小可变的文本域和一个发送按钮。另外，还有一些可选的配置，比如添加一些控制或者在组件周围添加应用程序上下文。

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML 元素
|`aiMessageInput`

|Java 类
|`AiMessageInput`
|===

该组件可以在应用程序中任何需要用户输入消息的地方独立使用。xref:ai-chat:aiChat.adoc[aiChat] 中嵌入并配置好了该组件，因此，在 `aiChat` 中可以使用本页介绍的所有功能。

[[overview]]
== 概览

消息输入组件将所有的控制功能都放在了同一行，其中的文本输入也适配为一行：

image::aichat-message-input-collapsed.png[Message input in its collapsed state, align="center", width="672"]

一旦文本输入超过一行，文本域会占据全部宽度，将控制功能调整到下一行的工具栏中：

image::aichat-message-input-expanded.png[Message input in its expanded state, align="center", width="672"]

[source,xml,indent=0]
----

一个独立的消息输入组件会占据父容器的所有宽度。与聊天组件中不同，在聊天组件中，消息输入本身没有宽度，因此需要指定一个宽度或放置在一个有限制宽度的容器中。

[[submitting]]
== 提交消息

在应用程序中，可以通过提交事件获取输入的消息文本：

[source,java,indent=0]
----
include::example$/ai-chat-ex1/src/main/java/com/company/demo/view/messageinput/MessageInputView.java[tags=submit]
----

事件中包含了提交的文本，然后文本域会自己清空内容。

[NOTE]
====
消息输入本身并没有开放对其文本的访问，即没有 `getValue()` 或 `setValue()` 方法，因此无发实现同步读取用户输入、预设置输入提示值或编程式清空值。仅当用户提交时才能获取到文本内容。
====

[[text-area]]
== 文本域

该控件会随着用户输入自动增长至 `maxRows` 行（默认 10 行），并自动滚动：

[source,xml,indent=0]

[source,xml,indent=0]

----

配置也支持移动端键盘如何显示操作。

[[styling]]
== 样式

消息输入框将其内部结构作为 shadow part 开放出来，可通过 `::part()` 选择器定位。

以下样式属性可在 CSS 样式表中用于自定义该组件的外观。

[cols="2,3", options="header"]
|===
|名称
|描述

|`--jmix-ai-message-input-background`
|输入框的背景。

|`--jmix-ai-message-input-padding`
|输入框的内边距。

|`--jmix-ai-message-input-gap`
|消息输入框各部分之间的间隙：区域、标签托盘、字段和按钮。

|`--jmix-ai-message-input-max-width`
|组件在其中居中的宽度。在聊天组件之外未设置，因此独立的消息输入框会填满其容器。

|`--jmix-ai-message-input-icon-send`
|发送按钮的字形。

|`--jmix-ai-message-input-icon-stop`
|答案正在生成时发送按钮显示的字形。
|===

[[theme-variants]]
=== 主题样式

[cols="2,3", options="header"]
|===
|主题名称
|效果

|`fixed-toolbar`
|始终将控件保持在单独的一行中，而不是仅在文本增长超过一行时才单列。参见 <<fixed-toolbar,固定工具栏>>。

|`no-header-footer-gap`
|移除区域与输入框之间的间隙，使区域看起来像是字段的延续。参见 <<bands,页眉和页脚区域>>。
|===

当组件在聊天组件内部使用时，两个配置都能作用于消息输入框。参见那里的 xref:ai-chat:aiChat.adoc#styling[样式]。

这些组件针对 Jmix 的两种主题 Aura 和 Lumo 都进行了样式设置，并遵循主题自身的焦点环、边框、圆角和间距方面的样式变量，因此上面的属性没有单一的默认值。此外，组件还处理了暗黑模式、高对比度模式以及减弱动画效果，并且其布局采用了与文本方向无关的属性来表示，从而能够自动适应文档的文本书写方向。

== 附件

消息输入框可以接受文件，通过拖拽的方式或从文件选择器添加，附件与消息一起传递。附件涉及到多个方面的内容，因此在 xref:ai-chat:attachments.adoc[] 中一并介绍。

== XML 内部元素

一个 `aiMessageInput` 可以包含 `prefix`、`suffix`、`header`、`footer`、`tooltip` 和 `i18n` 等内部元素。

[[prefix-suffix-elements]]
=== prefix、suffix

`prefix` 和 `suffix` 元素各包含一个组件，放置在输入框内部、输入控件之前和之后。参见 <<slots,前缀和后缀>>。

[[header-footer-elements]]
=== header、footer

`header` 和 `footer` 元素各包含一个组件，放置在消息输入组件内部但在输入框之外。参见 <<bands,页眉和页脚区域>>。

[[i18n-element]]
=== i18n

`i18n` 元素用于对列表文本进行本地化。支持 `placeholder`、`send`、`stop` 和 `attach` 属性，每个属性都支持消息键值。省略的属性使用其在扩展组件消息包中的值。参见 <<localization,本地化>>。
