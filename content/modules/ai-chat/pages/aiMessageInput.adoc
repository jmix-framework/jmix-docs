= aiMessageInput

Компонент `aiMessageInput` служит для ввода сообщения пользователем: это расширяющееся текстовое поле с кнопкой отправки, необязательными элементами управления рядом с полем и необязательным содержимым, задаваемым приложением, над и под ним.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML-элемент
|`aiMessageInput`

|Java-класс
|`AiMessageInput`
|===

Используйте его отдельно везде, где приложение получает сообщение от пользователя. xref:ai-chat:aiChat.adoc[aiChat] встраивает его и настраивает автоматически, поэтому всё, что описано на этой странице, доступно и через чат.

[[overview]]
== Обзор

Пока текст помещается в одну строку, поле ввода сообщений держит свои элементы управления в одном ряду:

image::aichat-message-input-collapsed.png[Поле ввода сообщений в свёрнутом состоянии, align="center", width="672"]

Когда текст становится длиннее одной строки, поле занимает всю ширину, а элементы управления перестраиваются в строку панели инструментов под ним:

image::aichat-message-input-expanded.png[Поле ввода сообщений в развёрнутом состоянии, align="center", width="672"]

== Основы

Объявите пространство имен `aichat` в XML-дескрипторе экрана:

----

Полю ввода сообщений не нужно ничего, кроме самого элемента:

[source,xml,indent=0]
----
include::example$/ai-chat-ex1/src/main/resources/com/company/demo/view/messageinput/message-input-view.xml[tags=basics]
----

Отдельное поле ввода сообщений занимает всю ширину своего контейнера. В отличие от поля внутри чата, у него нет собственной ширины, поэтому задайте ему ширину или поместите его в контейнер, который ограничивает ширину.

[[submitting]]
== Отправка сообщения

Текст передается в приложение через событие отправки:

[source,java,indent=0]
----
include::example$/ai-chat-ex1/src/main/java/com/company/demo/view/messageinput/MessageInputView.java[tags=submit]
----

Событие содержит отправленный текст, а поле затем очищается само, поэтому приложению не нужно это делать.

[NOTE]
====
Поле ввода сообщений не предоставляет доступ к введенному в нем тексту. В нем нет методов `getValue()` и `setValue()`, поэтому приложение не может прочитать то, что вводит пользователь, заранее заполнить поле предлагаемым запросом или очистить его до отправки. Текст становится доступен только тогда, когда пользователь отправляет его.
====

[[text-area]]
== Текстовое поле

Поле увеличивается вместе с содержимым до `maxRows` строк (по умолчанию десять), а после этого прокручивается внутри:

[source,xml,indent=0]
----
include::example$/ai-chat-ex1/src/main/resources/com/company/demo/view/messageinput/message-input-view.xml[tags=max-rows]
----

По умолчанию *Enter* отправляет сообщение, а *Shift+Enter* вставляет перенос строки. Установите `enterAction` в `NEWLINE`, чтобы поменять их местами: тогда *Enter* вставляет перенос строки, а *Ctrl/Cmd+Enter* отправляет сообщение:

[source,xml,indent=0]
----
include::example$/ai-chat-ex1/src/main/resources/com/company/demo/view/messageinput/message-input-view.xml[tags=enter-action]
----

Эта настройка также сообщает мобильным клавиатурам, какую подпись показывать на клавише действия.

== Верхняя и нижняя полосы

Элементы `header` и `footer` содержат контент приложения внутри поля ввода сообщений, но вне области ввода, например строку контекста над полем или предупреждение под ним:

----

.Пакет сообщений
[source,properties,indent=0]
----
include::example$/ai-chat-ex1/src/main/resources/com/company/demo/messages_en.properties[tags=message-input-bands]
----

Полосы повторяют ширину и выравнивание по центру области ввода, поэтому они выровнены по полю, а не по окружающему макету. Их содержимое можно инжектировать по id, и оно отключается вместе с полем ввода сообщений.

Чтобы прижать полосу к области ввода, убрав разделяющий их отступ, примените вариант темы `no-header-footer-gap`:

[source,xml,indent=0]
----
include::example$/ai-chat-ex1/src/main/resources/com/company/demo/view/messageinput/message-input-view.xml[tags=no-header-footer-gap]
----

Этот вариант действует сразу на обе полосы и не меняет отступы внутри области ввода.

[[fixed-toolbar]]
== Постоянная панель инструментов

По умолчанию поле ввода сообщений переключается между двумя макетами, показанными в разделе <<overview,Обзор>>, по мере увеличения текста. Вариант темы `fixed-toolbar` всегда сохраняет макет с панелью инструментов, поэтому элементы управления остаются в отдельной строке, даже когда в поле одна строка:

[source,xml,indent=0]
----
include::example$/ai-chat-ex1/src/main/resources/com/company/demo/view/messageinput/message-input-view.xml[tags=fixed-toolbar]
----

[[styling]]
== Стилизация

Поле ввода сообщений открывает доступ к своим внутренним частям как к shadow parts, к которым можно обращаться с помощью селектора `::part()`.

Следующие свойства стилей можно использовать в таблицах стилей CSS для настройки внешнего вида этого компонента.

[cols="2,3", options="header"]
|===
|Имя
|Описание

|`--jmix-ai-message-input-background`
|Фон области ввода.

|`--jmix-ai-message-input-padding`
|Внутренний отступ области ввода.

|`--jmix-ai-message-input-gap`
|Расстояние между частями поля ввода сообщений: полосами, лотком с вложениями, полем и кнопками.

|`--jmix-ai-message-input-max-width`
|Ширина, в пределах которой компонент выравнивается по центру. Вне чата не задана, поэтому отдельное поле ввода сообщений занимает весь свой контейнер.

|`--jmix-ai-message-input-icon-send`
|Значок кнопки отправки.

|`--jmix-ai-message-input-icon-stop`
|Значок, который показывает кнопка отправки, пока генерируется ответ.
|===

[[theme-variants]]
=== Варианты темы

[cols="2,3", options="header"]
|===
|Имя темы
|Результат

|`fixed-toolbar`
|Всегда держит элементы управления в отдельной строке, а не только когда текст становится длиннее одной строки. См. <<fixed-toolbar,Постоянная панель инструментов>>.

|`no-header-footer-gap`
|Убирает отступ между полосами и областью ввода, так что полоса выглядит как продолжение поля. См. <<bands,Верхняя и нижняя полосы>>.
|===

Если применить их к чату, оба варианта передаются его полю ввода сообщений. См. раздел xref:ai-chat:aiChat.adoc#styling[Стилизация] на странице чата.

Компоненты стилизованы для обеих тем Jmix, Aura и Lumo, и используют собственные токены темы для рамок фокуса, границ, радиусов скругления и отступов, поэтому у перечисленных выше свойств нет единого значения по умолчанию. Поддерживаются темный режим, режим высокой контрастности и уменьшение анимации, а макет описан свойствами, которые не зависят от направления, поэтому компоненты следуют направлению текста документа.

== Вложения

Поле ввода сообщений может принимать файлы, перетаскиванием или через диалог выбора файла, и передавать их вместе с сообщением. Вложения затрагивают несколько компонентов, поэтому они описаны вместе в разделе xref:ai-chat:attachments.adoc[].

== Элементы

`aiMessageInput` может содержать следующие вложенные элементы: `prefix`, `suffix`, `header`, `footer`, `tooltip` и `i18n`.

[[prefix-suffix-elements]]
=== prefix, suffix

Элементы `prefix` и `suffix` содержат по одному компоненту, который размещается внутри области ввода, перед полем и после него. См. <<slots,Префикс и суффикс>>.

[[header-footer-elements]]
=== header, footer

Элементы `header` и `footer` содержат по одному компоненту, который размещается внутри поля ввода сообщений, но вне области ввода. См. <<bands,Верхняя и нижняя полосы>>.

[[i18n-element]]
=== i18n

Элемент `i18n` изменяет тексты этого поля ввода сообщений. Он поддерживает атрибуты `placeholder`, `send`, `stop` и `attach`, каждый из которых принимает ключ сообщения. Атрибуты, которые не указаны, сохраняют значения из пакета сообщений. См. <<localization,Локализация>>.
