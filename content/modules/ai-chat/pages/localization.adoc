= Localization

Every label the components show — the composer's placeholder, the accessible names of its buttons, the error banner and its *Retry*, the copy and wrap actions of a code block, the *Show more* toggle of a long message — comes from the add-on's message bundle. There are two ways to change them, and they compose.

[[message-bundle]]
== Changing Every Chat

The add-on's keys are grouped by component:

[cols="1,3", options="header"]
|===
|Key family
|Covers

|`+aiChat.i18n.*+`
|The chat's own announcements of the generation lifecycle, read to screen readers.

|`+aiMessageInput.i18n.*+`
|The composer: placeholder, send, stop, attach, and the messages shown on a rejected file.

|`+aiMessageList.i18n.*+`
|The message list: error banner, retry, scroll-to-bottom, copy, and the collapse toggle.

|`+aiCodeBlock.i18n.*+`
|A code block: copy, copied, and the two wrap labels.
|===

Redefine any of them in the application's own message bundle, and every component in the application follows:

[[precedence]]
== Precedence

The two mechanisms layer, with the more specific winning:

. The add-on's own message bundle supplies every label.
. A key redefined in the application's message bundle replaces it everywhere.
. An attribute on a nested `i18n` element replaces it for that one instance.

An element overrides rather than replaces: a label you do not declare keeps the value from the level below, and an empty `i18n` element changes nothing. So a chat that declares no `i18n` at all still shows an application-wide override, and a chat that declares one still shows the application's wording for every label it does not mention.
