= aiChat

The `aiChat` component is a complete chat: a message list, a message input, an empty state, and the generation cycle that connects them to a language model.

[cols="1h,1", options="autowidth", grid=none, frame=none]
|===
|XML Element
|`aiChat`

|Java Class
|`AiChat`
|===

It composes xref:ai-chat:aiMessageList.adoc[aiMessageList] and xref:ai-chat:aiMessageInput.adoc[aiMessageInput] and configures both on your behalf, so most of what those pages describe is reachable from here as well.

[[persistence]]
== Persistence

`autoSave="true"`, shown in the example above, makes the chat persist through the view's `DataContext`: each committed message is merged and saved, and a message removed by a rewind is deleted.

[NOTE]
====
`autoSave` saves the whole `DataContext`, not only the message — sending a message also commits unrelated edits made elsewhere in the view. It is also an XML attribute with no Java equivalent: from a controller you install a save delegate and a remove delegate instead, which is also what an application does when it needs to persist differently.
====

If the chat is inside a detail view whose `DataContext` has a parent, a save reports success while the row reaches the database only when the parent view is saved — and cancelling there discards the conversation with the rest.

An application that persists messages itself can ignore both and listen for `MessageChangeEvent`, which reports every message added or removed.

[[configuring]]
== Configuring the Parts

Everything the message list and the message input offer is reachable from the chat. The `maxRows`, `enterAction`, and attachment attributes configure the composer; `announceMessages` configures the message list; the `thinkingIndicator`, `thinkingStages`, `userActions`, and `assistantActions` elements are declared on the chat and applied to the message list; and `inputPrefix` and `inputSuffix` fill the composer's slots. See xref:ai-chat:aiMessageList.adoc[] and xref:ai-chat:aiMessageInput.adoc[] for what each does.

`--jmix-ai-chat-max-width` sets the width of the whole conversation column — the message list, the message input, and the empty state together. Its default is `768px`.

NOTE: `AiChat` has no custom element of its own. It renders as a plain `div` containing the message list and message input elements, so it cannot be selected by a tag name in CSS or found by one in the browser's inspector. Use its id or a class name.

[[localization]]
== Localization

The chat's own announcements come from the add-on's message bundle, under the `+aiChat.i18n.*+` keys. Its nested `i18n` element mirrors the component tree: attributes on the element itself re-word the chat, and nested `messageList`, `messageInput`, and `codeBlock` elements reach the parts it composes. See xref:ai-chat:localization.adoc[].

[[attachments]]
== Attachments

The chat threads attachments end to end: the message input collects them, the message factory stores them, and the message list renders them. See xref:ai-chat:attachments.adoc[].

== Elements

An `aiChat` can include `actions`, `systemPrompt`, `inputPrefix`, `inputSuffix`, `inputHeader`, `inputFooter`, `thinkingIndicator`, `thinkingStages`, `userActions`, `assistantActions`, `emptyStateHeader`, `emptyStateFooter`, and `i18n` as its nested elements.

[[actions-element]]
=== actions

The `actions` element contains the chat's own `action` elements. See <<actions,Chat Actions>>.

[[systemPrompt-element]]
=== systemPrompt

The `systemPrompt` element holds a multi-line system prompt, as an alternative to the attribute of the same name.

[[input-slots-elements]]
=== inputPrefix, inputSuffix, inputHeader, inputFooter

These elements fill the composer's slots — the first two inside the input box, the last two as bands outside it. See <<bands,Composer Bands>> and xref:ai-chat:aiMessageInput.adoc#slots[Prefix and Suffix].

[[empty-state-elements]]
=== emptyStateHeader, emptyStateFooter

These elements hold the content shown above and below the composer while the chat is empty. See <<empty-state,Empty State>>.

[[transcript-elements]]
=== thinkingIndicator, thinkingStages, userActions, assistantActions

These elements configure the message list and behave as described for xref:ai-chat:aiMessageList.adoc#thinking-indicator[aiMessageList].

[[i18n-element]]
=== i18n

The `i18n` element re-words this chat and, through its nested `messageList`, `messageInput`, and `codeBlock` elements, the parts it composes. See <<localization,Localization>>.
