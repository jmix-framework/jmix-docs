`aiChat` 包含与 AI 对话所需的全部组件：消息列表、消息输入框、空状态，以及将与语言模型连接的生成周期。

[[persistence]]
== 持久化

上面示例中展示的 `autoSave="true"` 会让聊天通过视图的 `DataContext` 进行持久化：每条已提交消息都会被合并然后保存，而回退操作移除的消息会被删除。

[NOTE]
====
`autoSave` 会保存整个 `DataContext`，而不仅仅是当前的消息，因此发送消息也会同时提交在视图其他地方所做的、与此无关的修改。它也是一个只有 XML 属性而没有等价 Java 实现的配置：在控制器中，通常需要改为安装一个保存委托（save delegate）和一个移除委托（remove delegate），这也是应用程序在需要以不同方式进行持久化时所采用的做法。
====

不使用 `autoSave` 时，可以通过安装这两个委托进行消息的持久化。每条已提交消息都会运行 `saveDelegate`，在它进入对话之前运行，聊天会采用委托返回的实例。持久化层返回的对象通常与传入的对象不同，而容器和 `DataContext` 会继续跟踪返回的那个对象。回退丢弃的每条消息也都会运行 `removeDelegate`，最新的先执行。

如果需要用自己的方式持久化，也可以两个都不安装，转而监听 `MessageChangeEvent`，该事件会报告每一条添加或移除的消息。

[[configuring]]
== 配置各个部分

消息列表和消息输入框提供的所有功能都可以从聊天中访问。`maxRows`、`enterAction` 和附件属性用于配置消息输入框；`announceMessages` 用于配置消息列表；`thinkingIndicator`、`thinkingStages`、`userActions` 和 `assistantActions` 元素在聊天上声明并用于消息列表；`inputPrefix` 和 `inputSuffix` 填充消息输入框的插槽。每个功能的作用参见 xref:ai-chat:aiMessageList.adoc[] 和 xref:ai-chat:aiMessageInput.adoc[]。

[[localization]]
== 本地化

聊天自身的文本在扩展组件的消息包中定义，使用 `+aiChat.i18n.*+` 键。其嵌套的 `i18n` 元素与组件树对应：元素本身的属性可以用来重写聊天组件的文本，而嵌套的 `messageList`、`messageInput` 和 `codeBlock` 元素则可定义其组合的各个部分的文本。参见 xref:ai-chat:localization.adoc[]。

== XML 内部元素

一个 `aiChat` 元素内可以包含 `actions`、`systemPrompt`、`inputPrefix`、`inputSuffix`、`inputHeader`、`inputFooter`、`thinkingIndicator`、`thinkingStages`、`userActions`、`assistantActions`、`emptyStateHeader`、`emptyStateFooter` 和 `i18n` 作为嵌套元素。

[[actions-element]]
=== actions

`actions` 元素包含聊天自有的 `action` 元素。参建 <<actions,聊天操作>>。

[[systemPrompt-element]]
=== systemPrompt

`systemPrompt` 元素可以配置多行的系统提示词，与同名 XML 属性的作用一致。

[[input-slots-elements]]
=== inputPrefix、inputSuffix、inputHeader、inputFooter

这些元素用于填充消息输入框的插槽：前两个位于其框体内部，后两个作为其外部的区域。参见 <<bands,消息输入框区域>> 和 xref:ai-chat:aiMessageInput.adoc#slots[前缀和后缀]。

[[empty-state-elements]]
=== emptyStateHeader、emptyStateFooter

这些元素配置聊天为空时显示在消息输入框上方和下方的内容。参见 <<empty-state,空状态>>。

[[message-list-elements]]
=== thinkingIndicator、thinkingStages、userActions、assistantActions

这些元素配置消息列表，详情参考 xref:ai-chat:aiMessageList.adoc#thinking-indicator[aiMessageList]。

[[i18n-element]]
=== i18n

`i18n` 元素重新配置该聊天的本地化文本，并通过其嵌套的 `messageList`、`messageInput` 和 `codeBlock` 元素配置各个部分的文本。参见 <<localization,本地化>>。
