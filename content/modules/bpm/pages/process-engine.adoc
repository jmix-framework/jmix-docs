= Движок Процессов

Движок процессов Flowable является основным компонентом, ответственным за управление и выполнение бизнес-процессов в Jmix BPM. Он предоставляет необходимую инфраструктуру для развертывания, запуска и контроля над процессами.

image::bpm:process-engine.png[,700]

Внутри движка содержатся следующие сервисы:

* **RepositoryService**: Ответственен за развертывание и управление определениями процессов BPMN.
* **RuntimeService**: Управляет выполнением экземпляров процессов и обрабатывает их переходы состояний.
* **TaskService**: Управляет пользовательскими задачами, позволяя создавать, назначать и запрашивать задачи.
* **IdentityService**: Обеспечивает аутентификацию и авторизацию пользователей.
* **ManagementService**: Предоставляет административные функции для управления движком и его ресурсами.
* **HistoryService**: Управляет историческими данными, связанными с завершенными экземплярами процессов.
* **DynamicBpmnService**: Позволяет вносить динамические изменения в модели BPMN во время выполнения.
* **FormService**: Обеспечивает обработку форм в рамках процессов. (Не используется в Jmix BPM.)

Получить доступ к движку процессов можно через xref:jmix-bpm-api.adoc#flowable-api[Flowable API].

== Настройка движка процессов

Jmix BPM подключает Flowable Spring Boot starter, который создает движок процессов.
Чтобы изменить настройки движка, используйте https://www.flowable.com/open-source/docs/bpmn/ch05a-Spring-Boot#flowable-application-properties[свойства приложения^] `flowable.*`.
Для настройки, у которой нет свойства приложения, создайте Spring-бин, реализующий `EngineConfigurationConfigurer<SpringProcessEngineConfiguration>`.
См. раздел https://www.flowable.com/open-source/docs/bpmn/ch05a-Spring-Boot#customizing-engine-configuration[Customizing Engine Configuration^] в документации Flowable.

CAUTION: Jmix BPM настраивает движок процессов собственным конфигуратором `BpmSpringProcessEngineConfigurationConfigurer`. Он задает типизированные слушатели событий, обработчики разбора BPMN (custom default и post), фабрику поведения активностей, сервис задач и перехватчик запуска экземпляров процессов. Если ваш конфигуратор заменит любой из этих объектов, функции Jmix BPM могут перестать работать, часто без сообщений об ошибках.
