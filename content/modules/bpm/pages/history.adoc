= 历史记录

历史记录会捕捉流程执行过程发生的事情，并永久保存。
与运行时数据不同，即使流程示例完成了，历史数据也依然保存在数据库中。

流程引擎有六个历史记录实体：

[[historic-process-instances]]
* *历史流程实例（Historic Process Instances）* -- 当前和过去的流程实例。
* *历史变量实例（Historic Variable Instances）* -- 流程变量或任务变量的最新值。
* *历史活动实例（Historical Activity Instances）*-- 活动（流程中的节点）的单次执行的信息。
* *历史任务实例（Historic Task Instances）*-- 当前和过去（已完成和已删除）任务实例。
* *历史身份链接（Historic Identity Links）*-- 任务和流程实例的当前和过去身份链接的信息。
* *历史详细信息（Historic Details）*-- 与历史流程实例、活动实例或任务实例相关的各种附加信息，例如变量变更。

历史实体涵盖正在进行和已完成的实例。
为了保证流程的执行速度，请尽可能查询历史实体而不是运行时数据，例如在运行报表和监控时。
可用数据取决于 <<history-levels,历史级别>>。

[[history-levels]]
== 历史级别

历史级别定义流程引擎存储哪些历史实体：

[cols="1,6", grid=rows, frame=none]
|===
|*Level*
|*Stored entities*
|`none`
|无。
|`instance`
|历史流程实例。
|`task`
|历史流程实例和任务实例。
|`activity`
|历史流程实例、活动实例和变量实例。
|`audit`
|历史流程实例、任务实例、活动实例、变量实例和身份链接。这是默认级别。
|`full`
|`audit` 中存储的所有实体，加上每次变量值更改的历史详细信息。此级别会产生大量数据。
|===

如需为整个流程引擎设置级别，请使用 `flowable.history-level` https://www.flowable.com/open-source/docs/bpmn/ch05a-Spring-Boot#flowable-application-properties[应用程序属性^]：

[source,properties]
----
flowable.history-level=activity
----

如需为特定流程设置级别，请在 xref:bpm:menu-views/modeler-web.adoc[建模器] 中使用 *History level* xref:bpm:bpmn/bpmn-process.adoc#properties[流程属性]。

[NOTE]
====
如需忽略特定流程的历史级别并始终使用流程引擎的历史级别，请设置以下应用程序属性：

[source,properties]
----
flowable.process.enable-process-definition-history-level=false
----
====

详情参阅 https://www.flowable.com/open-source/docs/bpmn/ch10-History[Flowable 文档^]。
