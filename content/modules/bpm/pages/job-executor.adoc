= Job Executor

The job executor runs the jobs of the process engine in background threads.
The Flowable documentation calls it the async executor and describes how it works, see https://www.flowable.com/open-source/docs/bpmn/ch18-Advanced#async-executor[Async Executor^].

[[job-types]]
== Job Types

The process engine creates jobs for:

* xref:bpm:bpmn/transactions.adoc#asynchronous-continuation[Asynchronous continuations]: elements with the *Asynchronous* or *Asynchronous leave* property.
* xref:bpm:bpmn/bpmn-events.adoc#timer-events[Timer events].

[[failed-jobs]]
== Retries and Failed Jobs

If a job throws an exception, the process engine rolls back the job's transaction and retries the job later.
By default, a job has 3 retries.
To change the default, call `setAsyncExecutorNumberOfRetries()` in a xref:bpm:process-engine.adoc#process-engine-configuration[process engine configurer].
To set the number of retries and the delay between them for a service task, use its xref:bpm:bpmn/bpmn-service-task.adoc#configuring-fail-retry[*Failed job retry time cycle*] property.

When a job has no retries left, it becomes a failed job, which Flowable calls a dead letter job.
The job executor doesn't execute failed jobs.
To see, restore or delete them, use the *Failed jobs* tab of the xref:bpm:menu-views/process-instances.adoc#process-instance-detail[process instance detail view].

Retries apply only to jobs.
If an element runs in the transaction of an API call, for example, a service task that follows a user task, an exception rolls back this transaction to the last wait state and goes to the caller.
See xref:bpm:bpmn/transactions.adoc[].

[[job-executor-configuration]]
== Job Executor Configuration

To configure how the job executor acquires and locks jobs, use the `flowable.process.async.executor.*` application properties.
See https://www.flowable.com/open-source/docs/bpmn/ch05a-Spring-Boot#configuring-async-executors[Configuring Async Executors^] in the Flowable documentation, which also explains which thread pool the job executor uses.
