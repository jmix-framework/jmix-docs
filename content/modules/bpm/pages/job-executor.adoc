= Исполнитель заданий

Исполнитель заданий (job executor) выполняет задания движка процессов в фоновых потоках.
В документации Flowable он называется async executor. Как он работает, описано в разделе https://www.flowable.com/open-source/docs/bpmn/ch18-Advanced#async-executor[Async Executor^].

[[job-types]]
== Типы заданий

Движок процессов создает задания для:

* xref:bpm:bpmn/transactions.adoc#asynchronous-continuation[асинхронных продолжений] — элементов со свойством *Asynchronous* или *Asynchronous leave*;
* xref:bpm:bpmn/bpmn-events.adoc#timer-events[событий таймера].

[[failed-jobs]]
== Повторные попытки и неуспешные задания

Если задание выбрасывает исключение, движок процессов откатывает транзакцию задания и позже выполняет задание повторно.
По умолчанию у задания три повторные попытки.
Чтобы изменить это значение, вызовите `setAsyncExecutorNumberOfRetries()` в xref:bpm:process-engine.adoc#process-engine-configuration[конфигураторе движка процессов].
Для сервисной задачи количество попыток и интервал между ними задает ее свойство xref:bpm:bpmn/bpmn-service-task.adoc#configuring-fail-retry[*Failed job retry time cycle*].

Задание, у которого не осталось попыток, становится неуспешным (в Flowable — dead letter job).
Исполнитель заданий не выполняет неуспешные задания.
Чтобы посмотреть, восстановить или удалить их, откройте вкладку *Failed jobs* на экране xref:bpm:menu-views/process-instances.adoc#process-instance-detail[Process instance detail].

Повторные попытки есть только у заданий.
Если элемент выполняется в транзакции вызова API, например сервисная задача сразу после пользовательской, исключение откатывает эту транзакцию до последнего состояния ожидания и передается вызывающему коду.
См. раздел xref:bpm:bpmn/transactions.adoc[].

[[job-executor-configuration]]
== Настройка исполнителя заданий

Чтобы настроить, как исполнитель заданий получает и блокирует задания, используйте свойства приложения `flowable.process.async.executor.*`.
См. раздел https://www.flowable.com/open-source/docs/bpmn/ch05a-Spring-Boot#configuring-async-executors[Configuring Async Executors^] в документации Flowable. Там же описано, какой пул потоков использует исполнитель заданий.
