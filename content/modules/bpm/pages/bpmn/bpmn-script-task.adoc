= Задача сценариев

[[overview]]
== Обзор

*Задача сценариев* выполняет скрипт на _Groovy_, когда процесс доходит до нее.

Обычно такие задачи используются, чтобы инициализировать переменные процесса,
задать значения по умолчанию, вычислить выражения
и выполнить расчеты — все, что можно сделать небольшим фрагментом кода.

Но этим их применение не ограничивается. В скрипте можно реализовать любую бизнес-логику.

[NOTE]
====
Jmix BPM поддерживает только скрипты на Groovy. Сам Flowable поддерживает и JavaScript.
Будьте внимательны при импорте моделей процессов из внешних источников.
====

.*Графическая нотация*
Задача сценариев изображается как обычная задача BPMN 2.0 (прямоугольник со скругленными углами) с небольшим значком скрипта в левом верхнем углу.

image::bpmn-script-task/script-task.png[,150]


.*XML-представление*
Задача сценариев определяется атрибутами `script` и `scriptFormat`.

[source,xml]
----
<scriptTask id="script-task" name="Script task"
    scriptFormat="groovy"  <1>
    flowable:resultVariable="result"> <2>
      <script>
        printlnt "This is a script" <3>
        return "OK"
    </script>
</scriptTask>
----
<1> тип скрипта (только Groovy)
<2> переменная результата (необязательно)
<3> тело скрипта

[[variables-scripts]]
=== Переменные в скриптах

В скрипте можно использовать все переменные процесса, доступные через исполнение, которое доходит до задачи.
В этом примере переменная скрипта `inputArray` на самом деле переменная процесса (массив целых чисел).

[source,xml]
----
<script>
    sum = 0
    for ( i in inputArray ) {
        sum += i
    }
</script>
----

В скрипте также можно задавать переменные процесса, просто вызвав:

[source,groovy]
----
execution.setVariable("variableName", variableValue)
----

По умолчанию переменные автоматически не сохраняются.

[[beans-scripts]]
=== Бины в скриптах

В скриптах к бинам можно обращаться по имени. Следующий скрипт на Groovy вызывает метод `doSomething` бина `MyBean` и сохраняет результат в контексте исполнения как переменную:

[source, groovy]
----
res = MyBean.doSomething()
execution.setVariable("doSomething", res)
----

TIP: Основной и рекомендуемый способ вызвать бин — xref:bpmn/bpmn-service-task.adoc[]. Если нужно совместить логику на Groovy с вызовами Java-бинов, вызовите бин из сервисной задачи до или после задачи сценариев и передавайте данные между ними через переменные процесса.

[[script-result]]
=== Результат скрипта

Возвращаемое значение задачи можно присвоить существующей или новой переменной процесса.
Чтобы указать целевую переменную, задайте ее в поле *Result variable* на панели свойств задачи.

При выполнении задачи возвращаемое значение скрипта автоматически присваивается указанной переменной процесса.
Если переменной нет, Flowable создает новую с именем из поля *Result variable*.

С помощью поля *Result variable* результаты задач можно включить в переменные процесса,
чтобы хранить, изменять и использовать данные на протяжении всего выполнения процесса.

Возвращаемое значение скрипта можно присвоить существующей переменной или новой переменной процесса.
Ее можно задать в поле _Result variable_ на панели свойств.

В скрипте можно использовать оператор `return`. Например:

[source,groovy]
----
def a = "abc"
return a
----

Если в скрипте нет `return`, результатом станет результат последней строки. В этом примере это `"JMIX"`.

[source,groovy]
----
String a = "abc".toUpperCase()
String b = "jmix".toUpperCase()
----
