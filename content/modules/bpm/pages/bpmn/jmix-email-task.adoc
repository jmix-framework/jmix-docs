= Задача отправки электронной почты

[[overview]]
== Обзор
*Задача отправки электронной почты* позволяет отправлять электронные письма во время выполнения процесса.
Для успешной отправки должно быть установлено дополнение xref:email:index.adoc[Email].

Это собственная задача Jmix, а не стандартная задача BPMN.

*Графическая нотация*

Задача изображается как прямоугольник со скругленными углами и небольшим значком конверта в левом верхнем углу.
Значок закрашен, что обозначает семантику отправки.

[[email-parameters]]
== Параметры письма

У задачи есть общие параметры отправки писем: получатель, отправитель, тема и т. д.

[[set-address]]
=== Задание адресов

* Адреса получателей
** *To* — адреса основных получателей. Адрес можно задать переменной процесса или выражением либо ввести напрямую. Допускается несколько адресов.
** *Cc* — получатели копии. Можно использовать переменную процесса или ввести адреса напрямую. Допускается несколько адресов.
** *Bcc* — получатели скрытой копии. Можно использовать переменную процесса или ввести адреса напрямую. Допускается несколько адресов.
* *From* — адрес отправителя, поэтому допускается только одно значение. Это поле можно задать значением или выражением.
* *Subject* — тема письма. Для динамических значений поддерживаются переменные процесса.
* *Content* — текст письма. В редакторе можно выбрать тип содержимого: HTML или обычный текст. Для динамического формирования содержимого здесь также можно использовать переменные процесса.

[[async-sending]]
=== Асинхронная отправка
По умолчанию письма отправляются асинхронно. Это можно изменить флажком *Send asynchronously*.

[[attachements-content]]
=== Вложения

Чтобы приложить файлы, используйте раздел *Attachments*. Содержимое нужно передать выражением через переменную процесса или вызовом метода бина Spring, который возвращает один из типов: `File`, `FileRef`, `byte[]` или `FileDescription`.

Имя вложения указывать необязательно. Если имя не задано, используется имя, полученное из содержимого файла. Если содержимое файла передается как `byte[]`, имя по умолчанию строится по шаблону `attachment_<incremental_part>`.
