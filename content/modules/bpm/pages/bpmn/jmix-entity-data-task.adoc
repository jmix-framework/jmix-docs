= Задача обработки сущностей

[[overview]]
== Обзор

*Задача обработки сущностей* (Entity Data Task) — особый тип сервисной задачи,
который выполняет операции с _сущностями Jmix_ в процессе.
Для работы с данными ее удобнее использовать, чем обычную сервисную задачу.
Она позволяет загружать сущности из базы данных, изменять их и создавать новые.

.*Графическая нотация*

Задача обработки сущностей изображается как прямоугольник со скругленными углами и небольшим значком базы данных в левом верхнем углу.

image::jmix-data-task/data-task.png[,150]

NOTE: Задача обработки сущностей — расширение, специфичное для Jmix, поэтому другие инструменты моделирования BPMN ее не поддерживают. При экспорте модели она заменяется стандартной сервисной задачей, но ее свойства в XML сохраняются.

.*XML-представление*

XML-представление задачи обработки сущностей зависит от ее типа. Примеры см. в описаниях соответствующих типов задачи.

Вот только что созданная задача обработки сущностей; по умолчанию это задача _Load entity_.

[source,xml]
----
    <serviceTask id="entity-data-task" name="Entity Data Task"
        flowable:type="jmix-load-entities-jpql">
      <extensionElements />
    </serviceTask>
----

[[data-task-types]]
== Типы задачи обработки сущностей

Задача может выполнять одно из следующих действий:

* xref:modifying-entities[Изменение сущностей]
* xref:creating-entities[Создание сущностей]
* xref:loading-entities[Загрузка сущностей]

TIP: Чтобы удалить сущность, используйте сервисную задачу и вызовите метод, который удаляет ее с помощью xref:jmix:data-access:data-manager.adoc[DataManager].

[[loading-entities]]
=== Загрузка сущностей

Чтобы загрузить сущности, выберите тип задачи _Load Entities_ на панели свойств. Затем задайте *JPQL query* и при необходимости xref:loading-result[*переменную результата*].

[[query-parameters]]
==== Параметры JPQL-запроса
Параметры условий WHERE и ORDER BY можно задать прямо в теле запроса, например:

 select s from smpl_Order s where s.amount < 500

Но часто значения параметров нужно задавать извне, то есть во время выполнения.
Для этого создайте именованные параметры:

image::jmix-data-task/create-jpql-parameter.png[,463]

WARNING: Имя создаваемого параметра должно совпадать с именем параметра в запросе. Автоматической проверки нет.

Значения параметров можно передать в процесс двумя способами:

* Переменная процесса
* Выражение

[[loading-result]]
=== Результат загрузки

Чтобы использовать результат загрузки дальше в процессе, задайте *Result variable*.
Можно ввести имя существующей переменной процесса или произвольное имя — тогда будет создана новая переменная.

Если уже есть переменная процесса с таким именем, но другого типа, она будет перезаписана.
Тип переменной результата определяется типом результата запроса.

Кроме того, в поле *Save result as* можно выбрать один из двух вариантов в зависимости от ожидаемого результата запроса: *Single element* или *Collection*.

*XML-представление*

В XML задача загрузки сущностей объявляется как сервисная задача с собственным типом `flowable:type`.

[source,xml]
----
<serviceTask id="load-orders-task" name="Load orders"
    flowable:type="jmix-load-entities-jpql"> <1>
  <extensionElements>
    <flowable:field name="jpql"> <2>
      <flowable:string>select s from smpl_Order s where s.amount &gt; :amount1</flowable:string>
    </flowable:field>
    <flowable:field name="resultVariable">
      <flowable:string>order</flowable:string> <3>
    </flowable:field>
    <flowable:field name="saveLoadResultAs">
      <flowable:string>collection</flowable:string> <4>
    </flowable:field>
    <flowable:field name="jpqlParameters"> <5>
      <flowable:string>[{"name":"amount1","valueType":"processVariable","value":"targetAmount"}]</flowable:string>
    </flowable:field>
  </extensionElements>
</serviceTask>
----
<1> объявление задачи загрузки данных
<2> тело JPQL-запроса
<3> имя переменной результата
<4> тип результата
<5> параметры запроса в формате JSON

[[modifying-entities]]
== Изменение сущностей

Можно изменить сущность, которая хранится в одной из существующих переменных процесса. Тип сущности определяется автоматически, и все несистемные атрибуты доступны для изменения.

Также переменную процесса можно указать напрямую, введя ее имя.
Это нужно, если переменной нет в списке, например если она создается из кода в сервисной задаче или получена как результат загрузки сущности другой задачей обработки сущностей.

image::jmix-data-task/modify-data-task-properties.png[,463]

*XML-представление*

В XML задача изменения сущностей объявляется как сервисная задача с собственным типом `flowable:type`.
Атрибуты изменяемой сущности передаются в формате JSON.

[source,xml]
----
<serviceTask id="modify-order-task" name="Modify order"
    flowable:type="jmix-modify-entity"> <1>
  <extensionElements>
    <flowable:field name="entityName">
      <flowable:string>smpl_Order</flowable:string> <2>
    </flowable:field>
    <flowable:field name="processVariable">
      <flowable:string>order</flowable:string> <3>
    </flowable:field>
    <flowable:field name="entityAttributes">
      <flowable:string>[{"name":"approvalDate","valueType":"directValue"}]</flowable:string> <4>
    </flowable:field>
  </extensionElements>
</serviceTask>
----
<1> объявление типа задачи
<2> определение класса сущности
<3> определение переменной результата
<4> атрибуты сущности в формате JSON


[[creating-entities]]
== Создание сущностей

Чтобы создать сущность, выберите имя сущности в списке. Все несистемные атрибуты можно задать с помощью *BPMN Inspector*.

image::jmix-data-task/create-data-task-properties.png[,463]

Если эта сущность понадобится дальше в процессе, задайте параметр *Result variable*.

*XML-представление*

В XML задача создания сущностей объявляется как сервисная задача с собственным типом `flowable:type`.
Атрибуты создаваемой сущности передаются в формате JSON.

[source,xml]
----
<serviceTask id="create-order-task" name="Create order"
    flowable:type="jmix-create-entity"> <1>
  <extensionElements>
    <flowable:field name="entityName">
      <flowable:string>smpl_Order</flowable:string> <2>
    </flowable:field>
    <flowable:field name="resultVariable">
      <flowable:string>order</flowable:string> <3>
    </flowable:field>
    <flowable:field name="entityAttributes">
      <flowable:string>[{"name":"status","valueType":"directValue","value":"New"},{"name":"customer","valueType":"expression","value":"${customer}"}]</flowable:string> <4>
    </flowable:field>
  </extensionElements>
</serviceTask>
----
<1> объявление типа задачи
<2> определение класса сущности
<3> определение переменной результата
<4> атрибуты сущности в формате JSON
