= Element Reference
:page-aliases: bpm:bpmn/using-bpmn-20.adoc, bpm:bpmn/bpmn-tasks.adoc

This section describes the BPMN 2.0 elements that you can use in Jmix BPM and the tasks that Jmix adds: Entity Data, Send Email and Send Notification tasks. For each element, it lists the properties in the xref:menu-views/modeler-web.adoc[Modeler] view and explains how the process engine runs the element. In XML, the Jmix tasks are service tasks with a `flowable:type` attribute, for example, `jmix-send-email`. The section doesn't explain the BPMN notation. For the notation, see the https://www.omg.org/spec/BPMN/2.0.2/About-BPMN[BPMN 2.0.2 specification^] and https://www.flowable.com/open-source/docs/bpmn/ch07b-BPMN-Constructs[BPMN 2.0 Constructs^] in the Flowable documentation.

[[unsupported-elements]]
== Unsupported Elements

The *Change type* menu of the Modeler view doesn't offer the send task, receive task, manual task and collapsed subprocess.

Jmix BPM doesn't support:

* Complex gateway. The *Change type* menu of the Modeler view offers it, but the engine doesn't implement it: a process with a complex gateway deploys without errors, but the gateway doesn't work as BPMN defines.
* Loop marker. To run an activity several times, use its xref:bpmn/multi-instance-activities.adoc[multi-instance] properties.
* Some event types. See xref:bpmn/bpmn-events.adoc#bpmn-events-coverage[BPMN Events Coverage] and xref:bpmn/bpmn-events.adoc#workarounds[Workarounds for Unsupported Events].

A task without a type, called an abstract task, can be deployed, but the engine ignores it and moves on.

[[extension-properties]]
== Extension Properties

User tasks, service tasks and script tasks have the *Extension properties* field. An extension property is a name-value pair that is saved with the element in the process XML.

image::bpmn-service-task/extension-properties.png[,460]

In XML, extension properties are defined by the `jmix:property` element:

[source,xml]
----
<serviceTask id="service-task" name="Service Task" >
<!--    . . .   -->
<extensionElements>
<!--   . . .    -->
    <jmix:properties>
      <jmix:property name="color" value="red" />
    </jmix:properties>
  </extensionElements>
</serviceTask>
----
