= Decision Table Modeler

The *Decision Table Modeler* view lets you create and edit decision tables.

image::dmn/modeler-window.png[,1000]

[[modeler-actions]]
== Modeler Actions

The following actions are available:

* *Edit decision table* – Specify the decision ID and name, configure input and output columns, and add, remove, or reorder rules.
* *Deploy decision table* – Deploy the current table to the decision engine.
* *Open draft* – Open a previously saved decision table draft.
* *Save draft* – Save the current decision table as a draft.
* *Download* – Download the current table as a DMN XML file.
* *Upload* – Import a table from a DMN XML file.
* *View XML* – Switch to the *XML* tab to inspect the generated DMN definition.

See xref:dmn-1-3.adoc#modeling-decision-tables[Modeling Decision Tables] for details about configuring inputs, outputs, and rules.
