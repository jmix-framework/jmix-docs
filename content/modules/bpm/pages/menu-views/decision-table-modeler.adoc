= 决策表建模器

使用 *Decision Table Modeler* 创建或编辑决策表。参阅 xref:dmn-1-3.adoc#modeling-decision-tables[决策表建模]。

image::dmn/modeler-window.png[,1000]

[[modeler-actions]]
== 建模器操作

可以使用以下操作：

* *Edit decision table* – 指定决策 ID 和名称，配置输入和输出列，并对规则进行添加、移除或重新排序。
* *Deploy decision table* – 将当前表部署到决策引擎。
* *Open draft* – 打开先前保存的决策表草稿。
* *Save draft* – 将当前决策表保存为草稿。
* *Download* – 将当前表下载为 DMN XML 文件。
* *Upload* – 从 DMN XML 文件导入表。
* *View XML* – 切换到 *XML* 标签页以查看生成的 DMN 定义。

参考 xref:dmn-1-3.adoc#modeling-decision-tables[决策表建模]，了解如何配置输入、输出和规则。
