[[decision-table-list]]
== 决策表列表

可以使用以下操作：

* *Filter* – 按名称或键值筛选决策表，并选择是否仅显示每个表的最新版本。
* *Open in modeler* – 将选定的表加载到 xref:menu-views/decision-table-modeler.adoc[] 中进行编辑。
* *View details* – 为选定的表打开 <<decision-editor,决策编辑器>>。
* *Upload* – 从 XML 文件部署决策表。

NOTE: 默认情况下列表是空的。不设置过滤条件点击 *Apply* 可以加载所有数据。

[[decision-editor]]
== 决策编辑器

*Decision Editor* 视图实现所选的决策表属性和 XML 定义。点击 *Delete deployment* 可以删除包含该版本在内的决策表部署。
