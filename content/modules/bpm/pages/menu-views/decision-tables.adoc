= Decision Tables

Экран *Decision Tables* содержит список развернутых таблиц решений.

image::bpm-menu-views/decision-tables.png[,800]

[[decision-table-list]]
== Список таблиц решений

Доступны следующие действия:

* *Filter* — отфильтровать таблицы решений по имени или ключу и выбрать, следует ли отображать только последнюю версию каждой таблицы.
* *Open in modeler* — загрузить выбранную таблицу в xref:menu-views/decision-table-modeler.adoc[моделер] для редактирования.
* *View details* — открыть <<decision-editor,Decision Editor>> для выбранной таблицы.
* *Upload* — развернуть таблицу решений из XML-файла.

NOTE: По умолчанию список пуст. Чтобы загрузить все таблицы решений, нажмите *Apply*, не задавая условия фильтра.

[[decision-editor]]
== Decision Editor

Экран *Decision Editor* отображает свойства выбранной таблицы и ее определение XML. Нажмите *Delete deployment*, чтобы удалить развертывание, содержащее эту версию таблицы.
