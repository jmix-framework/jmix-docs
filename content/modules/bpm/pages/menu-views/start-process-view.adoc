= Start Process

The *Start Process* view lists the process definitions the current user can start based on the configured xref:bpmn/bpmn-process.adoc#properties[starter candidates].

image::bpm-menu-views/start-process-view.png[,800]

[[starting-a-process]]
== Starting a Process

The following actions are available:

* *Start process* – Start a new instance of the selected process definition. If the process has a start form, the form opens before the process starts.
* *Refresh* – Reload the list of available process definitions.
