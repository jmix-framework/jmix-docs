= Start Process

Экран *Start Process* содержит определения процессов, которые текущий пользователь может запустить с учетом настроенных xref:bpmn/bpmn-process.adoc#properties[кандидатов на запуск].

image::bpm-menu-views/start-process-view.png[,800]

[[starting-a-process]]
== Запуск процесса

Доступны следующие действия:

* *Start process* — запустить новый экземпляр выбранного определения процесса. Если у процесса есть форма запуска, она откроется до запуска процесса.
* *Refresh* — перезагрузить список доступных определений процессов.
