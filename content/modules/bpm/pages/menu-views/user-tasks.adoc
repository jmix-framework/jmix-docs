[[user-task-list]]
== 用户任务列表

可以使用以下操作：

* *Filter* – 按流程定义、分配人、候选用户或候选组筛选任务，然后点击 *Apply*。
* *Reassign task* – 将所选任务重新分配给另一个用户。
+
image::bpm-menu-views/task-reassign.png[,800]
+
* *Open process instance* – 打开与所选任务关联的流程实例。

NOTE: 默认情况下列表为空。要加载所有任务，请在不指定筛选条件的情况下点击 *Apply*。
