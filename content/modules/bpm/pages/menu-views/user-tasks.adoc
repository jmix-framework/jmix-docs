= User Tasks

Экран *User Tasks* содержит все активные пользовательские задачи из экземпляров процессов.

image::bpm-menu-views/user-tasks-list.png[,800]

[[user-task-list]]
== Список пользовательских задач

Доступны следующие действия:

* *Filter* — отфильтровать задачи по определению процесса, исполнителю, пользователю-кандидату или группе кандидатов, а затем нажать *Apply*.
* *Reassign task* — переназначить выбранную задачу другому пользователю.
+
image::bpm-menu-views/task-reassign.png[,800]
+
* *Open process instance* — открыть экземпляр процесса, связанный с выбранной задачей.

NOTE: По умолчанию список пуст. Чтобы загрузить все задачи, нажмите *Apply*, не задавая условия фильтра.
