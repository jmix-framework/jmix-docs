= User Groups

Экран *User Groups* позволяет создавать группы, которые можно выбирать в качестве кандидатов на выполнение пользовательских задач. Пользователь может входить в несколько групп.

image::bpm-menu-views/user-groups-list.png[,800]

[[user-group-list]]
== Список групп пользователей

Доступны следующие действия:

* *Create* — создать группу пользователей и настроить ее состав в <<user-group-editor,редакторе группы пользователей>>.
* *Edit* — изменить свойства или состав выбранной группы.
* *Remove* — удалить выбранную группу пользователей.

[[user-group-editor]]
== Редактор группы пользователей

В редакторе укажите имя группы, уникальный код, тип членства и необязательное описание. Для группы типа *Users* или *Roles* добавьте пользователей или роли, которые определяют ее состав.

image::bpm-menu-views/user-group-editor.png[,800]

Группа может иметь один из следующих типов:

* *Users* — включает выбранных пользователей.
* *Roles* — включает пользователей, у которых есть одна из выбранных ролей.
* *All users* — включает всех пользователей.
