= 用户组

*User Groups* 视图定义可作为用户任务候选人的分组。一个用户可以属于多个组。

image::bpm-menu-views/user-groups-list.png[,800]

[[user-group-list]]
== 用户组列表

可以使用以下操作：

* *Create* – 创建用户组并在 <<user-group-editor,用户组编辑器>> 中配置其成员。
* *Edit* – 更改所选组的属性或成员。
* *Remove* – 删除所选用户组。

[[user-group-editor]]
== 用户组编辑器

使用该编辑器可以设置组的名称、唯一代码、成员类型和可选描述。对于 *Users* 或 *Roles* 组，还可以添加成员用户或角色。

image::bpm-menu-views/user-group-editor.png[,800]

组可以是以下类型之一：

* *Users* – 包含选定的用户。
* *Roles* – 当用户拥有所选角色之一时，他们将成为该组的成员。
* *All users* – 包含所有用户。
