= 我的任务

*My Tasks* 视图显示当前用户的激活任务。任务树按分配类型、流程和任务名称进行分组。

image::my-tasks/my-tasks-view.png[,800]

[[task-list]]
== 任务列表

可以使用以下操作：

* *Assigned Tasks* – 包含直接分配给当前用户的任务。
* *Group Tasks* – 包含当前用户为候选人的任务。
* *Open task* – 打开所选任务的流程表单，查看或完成该任务。
* *Refresh* – 重新加载任务。

*Process instance business key* 列显示 xref:bpm:bpm-concepts.adoc#business-key[业务键值]，标识与流程关联的对象。

TIP: 设计流程时，应尽量设置业务键值。xref:data-model:entities.adoc#instance-name[实例名称] 可以作为有效的业务键。

*Due Date* 列显示任务预计完成的时间。该值仅供参考；跟踪逾期任务并对其做出响应需要自定义应用程序逻辑。

[[advanced-task-list-view]]
== 高级任务列表视图

在应用程序中，可以创建标准的任务列表视图并进行定制。新创建的视图不会替换标准的 *My Tasks* 视图。

image::my-tasks/advanced-my-tasks-view.png[align="center",width="982"]

* 页面左侧是一个过滤器组件，支持按任务名称、流程名称、分配人进行过滤。
* 右侧显示用户任务的列表。

=== 创建高级任务列表视图

在 Jmix Studio 的 xref:studio:view-wizard.adoc[视图向导] 中，选择 *BPM: Advanced Task List View* 模板。

image::my-tasks/advanced-my-tasks-view-template.png[align="center",width="776"]

Studio 会自动生成视图 XML 以及 Java 控制器，并带有注释解释如何定制。
