= My Tasks

Экран *My Tasks* содержит активные задачи текущего пользователя. В дереве задачи сгруппированы по типу назначения, процессу и имени задачи.

image::my-tasks/my-tasks-view.png[,800]

[[task-list]]
== Список задач

Доступны следующие действия:

* *Assigned Tasks* — содержит задачи, назначенные непосредственно текущему пользователю.
* *Group Tasks* — содержит задачи, для которых текущий пользователь указан как кандидат.
* *Open task* — открыть форму процесса для выбранной задачи, чтобы просмотреть или выполнить ее.
* *Refresh* — перезагрузить задачи.

Столбец *Process instance business key* содержит xref:bpm:bpm-concepts.adoc#business-key[бизнес-ключ], который определяет объект, связанный с процессом.

TIP: При проектировании процессов старайтесь указывать бизнес-ключ. xref:data-model:entities.adoc#instance-name[Имя экземпляра] сущности может служить подходящим бизнес-ключом.

Столбец *Due Date* показывает ожидаемый срок выполнения задачи. Значение носит справочный характер. Для отслеживания просроченных задач и реагирования на них требуется пользовательская логика приложения.

[[advanced-task-list-view]]
== Альтернативный экран задач

Вы можете создать отдельный экран списка задач и настроить его для своего приложения. Он не заменяет стандартный экран *My Tasks*.

image::my-tasks/advanced-my-tasks-view.png[align="center",width="982"]

* Слева расположен компонент фильтра, который позволяет отбирать задачи по имени задачи, имени процесса или исполнителю.
* Справа расположена таблица со списком пользовательских задач.

=== Создание альтернативного экрана задач

В xref:studio:view-wizard.adoc[мастере создания экранов] Jmix Studio выберите шаблон *BPM: Advanced Task List View*.

image::my-tasks/advanced-my-tasks-view-template.png[align="center",width="776"]

Studio сгенерирует дескриптор и контроллер экрана с комментариями, которые поясняют, как их настраивать.
