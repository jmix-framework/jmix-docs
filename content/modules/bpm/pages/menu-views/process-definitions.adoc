= 流程定义

*Process Definitions（流程定义）* 视图展示可用的流程定义列表。

image::bpm-menu-views/process-definitions-list.png[,800]

[[process-definition-list]]
== 流程定义列表

可以使用以下操作：

* *Filter* – 按名称或键值筛选定义，并选择是否仅显示每个定义的最新版本。
* *Open in modeler* – 将所选的定义加载到 xref:bpm:menu-views/modeler-web.adoc[] 中进行编辑。
* *View details* – 打开 <<process_definition_details,流程定义详情>> 视图。
* *Start process* – 启动所选流程定义的一个新实例。
* *Upload BPMN XML* – 从 BPMN XML 文件部署流程定义。

[[process_definition_details]]
== 流程定义详情

*Process Definition Details（流程定义详情）* 视图展示流程定义的属性、BPMN XML 文件以及所有激活的流程实例。

image::bpm-menu-views/process-deinition-details.png[,800]

可以使用以下操作：

* *Version* – 选择流程定义的另一个版本。
* *View process instance* – 打开以激活的选定实例。
* *Suspend* – 阻止从选择的定义启动新实例。在确认对话框中，还可以暂停其激活的实例。已暂停实例中的任务不会出现在 xref:menu-views/my-tasks.adoc[我的任务] 中，并且任务的计时器和作业会停止运行。
+
image::bpm-menu-views/process-definition-suspend.png[,800]
+
* *Activate* - 可恢复先前被挂起的流程定义。在确认对话框中，还可恢复流程实例的执行。
+
image::bpm-menu-views/process-definition-activate.png[,800]
+
* *Migrate all process instances（迁移所有流程实例）* - 可启动 xref:bpm:instance-migration.adoc[流程实例迁移]。
+
image::bpm-menu-views/process-definition-migrate-all.png[]
+
* *Delete deployment* - 可以删除包含特定版本流程定义的部署。
+
image::bpm-menu-views/process-definitions-delete.png[]
+
IMPORTANT: 删除部署也会同时删除其相关的流程实例、历史和任务。
