= Process Definitions

Экран *Process Definitions* содержит список развернутых определений процессов.

image::bpm-menu-views/process-definitions-list.png[,800]

[[process-definition-list]]
== Список определений процессов

Доступны следующие действия:

* *Filter* — отфильтровать определения по имени или ключу и выбрать, следует ли отображать только последнюю версию каждого определения.
* *Open in modeler* — загрузить выбранное определение в xref:bpm:menu-views/modeler-web.adoc[моделер] для редактирования.
* *View details* — открыть экран <<process_definition_details,Process Definition Details>>.
* *Start process* — запустить новый экземпляр выбранного определения процесса.
* *Upload BPMN XML* — развернуть определение процесса из XML-файла BPMN.

[[process_definition_details]]
== Process Definition Details

Экран *Process Definition Details* отображает свойства определения, BPMN XML и активные экземпляры процесса.

image::bpm-menu-views/process-deinition-details.png[,800]

Доступны следующие действия:

* *Version* — выбрать другую версию определения процесса.
* *View process instance* — открыть выбранный активный экземпляр процесса.
* *Suspend* — запретить запуск новых экземпляров выбранного определения. В диалоге подтверждения можно также приостановить его активные экземпляры. Задачи приостановленных экземпляров не отображаются в xref:menu-views/my-tasks.adoc[My Tasks], а их таймеры и задания перестают выполняться.
+
image::bpm-menu-views/process-definition-suspend.png[,800]
+
* *Activate* — активировать приостановленное определение. В диалоге подтверждения можно также активировать его приостановленные экземпляры процесса.
+
image::bpm-menu-views/process-definition-activate.png[,800]
+
* *Migrate all process instances* — запустить xref:bpm:instance-migration.adoc[миграцию экземпляров процесса].
+
image::bpm-menu-views/process-definition-migrate-all.png[]
+
* *Delete deployment* — удалить развертывание, содержащее выбранную версию определения процесса.
+
image::bpm-menu-views/process-definitions-delete.png[]
+
IMPORTANT: При удалении развертывания также удаляются связанные экземпляры процессов, история и задачи.
