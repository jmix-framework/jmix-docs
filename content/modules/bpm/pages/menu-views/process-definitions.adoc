= Process Definitions

The *Process Definitions* view displays a list of deployed process definitions.

image::bpm-menu-views/process-definitions-list.png[,800]

[[process-definition-list]]
== Process Definition List

The following actions are available:

* *Filter* – Filter definitions by name or key and choose whether to display only the latest version of each definition.
* *Open in modeler* – Load the selected definition in the xref:bpm:menu-views/modeler-web.adoc[] for editing.
* *View details* – Open the <<process_definition_details,Process Definition Details>> view.
* *Start process* – Start a new instance of the selected process definition.
* *Upload BPMN XML* – Deploy a process definition from a BPMN XML file.

[[process_definition_details]]
== Process Definition Details

The *Process Definition Details* view displays the definition properties, BPMN XML, and active process instances.

image::bpm-menu-views/process-deinition-details.png[,800]

The following actions are available:

* *Version* – Select another version of the process definition.
* *View process instance* – Open the selected active process instance.
* *Suspend* – Prevent new instances from starting from the selected definition. In the confirmation dialog, you can also suspend its active instances. Tasks from suspended instances do not appear in xref:menu-views/my-tasks.adoc[My tasks], and their timers and jobs stop running.
+
image::bpm-menu-views/process-definition-suspend.png[,800]
+
* *Activate* – Reactivate a suspended definition. In the confirmation dialog, you can also reactivate its suspended process instances.
+
image::bpm-menu-views/process-definition-activate.png[,800]
+
* *Migrate all process instances* – Start xref:bpm:instance-migration.adoc[process instance migration].
+
image::bpm-menu-views/process-definition-migrate-all.png[]
+
* *Delete deployment* – Delete the deployment containing the selected version of the process definition.
+
image::bpm-menu-views/process-definitions-delete.png[]
+
IMPORTANT: Deleting a deployment also deletes its associated process instances, history, and tasks.
