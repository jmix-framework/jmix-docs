// Rows of the asynchronous execution properties for the property tables of BPMN elements.
// Use the "async" tag for elements that had the Asynchronous property in the modeler before Jmix 3.1,
// and the "async-since" tag for the other elements.
// tag::async[]
|Asynchronous
|The process engine commits the current transaction before the element. Then the job executor executes the element and continues the process in a new transaction. See xref:bpm:bpmn/transactions.adoc#asynchronous-continuation[Asynchronous Continuation].
// end::async[]
// tag::async-since[]
|Asynchronous
a|The process engine commits the current transaction before the element. Then the job executor executes the element and continues the process in a new transaction. See xref:bpm:bpmn/transactions.adoc#asynchronous-continuation[Asynchronous Continuation].

[.since]
Since Jmix 3.1
// end::async-since[]
// tag::exclusive[]
|Exclusive
a|The job created for *Asynchronous* is exclusive: the job executor doesn't execute it concurrently with other exclusive jobs of the same process instance. Selected by default. Enabled only when *Asynchronous* is selected. See xref:bpm:bpmn/transactions.adoc#exclusive-jobs[Exclusive Jobs].

[.since]
Since Jmix 3.1
// end::exclusive[]
// tag::leave[]
|Asynchronous leave
a|The element is executed in the current transaction. The process engine commits the transaction before leaving the element. Then the job executor completes the element and continues the process in a new transaction. See xref:bpm:bpmn/transactions.adoc#asynchronous-execution-properties[Asynchronous Execution Properties].

[.since]
Since Jmix 3.1
|Asynchronous leave exclusive
a|The job created for *Asynchronous leave* is exclusive: the job executor doesn't execute it concurrently with other exclusive jobs of the same process instance. Selected by default. Enabled only when *Asynchronous leave* is selected. See xref:bpm:bpmn/transactions.adoc#exclusive-jobs[Exclusive Jobs].

[.since]
Since Jmix 3.1
// end::leave[]
