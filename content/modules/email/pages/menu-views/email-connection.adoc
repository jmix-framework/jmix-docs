= 邮件连接
:page-aliases: email:menu-views/oauth-token.adoc

[.since]
Jmix 3.1+

*Email connection* 管理视图显示与邮件服务器连接的参数：认证类型、邮箱账户（`spring.mail.username`）和服务器（`spring.mail.host` 与 `spring.mail.port`）。

可执行以下操作：

* *Test connection*：连接到邮件服务器并登录，但不发送邮件。使用 xref:email:authentication.adoc#oauth2-authentication[OAuth2 认证] 时，测试还会获取访问令牌，因此无效或已撤销的刷新令牌会导致测试失败。
* *Connect via authorization code*：在供应商页面登录邮箱账户并存储获得的刷新令牌。适用于 `google` 和 `microsoft`。
* *Connect via device code*：使用对话框中显示的代码登录邮箱账户并存储获得的刷新令牌。适用于 `microsoft`。
* *Advanced* 部分中的 *Manual update*：用输入的值替换已存储的刷新令牌。请参见 xref:email:authentication.adoc#manual-refresh-token[手动输入刷新令牌]。

连接按钮仅在 OAuth2 认证下启用，*Advanced* 部分也仅在此时显示。有关步骤，请参见 xref:email:authentication.adoc#connecting-mailbox[连接邮箱账户]。

[[connection-status]]
== 连接状态

在测试连接之前，如果数据库中有已存储的刷新令牌（OAuth2 认证）或设置了 `spring.mail.host`（基本认证），视图显示 *Connected (not verified)*，否则显示 *Not connected*。仅在 xref:email:configuration.adoc#jmix.email.oauth2.refresh-token[jmix.email.oauth2.refresh-token] 属性中设置的令牌会显示为 *Not connected*。

测试后，状态为 *Connection verified* 或 *Connection error*。
