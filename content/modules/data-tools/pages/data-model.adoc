= 数据模型

*Data model* 视图（*Data tools -> Data model*）显示运行中应用程序的实体及其属性。

image:data-model-view.png[width=776]

*Entities* 表格显示每个实体的名称及其对应的数据库表名。选择一个实体后，*Attributes* 表格会更新，列出该实体的所有属性，包括属性名、Java 类型、数据库列名、数据库类型以及“是否必填”标志。

[[filtering-entities]]
== 搜索实体

使用 *Show system* 复选框可以同时包含项目实体和来自扩展组件的内部 Jmix 实体。如需搜索特定实体，请输入以逗号分隔的实体名称，例如 `Customer, Order, User`，或者使用正则表达式。*Entities* 表格会更新以显示匹配的结果。

[[data-model-diagram]]
== PlantUML 图

点击 *Diagram* 会在新的浏览器标签页中打开一个 PlantUML 图，该图包含视图中当前筛选出的实体。默认情况下，使用 https://www.plantuml.com 的公共 PlantUML 服务对 UML 图进行渲染。也可以使用 <<self-hosted-server,自托管的服务>> 渲染。

[[self-hosted-server]]
=== 使用自托管服务器

通过 `\{host}/\{path}/png/<encoded diagram>` 请求 UML 图。若要使用自己的 PlantUML 服务渲染图表，请使用以下应用程序属性设置其主机和路径。

[[jmix.datatools.data-model-diagram.host]]
`jmix.datatools.data-model-diagram.host`::
PlantUML 服务器的地址。设置后，不会使用公共服务器。

[[jmix.datatools.data-model-diagram.path]]
`jmix.datatools.data-model-diagram.path`::
+
[.since]
Jmix 3.1+
+
PlantUML 服务器可用的路径。如果服务器在主机地址下无需路径即可访问，或者主机已包含路径，请设置空值。
+
默认值：`plantuml`

[[jmix.datatools.data-model-diagram.public-server-enabled]]
=== 禁用公共服务器

在公共 PlantUML 服务器上渲染图表会将应用程序的实体架构发送到外部服务。如果需要防止数据外泄，请将 `jmix.datatools.data-model-diagram.public-server-enabled` 应用程序属性设置为 `false`：

.application.properties
----
jmix.datatools.data-model-diagram.public-server-enabled=false
----

当未通过 `jmix.datatools.data-model-diagram.host` 配置私有主机时，仅当此属性和全局 xref:ROOT:app-properties.adoc#jmix.core.unsafe-runtime-features-enabled[jmix.core.unsafe-runtime-features-enabled] 开关都启用时，才会使用公共服务器。无论这些开关如何设置，配置的私有主机始终可用。如果未设置主机且不允许使用公共服务器，则会隐藏 *Diagram* 按钮。

默认值：`true`

[[jmix.datatools.data-model-diagram.read-timeout]]
=== 渲染超时

[.since]
Jmix 3.1+

`jmix.datatools.data-model-diagram.read-timeout` 应用程序属性设置等待 PlantUML 服务器响应的最长时间，例如 `30s`。渲染大型数据模型可能比默认时间更长。

默认值：`10s`
