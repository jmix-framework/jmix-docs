= Data Model

Экран *Data model* (*Data tools -> Data model*) отображает сущности и их атрибуты в запущенном приложении.

image:data-model-view.png[width=776]

Таблица *Entities* показывает имя каждой сущности и имя соответствующей таблицы в базе данных. При выборе сущности таблица *Attributes* отображает атрибуты этой сущности: имя атрибута, Java-тип, имя столбца в базе данных, тип в базе данных и флаг "Is mandatory".

[[filtering-entities]]
== Поиск сущностей

Используйте чекбокс *Show system*, чтобы одновременно отображать сущности проекта и системные сущности Jmix из аддонов.  Для поиска конкретных сущностей введите их имена через запятую, например `Customer, Order, User`, или используйте регулярное выражение. Таблица *Entities* обновится и покажет совпадающие результаты.

[[data-model-diagram]]
== Диаграмма PlantUML

Нажмите *Diagram*, чтобы открыть в новой вкладке браузера диаграмму PlantUML с сущностями, которые сейчас отфильтрованы на экране. По умолчанию диаграмма генерируется на публичном сервере PlantUML по адресу https://www.plantuml.com. Вместо него можно использовать <<self-hosted-server,собственный сервер>>.

[[self-hosted-server]]
=== Использование собственного сервера

Диаграмма запрашивается по адресу `\{host}/\{path}/png/<encoded diagram>`. Чтобы генерировать диаграмму на собственном сервере PlantUML, задайте его хост и путь в следующих свойствах приложения.

[[jmix.datatools.data-model-diagram.host]]
`jmix.datatools.data-model-diagram.host`::
Адрес сервера PlantUML. Если свойство задано, публичный сервер не используется.

[[jmix.datatools.data-model-diagram.path]]
`jmix.datatools.data-model-diagram.path`::
+
[.since]
Начиная с Jmix 3.1
+
Путь, по которому доступен сервер PlantUML. Задайте пустое значение, если сервер доступен по адресу хоста без пути или если путь уже указан в хосте.
+
Значение по умолчанию: `plantuml`

[[jmix.datatools.data-model-diagram.public-server-enabled]]
=== Отключение публичного сервера

При генерации диаграммы на публичном сервере PlantUML схема сущностей вашего приложения отправляется во внешний сервис. Чтобы предотвратить это, задайте свойству приложения `jmix.datatools.data-model-diagram.public-server-enabled` значение `false`:

.application.properties
----
jmix.datatools.data-model-diagram.public-server-enabled=false
----

Если собственный хост не настроен через `jmix.datatools.data-model-diagram.host`, публичный сервер используется только в том случае, если включены и это свойство, и глобальный переключатель xref:ROOT:app-properties.adoc#jmix.core.unsafe-runtime-features-enabled[jmix.core.unsafe-runtime-features-enabled]. Настроенный собственный хост всегда работает независимо от этих переключателей. Если хост не задан, а публичный сервер не разрешён, кнопка *Diagram* скрыта.

Значение по умолчанию: `true`

[[jmix.datatools.data-model-diagram.read-timeout]]
=== Тайм-аут генерации

[.since]
Начиная с Jmix 3.1

Свойство приложения `jmix.datatools.data-model-diagram.read-timeout` задаёт максимальное время ожидания ответа от сервера PlantUML, например `30s`. Для большой модели данных генерация может длиться дольше значения по умолчанию.

Значение по умолчанию: `10s`
