= 数据模型

*Data model* 视图（*Data tools -> Data model*）显示运行中应用程序的实体及其属性。

image:data-model-view.png[width=776]

*Entities* 表格显示每个实体的名称及其对应的数据库表名。选择一个实体后，*Attributes* 表格会更新，列出该实体的所有属性，包括属性名、Java 类型、数据库列名、数据库类型以及“是否必填”标志。

[[filtering-entities]]
== 搜索实体

使用 *Show system* 复选框可以同时包含项目实体和来自扩展组件的内部 Jmix 实体。如需搜索特定实体，请输入以逗号分隔的实体名称，例如 `Customer, Order, User`，或者使用正则表达式。*Entities* 表格会更新以显示匹配的结果。

[[data-model-diagram]]
== PlantUML 图

点击 *Diagram* 会在新的浏览器标签页中打开一个 PlantUML 图，该图包含视图中当前筛选出的实体。默认情况下，使用 https://www.plantuml.com 的公共 PlantUML 服务对 UML 图进行渲染。通过设置应用程序属性可以切换到自托管的服务器：

.application.properties
----
jmix.datatools.data-model-diagram.host = <self-hosted-server>
----

[[jmix.datatools.data-model-diagram.public-server-enabled]]
=== 禁用公共服务器

在公共 PlantUML 服务器上渲染图表会将应用程序的实体架构发送到外部服务。如果需要防止数据外泄，请将 `jmix.datatools.data-model-diagram.public-server-enabled` 应用程序属性设置为 `false`：

当 `jmix.datatools.data-model-diagram.host` 配置这不存在私有主机时，仅当该属性和全局 xref:ROOT:app-properties.adoc#jmix.core.unsafe-runtime-features-enabled[jmix.core.unsafe-runtime-features-enabled] 开关都启用时，才会使用公共服务器。配置了私有主机后，就不关心这些设置了。
