= 应用程序属性

通过以下属性可以配置扩展组件不同方面的行为。

[[jmix.dynmodel.attribute-load-batch-size]]
== jmix.dynmodel.attribute-load-batch-size

加载静态实体动态属性和动态引用实体的批次数量。

默认值：`1000`

[[jmix.dynmodel.calculated-attributes.default-evaluator]]
== jmix.dynmodel.calculated-attributes.default-evaluator

当未配置时，用于计算型动态属性的默认 evaluator。

默认值：`spel`

[[jmix.dynmodel.cluster.apply-lock-timeout-sec]]
== jmix.dynmodel.cluster.apply-lock-timeout-sec

[.since]
Jmix 3.1+

如果持有发布锁的节点在发布期间停止，则发布锁在此时间（秒）后过期。该值必须大于应用程序中最长的发布耗时。如果发布耗时更长，另一个节点可以获取锁并在同一时间发布模型。

默认值：`300`

[[jmix.dynmodel.cluster.apply-lock-wait-sec]]
== jmix.dynmodel.cluster.apply-lock-wait-sec

[.since]
Jmix 3.1+

节点在启动时发布模型或发布从其他节点收到的模型时，会等待配置的时间（秒），以获取发布锁。

默认值：`60`

[[jmix.dynmodel.cluster.enabled]]
== jmix.dynmodel.cluster.enabled

[.since]
Jmix 3.1+

如果设置为 `true`，发布在集群中一个节点的模型也会发布到所有其他节点上，并且同一时间只能运行一个发布。需要安装悲观锁扩展组件。参考 xref:dyn-model:concepts.adoc#cluster[集群]。

默认值：`false`

[[jmix.dynmodel.deploy-on-app-start]]
== jmix.dynmodel.deploy-on-app-start

如果设置为 `true`，则在应用程序启动时自动使用激活的动态模型版本。

默认值：`true`

[[jmix.dynmodel.dynamic-entity-table-prefix]]
== jmix.dynmodel.dynamic-entity-table-prefix

动态实体表的前缀。

默认值：`DYN_`

[[jmix.dynmodel.security.full-access-roles]]
== jmix.dynmodel.security.full-access-roles

以逗号分隔的资源角色代码，为这些角色授予动态模型管理的完全访问权限。如果用户有其中一个角色（即使是作为基础角色），用户依然有完全访问权限。参考 xref:dyn-model:defining-model.adoc#inherited-roles[角色继承]。

默认值：`system-full-access`

[[jmix.dynmodel.static-entity-table-prefix]]
== jmix.dynmodel.static-entity-table-prefix

用于存储静态实体动态属性的侧表前缀。

默认值：`DYN_`
