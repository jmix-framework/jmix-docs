= 动态模型

动态模型支持在正在运行的应用程序中扩展数据模型：可以向已有实体添加属性，或者定义全新的实体，而无需更改源码或重新启动应用程序。该扩展包含了运行时 UI，例如视图和菜单项。

主要功能：

* 为已有（静态）实体添加动态属性，或定义新的动态实体。
* 将动态数据存储在特定的数据库表中（静态实体使用侧表，动态实体使用专用表）以提供良好的性能。
* 通过声明新视图和菜单项来自定义运行时 UI。
* 基于资源角色定义验证、属性的唯一性和安全性。
* 提供动态枚举、引用、集合和计算型属性。
* 为动态模型提供本地化名称和消息。
* 模型在图形管理 UI 中编辑，并存储为带版本的 YAML 定义。

CAUTION: 动态模型扩展组件目前处于实验状态，在下一个 Jmix 版本中可能会有重大变更。

[[vs-dynamic-attributes]]
== 动态模型与动态属性

Jmix 提供了两种不同的扩展组件，用于在运行时扩展数据模型。

xref:dyn-attr:index.adoc[动态属性] 将附加值存储在 https://en.wikipedia.org/wiki/Entity–attribute–value_model[实体-属性-值^] 结构中。适合为已有实体添加由管理员定义的自定义字段。

*动态模型* 添加了由专用数据库表支持的真实属性和新实体。除数据外，还可以定义运行时视图和菜单项，并且其模型定义是可编辑和版本化的。当需要新实体、专用表、运行时 UI 或受管理的版本化模型定义时，请使用动态模型。
