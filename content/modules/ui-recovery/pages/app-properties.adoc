= 相关属性配置

[[jmix.uirecovery.drafts.enabled]]
== jmix.uirecovery.drafts.enabled

定义 xref:ui-recovery:drafts-facet.adoc[drafts facet] 是否保存和恢复草稿。如果设置为 `false`，该 facet 在所有视图中都不执行任何操作。

默认值：`true`

[[jmix.uirecovery.drafts.default-min-save-interval]]
== jmix.uirecovery.drafts.default-min-save-interval

定义视图草稿两次保存之间的间隔。facet 的 xref:ui-recovery:drafts-facet.adoc#minSaveInterval[minSaveInterval] 属性会覆盖该配置。

默认值：`5s`

[[jmix.uirecovery.drafts.default-restore-mode]]
== jmix.uirecovery.drafts.default-restore-mode

定义打开视图时如何恢复草稿：`ASK` 或 `AUTO`。请参阅 xref:ui-recovery:drafts-facet.adoc#restore-modes[恢复模式]。facet 的 xref:ui-recovery:drafts-facet.adoc#restoreMode[restoreMode] 属性会覆盖该配置。

默认值：`ASK`

[[jmix.uirecovery.drafts.retention]]
== jmix.uirecovery.drafts.retention

定义草稿的保留时长。超过此时长的草稿即过期。扩展组件不会将过期草稿提供给用户，并在找到该草稿时将其删除。如需删除用户一直不打开的视图的过期草稿，请按照 xref:ui-recovery:deleting-expired-drafts.adoc[] 中所述设置定时任务。

默认值：`30d`

[[jmix.uirecovery.drafts.show-on-login]]
== jmix.uirecovery.drafts.show-on-login

定义当用户有草稿时，是否在登录后打开 xref:ui-recovery:drafts-list.adoc[未保存的草稿] 视图。请参阅 xref:ui-recovery:drafts-list.adoc#show-on-login[登录后显示草稿]。

默认值：`false`
