= Свойства UI Recovery

[[jmix.uirecovery.drafts.enabled]]
== jmix.uirecovery.drafts.enabled

Определяет, сохраняет и восстанавливает ли фасет xref:ui-recovery:drafts-facet.adoc[drafts] черновики. Если установлено значение `false`, фасет ничего не делает ни в одном экране.

Значение по умолчанию: `true`

[[jmix.uirecovery.drafts.default-min-save-interval]]
== jmix.uirecovery.drafts.default-min-save-interval

Определяет минимальное время между двумя сохранениями черновика экрана. Атрибут фасета xref:ui-recovery:drafts-facet.adoc#minSaveInterval[minSaveInterval] переопределяет это значение.

Значение по умолчанию: `5s`

[[jmix.uirecovery.drafts.default-restore-mode]]
== jmix.uirecovery.drafts.default-restore-mode

Определяет, как восстанавливается черновик при открытии экрана: `ASK` или `AUTO`. См. xref:ui-recovery:drafts-facet.adoc#restore-modes[Режимы восстановления]. Атрибут фасета xref:ui-recovery:drafts-facet.adoc#restoreMode[restoreMode] переопределяет это значение.

Значение по умолчанию: `ASK`

[[jmix.uirecovery.drafts.retention]]
== jmix.uirecovery.drafts.retention

Определяет, как долго хранится черновик. Черновик старше этого срока считается устаревшим. Дополнение не предлагает его пользователю и удаляет, когда находит. Чтобы удалять устаревшие черновики экранов, которые пользователи больше не открывают, настройте регулярное задание, как описано в разделе xref:ui-recovery:deleting-expired-drafts.adoc[].

Значение по умолчанию: `30d`

[[jmix.uirecovery.drafts.show-on-login]]
== jmix.uirecovery.drafts.show-on-login

Определяет, открывается ли экран xref:ui-recovery:drafts-list.adoc[Unsaved drafts] после входа в систему, если у пользователя есть черновики. См. xref:ui-recovery:drafts-list.adoc#show-on-login[Показ черновиков после входа].

Значение по умолчанию: `false`
