= Экран Unsaved drafts

Экран *Unsaved drafts* показывает все черновики текущего пользователя. Он помогает пользователям найти несохраненную работу, например, после перезапуска приложения.

image::drafts-list.png[align="center",width="1010"]

Каждый черновик показан в виде карточки с заголовком экрана, записью и датой сохранения черновика. При нажатии на карточку открывается экран черновика, и фасет xref:ui-recovery:drafts-facet.adoc[drafts] этого экрана предлагает восстановить его. Сам экран ничего не восстанавливает.

Кнопка с корзиной на карточке удаляет черновик, а кнопка *Discard all* удаляет все черновики пользователя. Обе кнопки запрашивают подтверждение. Кнопка *Continue* открывает главный экран.

Если экрана черновика больше нет в приложении, на карточку нельзя нажать, но черновик можно удалить.

[[opening]]
== Открытие экрана

Экран имеет идентификатор `uirec_DraftListView` и маршрут `uirec/drafts`. Он доступен всем аутентифицированным пользователям, поэтому назначать для него роли не нужно.

Дополнение не добавляет экран в главное меню. Чтобы добавить его, включите пункт в xref:flow-ui:menu-config.adoc[конфигурацию меню]:

[source,properties,indent=0]
----
include::example$ui-recovery-ex1/src/main/resources/application.properties[tags=show-on-login]
----

Экран показывается один раз за сессию вместо главного экрана. Если пользователь входит в систему, чтобы открыть определенный URL, например ссылку на запись, приложение открывает этот URL и не показывает черновики.
