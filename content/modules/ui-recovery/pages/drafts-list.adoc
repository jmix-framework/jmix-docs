= 未保存的草稿视图

*未保存的草稿* 视图显示当前用户的所有草稿。用户可以在这里找到未保存的工作，例如在应用程序重启之后。

image::drafts-list.png[align="center",width="1010"]

每个草稿显示为一张卡片，包含视图标题、被修改的记录以及草稿保存的日期。点击卡片会打开草稿对应的视图，该视图的 xref:ui-recovery:drafts-facet.adoc[drafts facet] 会提示恢复草稿。该视图本身不会恢复任何内容。

使用卡片上的删除按钮会删除草稿，*Discard all* 按钮会删除该用户的所有草稿。两个操作都要求确认。*Continue* 按钮会打开主视图。

如果应用程序中草稿对应的视图已不存在，则卡片无法点击，但草稿仍可删除。

[[opening]]
== 打开视图

该视图的标识符为 `uirec_DraftListView`，路由为 `uirec/drafts`。所有已认证用户都可使用，因此无需为授予任何角色。

扩展组件不会将该视图添加到主菜单。如需添加，请修改 xref:flow-ui:menu-config.adoc[菜单配置]：

如果用户有草稿，可以在登录后自动打开该视图。如需启用此功能，请设置 xref:ui-recovery:app-properties.adoc#jmix.uirecovery.drafts.show-on-login[jmix.uirecovery.drafts.show-on-login] 属性：

[source,properties,indent=0]
----
include::example$ui-recovery-ex1/src/main/resources/application.properties[tags=show-on-login]
----

该视图每个会话显示一次，替代主视图。如果用户登录是为了打开某个特定 URL，例如指向某条记录的链接，则应用程序会打开该 URL，而不会显示草稿。
