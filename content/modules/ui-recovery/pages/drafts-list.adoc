= Unsaved Drafts View

The *Unsaved drafts* view shows all drafts of the current user. It helps users find the work they did not save, for example after the application was restarted.

image::drafts-list.png[align="center",width="1010"]

Each draft is shown as a card with the view title, the record and the date when the draft was saved. Clicking a card opens the view of the draft, and the xref:ui-recovery:drafts-facet.adoc[drafts facet] of that view offers to restore it. The view itself does not restore anything.

The trash button on a card deletes the draft, and the *Discard all* button deletes all drafts of the user. Both ask for confirmation. The *Continue* button opens the main view.

If the view of a draft no longer exists in the application, the card cannot be clicked, but the draft can be deleted.

[[opening]]
== Opening the View

The view has the `uirec_DraftListView` identifier and the `uirec/drafts` route. It is available to all authenticated users, so you don't need to grant any roles for it.

The add-on doesn't add the view to the main menu. To add it, include an item in the xref:flow-ui:menu-config.adoc[menu configuration]:

== Showing Drafts After Login

The view can be opened automatically after login if the user has drafts. To enable this, set the xref:ui-recovery:app-properties.adoc#jmix.uirecovery.drafts.show-on-login[jmix.uirecovery.drafts.show-on-login] property:

[source,properties,indent=0]
----
include::example$ui-recovery-ex1/src/main/resources/application.properties[tags=show-on-login]
----

The view is shown once per session, instead of the main view. If the user logs in to open a particular URL, for example a link to a record, the application opens that URL and doesn't show the drafts.
