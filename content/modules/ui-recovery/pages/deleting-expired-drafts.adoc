= Deleting Expired Drafts

A draft expires when it is older than the period set in the xref:ui-recovery:app-properties.adoc#jmix.uirecovery.drafts.retention[jmix.uirecovery.drafts.retention] property. The add-on deletes an expired draft when it finds the draft, that is when the user opens the view of the draft or the xref:ui-recovery:drafts-list.adoc[Unsaved drafts] view. Drafts of the views that users never open again stay in the database. To delete them, set up a regular job.

The job calls the `deleteExpired()` method of the `ViewDraftService` bean. The method deletes expired drafts of all users and doesn't require an authenticated user, so you can call it from any scheduled task.

For example, the following bean uses the Spring `@Scheduled` annotation:

----
include::example$ui-recovery-ex1/src/main/java/com/company/sample/job/DraftsCleanupJob.java[tags=cleanup-job]
----
<1> Runs the method every day at 3 a.m.
<2> Deletes the expired drafts and returns their number.

[source,java,indent=0]
----
include::example$ui-recovery-ex1/src/main/java/com/company/sample/job/SchedulingConfiguration.java[tags=enable-scheduling]

You can also call the method from a job of the xref:quartz:index.adoc[Quartz] add-on.
