= 删除过期的草稿

草稿的保存时间超过 xref:ui-recovery:app-properties.adoc#jmix.uirecovery.drafts.retention[jmix.uirecovery.drafts.retention] 属性所设置的期限后就会过期。扩展组件在找到过期草稿时会将其删除，也就是在用户打开草稿对应的视图或 xref:ui-recovery:drafts-list.adoc[未保存的草稿] 视图时删除。如果用户一直不打开某个视图，其草稿会一直保留在数据库中。如需删除这些草稿，请设置一个定时任务。

该任务调用 `ViewDraftService` bean 的 `deleteExpired()` 方法。该方法会删除所有用户的过期草稿，且不需要用户认证，因此可以在任何定时任务中调用。
