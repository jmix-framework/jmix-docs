= Настройка ИИ-агента

На этой странице описано, как настроить Jmix-проект для работы ИИ-агента для написания кода.

Агент работает в проекте, открытом в Jmix Studio, и использует IDE для проверки написанного им кода. Разработчик использует Studio, чтобы проверить, что сделал агент, запустить приложение и внести собственные изменения.

[[steps]]
== Шаги настройки

. Установите ИИ-агента для написания кода, который вы хотите использовать, например Claude Code, Codex или OpenCode.

. Установите Studio и JDK, как описано в разделе xref:setup.adoc[].

. Включите MCP-сервер в IntelliJ IDEA: откройте *Settings -> Tools -> MCP Server* и выберите *Enable MCP Server*.

. Создайте проект с <<toolkit,Jmix Agent Toolkit>> одним из следующих способов.

** С помощью Studio:

.. Создайте проект, как описано в разделе xref:studio:project.adoc#creating-new-project[Создание нового проекта].
.. Запустите действие *AI Agents Toolkit* в xref:studio:tool-window.adoc#settings[окне инструментов Jmix -> Settings] и следуйте указаниям визарда.

** С помощью Jmix CLI:

.. Установите Jmix CLI и создайте проект, как описано в разделе xref:setup.adoc#jmix-cli[Использование Jmix CLI]. По умолчанию CLI добавляет набор инструментов в проект.
.. Откройте проект в Studio, как описано в разделе xref:studio:project.adoc#opening-existing-project[Открытие существующего проекта].

. Запустите агента в папке проекта и убедитесь, что агенту доступны навыки Jmix и MCP-серверы.

** Введите команду `/skills` и проверьте, что навыки `jmix*` доступны.
** Введите команду `/mcp` и проверьте, что подключены следующие MCP-серверы:
*** `jetbrains`
*** `context7`, `jmix-docs` (хотя бы один из них; оба используются для получения документации Jmix)
*** `playwright`

[[first-request]]
== Первый запрос

Опишите задачу в терминах Jmix: сущности, атрибуты, экраны, роли. Небольшая первая задача может выглядеть так:

[source,text]
----
Создай сущность Customer с атрибутами name, email и phone.
Атрибут name обязательный. Создай экраны списка и деталей для Customer
и добавь экран списка в главное меню.
----

Для более крупной задачи попросите агента сначала составить план. Просмотрите план, затем попросите агента реализовать его.

Посмотрите изменения, сделанные агентом, в Studio:

* Новая сущность и экраны появятся в xref:studio:tool-window.adoc[окне инструментов Jmix]. Откройте их в xref:studio:entity-designer.adoc[дизайнере сущностей] и xref:studio:view-designer.adoc[дизайнере экранов], чтобы проверить атрибуты и расположение компонентов.
* Запустите приложение, как описано в разделе xref:studio:project.adoc#starting-application[Запуск приложения].
* Войдите в приложение и откройте новый экран.

Если что-то не так, опишите агенту, что вы видите, и попросите его исправить проблему, или измените код самостоятельно в Studio.

[[toolkit]]
== Jmix Agent Toolkit

Jmix Agent Toolkit помогает ИИ-агенту следовать паттернам, архитектуре и лучшим практикам Jmix. Его исходный код доступен на https://github.com/jmix-framework/jmix-agent-toolkit[GitHub^].

Набор инструментов добавляет в ваш проект следующее:

* Навыки агентов для функциональности Jmix: сущностей, экранов, доступа к данным и многого другого. Навыки устанавливаются в `.agents/skills`, а в `.claude/skills` на них создаются ссылки.
* Короткий блок в `AGENTS.md`, который указывает агенту на навыки Jmix. Для Claude Code набор инструментов также добавляет файл `CLAUDE.md`, который импортирует `AGENTS.md`.
* Конфигурацию MCP-серверов:
** `jetbrains` позволяет агенту использовать анализ кода и инспекции IntelliJ IDEA. Чтобы использовать его, включите MCP-сервер в IntelliJ IDEA: откройте *Settings -> Tools -> MCP Server* и выберите *Enable MCP Server*. Пока агент работает, держите IntelliJ IDEA запущенной с открытым проектом.
** `context7` предоставляет агенту документацию и примеры кода библиотек, включая Jmix, из их официальных источников.
** https://github.com/jmix-framework/jmix-docs-mcp[jmix-docs^] позволяет агенту искать по документации Jmix, Java API и примерам UI. Его эндпойнт Streamable HTTP доступен по адресу `\https://docs-mcp.jmix.ru/mcp`.
** `playwright` позволяет агенту проверять работающее приложение в веб-браузере.

Чтобы установить набор инструментов, используйте действие xref:studio:tool-window.adoc#settings[AI Agents Toolkit] в Studio или https://github.com/jmix-framework/jmix-agent-toolkit#quick-cli-installation[CLI-скрипт^]. Проекты, созданные с помощью xref:setup.adoc#jmix-cli[Jmix CLI], включают его по умолчанию.
